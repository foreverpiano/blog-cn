利用 vs 探索#

探索与利用的困境贯穿我们生活的许多方面。比如，你最爱的餐厅就在街角。如果你每天都去那儿，会对能得到什么很有把握，但也错过了发现更好选择的机会。如果你总是尝试新地方，则很可能不时要吃到难吃的食物。同样，在线广告系统也要在已知最吸引人的广告与可能更成功的新广告之间取得平衡。

如果我们已经掌握了环境的所有信息，即使不用其他聪明方法，仅通过暴力模拟也能找到最佳策略。困境源于信息不完整：我们需要在控制风险的同时收集足够信息来做出全局最优决策。利用（exploitation）是指充分利用我们已知的最佳选项；探索（exploration）则是冒一定风险去收集未知选项的信息。最佳长期策略往往需要短期的牺牲。例如，一次探索尝试可能彻底失败，但它会警示我们今后不要过于频繁地采取该行动。

什么是多臂老虎机？#

multi-armed bandit 问题是一个经典问题，它很好地体现了探索与利用的困境。想象你在赌场里面对多台老虎机，每台机器中奖的概率都是未知的。问题是：怎样制定最佳策略才能获得最高的长期奖励？

本文仅讨论试验次数无限的情况。对试验次数设上限会引入另一种探索问题。例如，如果试验次数少于老虎机数量，我们甚至无法尝试每台机器来估计中奖概率（！），因此必须在有限的知识和资源（即时间）下聪明地行动。

一种朴素的方法是持续在同一台机器上玩很多轮，最终根据 大数定律 估计出“真实”的奖励概率。然而这种做法非常浪费，而且肯定无法保证获得最佳的长期奖励。

定义#

现在我们给出一个科学的定义。

伯努利多臂老虎机可描述为一个元组 \langle \mathcal{A}, \mathcal{R} \rangle，其中：

我们有 K 台机器，各自的奖励概率为 \{ \theta_1, \dots, \theta_K \}。 在每个时间步 t，我们对某台老虎机采取动作 a 并获得奖励 r。 \mathcal{A} 是动作集合，每个动作对应与一台老虎机的交互。动作 a 的价值是其期望奖励 Q(a) = \mathbb{E} [r \vert a] = \theta。若在时间步 t 选择的动作 a_t 对应第 i 台机器，则 Q(a_t) = \theta_i。 \mathcal{R} 是奖励函数。对于伯努利老虎机，奖励 r 以随机方式观测到。在时间步 t，r_t = \mathcal{R}(a_t) 以概率 Q(a_t) 返回奖励 1，否则返回 0。

它是 Markov decision process 的简化版本，因为不存在状态 \mathcal{S}。

目标是最大化累积奖励 \sum_{t=1}^T r_t。 如果我们知道能带来最佳奖励的最优动作，那么目标就等价于最小化因没有选择最优动作而产生的潜在 regret（遗憾）或损失。

最优动作 a^{*} 的最优奖励概率 \theta^{*} 为：

\theta^{*}=Q(a^{*})=\max_{a \in \mathcal{A}} Q(a) = \max_{1 \leq i \leq K} \theta_i

我们的损失函数是直到时间步 T 为止，因未选择最优动作而可能产生的总遗憾：

\mathcal{L}_T = \mathbb{E} \Big[ \sum_{t=1}^T \big( \theta^{*} - Q(a_t) \big) \Big]

老虎机策略#

根据探索方式的不同，解决多臂老虎机问题有以下几种方法：

不探索：最朴素但效果最差的方法。 随机探索 智能探索，更偏好不确定性高的选项

ε-Greedy 算法#

ε-greedy 算法大部分时间选择当前认为的最佳动作，但偶尔进行随机探索。动作价值根据过去经验估算，即对目标动作 a 到当前时间步 t 为止观测到的所有奖励取平均：

\hat{Q}_t(a) = \frac{1}{N_t(a)} \sum_{\tau=1}^t r_\tau \mathbb{1}[a_\tau = a]

其中 \mathbb{1} 是二值指示函数，N_t(a) 表示到目前为止动作 a 被选择的次数，即 N_t(a) = \sum_{\tau=1}^t \mathbb{1}[a_\tau = a]。

根据 ε-greedy 算法，我们以很小的概率 \epsilon 选择随机动作，而在其余大部分时间（概率 1-\epsilon）选择目前已知的最佳动作：\hat{a}^{*}_t = \arg\max_{a \in \mathcal{A}} \hat{Q}_t(a)。

上置信界#

随机探索让我们有机会尝试那些还不了解的选项。但由于随机性，我们有可能再次探索过去已经确认不好的动作（运气不好！）。为了避免这种低效探索，一种方法是随时间减小 ε 参数，另一种方法是对不确定性高的选项保持乐观，从而优先选择那些我们尚未获得可靠价值估计的动作。换句话说，我们更倾向于探索那些很有潜力达到最优价值的动作。

Upper Confidence Bounds（UCB，上置信界）算法通过奖励价值的上置信界 \hat{U}_t(a) 来衡量这种潜力，使得真实价值以很高概率低于该界限 Q(a) \leq \hat{Q}_t(a) + \hat{U}_t(a)。上界 \hat{U}_t(a) 是 N_t(a) 的函数；尝试次数 N_t(a) 越多，上界 \hat{U}_t(a) 就应该越小。

在 UCB 算法中，我们总是选择能最大化上置信界的贪心动作：

a^{UCB}_t = argmax_{a \in \mathcal{A}} \hat{Q}_t(a) + \hat{U}_t(a)

现在的问题是如何估计这个上置信界。

Hoeffding 不等式#

如果我们不想对分布做任何先验假设，可以借助 “Hoeffding 不等式”——一个适用于任意有界分布的定理。

设 X_1, \dots, X_t 是 i.i.d.（独立同分布）的随机变量，且均被限制在区间 [0, 1] 内。样本均值为 \overline{X}_t = \frac{1}{t}\sum_{\tau=1}^t X_\tau。则对于任意 u > 0，有：

\mathbb{P} [ \mathbb{E}[X] > \overline{X}_t + u] \leq e^{-2tu^2}

对于某个目标动作 a，我们考虑：

r_t(a) 为随机变量， Q(a) 为真实均值， \hat{Q}_t(a) 为样本均值， 以及 u 为上置信界 u = U_t(a)

于是有：

\mathbb{P} [ Q(a) > \hat{Q}_t(a) + U_t(a)] \leq e^{-2t{U_t(a)}^2}

我们希望选择的界能以很高概率保证真实均值小于样本均值加上上置信界。因此 e^{-2t U_t(a)^2} 应该是一个很小的概率。假设我们接受一个很小的阈值 p：

e^{-2t U_t(a)^2} = p \text{ Thus, } U_t(a) = \sqrt{\frac{-\log p}{2 N_t(a)}}

UCB1#

一种启发式做法是随时间减小阈值 p，因为我们希望在观测到更多奖励后能得到更可靠的界估计。将 p=t^{-4} 代入即可得到 UCB1 算法：

U_t(a) = \sqrt{\frac{2 \log t}{N_t(a)}} \text{ and } a^{UCB1}_t = \arg\max_{a \in \mathcal{A}} Q(a) + \sqrt{\frac{2 \log t}{N_t(a)}}

贝叶斯 UCB#

在 UCB 或 UCB1 算法中，我们不对奖励分布做任何先验假设，因此必须依赖 Hoeffding 不等式来进行高度通用的估计。如果我们能事先知道分布形式，就能做出更好的界估计。

例如，如果我们预期每台老虎机的平均奖励服从如图 2 所示的高斯分布，就可以将上界设为 95% 置信区间，即令 \hat{U}_t(a) 为标准差的两倍。

Thompson Sampling#

Thompson sampling 思想简单，但在解决多臂老虎机问题上表现非常出色。

在每个时间步，我们希望按照动作 a 是最优动作的概率来选择它：

\begin{aligned} \pi(a \; \vert \; h_t) &= \mathbb{P} [ Q(a) > Q(a'), \forall a' \neq a \; \vert \; h_t] \\ &= \mathbb{E}_{\mathcal{R} \vert h_t} [ \mathbb{1}(a = \arg\max_{a \in \mathcal{A}} Q(a)) ] \end{aligned}

其中 \pi(a ; \vert ; h_t) 表示给定历史 h_t 时选择动作 a 的概率。

对于伯努利老虎机，很自然地假设 Q(a) 服从 Beta 分布，因为 Q(a) 本质上就是 Bernoulli 分布中的成功概率 θ。\text{Beta}(\alpha, \beta) 的取值范围是 [0, 1]；α 和 β 分别对应我们获得奖励成功和失败的次数。

首先，根据对每个动作的一些先验知识或信念来初始化 Beta 分布的参数 α 和 β。例如：

α = 1，β = 1：我们预期奖励概率为 50%，但信心不是很强。 α = 1000，β = 9000：我们强烈相信奖励概率只有 10%。

在每个时间 t，我们从每个动作的先验分布 \text{Beta}(\alpha_i, \beta_i) 中采样一个期望奖励 \tilde{Q}(a)。然后在这些采样值中选择最佳动作 a^{TS}_t = \arg\max_{a \in \mathcal{A}} \tilde{Q}(a)。当观测到真实奖励后，我们可以相应地更新 Beta 分布，这实质上是在用已知的先验和观测数据的似然进行贝叶斯推断来计算后验。

\begin{aligned} \alpha_i & \leftarrow \alpha_i + r_t \mathbb{1}[a^{TS}_t = a_i] \\ \beta_i & \leftarrow \beta_i + (1-r_t) \mathbb{1}[a^{TS}_t = a_i] \end{aligned}

Thompson sampling 实现了 概率匹配 的思想。由于其奖励估计 \tilde{Q} 是从后验分布中采样得到的，每个概率都等于对应动作在已观测历史条件下为最优动作的概率。

然而，对于许多实际且复杂的场景，使用贝叶斯推断根据观测到的真实奖励来估计后验分布可能在计算上不可行。这时如果我们能通过 Gibbs 采样、Laplace 近似或自助法等方法来近似后验分布，Thompson sampling 仍然可以有效工作。这篇 教程 给出了全面的综述；如果你想深入了解 Thompson sampling，强烈推荐阅读。

总结#

我们需要探索，因为信息是有价值的。从探索策略来看，我们可以完全不探索，只关注短期回报；也可以偶尔进行随机探索；还可以更进一步，不仅探索，而且对探索哪些选项很挑剔——不确定性越高的动作越受青睐，因为它们能带来更高的信息增益。
