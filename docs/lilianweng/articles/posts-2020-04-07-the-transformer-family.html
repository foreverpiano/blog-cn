符号说明#

Symbol Meaning
d The model size / hidden state dimension / positional encoding size.
h The number of heads in multi-head attention layer.
L The segment length of input sequence.
\mathbf{X} \in \mathbb{R}^{L \times d} The input sequence where each element has been mapped into an embedding vector of shape d, same as the model size.
\mathbf{W}^k \in \mathbb{R}^{d \times d_k} The key weight matrix.
\mathbf{W}^q \in \mathbb{R}^{d \times d_k} The query weight matrix.
\mathbf{W}^v \in \mathbb{R}^{d \times d_v} The value weight matrix. Often we have d_k = d_v = d.
\mathbf{W}^k_i, \mathbf{W}^q_i \in \mathbb{R}^{d \times d_k/h}; \mathbf{W}^v_i \in \mathbb{R}^{d \times d_v/h} The weight matrices per head.
\mathbf{W}^o \in \mathbb{R}^{d_v \times d} The output weight matrix.
\mathbf{Q} = \mathbf{X}\mathbf{W}^q \in \mathbb{R}^{L \times d_k} The query embedding inputs.
\mathbf{K} = \mathbf{X}\mathbf{W}^k \in \mathbb{R}^{L \times d_k} The key embedding inputs.
\mathbf{V} = \mathbf{X}\mathbf{W}^v \in \mathbb{R}^{L \times d_v} The value embedding inputs.
S_i A collection of key positions for the i-th query \mathbf{q}_i to attend to.
\mathbf{A} \in \mathbb{R}^{L \times L} The self-attention matrix between a input sequence of length L and itself. \mathbf{A} = \text{softmax}(\mathbf{Q}\mathbf{K}^\top / \sqrt{d_k}).
a_{ij} \in \mathbf{A} The scalar attention score between query \mathbf{q}_i and key \mathbf{k}_j.
\mathbf{P} \in \mathbb{R}^{L \times d} position encoding matrix, where the i-th row \mathbf{p}_i is the positional encoding for input \mathbf{x}_i.

Attention 与 Self-Attention#

Attention 是神经网络中的一种机制，模型可以通过选择性地关注给定数据来学习进行预测。注意力的大小通过学习到的权重来量化，因此输出通常表现为加权平均的形式。

Self-attention 是一种特殊的注意力机制，模型利用同一数据样本中其他部分的信息来对该样本的某一位置进行预测。从概念上讲，它与 non-local means 非常相似。还需要注意的是，self-attention 是置换不变的；换句话说，它是对集合进行的操作。

Attention / Self-Attention 有多种形式，Transformer（Vaswani et al., 2017）采用的是缩放点积注意力（scaled dot-product attention）：给定查询矩阵 \mathbf{Q}、键矩阵 \mathbf{K} 和值矩阵 \mathbf{V}，输出是值向量的加权求和，其中分配给每个值向量的权重由查询与对应键的点积决定：

\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}(\frac{\mathbf{Q} {\mathbf{K}}^\top}{\sqrt{d_k}})\mathbf{V}

对于查询向量和键向量 \mathbf{q}_i, \mathbf{k}_j \in \mathbb{R}^d（查询和键矩阵中的行向量），我们得到一个标量分数：

a_{ij} = \text{softmax}(\frac{\mathbf{q}_i {\mathbf{k}_j}^\top}{\sqrt{d_k}}) = \frac{\exp(\mathbf{q}_i {\mathbf{k}_j}^\top)}{ \sqrt{d_k} \sum_{r \in S_i} \exp(\mathbf{q}_i {\mathbf{k}_r}^\top) }

如果感兴趣，可以参考我之前的 注意？注意！，其中介绍了其他类型的注意力机制。

Multi-Head Self-Attention#

多头自注意力模块是 Transformer 的核心组件之一。它不是只计算一次注意力，而是将输入拆分成多个更小的子空间，然后并行地在每个子空间上计算缩放点积注意力。最后将独立的注意力输出拼接起来，经过线性变换得到期望的维度。

\begin{aligned} \text{MultiHeadAttention}(\mathbf{X}_q, \mathbf{X}_k, \mathbf{X}_v) &= [\text{head}_1; \dots; \text{head}_h] \mathbf{W}^o \\ \text{where head}_i &= \text{Attention}(\mathbf{X}_q\mathbf{W}^q_i, \mathbf{X}_k\mathbf{W}^k_i, \mathbf{X}_v\mathbf{W}^v_i) \end{aligned}

其中 [.;.] 表示拼接操作，\mathbf{W}^q_i, \mathbf{W}^k_i \in \mathbb{R}^{d \times d_k/h}, \mathbf{W}^v_i \in \mathbb{R}^{d \times d_v/h} 是将维度为 L \times d 的输入嵌入映射为查询、键和值矩阵的权重矩阵，\mathbf{W}^o \in \mathbb{R}^{d_v \times d} 是最终的输出线性变换。所有权重均在训练过程中学习得到。

Transformer#

Transformer（为与后续改进版本区分，本文中称为“vanilla Transformer”；Vaswani et al., 2017）采用经典的编码器-解码器架构，这在许多 注意？注意！ 模型中很常见。后来，人们发现简化后的 Transformer 在语言建模任务中也能取得极佳性能，例如仅使用编码器的 通用语言模型 或仅使用解码器的 通用语言模型。

编码器-解码器架构

编码器生成基于注意力的表示，能够从大量上下文中定位特定信息。它由 6 个完全相同的模块堆叠而成，每个模块包含两个子模块：一个多头自注意力层和一个逐位置全连接前馈网络。所谓“逐位置”，是指对序列中的每个元素使用相同的线性变换（共享权重）。这也可以看作是滤波器大小为 1 的卷积层。每个子模块都带有残差连接和层归一化，所有子模块输出的数据维度均为 d。

Transformer 解码器的作用是从编码后的表示中提取信息。其架构与编码器非常相似，不同之处在于每个重复模块中包含两个多头注意力子模块，而不是一个。第一个多头注意力子模块使用了掩码，以防止当前位置关注未来信息。

位置编码

由于自注意力操作具有置换不变性，使用合适的位置编码（positional encoding）来为模型提供顺序信息非常重要。位置编码 \mathbf{P} \in \mathbb{R}^{L \times d} 与输入嵌入具有相同的维度，因此可以直接加到输入上。Vanilla Transformer 考虑了两种位置编码方式：

（1）正弦位置编码定义如下，其中 i=1,\dots,L 表示 token 的位置，\delta=1,\dots,d 表示维度：

\text{PE}(i,\delta) = \begin{cases} \sin(\frac{i}{10000^{2\delta'/d}}) & \text{if } \delta = 2\delta'\\ \cos(\frac{i}{10000^{2\delta'/d}}) & \text{if } \delta = 2\delta' + 1\\ \end{cases}

这样，位置编码的每个维度对应不同波长的正弦函数，波长范围从 2\pi 到 10000 \cdot 2\pi。

（2）可学习的位置编码，正如其名称所示，为每个位置分配一个可学习的列向量，用于编码其绝对位置（Gehring et al., 2017）。

后续快速进展

在 vanilla Transformer 之后，Al-Rfou et al. (2018) 引入了一组辅助损失，使得能够在字符级语言建模任务上训练更深的 Transformer 模型，其性能超过了 LSTM。他们使用了以下几种辅助任务：

不再只在序列末尾产生一个预测，而是要求每个中间位置也做出正确预测，迫使模型在更小的上下文（例如上下文窗口开头的前几个 token）下进行预测。 每个中间 Transformer 层也被用于做出预测。随着训练进行，较低层的权重对总损失的贡献会越来越小。 序列中的每个位置可以预测多个目标，即对未来两个或更多 token 进行预测。

自适应计算时间（ACT）#

自适应计算时间（Adaptive Computation Time，简称 ACT；Graves, 2016）是一种动态决定循环神经网络需要执行多少计算步数的机制。distill.pub 上有一篇很棒的 教程 介绍了 ACT。

假设我们有一个 RNN 模型 \mathcal{R}，它包含输入权重 W_x、参数化的状态转移函数 \mathcal{S}(.)、输出权重 W_y 以及输出偏置 b_y。给定输入序列 (x_1, \dots, x_L)，输出序列 (y_1, \dots, y_L) 的计算方式为：

s_t = \mathcal{S}(s_{t-1}, W_x x_t), \quad y_t = W_y s_t + b_y\quad\text{for }t=1, \dots, L

ACT 允许上述 RNN 在处理每个输入元素时执行可变数量的计算步骤。多次计算会产生一系列中间状态 (s_t^1, \dots, s_t^{N(t)}) 和输出 (y_t^1, \dots, y_t^{N(t)})——它们共享相同的状态转移函数 \mathcal{S}(.)、输出权重 W_y 和偏置 b_y：

\begin{aligned} s_t^0 &= s_{t-1} \\ s_t^n &= \mathcal{S}(s_{t}^{n-1}, x_t^n) = \mathcal{S}(s_{t}^{n-1}, x_t + \delta_{n,1}) \text{ for } n=1, \dots, N(t)\\ y_t^n &= W_y s_t^n + b_y \end{aligned}

其中 \delta_{n,1} 是一个二进制标志，表示是否已经递增了输入步数。

计算步数 N(t) 由一个额外的 sigmoid 停止单元 h 决定，该单元带有对应的权重矩阵 W_h 和偏置 b_h，在第 n 个即时步对第 t 个输入元素输出停止概率 p_t^n：

h_t^n = \sigma(W_h s_t^n + b_h)

为了允许计算在一步之后即可停止，ACT 引入了一个很小的常数 \epsilon（例如 0.01），当累积概率超过 1-\epsilon 时计算就会停止。

\begin{aligned} N(t) &= \min(\min\{n': \sum_{n=1}^{n'} h_t^n \geq 1 -\epsilon\}, M) \\ p_t^n &= \begin{cases} h_t^n & \text{if }n < N(t) \\ R(t) = 1 - \sum_{n=1}^{N(t)-1} h_t^n & \text{if }n= N(t)\\ \end{cases} \end{aligned}

其中 M 是允许的最大即时步数上限。

最终的状态和输出通过均场更新得到：

s_t = \sum_{n=1}^{N(t)} p_t^n s_t^n,\quad y_t = \sum_{n=1}^{N(t)} p_t^n y_t^n

为了避免在每个输入上进行不必要的思考，ACT 在损失函数中加入了一个 ponder cost \mathcal{P}(x) = \sum_{t=1}^L N(t) + R(t) ，以鼓励更少的中间计算步数。

改进注意力跨度#

改进注意力跨度的目标是使自注意力机制能够使用更长、更高效且更灵活的上下文。

更长的注意力跨度（Transformer-XL）#

Vanilla Transformer 的注意力跨度是固定且有限的。在每次更新时，模型只能关注同一段（segment）内的其他元素，不同固定长度段之间无法传递信息。

这种上下文切分导致了以下几个问题：

模型无法捕捉极长期的依赖关系。 由于上下文缺失或过少，很难预测每个段开头的几个 token。 评估代价很高。每当段向右移动一个位置时，新的段都需要从头重新处理，尽管其中存在大量重叠的 token。

Transformer-XL（Dai et al., 2019；“XL”代表“extra long”）通过两个主要修改解决了上下文切分问题：

在段之间复用隐藏状态。 采用一种适合复用状态的新型位置编码。

隐藏状态复用

通过持续使用前一段的隐藏状态，将段之间的循环连接引入模型。

我们将模型中第 n 层、第 (\tau + 1) 个段的隐藏状态记为 \mathbf{h}_{\tau+1}^{(n)} \in \mathbb{R}^{L \times d}。除了同一段最后一层的隐藏状态 \mathbf{h}_{\tau+1}^{(n-1)} 外，它还依赖于前一段同一层的隐藏状态 \mathbf{h}_{\tau}^{(n)}。通过引入先前隐藏状态的信息，模型能够将注意力跨度大幅向前延伸，跨越多个段。

\begin{aligned} \color{red}{\widetilde{\mathbf{h}}_{\tau+1}^{(n-1)}} &= [\text{stop-gradient}(\mathbf{h}_{\tau}^{(n-1)}) \circ \mathbf{h}_{\tau+1}^{(n-1)}] \\ \mathbf{Q}_{\tau+1}^{(n)} &= \mathbf{h}_{\tau+1}^{(n-1)}\mathbf{W}^q \\ \mathbf{K}_{\tau+1}^{(n)} &= \color{red}{\widetilde{\mathbf{h}}_{\tau+1}^{(n-1)}} \mathbf{W}^k \\ \mathbf{V}_{\tau+1}^{(n)} &= \color{red}{\widetilde{\mathbf{h}}_{\tau+1}^{(n-1)}} \mathbf{W}^v \\ \mathbf{h}_{\tau+1}^{(n)} &= \text{transformer-layer}(\mathbf{Q}_{\tau+1}^{(n)}, \mathbf{K}_{\tau+1}^{(n)}, \mathbf{V}_{\tau+1}^{(n)}) \end{aligned}

注意，键和值都依赖于扩展后的隐藏状态，而查询只使用当前步的隐藏状态。拼接操作 [. \circ .] 是沿着序列长度维度进行的。

相对位置编码

为了适应这种新的注意力跨度形式，Transformer-XL 提出了一种新的位置编码。如果像 vanilla Transformer 那样对绝对位置进行编码，前一段和当前段会被赋予相同的位置编码，这并不理想。

为了让位置信息能够连贯地在段之间流动，Transformer-XL 改为对相对位置进行编码。因为只要知道位置偏移量，就足以做出良好的预测，即查询 \mathbf{q}_{\tau, i} 与键 \mathbf{k}_{\tau, j} 之间的偏移 i-j。

如果省略 softmax 中的标量 1/\sqrt{d_k} 和归一化项，但包含位置编码，那么位置 i 的查询与位置 j 的键之间的注意力分数可以写为：

\begin{aligned} a_{ij} &= \mathbf{q}_i {\mathbf{k}_j}^\top = (\mathbf{x}_i + \mathbf{p}_i)\mathbf{W}^q ((\mathbf{x}_j + \mathbf{p}_j)\mathbf{W}^k)^\top \\ &= \mathbf{x}_i\mathbf{W}^q {\mathbf{W}^k}^\top\mathbf{x}_j^\top + \mathbf{x}_i\mathbf{W}^q {\mathbf{W}^k}^\top\mathbf{p}_j^\top + \mathbf{p}_i\mathbf{W}^q {\mathbf{W}^k}^\top\mathbf{x}_j^\top + \mathbf{p}_i\mathbf{W}^q {\mathbf{W}^k}^\top\mathbf{p}_j^\top \end{aligned}

Transformer-XL 对上述四个项进行了重新参数化：

a_{ij}^\text{rel} = \underbrace{ \mathbf{x}_i\mathbf{W}^q \color{blue}{ {\mathbf{W}_E^k}^\top } \mathbf{x}_j^\top }_\text{content-based addressing} + \underbrace{ \mathbf{x}_i\mathbf{W}^q \color{blue}{ {\mathbf{W}_R^k}^\top } \color{green}{\mathbf{r}_{i-j}^\top} }_\text{content-dependent positional bias} + \underbrace{ \color{red}{\mathbf{u}} \color{blue}{ {\mathbf{W}_E^k}^\top } \mathbf{x}_j^\top }_\text{global content bias} + \underbrace{ \color{red}{\mathbf{v}} \color{blue}{ {\mathbf{W}_R^k}^\top } \color{green}{\mathbf{r}_{i-j}^\top} }_\text{global positional bias}
将 \mathbf{p}_j 替换为相对位置编码 \mathbf{r}_{i-j} \in \mathbf{R}^{d}； 将 \mathbf{p}_i\mathbf{W}^q 替换为两个可训练参数 \mathbf{u}（用于内容）和 \mathbf{v}（用于位置），分别用于两个不同项； 将 \mathbf{W}^k 拆分为两个矩阵，\mathbf{W}^k_E 用于内容信息，\mathbf{W}^k_R 用于位置信息。

自适应注意力跨度#

Transformer 的一个关键优势是能够捕捉长期依赖关系。根据上下文不同，模型有时可能更希望关注更远的位置；或者不同的注意力头可能具有不同的注意力模式。如果注意力跨度能够灵活地调整长度，并且只在必要时才关注更远的位置，那么就能同时减少计算和内存开销，从而支持更大的最大上下文长度。

这正是自适应注意力跨度（Adaptive Attention Span）的动机。Sukhbaatar et al. (2019) 提出了一种寻找最优注意力跨度的自注意力机制。他们假设在同一个上下文窗口内，不同的注意力头可能会以不同方式分配注意力分数（见 Fig. 7），因此最优跨度应针对每个头单独训练。

给定第 i 个 token，我们需要计算该 token 与位置在 j \in S_i 的其他键之间的注意力权重，其中 S_i 定义了第 i 个 token 的上下文窗口。

\begin{aligned} e_{ij} &= \mathbf{q}_i {\mathbf{k}_j}^\top \\ a_{ij} &= \text{softmax}(e_{ij}) = \frac{\exp(e_{ij})}{\sum_{r=i-s}^{i-1} \exp(e_{ir})} \\ \mathbf{y}_i &= \sum_{r=i-s}^{i-1}a_{ir}\mathbf{v}_r = \sum_{r=i-s}^{i-1}a_{ir}\mathbf{x}_r\mathbf{W}^v \end{aligned}

引入了一个软掩码函数 m_z 来控制可调整的有效注意力跨度，它将查询和键之间的距离映射到 [0, 1] 区间。m_z 由 z \in [0, s] 参数化，其中 z 是需要学习的：

m_z(x) = \text{clamp}(\frac{1}{R}(R+z-x), 0, 1)

其中 R 是一个超参数，用于控制 m_z 的平滑程度。

软掩码函数被应用于注意力权重中的 softmax 元素：

a_{ij} = \frac{m_z(i-j)\exp(s_{ij})}{\sum_{r=i-s}^{i-1}m_z(i-r) \exp(s_{ir})}

在上述公式中，z 是可微的，因此可以与模型其他部分联合训练。参数 z^{(i)}, i=1, \dots, h 针对每个注意力头单独学习。此外，损失函数中还对 \sum_{i=1}^h z^{(i)} 施加了一个额外的 L1 正则化项。

结合自适应计算时间（ACT），该方法可以进一步扩展为具有灵活注意力跨度长度，并能根据当前输入动态调整。在时间 t 时，注意力头的跨度参数 z_t 是一个 sigmoid 函数 z_t = S \sigma(\mathbf{v} \cdot \mathbf{x}_t +b)，其中向量 \mathbf{v} 和偏置标量 b 与其他参数一起联合学习。

在使用自适应注意力跨度的 Transformer 实验中，Sukhbaatar et al. (2019) 发现一个普遍趋势：较低层通常不需要很长的注意力跨度，而较高层中的少数注意力头可能会使用特别长的跨度。自适应注意力跨度还能显著减少 FLOPS，尤其是在具有多层注意力且上下文长度很大的大型模型中。

局部注意力跨度（Image Transformer）#

Transformer 最初也是最流行的应用场景是语言建模。文本序列是一维的，具有明确的时序，因此注意力跨度会随着上下文大小的增加而线性增长。

然而，如果我们想在图像上使用 Transformer，如何定义上下文范围或顺序就不那么清晰了。Image Transformer（Parmar et al., 2018）在 Transformer 框架内采用了一种类似于序列建模的图像生成形式。此外，Image Transformer 将自注意力跨度限制在局部邻域内，从而使模型能够并行处理更多图像，并保持似然损失可控。

编码器-解码器架构依然保留，用于图像条件生成：

编码器生成源图像的、按像素通道上下文化的表示； 解码器自回归地生成输出图像，每个时间步生成一个像素的一个通道。

我们将当前待生成像素的表示记为查询 \mathbf{q}。其他将用于计算 \mathbf{q} 的位置的表示作为键向量 \mathbf{k}_1, \mathbf{k}_2, \dots，它们共同构成内存矩阵 \mathbf{M}。\mathbf{M} 的范围定义了像素查询 \mathbf{q} 的上下文窗口。

Image Transformer 提出了两种局部 \mathbf{M}，如下图所示。

（1）1D 局部注意力：输入图像按照 光栅扫描 顺序展平，即从左到右、从上到下。然后将线性化后的图像分割成不重叠的查询块。上下文窗口包括与 \mathbf{q} 位于同一查询块中的像素，以及在该查询块之前生成的一定数量的额外像素。

（2）2D 局部注意力：图像被分割成多个不重叠的矩形查询块。查询像素可以关注同一内存块中的所有其他像素。为了确保左上角的像素也能拥有有效的上下文窗口，内存块会分别向上、向左和向右扩展固定数量。

减少时间与内存开销#

本节介绍几种针对 Transformer 的改进，以降低计算时间和内存消耗。

稀疏注意力矩阵分解（Sparse Transformers）#

Vanilla Transformer 的计算和内存开销随序列长度二次增长，因此很难应用于极长的序列。

Sparse Transformer（Child et al., 2019）通过稀疏矩阵分解引入了因子分解自注意力，使得能够在序列长度高达 16384 的情况下训练具有数百层的稠密注意力网络，否则这在现代硬件上是不可行的。

给定一组注意力连接模式 \mathcal{S} = \{S_1, \dots, S_n\}，其中每个 S_i 记录了第 i 个查询向量所关注的键的位置集合。

\begin{aligned} \text{Attend}(\mathbf{X}, \mathcal{S}) &= \Big( a(\mathbf{x}_i, S_i) \Big)_{i \in \{1, \dots, L\}} \\ \text{ where } a(\mathbf{x}_i, S_i) &= \text{softmax}\Big(\frac{(\mathbf{x}_i \mathbf{W}^q)(\mathbf{x}_j \mathbf{W}^k)_{j \in S_i}^\top}{\sqrt{d_k}}\Big) (\mathbf{x}_j \mathbf{W}^v)_{j \in S_i} \end{aligned}

虽然 S_i 的大小不固定，但 a(\mathbf{x}_i, S_i) 始终是大小为 d_v 的，因此 \text{Attend}(\mathbf{X}, \mathcal{S}) \in \mathbb{R}^{L \times d_v}。

在自回归模型中，一个注意力跨度被定义为 S_i = \{j: j \leq i\}，因为它允许每个 token 关注过去的所有位置。

在因子分解自注意力中，集合 S_i 被分解为一个依赖树，使得对于每一对满足 j \leq i 的 (i, j)，都存在一条路径将 i 连接回 j，并且 i 可以直接或间接地关注 j。

具体而言，集合 S_i 被划分成 p 个不重叠的子集，其中第 m 个子集记为 A^{(m)}_i \subset S_i, m = 1,\dots, p。因此，输出位置 i 与任意 j 之间的路径最大长度为 p + 1。例如，如果 (j, a, b, c, \dots, i) 是 i 和 j 之间索引的路径，那么我们有 j \in A_a^{(1)}, a \in A_b^{(2)}, b \in A_c^{(3)}, \dots，以此类推。

稀疏因子分解注意力

Sparse Transformer 提出了两种因子分解注意力方式。用 2D 图像输入作为例子，图 10 能更直观地说明这些概念。

（1）步长为 \ell \sim \sqrt{n} 的跨步注意力。这在图像数据上表现良好，因为图像结构与跨步对齐。在图像情况下，每个像素会关注光栅扫描顺序中之前的所有 \ell 个像素（自然覆盖图像的整个宽度），然后这些像素再关注同一列中的其他像素（由另一个注意力连接子集定义）。

\begin{aligned} A_i^{(1)} &= \{ t, t+1, \dots, i\} \text{, where } t = \max(0, i - \ell) \\ A_i^{(2)} &= \{j: (i-j) \mod \ell = 0\} \end{aligned}

（2）固定注意力。一小组 token 对之前的位置进行汇总，并将信息传播到所有后续位置。

\begin{aligned} A_i^{(1)} &= \{j: \lfloor \frac{j}{\ell} \rfloor = \lfloor \frac{i}{\ell} \rfloor \} \\ A_i^{(2)} &= \{j: j \mod \ell \in \{\ell-c, \dots, \ell-1\} \} \end{aligned}

其中 c 是一个超参数。如果 c=1，则会限制表示，使得许多位置都依赖于少量位置。论文选择了 c\in \{ 8, 16, 32 \} 作为 \ell \in \{ 128, 256 \}。

在 Transformer 中使用因子分解自注意力

在 Transformer 架构中有三种方式来使用稀疏因子分解注意力模式：

每个残差块使用一种注意力类型，然后交替使用，形式为 \text{attention}(\mathbf{X}) = \text{Attend}(\mathbf{X}, A^{(n \mod p)}) \mathbf{W}^o，其中 n 是当前残差块的索引。 设置一个单独的头，关注所有因子分解头所关注的全部位置，即 \text{attention}(\mathbf{X}) = \text{Attend}(\mathbf{X}, \cup_{m=1}^p A^{(m)}) \mathbf{W}^o 。 使用多头注意力机制，但与 vanilla Transformer 不同，每个头可以采用上述两种模式之一。=> 这种方式通常性能最好。

Sparse Transformer 还提出了一系列改动，以便能够训练多达数百层的 Transformer，包括梯度检查点、在反向传播时重新计算注意力与前馈层、混合精度训练、高效的块稀疏实现等。更多细节请参考 原论文。

局部敏感哈希（Reformer）#

Reformer 模型（Kitaev et al., 2020）提出的改进旨在解决 Transformer 中的以下痛点：

具有 N 层的模型的内存是单层模型的 N 倍，因为我们需要为反向传播存储每一层的激活。 中间的前馈层通常非常大。 长度为 L 的序列上的注意力矩阵通常需要在内存和时间上消耗 O(L^2)。

Reformer 提出了两个主要改进：

用局部敏感哈希（LSH）注意力替代点积注意力，将复杂度从 O(L^2) 降低到 O(L\log L)。 用可逆残差层替代标准残差块，这样在训练期间只需存储一次激活，而不是 N 次（即与层数成正比）。

局部敏感哈希注意力

在注意力公式中的 \mathbf{Q} \mathbf{K}^\top 部分，我们只对最大的元素感兴趣，因为 softmax 之后只有大元素会产生显著贡献。对于每个查询 \mathbf{q}_i \in \mathbf{Q}，我们需要找到 \mathbf{K} 中与 \mathbf{q}_i 最接近的行向量。为了在高维空间中快速找到最近邻，Reformer 将 局部敏感哈希（Locality-Sensitive Hashing, LSH） 引入其注意力机制。

如果一个哈希方案 x \mapsto h(x) 能够保留数据点之间的距离信息，使得相近的向量获得相似的哈希，而遥远的向量获得差异很大的哈希，则称其为局部敏感的。Reformer 采用的哈希方案如下：给定一个固定的随机矩阵 \mathbf{R} \in \mathbb{R}^{d \times b/2}（其中 b 是一个超参数），哈希函数为 h(x) = \arg\max([xR; −xR])。

如果省略自注意力中的标量，并将分母归纳为一个归一化项 Z(.)，普通的注意力输出如下所示： <div>

\mathbf{o}_i = \sum_{j \in S_i} \exp(\mathbf{q}_i \cdot \mathbf{k}_j - Z(i, S_i)) \mathbf{v}_j \text{, where } S_i = \{j: j \leq i\}

</div>

在 LSH 注意力中，查询只能关注同一哈希桶内的位置 S_i = \{j: h(\mathbf{q}_i) = h(\mathbf{k}_j)\}。其过程如图 11 所示：

可逆残差网络

Reformer 的另一项改进是使用可逆残差层（Gomez et al., 2017）。可逆残差网络的设计目标是：任意一层的激活都可以仅通过模型参数从下一层的激活中恢复。因此，我们可以在反向传播时重新计算激活，而无需存储所有激活，从而节省内存。

对于一个层 x \mapsto y，普通残差层执行 y = x + F(x)，而可逆层将输入和输出都拆分成两部分 (x_1, x_2) \mapsto (y_1, y_2)，然后执行以下操作：

y_1 = x_1 + F(x_2),\; y_2 = x_2 + G(y_1)

反向操作则非常简单：

x_2 = y_2 - G(y_1), \; x_1 = y_1 − F(x_2)

Reformer 将这一思想应用到 Transformer 中，在一个可逆网络块内组合注意力（F）和前馈层（G）：

Y_1 = X_1 + \text{Attention}(X_2), \; Y_2 = X_2 + \text{FeedForward}(Y_1)

通过对前馈计算进行分块，可以进一步减少内存消耗：

Y_2 = [Y_2^{(1)}; \dots; Y_2^{(c)}] = [X_2^{(1)} + \text{FeedForward}(Y_1^{(1)}); \dots; X_2^{(c)} + \text{FeedForward}(Y_1^{(c)})]

得到的可逆 Transformer 不需要在每一层都存储激活值。

使其具有循环特性（Universal Transformer）#

Universal Transformer（Dehghani et al., 2019）将 Transformer 中的自注意力与 RNN 中的循环机制相结合，旨在同时受益于 Transformer 的长期全局感受野和 RNN 的归纳偏置学习能力。

Universal Transformer 不是使用固定数量的层，而是通过自适应计算时间动态调整步数。如果固定步数，那么 Universal Transformer 就等价于一个在各层之间共享参数的多层 Transformer。

从高层来看，Universal Transformer 可以看作是一个循环函数，用于学习每个 token 的隐藏状态表示。该循环函数在所有 token 位置上并行演化，位置之间的信息通过自注意力进行共享。

给定长度为 L 的输入序列，Universal Transformer 在第 t 步迭代更新表示 \mathbf{H}^t \in \mathbb{R}^{L \times d}，步数可调。在第 0 步，\mathbf{H}^0 被初始化为与输入嵌入矩阵相同。所有位置在多头自注意力机制中并行处理，然后经过一个循环转移函数。

\begin{aligned} \mathbf{A}^t &= \text{LayerNorm}(\mathbf{H}^{t-1} + \text{MultiHeadAttention}(\mathbf{H}^{t-1} + \mathbf{P}^t) \\ \mathbf{H}^t &= \text{LayerNorm}(\mathbf{A}^{t-1} + \text{Transition}(\mathbf{A}^t)) \end{aligned}

其中 \text{Transition}(.) 要么是 可分离卷积，要么是一个全连接神经网络，由两个逐位置（即对 \mathbf{A}^t 的每一行分别应用）的仿射变换加一个 ReLU 组成。

位置编码 \mathbf{P}^t 使用正弦位置信号，但增加了一个时间维度：

\text{PE}(i, t, \delta) = \begin{cases} \sin(\frac{i}{10000^{2\delta'/d}}) \oplus \sin(\frac{t}{10000^{2\delta'/d}}) & \text{if } \delta = 2\delta'\\ \cos(\frac{i}{10000^{2\delta'/d}}) \oplus \cos(\frac{t}{10000^{2\delta'/d}}) & \text{if } \delta = 2\delta' + 1\\ \end{cases}

在 Universal Transformer 的自适应版本中，循环步数 T 由 ACT 动态决定。每个位置都配备了一个动态的 ACT 停止机制。一旦某个 token 的循环块停止，它就不再进行更多的循环更新，而是将当前值简单复制到后续步骤，直到所有块都停止，或达到模型允许的最大步数。

针对强化学习的稳定化措施（GTrXL）#

自注意力机制避免了将整个历史压缩到一个固定大小的隐藏状态中，并且不像 RNN 那样容易出现梯度消失或爆炸问题。强化学习任务无疑可以从这些特性中受益。然而，即使在监督学习中，训练 Transformer 也相当困难，更不用说在 RL 环境中了。毕竟，单独稳定并训练一个 LSTM 智能体就已经很有挑战性了。

Gated Transformer-XL（GTrXL；Parisotto et al., 2019）是尝试将 Transformer 用于 RL 的一种方案。GTrXL 在 Transformer-XL 的基础上通过两处修改成功稳定了训练过程：

层归一化只应用于残差模块的输入流，而不对快捷连接流应用。这种重排序的一个关键好处是允许原始输入从第一层一直流动到最后一层。 残差连接被替换为类似 GRU（Gated Recurrent Unit；Chung et al., 2014）的门控机制。
\begin{aligned} r &= \sigma(W_r^{(l)} y + U_r^{(l)} x) \\ z &= \sigma(W_z^{(l)} y + U_z^{(l)} x - b_g^{(l)}) \\ \hat{h} &= \tanh(W_g^{(l)} y + U_g^{(l)} (r \odot x)) \\ g^{(l)}(x, y) &= (1-z)\odot x + z\odot \hat{h} \end{aligned}

门控函数的参数被显式初始化为接近单位映射——这就是为什么存在 b_g 项。一个 b_g > 0 可以显著加快学习速度。
