符号说明#

Symbol Meaning

h The number of heads in multi-head attention layer.
L The segment length of input sequence.
\mathbf{X} \in \mathbb{R}^{L \times d} The input sequence where each element has been mapped into an embedding vector of shape d, same as the model size.
\mathbf{W}^k \in \mathbb{R}^{d \times d_k} The key weight matrix.
\mathbf{W}^q \in \mathbb{R}^{d \times d_k} The query weight matrix.
\mathbf{W}^v \in \mathbb{R}^{d \times d_v} The value weight matrix. Often we have d_k = d_v = d.
\mathbf{W}^k_i, \mathbf{W}^q_i \in \mathbb{R}^{d \times d_k/h}; \mathbf{W}^v_i \in \mathbb{R}^{d \times d_v/h} The weight matrices per head.
\mathbf{W}^o \in \mathbb{R}^{d_v \times d} The output weight matrix.
\mathbf{Q} = \mathbf{X}\mathbf{W}^q \in \mathbb{R}^{L \times d_k} The query embedding inputs.
\mathbf{K} = \mathbf{X}\mathbf{W}^k \in \mathbb{R}^{L \times d_k} The key embedding inputs.
\mathbf{V} = \mathbf{X}\mathbf{W}^v \in \mathbb{R}^{L \times d_v} The value embedding inputs.
S_i A collection of key positions for the i-th query \mathbf{q}_i to attend to.
\mathbf{A} \in \mathbb{R}^{L \times L} The self-attention matrix between a input sequence of length L and itself. \mathbf{A} = \text{softmax}(\mathbf{Q}\mathbf{K}^\top / \sqrt{d_k}).
a_{ij} \in \mathbf{A} The scalar attention score between query \mathbf{q}_i and key \mathbf{k}_j.
\mathbf{P} \in \mathbb{R}^{L \times d} position encoding matrix, where the i-th row \mathbf{p}_i is the positional encoding for input \mathbf{x}_i.

Attention 与 Self-Attention#

Attention 是神经网络中的一种机制，模型通过选择性地关注给定数据中的特定部分来学习进行预测。注意力的大小由学习到的权重量化，因此输出通常表现为加权平均的形式。

Self-attention（自注意力）是注意力机制的一种，模型利用同一数据样本中的其他部分来对该样本的某一部分进行预测。从概念上讲，它与 non-local means 非常相似。还需要注意的是，自注意力具有置换不变性；换句话说，它是对集合进行的操作。

注意力 / 自注意力有多种形式，Transformer（Vaswani et al., 2017）依赖的是缩放点积注意力（scaled dot-product attention）：给定查询矩阵 \mathbf{Q}、键矩阵 \mathbf{K} 和值矩阵 \mathbf{V}，输出是值向量的加权和，其中分配给每个值槽的权重由查询与对应键的点积决定：

\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}(\frac{\mathbf{Q} {\mathbf{K}}^\top}{\sqrt{d_k}})\mathbf{V}

对于一个查询向量和一个键向量 \mathbf{q}_i, \mathbf{k}_j \in \mathbb{R}^d（查询矩阵和键矩阵中的行向量），我们得到一个标量得分：

a_{ij} = \text{softmax}(\frac{\mathbf{q}_i {\mathbf{k}_j}^\top}{\sqrt{d_k}}) = \frac{\exp(\mathbf{q}_i {\mathbf{k}_j}^\top)}{ \sqrt{d_k} \sum_{r \in S_i} \exp(\mathbf{q}_i {\mathbf{k}_r}^\top) }

如果感兴趣，可以参考我之前的 注意力？注意力！ 来了解其他类型的注意力。

Multi-Head Self-Attention#

多头自注意力模块是 Transformer 中的关键组件。它并非只计算一次注意力，而是将输入分割成更小的块，然后并行地在每个子空间上计算缩放点积注意力。独立的注意力输出被简单地拼接起来，再经过线性变换映射到期望的维度。

\begin{aligned} \text{MultiHeadAttention}(\mathbf{X}_q, \mathbf{X}_k, \mathbf{X}_v) &= [\text{head}_1; \dots; \text{head}_h] \mathbf{W}^o \\ \text{where head}_i &= \text{Attention}(\mathbf{X}_q\mathbf{W}^q_i, \mathbf{X}_k\mathbf{W}^k_i, \mathbf{X}_v\mathbf{W}^v_i) \end{aligned}

其中 [.;.] 是拼接操作。\mathbf{W}^q_i, \mathbf{W}^k_i \in \mathbb{R}^{d \times d_k/h}, \mathbf{W}^v_i \in \mathbb{R}^{d \times d_v/h} 是权重矩阵，用于将大小为 L \times d 的输入嵌入映射为查询、键和值矩阵。\mathbf{W}^o \in \mathbb{R}^{d_v \times d} 是输出的线性变换。所有这些权重都需要在训练过程中学习得到。

Transformer#

Transformer（为与后续增强版本区分，本文将其称为“vanilla Transformer”；Vaswani, et al., 2017）采用编码器-解码器架构，这在许多 注意力？注意力！ 模型中很常见。后来简化后的 Transformer 在语言建模任务中展现出出色性能，例如仅使用编码器的 泛化语言模型 或仅使用解码器的 泛化语言模型。

编码器-解码器架构

编码器生成基于注意力的表示，能够从大量上下文中定位特定信息。它由 6 个相同的模块堆叠而成，每个模块包含两个子模块：一个多头自注意力层和一个逐点全连接前馈网络。“逐点”是指对序列中的每个元素都应用相同的线性变换（使用相同权重）。这也可以看作是滤波器大小为 1 的卷积层。每个子模块都有残差连接和层归一化。所有子模块输出的数据维度相同，均为 d。

Transformer 解码器的作用是从编码后的表示中检索信息。其架构与编码器非常相似，不同之处在于解码器中的每个重复模块包含两个多头注意力子模块，而不是一个。第一个多头注意力子模块使用了掩蔽（mask），以防止当前位置关注未来的信息。

位置编码

由于自注意力操作具有置换不变性，使用合适的位置编码（positional encoding）来为模型提供顺序信息非常重要。位置编码 \mathbf{P} \in \mathbb{R}^{L \times d} 与输入嵌入的维度相同，因此可以直接加到输入上。原始 Transformer 考虑了两种编码方式：

(1) 正弦位置编码定义如下，其中 i=1,\dots,L 表示 token 的位置，\delta=1,\dots,d 表示维度：

\text{PE}(i,\delta) = \begin{cases} \sin(\frac{i}{10000^{2\delta'/d}}) & \text{if } \delta = 2\delta'\\ \cos(\frac{i}{10000^{2\delta'/d}}) & \text{if } \delta = 2\delta' + 1\\ \end{cases}

这样，位置编码的每个维度对应于不同波长的正弦函数，波长范围从 2\pi 到 10000 \cdot 2\pi。

(2) 学习的位置编码，如其名称所示，为每个元素分配一个可学习的列向量来编码其绝对位置（Gehring, et al. 2017）。

在原始 Transformer 之后，Al-Rfou et al. (2018) 引入了一组辅助损失，使其能够在字符级语言建模上训练深层 Transformer 模型，并超越了 LSTM。他们使用了以下几种辅助任务：

不仅在序列末尾生成一个预测，每个中间位置也被要求做出正确预测，迫使模型在较小的上下文中进行预测（例如在上下文窗口开始处的最初几个 token）。 每个中间 Transformer 层也被用于进行预测。随着训练的进行，较低层对总损失的贡献权重会逐渐降低。 序列中的每个位置可以预测多个目标，即对未来多个 token 进行预测。

自适应计算时间（ACT）#

自适应计算时间（简称 ACT；Graves, 2016）是一种机制，用于动态决定循环神经网络中需要多少计算步骤。distill.pub 上有一篇很棒的 教程 介绍 ACT。

假设我们有一个 RNN 模型 \mathcal{R}，它包含输入权重 W_x、参数化的状态转移函数 \mathcal{S}(.)、一组输出权重 W_y 和输出偏置 b_y。给定输入序列 (x_1, \dots, x_L)，输出序列 (y_1, \dots, y_L) 通过以下方式计算：

s_t = \mathcal{S}(s_{t-1}, W_x x_t), \quad y_t = W_y s_t + b_y\quad\text{for }t=1, \dots, L

ACT 使上述 RNN 结构在每个输入元素上能够执行可变数量的计算步骤。多次计算步骤会产生一系列中间状态 (s_t^1, \dots, s_t^{N(t)}) 和输出 (y_t^1, \dots, y_t^{N(t)})——它们共享相同的状态转移函数 \mathcal{S}(.)，以及相同的输出权重 W_y 和偏置 b_y：

\begin{aligned} s_t^0 &= s_{t-1} \\ s_t^n &= \mathcal{S}(s_{t}^{n-1}, x_t^n) = \mathcal{S}(s_{t}^{n-1}, x_t + \delta_{n,1}) \text{ for } n=1, \dots, N(t)\\ y_t^n &= W_y s_t^n + b_y \end{aligned}

其中 \delta_{n,1} 是一个二进制标志，表示输入步数是否已经递增。

计算步骤数 N(t) 由一个额外的 sigmoid 停止单元 h 决定，该单元带有对应的权重矩阵 W_h 和偏置 b_h，在第 n 个即时步骤为第 t 个输入元素输出停止概率 p_t^n：

h_t^n = \sigma(W_h s_t^n + b_h)

为了允许计算在单步后即可停止，ACT 引入了一个很小的常数 \epsilon（例如 0.01），使得累积概率一旦超过 1-\epsilon，计算就会停止。

\begin{aligned} N(t) &= \min(\min\{n': \sum_{n=1}^{n'} h_t^n \geq 1 -\epsilon\}, M) \\ p_t^n &= \begin{cases} h_t^n & \text{if }n < N(t) \\ R(t) = 1 - \sum_{n=1}^{N(t)-1} h_t^n & \text{if }n= N(t)\\ \end{cases} \end{aligned}

其中 M 是允许的最大即时步骤数上限。

最终的状态和输出通过均值场更新得到：

s_t = \sum_{n=1}^{N(t)} p_t^n s_t^n,\quad y_t = \sum_{n=1}^{N(t)} p_t^n y_t^n

为了避免对每个输入进行不必要的过多思考，ACT 在损失函数中加入了思考成本 \mathcal{P}(x) = \sum_{t=1}^L N(t) + R(t) ，以鼓励更少的中间计算步骤。

改进注意力跨度#

改进注意力跨度的目标是让自注意力可以利用的上下文更长、更高效且更灵活。

更长的注意力跨度（Transformer-XL）#

原始 Transformer 的注意力跨度是固定且有限的。在每次更新步骤中，模型只能关注同一片段内的其他元素，不同固定长度片段之间无法传递信息。

这种上下文分割会导致几个问题：

模型无法捕捉非常长期的依赖关系。 在每个片段开头的前几个 token 由于上下文不足或缺失，难以进行预测。 评估代价很高。每当片段向右移动一个位置时，新的片段都需要从头重新处理，尽管其中存在大量重叠的 token。

Transformer-XL（Dai et al., 2019；“XL”意为“extra long”）通过两个主要修改解决了上下文分割问题：

在片段之间复用隐藏状态。 采用一种适合复用状态的新型位置编码。

隐藏状态复用

通过持续使用前一片段的隐藏状态，模型引入了片段之间的循环连接。

我们将模型中第 n 层、第 (\tau + 1) 个片段的隐藏状态记为 \mathbf{h}_{\tau+1}^{(n)} \in \mathbb{R}^{L \times d}。除了同一片段最后一层的隐藏状态 \mathbf{h}_{\tau+1}^{(n-1)} 之外，它还依赖于前一片段同一层的隐藏状态 \mathbf{h}_{\tau}^{(n)}。通过引入先前隐藏状态的信息，模型将注意力跨度大幅向过去延伸，跨越多个片段。

\begin{aligned} \color{red}{\widetilde{\mathbf{h}}_{\tau+1}^{(n-1)}} &= [\text{stop-gradient}(\mathbf{h}_{\tau}^{(n-1)}) \circ \mathbf{h}_{\tau+1}^{(n-1)}] \\ \mathbf{Q}_{\tau+1}^{(n)} &= \mathbf{h}_{\tau+1}^{(n-1)}\mathbf{W}^q \\ \mathbf{K}_{\tau+1}^{(n)} &= \color{red}{\widetilde{\mathbf{h}}_{\tau+1}^{(n-1)}} \mathbf{W}^k \\ \mathbf{V}_{\tau+1}^{(n)} &= \color{red}{\widetilde{\mathbf{h}}_{\tau+1}^{(n-1)}} \mathbf{W}^v \\ \mathbf{h}_{\tau+1}^{(n)} &= \text{transformer-layer}(\mathbf{Q}_{\tau+1}^{(n)}, \mathbf{K}_{\tau+1}^{(n)}, \mathbf{V}_{\tau+1}^{(n)}) \end{aligned}

注意，键和值都依赖于扩展后的隐藏状态，而查询只使用当前步骤的隐藏状态。拼接操作 [. \circ .] 是沿着序列长度维度进行的。

相对位置编码

为了适应这种新型注意力跨度，Transformer-XL 提出了一种新的位置编码。如果沿用原始 Transformer 的方法对绝对位置进行编码，前一片段和当前片段将被赋予相同的编码，这并非我们所希望的。

为了让位置信息能够在片段之间连贯地流动，Transformer-XL 转而对相对位置进行编码，因为只要知道位置偏移量就足以做出良好预测，即键向量 \mathbf{k}_{\tau, j} 与其查询 \mathbf{q}_{\tau, i} 之间的 i-j。

如果省略 softmax 中的标量 1/\sqrt{d_k} 和归一化项，但包含位置编码，我们可以把位置 i 的查询与位置 j 的键之间的注意力得分写成：

\begin{aligned} a_{ij} &= \mathbf{q}_i {\mathbf{k}_j}^\top = (\mathbf{x}_i + \mathbf{p}_i)\mathbf{W}^q ((\mathbf{x}_j + \mathbf{p}_j)\mathbf{W}^k)^\top \\ &= \mathbf{x}_i\mathbf{W}^q {\mathbf{W}^k}^\top\mathbf{x}_j^\top + \mathbf{x}_i\mathbf{W}^q {\mathbf{W}^k}^\top\mathbf{p}_j^\top + \mathbf{p}_i\mathbf{W}^q {\mathbf{W}^k}^\top\mathbf{x}_j^\top + \mathbf{p}_i\mathbf{W}^q {\mathbf{W}^k}^\top\mathbf{p}_j^\top \end{aligned}

Transformer-XL 将上述四个项重新参数化为如下形式：

a_{ij}^\text{rel} = \underbrace{ \mathbf{x}_i\mathbf{W}^q \color{blue}{ {\mathbf{W}_E^k}^\top } \mathbf{x}_j^\top }_\text{content-based addressing} + \underbrace{ \mathbf{x}_i\mathbf{W}^q \color{blue}{ {\mathbf{W}_R^k}^\top } \color{green}{\mathbf{r}_{i-j}^\top} }_\text{content-dependent positional bias} + \underbrace{ \color{red}{\mathbf{u}} \color{blue}{ {\mathbf{W}_E^k}^\top } \mathbf{x}_j^\top }_\text{global content bias} + \underbrace{ \color{red}{\mathbf{v}} \color{blue}{ {\mathbf{W}_R^k}^\top } \color{green}{\mathbf{r}_{i-j}^\top} }_\text{global positional bias}
用相对位置编码 \mathbf{r}_{i-j} \in \mathbf{R}^{d} 替换 \mathbf{p}_j； 用两个可训练参数 \mathbf{u}（用于内容）和 \mathbf{v}（用于位置）分别替换两个项中的 \mathbf{p}_i\mathbf{W}^q； 将 \mathbf{W}^k 分割成两个矩阵，\mathbf{W}^k_E 用于内容信息，\mathbf{W}^k_R 用于位置信息。

自适应注意力跨度#

Transformer 的一个关键优势是能够捕捉长期依赖关系。根据上下文不同，模型有时可能希望关注更远的位置；或者不同的注意力头可能具有不同的注意力模式。如果注意力跨度能够灵活地调整其长度，并且仅在需要时才关注更远的位置，那么这将有助于同时降低计算和内存开销，从而支持更大的最大上下文长度。

这就是自适应注意力跨度（Adaptive Attention Span）的动机。Sukhbaatar, et al., (2019) 提出了一种自注意力机制，旨在寻找最优的注意力跨度。他们假设在相同的上下文窗口内，不同的注意力头可能会分配不同的注意力分数（见图 7），因此最优跨度应该按注意力头单独训练。

给定第 i 个 token，我们需要计算该 token 与其他位于位置 j \in S_i 的键之间的注意力权重，其中 S_i 定义了第 i 个 token 的上下文窗口。

\begin{aligned} e_{ij} &= \mathbf{q}_i {\mathbf{k}_j}^\top \\ a_{ij} &= \text{softmax}(e_{ij}) = \frac{\exp(e_{ij})}{\sum_{r=i-s}^{i-1} \exp(e_{ir})} \\ \mathbf{y}_i &= \sum_{r=i-s}^{i-1}a_{ir}\mathbf{v}_r = \sum_{r=i-s}^{i-1}a_{ir}\mathbf{x}_r\mathbf{W}^v \end{aligned}

引入了一个软掩蔽函数 m_z 来控制可调整的有效注意力跨度，它将查询与键之间的距离映射到 [0, 1] 区间。m_z 由 z \in [0, s] 参数化，z 是需要学习的：

m_z(x) = \text{clamp}(\frac{1}{R}(R+z-x), 0, 1)

其中 R 是一个超参数，用于控制 m_z 的软度。

软掩蔽函数被应用到注意力权重的 softmax 元素上：

a_{ij} = \frac{m_z(i-j)\exp(s_{ij})}{\sum_{r=i-s}^{i-1}m_z(i-r) \exp(s_{ir})}

在上述方程中，z 是可微分的，因此可以与模型的其他部分联合训练。参数 z^{(i)}, i=1, \dots, h 按注意力头分别学习。此外，损失函数对 \sum_{i=1}^h z^{(i)} 施加了额外的 L1 正则化。

结合自适应计算时间，该方法可以进一步增强，使注意力跨度长度具有灵活性，能够根据当前输入动态调整。注意力头在时刻 t 的跨度参数 z_t 是一个 sigmoid 函数 z_t = S \sigma(\mathbf{v} \cdot \mathbf{x}_t +b)，其中向量 \mathbf{v} 和偏置标量 b 与其他参数一起联合学习。

在使用自适应注意力跨度的 Transformer 实验中，Sukhbaatar, et al. (2019) 发现一个普遍趋势：较低层不需要非常长的注意力跨度，而较高层的少数注意力头可能会使用特别长的跨度。自适应注意力跨度还能大幅减少 FLOPS 数量，尤其是在具有多层注意力和大上下文长度的大型模型中。

局部注意力跨度（Image Transformer）#

Transformer 最初也是最流行的应用场景是语言建模。文本序列是一维的，具有明确的时间顺序，因此注意力跨度会随着上下文大小的增加而线性增长。

然而，如果我们想在图像上使用 Transformer，如何定义上下文范围或顺序并不明确。Image Transformer（Parmer, et al 2018）在 Transformer 框架内采用了一种类似于序列建模的图像生成形式。此外，Image Transformer 将自注意力跨度限制在局部邻域内，从而使模型能够扩展到并行处理更多图像，并保持似然损失易于处理。

编码器-解码器架构在图像条件生成中依然保留：

编码器生成源图像的、基于上下文的、每个像素通道的表示； 解码器自回归地生成输出图像，在每个时间步生成每个像素的一个通道。

我们将当前待生成像素的表示记为查询 \mathbf{q}。其他将被用于计算 \mathbf{q} 的位置的表示作为键向量 \mathbf{k}_1, \mathbf{k}_2, \dots，它们共同构成记忆矩阵 \mathbf{M}。\mathbf{M} 的范围定义了像素查询 \mathbf{q} 的上下文窗口。

Image Transformer 引入了两种类型的局部 \mathbf{M}，如下图所示。

(1) 1D 局部注意力：输入图像按 光栅扫描 顺序展平，即从左到右、从上到下。然后将线性化后的图像分割成不重叠的查询块。上下文窗口由与 \mathbf{q} 处于同一查询块内的像素，以及在该查询块之前生成的一定数量的额外像素组成。

(2) 2D 局部注意力：图像被分割成多个不重叠的矩形查询块。查询像素可以关注同一记忆块中的所有其他像素。为了确保左上角的像素也能拥有有效的上下文窗口，记忆块会分别向上、向左和向右扩展固定数量。

减少时间与内存开销#

本节介绍几种针对 Transformer 的改进，以降低计算时间和内存消耗。

稀疏注意力矩阵分解（Sparse Transformers）#

原始 Transformer 的计算和内存开销随序列长度二次增长，因此很难应用于非常长的序列。

Sparse Transformer（Child et al., 2019）通过稀疏矩阵分解引入了因子分解自注意力，使得能够在序列长度高达 16,384 的情况下训练具有数百层的稠密注意力网络，而这在现代硬件上原本是不可行的。

给定一组注意力连接模式 \mathcal{S} = \{S_1, \dots, S_n\}，其中每个 S_i 记录了第 i 个查询向量所关注的键的位置集合。

\begin{aligned} \text{Attend}(\mathbf{X}, \mathcal{S}) &= \Big( a(\mathbf{x}_i, S_i) \Big)_{i \in \{1, \dots, L\}} \\ \text{ where } a(\mathbf{x}_i, S_i) &= \text{softmax}\Big(\frac{(\mathbf{x}_i \mathbf{W}^q)(\mathbf{x}_j \mathbf{W}^k)_{j \in S_i}^\top}{\sqrt{d_k}}\Big) (\mathbf{x}_j \mathbf{W}^v)_{j \in S_i} \end{aligned}

注意，虽然 S_i 的大小不固定，但 a(\mathbf{x}_i, S_i) 始终是大小为 d_v 的，因此 \text{Attend}(\mathbf{X}, \mathcal{S}) \in \mathbb{R}^{L \times d_v}。

在自回归模型中，一个注意力跨度被定义为 S_i = \{j: j \leq i\}，因为它允许每个 token 关注过去的所有位置。

在因子分解自注意力中，集合 S_i 被分解成一个依赖树，使得对于每一对 (i, j) 且 j \leq i，都存在一条路径将 i 连接回 j，并且 i 可以直接或间接地关注 j。

精确地说，集合 S_i 被划分为 p 个不重叠的子集，其中第 m 个子集记为 A^{(m)}_i \subset S_i, m = 1,\dots, p。因此，输出位置 i 与任意 j 之间的路径的最大长度为 p + 1。例如，如果 (j, a, b, c, \dots, i) 是 i 和 j 之间索引的路径，那么我们有 j \in A_a^{(1)}, a \in A_b^{(2)}, b \in A_c^{(3)}, \dots，以此类推。

稀疏因子分解注意力

Sparse Transformer 提出了两种因子分解注意力。结合图 10 以 2D 图像输入为例，更容易理解这些概念。

(1) 步长为 \ell \sim \sqrt{n} 的 stride 注意力。这对于图像数据效果很好，因为图像结构与步长对齐。在图像情况下，每个像素会关注光栅扫描顺序中之前的所有 \ell 个像素（自然覆盖整个图像宽度），然后这些像素再关注同一列中的其他像素（由另一个注意力连接子集定义）。

\begin{aligned} A_i^{(1)} &= \{ t, t+1, \dots, i\} \text{, where } t = \max(0, i - \ell) \\ A_i^{(2)} &= \{j: (i-j) \mod \ell = 0\} \end{aligned}

(2) 固定注意力。一小组 token 对先前位置进行汇总，并将该信息传播到所有未来位置。

\begin{aligned} A_i^{(1)} &= \{j: \lfloor \frac{j}{\ell} \rfloor = \lfloor \frac{i}{\ell} \rfloor \} \\ A_i^{(2)} &= \{j: j \mod \ell \in \{\ell-c, \dots, \ell-1\} \} \end{aligned}

其中 c 是一个超参数。如果 c=1，则会限制表示，导致许多位置依赖于少数几个位置。论文选择了 c\in \{ 8, 16, 32 \} 作为 \ell \in \{ 128, 256 \} 的值。

在 Transformer 中使用因子分解自注意力

在 Transformer 架构中有三种方式使用稀疏因子分解注意力模式：

每个残差块使用一种注意力类型，然后交替使用， \text{attention}(\mathbf{X}) = \text{Attend}(\mathbf{X}, A^{(n \mod p)}) \mathbf{W}^o，其中 n 是当前残差块的索引。 设置一个单一的注意力头，关注所有因子分解头所关注的位置， \text{attention}(\mathbf{X}) = \text{Attend}(\mathbf{X}, \cup_{m=1}^p A^{(m)}) \mathbf{W}^o 。 使用多头注意力机制，但与原始 Transformer 不同，每个头可能采用上述模式 1 或 2。=> 这种方式通常效果最好。

Sparse Transformer 还提出了一系列改动，以便能够训练多达数百层的 Transformer，包括梯度检查点、在反向传播时重新计算注意力层和前馈层、混合精度训练、高效的块稀疏实现等。更多细节请参阅 原论文。

局部敏感哈希（Reformer）#

Reformer 模型（Kitaev, et al. 2020）提出的改进旨在解决 Transformer 中的以下痛点：

具有 N 层的模型的内存是单层模型的 N 倍，因为我们需要为反向传播存储激活值。 中间的前馈层通常非常大。 长度为 L 的序列上的注意力矩阵通常在内存和时间上都需要 O(L^2) 的开销。

Reformer 提出了两个主要改动：

用局部敏感哈希（LSH）注意力替代点积注意力，将复杂度从 O(L^2) 降低到 O(L\log L)。 用可逆残差层替代标准残差块，这允许在训练期间只存储一次激活值，而不是 N 次（即与层数成正比）。

局部敏感哈希注意力

在注意力公式的 \mathbf{Q} \mathbf{K}^\top 部分，我们只对最大的元素感兴趣，因为只有大元素在 softmax 之后贡献显著。对于每个查询 \mathbf{q}_i \in \mathbf{Q}，我们寻找 \mathbf{K} 中最接近 \mathbf{q}_i 的行向量。为了在高维空间中快速找到最近邻，Reformer 将 局部敏感哈希（LSH） 融入其注意力机制。

如果一个哈希方案 x \mapsto h(x) 能够保留数据点之间的距离信息，使得相近的向量获得相似的哈希，而相距较远的向量获得差异很大的哈希，那么它就是局部敏感的。Reformer 采用了一种这样的哈希方案，给定一个固定的随机矩阵 \mathbf{R} \in \mathbb{R}^{d \times b/2}（其中 b 是一个超参数），哈希函数为 h(x) = \arg\max([xR; −xR])。

如果省略自注意力中的标量，并将分母汇总为一个归一化项 Z(.)，则普通的注意力输出如下所示：

\mathbf{o}_i = \sum_{j \in S_i} \exp(\mathbf{q}_i \cdot \mathbf{k}_j - Z(i, S_i)) \mathbf{v}_j \text{, where } S_i = \{j: j \leq i\}

</div>

在 LSH 注意力中，查询只能关注位于同一哈希桶中的位置 S_i = \{j: h(\mathbf{q}_i) = h(\mathbf{k}_j)\}。该过程如图 11 所示，具体步骤如下：

(a) 完整注意力的注意力矩阵通常是稀疏的。 (b) 使用 LSH，我们可以将键和查询按照它们的哈希桶进行排序对齐。 (c) 设置 \mathbf{Q} = \mathbf{K}（精确为 \mathbf{k}_j = \mathbf{q}_j / |\mathbf{q}_j|），使每个桶内键和查询的数量相等，便于批处理。有趣的是，这种“共享 QK”的配置不会影响 Transformer 的性能。 (d) 对批处理进行分块，将 m 个连续的查询分到一组。

可逆残差网络

Reformer 的另一项改进是使用可逆残差层（Gomez et al. 2017）。可逆残差网络的动机是设计一种架构，使得任意给定层的激活值可以仅使用模型参数从下一层的激活值中恢复。因此，我们可以在反向传播时重新计算激活值，而不是存储所有激活值，从而节省内存。

给定一层 x \mapsto y，普通残差层执行 y = x + F(x)，而可逆层将输入和输出都拆分成对 (x_1, x_2) \mapsto (y_1, y_2)，然后执行以下操作：

y_1 = x_1 + F(x_2),\; y_2 = x_2 + G(y_1)

反向操作则很简单：

x_2 = y_2 - G(y_1), \; x_1 = y_1 − F(x_2)

Reformer 通过在可逆网络块中组合注意力（F）和前馈层（G）将这一思想应用到 Transformer 中：

Y_1 = X_1 + \text{Attention}(X_2), \; Y_2 = X_2 + \text{FeedForward}(Y_1)

通过对前馈计算进行分块可以进一步减少内存：

Y_2 = [Y_2^{(1)}; \dots; Y_2^{(c)}] = [X_2^{(1)} + \text{FeedForward}(Y_1^{(1)}); \dots; X_2^{(c)} + \text{FeedForward}(Y_1^{(c)})]

得到的可逆 Transformer 不需要在每一层都存储激活值。

使其具有循环特性（Universal Transformer）#

Universal Transformer（Dehghani, et al. 2019）将 Transformer 中的自注意力与 RNN 中的循环机制相结合，旨在同时受益于 Transformer 的长期全局感受野和 RNN 学到的归纳偏置。

Universal Transformer 并非经过固定数量的层，而是使用自适应计算时间动态调整步数。如果固定步数，那么 Universal Transformer 等价于一个在各层之间共享参数的多层 Transformer。

从高层来看，Universal Transformer 可以看作是一个用于学习每个 token 隐藏状态表示的循环函数。该循环函数在所有 token 位置上并行演化，位置之间的信息通过自注意力进行共享。

给定长度为 L 的输入序列，Universal Transformer 在第 t 步迭代地更新表示 \mathbf{H}^t \in \mathbb{R}^{L \times d}，步数可调。在第 0 步，\mathbf{H}^0 被初始化为与输入嵌入矩阵相同。所有位置在多头自注意力机制中并行处理，然后通过一个循环转移函数。

\begin{aligned} \mathbf{A}^t &= \text{LayerNorm}(\mathbf{H}^{t-1} + \text{MultiHeadAttention}(\mathbf{H}^{t-1} + \mathbf{P}^t) \\ \mathbf{H}^t &= \text{LayerNorm}(\mathbf{A}^{t-1} + \text{Transition}(\mathbf{A}^t)) \end{aligned}

其中 \text{Transition}(.) 要么是 可分离卷积，要么是一个全连接神经网络，由两个逐位置（即分别应用于 \mathbf{A}^t 的每一行）的仿射变换 + 一个 ReLU 组成。

位置编码 \mathbf{P}^t 使用正弦位置信号，但增加了一个时间维度：

\text{PE}(i, t, \delta) = \begin{cases} \sin(\frac{i}{10000^{2\delta'/d}}) \oplus \sin(\frac{t}{10000^{2\delta'/d}}) & \text{if } \delta = 2\delta'\\ \cos(\frac{i}{10000^{2\delta'/d}}) \oplus \cos(\frac{t}{10000^{2\delta'/d}}) & \text{if } \delta = 2\delta' + 1\\ \end{cases}

在 Universal Transformer 的自适应版本中，循环步数 T 由 ACT 动态决定。每个位置都配备了一个动态的 ACT 停止机制。一旦某个 token 的循环块停止，它就不再接受更多的循环更新，而只是将当前值复制到下一步，直到所有块都停止或达到模型的最大步数限制。

用于强化学习的稳定机制（GTrXL）#

自注意力机制避免了将整个过去压缩到一个固定大小的隐藏状态中，并且不像 RNN 那样容易遭受梯度消失或爆炸问题。强化学习任务肯定能从这些特性中受益。然而，即使在监督学习中，训练 Transformer 也相当困难，更不用说在强化学习场景中了。毕竟，单独稳定并训练一个 LSTM 智能体就已经很有挑战性了。

Gated Transformer-XL（GTrXL；Parisotto, et al. 2019）是尝试将 Transformer 用于强化学习的一种努力。GTrXL 在 Transformer-XL 的基础上通过两个改动成功稳定了训练：

层归一化只应用于残差模块的输入流，而不应用于捷径流。这种重排序的一个关键好处是允许原始输入从第一层流到最后一层。 残差连接被替换为 GRU 风格（Gated Recurrent Unit；Chung et al., 2014）的门控机制。
\begin{aligned} r &= \sigma(W_r^{(l)} y + U_r^{(l)} x) \\ z &= \sigma(W_z^{(l)} y + U_z^{(l)} x - b_g^{(l)}) \\ \hat{h} &= \tanh(W_g^{(l)} y + U_g^{(l)} (r \odot x)) \\ g^{(l)}(x, y) &= (1-z)\odot x + z\odot \hat{h} \end{aligned}

门控函数的参数被显式初始化为接近恒等映射——这就是为什么存在 b_g 项。一个 b_g > 0 可以极大地加快学习速度。
