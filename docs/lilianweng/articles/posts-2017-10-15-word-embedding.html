词嵌入学习

人类的词汇以自由文本形式存在。为了让机器学习模型理解和处理自然语言，我们需要将自由文本的词转换为数值形式。最简单的转换方法之一是采用 one-hot 编码，其中每个不同的词对应结果向量的一个维度，用二进制值 1 或 0 来表示该词是否出现。

然而，当处理整个词汇表时，one-hot 编码在计算上非常不切实际，因为它需要数十万维的表示。词嵌入则用维度更低且更密集的（非二进制）数值向量来表示词和短语。一个好的词嵌入应能近似词之间的相似性（例如“cat”和“kitten”是相似词，因此在降维后的向量空间中应靠得很近），或者揭示隐藏的语义关系（例如“cat”与“kitten”的关系类似于“dog”与“puppy”）。上下文信息对于学习词义和关系非常有用，因为相似词往往出现在相似的上下文中。

学习词嵌入主要有两种方法，两者都依赖于上下文知识。

  • 基于计数：第一种是无监督方法，基于全局词共现矩阵的分解。原始共现计数效果不佳，因此我们需要在上面做一些巧妙处理。
  • 基于上下文：第二种是监督方法。给定局部上下文，我们希望设计一个模型来预测目标词，同时让该模型学习到高效的词嵌入表示。

基于计数的向量空间模型

基于计数的向量空间模型 heavily 依赖词频和共现矩阵，假设出现在相同上下文中的词具有相似或相关的语义含义。这些模型将基于计数的统计量（如邻近词之间的共现）映射到小而密集的词向量。PCA、主题模型和神经概率语言模型都属于这一类。

与基于计数的方法不同，基于上下文的方法构建预测模型，直接以给定邻近词预测目标词为目标。密集词向量是模型参数的一部分。每个词的最佳向量表示是在模型训练过程中学习得到的。

基于上下文：Skip-Gram 模型

假设你有一个固定大小的滑动窗口沿着句子移动：中间的词是“目标”，窗口内左右两侧的词是上下文词。Skip-Gram 模型（Mikolov et al., 2013）被训练用于预测给定目标词时，某个词成为其上下文词的概率。

以下示例展示了由一个 5 词窗口沿着句子滑动生成的多对目标词和上下文词作为训练样本。

“The man who passes the sentence should swing the sword.” – Ned Stark
Sliding window (size = 5) Target word Context
[The man who] the man, who
[The man who passes] man the, who, passes
[The man who passes the] who the, man, passes, the
[man who passes the sentence] passes man, who, the, sentence
… … …
[sentence should swing the sword] swing sentence, should, the, sword
[should swing the sword] the should, swing, sword
[swing the sword] sword swing, the
{:.info}

每个上下文-目标对都被视为数据中的一个新观测。例如，上例中的目标词“swing”产生了四个训练样本：(“swing”, “sentence”)、(“swing”, “should”)、(“swing”, “the”) 和 (“swing”, “sword”)。

给定词汇表大小 V，我们要学习大小为 N 的词嵌入向量。该模型每次用一个目标词（输入）来预测一个上下文词（输出）。

根据图 1，

  • 输入词 w_i 和输出词 w_j 都被 one-hot 编码为大小为 V 的二进制向量 \mathbf{x} 和 \mathbf{y}。
  • 首先，二进制向量 \mathbf{x} 与大小为 V \times N 的词嵌入矩阵 W 相乘，得到输入词的嵌入向量 w_i：即矩阵 W 的第 i 行。
  • 这个新得到的维度为 N 的嵌入向量构成隐藏层。
  • 隐藏层与大小为 N \times V 的词上下文矩阵 W’ 相乘，产生输出 one-hot 编码向量 \mathbf{y}。
  • 输出上下文矩阵 W’ 以上下文方式编码词的含义，与嵌入矩阵 W 不同。注意：尽管名称如此，W’ 与 W 是独立的，既不是转置也不是逆矩阵或其他。

基于上下文：连续词袋模型（CBOW）

连续词袋模型（CBOW）是另一种用于学习词向量的相似模型。它根据源上下文词（例如“sentence should the sword”）来预测目标词（即“swing”）。

由于存在多个上下文词，我们将它们对应的词向量（通过输入向量与矩阵 W 相乘得到）进行平均。因为平均操作会平滑掉大量分布信息，有些人认为 CBOW 模型更适合小数据集。

损失函数

Skip-Gram 模型和 CBOW 模型都应该被训练以最小化设计良好的损失/目标函数。我们可以使用几种损失函数来训练这些语言模型。在下面的讨论中，我们以 Skip-Gram 模型为例来说明损失是如何计算的。

完整 Softmax

Skip-Gram 模型通过矩阵 W 定义每个词的嵌入向量，通过输出矩阵 W’ 定义上下文向量。给定输入词 w_I，我们将其在 W 中对应的行标记为向量 v_{w_I}（嵌入向量），将其在 W’ 中对应的列标记为 v’_{w_I}（上下文向量）。最终输出层应用 softmax 来计算给定 w_I 时预测输出词 w_O 的概率，因此：

p(w_O \vert w_I) = \frac{\exp({v'_{w_O}}^{\top} v_{w_I})}{\sum_{i=1}^V \exp({v'_{w_i}}^{\top} v_{w_I})}

如上所示是准确的，但当 V 极大时，对每个样本遍历所有词来计算分母在计算上是不切实际的。对更高效的条件概率估计的需求催生了分层 softmax 等新方法。

分层 Softmax

Morin 和 Bengio（2005）提出了分层 softmax，利用二叉树结构加快求和计算。分层 softmax 将语言模型的输出 softmax 层编码为树状层次结构，每个叶节点是一个词，每个内部节点代表其子节点的相对概率。

每个词 w_i 都有一条从根节点到其对应叶节点的唯一路径。选中该词的概率等价于沿着这条路径从根节点向下穿越树枝的概率。由于我们知道内部节点 n 的嵌入向量 v_n，得到该词的概率可以通过在每个内部节点处选择左转或右转的概率乘积来计算。

根据图 3，一个节点的概率为（\sigma 是 sigmoid 函数）：

\begin{align} p(\text{turn right} \to \dots w_I \vert n) &= \sigma({v'_n}^{\top} v_{w_I})\\ p(\text{turn left } \to \dots w_I \vert n) &= 1 - p(\text{turn right} \vert n) = \sigma(-{v'_n}^{\top} v_{w_I}) \end{align}

给定输入词 w_I 得到上下文词 w_O 的最终概率是：

p(w_O \vert w_I) = \prod_{k=1}^{L(w_O)} \sigma(\mathbb{I}_{\text{turn}}(n(w_O, k), n(w_O, k+1)) \cdot {v'_{n(w_O, k)}}^{\top} v_{w_I})

其中 L(w_O) 是通向词 w_O 的路径深度，\mathbb{I}_{\text{turn}} 是一个特殊的指示函数，若 n(w_O, k+1) 是 n(w_O, k) 的左子节点则返回 1，否则返回 -1。内部节点的嵌入是在模型训练过程中学习的。树结构在训练时将分母估计的复杂度从 O(V)（词汇量大小）大幅降低到 O(log V)（树的深度）。然而，在预测时，我们仍然需要计算每个词的概率并挑选最好的，因为我们事先不知道要到达哪个叶节点。

一个好的树结构对模型性能至关重要。几个实用的原则是：像 Huffman 树那样按频率对词进行分组以实现简单加速；将相似词分组到相同或相邻的分支中（例如使用预定义的词聚类、WordNet）。

交叉熵

另一种方法完全避开了 softmax 框架。相反，损失函数衡量预测概率 p 与真实二进制标签 \mathbf{y} 之间的交叉熵。

首先回顾两个分布 p 和 q 之间的交叉熵定义为 H(p, q) = -\sum_x p(x) \log q(x) 。在我们的例子中，只有当 w_i 是输出词时真实标签 y_i 才为 1，否则为 0。具有参数配置 \theta 的模型的损失函数 \mathcal{L}_\theta 旨在最小化预测与真实值之间的交叉熵，因为较低的交叉熵表示两个分布之间的高度相似性。y_j

\mathcal{L}_\theta = - \sum_{i=1}^V y_i \log p(w_i | w_I) = - \log p(w_O \vert w_I)

回想一下，

p(w_O \vert w_I) = \frac{\exp({v'_{w_O}}^{\top} v_{w_I})}{\sum_{i=1}^V \exp({v'_{w_i}}^{\top} v_{w_I})}

因此，

\mathcal{L}_{\theta} = - \log \frac{\exp({v'_{w_O}}^{\top}{v_{w_I}})}{\sum_{i=1}^V \exp({v'_{w_i}}^{\top}{v_{w_I} })} = - {v'_{w_O}}^{\top}{v_{w_I} } + \log \sum_{i=1}^V \exp({v'_{w_i} }^{\top}{v_{w_I}})

为了使用带 SGD 的反向传播开始训练模型，我们需要计算损失函数的梯度。为了简化，设 z_{IO} = {v’_{w_O}}^{\top}{v_{w_I}}。

\begin{align} \nabla_\theta \mathcal{L}_{\theta} &= \nabla_\theta\big( - z_{IO} + \log \sum_{i=1}^V e^{z_{Ii}} \big) \\ &= - \nabla_\theta z_{IO} + \nabla_\theta \big( \log \sum_{i=1}^V e^{z_{Ii}} \big) \\ &= - \nabla_\theta z_{IO} + \frac{1}{\sum_{i=1}^V e^{z_{Ii}}} \sum_{i=1}^V e^{z_{Ii}} \nabla_\theta z_{Ii} \\ &= - \nabla_\theta z_{IO} + \sum_{i=1}^V \frac{e^{z_{Ii}}}{\sum_{i=1}^V e^{z_{Ii}}} \nabla_\theta z_{Ii} \\ &= - \nabla_\theta z_{IO} + \sum_{i=1}^V p(w_i \vert w_I) \nabla_\theta z_{Ii} \\ &= - \nabla_\theta z_{IO} + \mathbb{E}_{w_i \sim Q(\tilde{w})} \nabla_\theta z_{Ii} \end{align}

其中 Q(\tilde{w}) 是噪声样本的分布。

根据上面的公式，正确的输出词通过第一项获得正向强化（\nabla_\theta z_{IO} 越大损失越好），而其他词则通过第二项产生负面影响。

如何用一组噪声词样本而不是遍历整个词汇表来估计 \mathbb{E}_{w_i \sim Q(\tilde{w})} \nabla_\theta {v’_{w_i}}^{\top}{v_{w_I}}，是使用基于交叉熵的采样方法的关键。

噪声对比估计（NCE）

噪声对比估计（NCE）指标旨在使用 logistic 回归分类器来区分目标词和噪声样本（Gutmann and Hyvärinen, 2010）。

给定输入词 w_I，正确的输出词记为 w。同时，我们从噪声样本分布 Q 中采样 N 个其他词，记为 \tilde{w}_1, \tilde{w}_2, \dots, \tilde{w}_N \sim Q。将二分类器的决策记为 d，$d$ 只能取二进制值。

\mathcal{L}_\theta = - [ \log p(d=1 \vert w, w_I) + \sum_{i=1, \tilde{w}_i \sim Q}^N \log p(d=0|\tilde{w}_i, w_I) ]

当 N 足够大时，根据 大数定律，

\mathcal{L}_\theta = - [ \log p(d=1 \vert w, w_I) + N\mathbb{E}_{\tilde{w}_i \sim Q} \log p(d=0|\tilde{w}_i, w_I)]

要计算概率 p(d=1 \vert w, w_I)，我们可以从联合概率 p(d, w \vert w_I) 开始。在 w, \tilde{w}_1, \tilde{w}_2, \dots, \tilde{w}_N 中，我们有 1/(N+1) 的概率选中真实词 w，它是从条件概率 p(w \vert w_I) 中采样的；同时，我们有 N/(N+1) 的概率选中噪声词，每个都来自 q(\tilde{w}) \sim Q。因此，

p(d, w | w_I) = \begin{cases} \frac{1}{N+1} p(w \vert w_I) & \text{if } d=1 \\ \frac{N}{N+1} q(\tilde{w}) & \text{if } d=0 \end{cases}

然后我们可以得出 p(d=1 \vert w, w_I) 和 p(d=0 \vert w, w_I)：

\begin{align} p(d=1 \vert w, w_I) &= \frac{p(d=1, w \vert w_I)}{p(d=1, w \vert w_I) + p(d=0, w \vert w_I)} &= \frac{p(w \vert w_I)}{p(w \vert w_I) + Nq(\tilde{w})} \end{align}
\begin{align} p(d=0 \vert w, w_I) &= \frac{p(d=0, w \vert w_I)}{p(d=1, w \vert w_I) + p(d=0, w \vert w_I)} &= \frac{Nq(\tilde{w})}{p(w \vert w_I) + Nq(\tilde{w})} \end{align}

最终 NCE 二分类器的损失函数变为：

\begin{align} \mathcal{L}_\theta & = - [ \log p(d=1 \vert w, w_I) + \sum_{\substack{i=1 \\ \tilde{w}_i \sim Q}}^N \log p(d=0|\tilde{w}_i, w_I)] \\ & = - [ \log \frac{p(w \vert w_I)}{p(w \vert w_I) + Nq(\tilde{w})} + \sum_{\substack{i=1 \\ \tilde{w}_i \sim Q}}^N \log \frac{Nq(\tilde{w}_i)}{p(w \vert w_I) + Nq(\tilde{w}_i)}] \end{align}

然而，p(w \vert w_I) 仍然涉及在分母中对整个词汇表求和。我们将分母标记为输入词的配分函数 Z(w_I)。一个常见假设是 Z(w) \approx 1，因为我们期望 softmax 输出层被归一化（Minh and Teh, 2012）。这样损失函数就简化为：

\mathcal{L}_\theta = - [ \log \frac{\exp({v'_w}^{\top}{v_{w_I}})}{\exp({v'_w}^{\top}{v_{w_I}}) + Nq(\tilde{w})} + \sum_{\substack{i=1 \\ \tilde{w}_i \sim Q}}^N \log \frac{Nq(\tilde{w}_i)}{\exp({v'_w}^{\top}{v_{w_I}}) + Nq(\tilde{w}_i)}]

噪声分布 Q 是一个可调参数，我们希望以这样的方式设计它：

  • intuitively it should be very similar to the real data distribution; and
  • it should be easy to sample from.

例如，tensorflow 中 NCE 损失的采样实现（log_uniform_candidate_sampler）假设这类噪声样本服从对数均匀分布，也称为 Zipf 定律。一个词在对数下的概率预期与其按频率降序排列的排名成反比，高频词被赋予较低排名。在这种情况下，q(\tilde{w}) = \frac{1}{ \log V}(\log (r_{\tilde{w}} + 1) - \log r_{\tilde{w}})，其中 r_{\tilde{w}} \in [1, V] 是按频率降序排列的词的排名。

负采样（NEG）

Mikolov 等人（2013）提出的负采样（NEG）是 NCE 损失的一种简化变体。它特别因训练 Google 的 word2vec 项目而闻名。与试图近似最大化 softmax 输出对数概率的 NCE 损失不同，负采样做了进一步简化，因为它专注于学习高质量词嵌入，而不是对自然语言中的词分布建模。

NEG 使用 sigmoid 函数近似二分类器的输出如下：

\begin{align} p(d=1 \vert w_, w_I) &= \sigma({v'_{w}}^\top v_{w_I}) \\ p(d=0 \vert w, w_I) &= 1 - \sigma({v'_{w}}^\top v_{w_I}) = \sigma(-{v'_{w}}^\top v_{w_I}) \end{align}

最终的 NCE 损失函数如下：

\mathcal{L}_\theta = - [ \log \sigma({v'_{w}}^\top v_{w_I}) + \sum_{\substack{i=1 \\ \tilde{w}_i \sim Q}}^N \log \sigma(-{v'_{\tilde{w}_i}}^\top v_{w_I})]

学习词嵌入的其他技巧

Mikolov 等人（2013）提出了几项有帮助的实践，可以带来良好的词嵌入学习效果。

  • 柔性滑动窗口。在配对滑动窗口内的词时，我们可以为距离更远的词赋予更小的权重。一个启发式方法是——给定定义的最大窗口大小参数 s_{\text{max}}，对每个训练样本，实际窗口大小在 1 到 s_{\text{max}} 之间随机采样。因此，每个上下文词被观察到的概率为 1/（它与目标词的距离），而相邻词总是会被观察到。
  • 对高频词进行子采样。极高频的词可能过于通用而无法有效区分上下文（例如停用词）。另一方面，稀有词更可能携带独特信息。为了平衡高频词和稀有词，Mikolov 等人提出在采样时以概率 1-\sqrt{t/f(w)} 丢弃词 w。这里 f(w) 是词频，t 是一个可调节的阈值。
  • 先学习短语。短语通常作为一个概念单元存在，而不是单个词的简单组合。例如，即使我们知道“new”和“york”的含义，也无法真正判断“New York”是一个城市名。先学习这类短语并将其视为词单元，再训练词嵌入模型可以提升结果质量。一个简单的数据驱动方法基于一元和二元计数：s_{\text{phrase}} = \frac{C(w_i w_j) - \delta}{ C(w_i)C(w_j)}，其中 C(.) 是单个一元词 w_i 或二元词组 w_i w_j 的简单计数，\delta 是一个折扣阈值，用于防止过于稀少的词和短语。更高的分数表示成为短语的可能性越大。要形成超过两个词的短语，我们可以用逐渐降低的分数阈值多次扫描词汇表。

GloVe：全局向量

Pennington 等人（2014）提出的全局向量（GloVe）模型旨在将基于计数的矩阵分解和基于上下文的 Skip-Gram 模型结合起来。

我们都知道计数和共现能够揭示词的含义。为了与词嵌入上下文中的 p(w_O \vert w_I) 区分开来，我们将共现概率定义为：

p_{\text{co}}(w_k \vert w_i) = \frac{C(w_i, w_k)}{C(w_i)}

C(w_i, w_k) 计算词 w_i 和 w_k 之间的共现。

假设我们有两个词，w_i=“ice”和 w_j=“steam”。第三个词 \tilde{w}_k=“solid”与“ice”相关但与“steam”无关，因此我们预期 p_{\text{co}}(\tilde{w}_k \vert w_i) 远大于 p_{\text{co}}(\tilde{w}_k \vert w_j)，从而 \frac{p_{\text{co}}(\tilde{w}_k \vert w_i)}{p_{\text{co}}(\tilde{w}_k \vert w_j)} 非常大。如果第三个词 \tilde{w}_k = “water”与两者都相关，或者 \tilde{w}_k = “fashion”与两者都无关，则 \frac{p_{\text{co}}(\tilde{w}_k \vert w_i)}{p_{\text{co}}(\tilde{w}_k \vert w_j)} 预期接近 1。

这里的直觉是，词义是由共现概率的比率而不是概率本身来捕捉的。全局向量将两个词相对于第三个上下文词的关系建模为：

F(w_i, w_j, \tilde{w}_k) = \frac{p_{\text{co}}(\tilde{w}_k \vert w_i)}{p_{\text{co}}(\tilde{w}_k \vert w_j)}

进一步，由于目标是学习有意义的词向量，F 被设计为两个词 w_i - w_j 之间线性差的函数：

F((w_i - w_j)^\top \tilde{w}_k) = \frac{p_{\text{co}}(\tilde{w}_k \vert w_i)}{p_{\text{co}}(\tilde{w}_k \vert w_j)}

考虑到 F 在目标词和上下文词之间是对称的，最终解决方案是将 F 建模为指数函数。请阅读原始论文（Pennington et al., 2014）以了解更多方程细节。

\begin{align} F({w_i}^\top \tilde{w}_k) &= \exp({w_i}^\top \tilde{w}_k) = p_{\text{co}}(\tilde{w}_k \vert w_i) \\ F((w_i - w_j)^\top \tilde{w}_k) &= \exp((w_i - w_j)^\top \tilde{w}_k) = \frac{\exp(w_i^\top \tilde{w}_k)}{\exp(w_j^\top \tilde{w}_k)} = \frac{p_{\text{co}}(\tilde{w}_k \vert w_i)}{p_{\text{co}}(\tilde{w}_k \vert w_j)} \end{align}

最终，

{w_i}^\top \tilde{w}_k = \log p_{\text{co}}(\tilde{w}_k \vert w_i) = \log \frac{C(w_i, \tilde{w}_k)}{C(w_i)} = \log C(w_i, \tilde{w}_k) - \log C(w_i)

由于第二项 -\log C(w_i) 与 k 无关，我们可以为 w_i 加入偏置项 b_i 来捕捉 -\log C(w_i)。为了保持对称形式，我们也为 \tilde{w}_k 加入偏置 \tilde{b}_k。

\log C(w_i, \tilde{w}_k) = {w_i}^\top \tilde{w}_k + b_i + \tilde{b}_k

GloVe 模型的损失函数旨在通过最小化平方误差之和来保留上述公式：

\mathcal{L}_\theta = \sum_{i=1, j=1}^V f(C(w_i,w_j)) ({w_i}^\top \tilde{w}_j + b_i + \tilde{b}_j - \log C(w_i, \tilde{w}_j))^2

权重模式 f(c) 是 w_i 和 w_j 共现的函数，是一个可调节的模型配置。它在 c \to 0 时应接近零；随着共现增加应非递减（更高的共现应有更大影响）；当 c 变得极大时应趋于饱和。论文提出了以下权重函数。

f(c) = \begin{cases} (\frac{c}{c_{\max}})^\alpha & \text{if } c < c_{\max} \text{, } c_{\max} \text{ is adjustable.} \\ 1 & \text{if } \text{otherwise} \end{cases}

import sys
from nltk.corpus import stopwords
from nltk.tokenize import sent_tokenize

STOP_WORDS = set(stopwords.words('english'))

def get_words(txt):
    return filter(
        lambda x: x not in STOP_WORDS, 
        re.findall(r'\b(\w+)\b', txt)
    )

def parse_sentence_words(input_file_names):
   """Returns a list of a list of words. Each sublist is a sentence."""
    sentence_words = []
    for file_name in input_file_names:
        for line in open(file_name):
            line = line.strip().lower()
            line = line.decode('unicode_escape').encode('ascii','ignore')
            sent_words = map(get_words, sent_tokenize(line))
            sent_words = filter(lambda sw: len(sw) > 1, sent_words)
            if len(sent_words) > 1:
                sentence_words += sent_words
    return sentence_words
