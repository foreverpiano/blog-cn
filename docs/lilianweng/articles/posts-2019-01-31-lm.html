作为词嵌入文章的后续，我们将讨论学习上下文相关词向量的模型，以及大规模无监督预训练语言模型的最新趋势，这些模型在各种语言任务上取得了惊人的 SOTA 结果。

2018 年我们在 NLP 领域看到了惊人的进展。像 OpenAI GPT 和 BERT 这样的大规模预训练语言模型，使用通用的模型架构，在各种语言任务上都取得了极佳的性能。其核心思想类似于 ImageNet 分类预训练对众多视觉任务的帮助（*）。比视觉分类预训练更好的是，这种在 NLP 中简单而强大的方法不需要带标签的数据进行预训练，让我们可以将训练规模不断扩大，直到硬件极限。

(*) He et al. (2018) 发现，在图像分割任务中预训练可能并非必需。

在我之前关于 NLP 的文章中，所介绍的嵌入并不是上下文相关的——它们仅基于词的共现关系学习，而没有考虑序列上下文。因此在“我正在吃一个 apple”和“我有一部 Apple 手机”这两句话中，两个“apple”指代完全不同的事物，却会共享相同的词嵌入向量。学习词嵌入

尽管如此，早期在解决问题时采用词嵌入的方式主要是将其作为现有特定任务模型的额外特征，因此性能提升是有限的。

在这篇文章中，我们将讨论各种方法如何让嵌入依赖于上下文，并让它们以更通用、更容易、更低成本的形式应用于下游任务。

CoVe#

CoVe（McCann et al. 2017），全称 Contextual Word Vectors，是一种由 机器翻译模型中的编码器学习得到的词嵌入。与之前介绍的传统词嵌入 不同，CoVe 词表示是整个输入句子的函数。注意力？注意力！学习词嵌入

NMT 回顾#

这里的神经机器翻译（NMT）模型由一个标准的两层双向 LSTM 编码器和一个带注意力机制的两层单向 LSTM 解码器组成。它在英德翻译任务上进行预训练。编码器学习并优化英文词的嵌入向量，以便将其翻译成德文。基于“编码器在把词转换成另一种语言前应该先捕捉高层语义和句法含义”的直觉，编码器的输出被用来为各种下游语言任务提供上下文相关的词嵌入。

源语言（英文）中长度为 n 的词序列：x = [x_1, \dots, x_n]。 目标语言（德文）中长度为 m 的词序列：y = [y_1, \dots, y_m]。 源语言词的 学习词嵌入 向量：\text{GloVe}(x)。 随机初始化的目标语言词嵌入向量：z = [z_1, \dots, z_m]。 双向 LSTM 编码器输出的隐藏状态序列：h = [h_1, \dots, h_n] = \text{biLSTM}(\text{GloVe}(x)) 和 h_t = [\overrightarrow{h}_t; \overleftarrow{h}_t]，其中前向 LSTM 计算 \overrightarrow{h}_t = \text{LSTM}(x_t, \overrightarrow{h}_{t-1})，后向计算得到 \overleftarrow{h}_t = \text{LSTM}(x_t, \overleftarrow{h}_{t-1})。 带注意力机制的解码器输出词上的概率分布：p(y_t \mid H, y_1, \dots, y_{t-1})，其中 H 是沿时间维度堆叠的隐藏状态 \{h\}：
\begin{aligned} \text{decoder hidden state: } s_t &= \text{LSTM}([z_{t-1}; \tilde{h}_{t-1}], s_{t-1}) \\ \text{attention weights: } \alpha_t &= \text{softmax}(H(W_1 s_t + b_1)) \\ \text{context-adjusted hidden state: } \tilde{h}_t &= \tanh(W_2[H^\top\alpha_t;s_t] + b_2) \\ \text{decoder output: } p(y_t\mid H, y_1, \dots, y_{t-1}) &= \text{softmax}(W_\text{out} \tilde{h}_t + b_\text{out}) \end{aligned}

在下游任务中使用 CoVe#

NMT 编码器的隐藏状态被定义为其他语言任务的上下文向量：

\text{CoVe}(x) = \text{biLSTM}(\text{GloVe}(x))

论文提出在问答和分类任务中使用 GloVe 和 CoVe 的拼接向量。GloVe 从全局词共现比率中学习，因此没有句子上下文；而 CoVe 通过处理文本序列生成，能够捕捉上下文信息。

v = [\text{GloVe}(x); \text{CoVe}(x)]

对于给定的下游任务，我们首先生成输入词的 GloVe + CoVe 拼接向量，然后将它们作为额外特征输入到特定任务的模型中。

总结：CoVe 的局限性很明显：(1) 预训练受限于有监督翻译任务的可用数据集；(2) CoVe 对最终性能的贡献受特定任务模型架构的制约。

在接下来的章节中，我们会看到 ELMo 通过无监督预训练解决了问题 (1)，而 OpenAI GPT 和 BERT 则通过无监督预训练 + 使用生成式模型架构进一步同时解决了这两个问题。

ELMo#

ELMo，全称 Embeddings from Language Model（Peters, et al, 2018），通过以无监督方式预训练语言模型来学习上下文相关的词表示。

双向语言模型#

双向语言模型（biLM）是 ELMo 的基础。输入是一个由 n 个 token 组成的序列 (x_1, \dots, x_n)，语言模型需要根据历史信息预测下一个 token 的概率。

在前向传递中，历史包含目标 token 之前的词，

p(x_1, \dots, x_n) = \prod_{i=1}^n p(x_i \mid x_1, \dots, x_{i-1})

在后向传递中，历史包含目标 token 之后的词，

p(x_1, \dots, x_n) = \prod_{i=1}^n p(x_i \mid x_{i+1}, \dots, x_n)

两个方向的预测都由多层 LSTM 建模，对于第 \ell=1,\dots,L 层的输入 token x_i，其隐藏状态分别为 \overrightarrow{\mathbf{h}}_{i,\ell} 和 \overleftarrow{\mathbf{h}}_{i,\ell}。 最后一层的隐藏状态 \mathbf{h}_{i,L} = [\overrightarrow{\mathbf{h}}_{i,L}; \overleftarrow{\mathbf{h}}_{i,L}] 在经过 softmax 归一化后用于输出 token 概率。它们共享嵌入层和 softmax 层，分别由 \Theta_e 和 \Theta_s 参数化。

模型训练目标是最小化两个方向的负对数似然（即最大化真实词的对数似然）：

\begin{aligned} \mathcal{L} = - \sum_{i=1}^n \Big( \log p(x_i \mid x_1, \dots, x_{i-1}; \Theta_e, \overrightarrow{\Theta}_\text{LSTM}, \Theta_s) + \\ \log p(x_i \mid x_{i+1}, \dots, x_n; \Theta_e, \overleftarrow{\Theta}_\text{LSTM}, \Theta_s) \Big) \end{aligned}

ELMo 表示#

在 L 层 biLM 的基础上，ELMo 通过学习特定任务的线性组合，将所有层的隐藏状态堆叠起来。token x_i 的隐藏状态表示包含 2L+1 个向量：

R_i = \{ \mathbf{h}_{i,\ell} \mid \ell = 0, \dots, L \}

其中 \mathbf{h}_{0, \ell} 是嵌入层输出，\mathbf{h}_{i, \ell} = [\overrightarrow{\mathbf{h}}_{i,\ell}; \overleftarrow{\mathbf{h}}_{i,\ell}]。

线性组合中的权重 \mathbf{s}^\text{task} 是针对每个终端任务学习的，并通过 softmax 归一化。缩放因子 \gamma^\text{task} 用于校正 biLM 隐藏状态分布与任务特定表示分布之间的错位。

v_i = f(R_i; \Theta^\text{task}) = \gamma^\text{task} \sum_{\ell=0}^L s^\text{task}_i \mathbf{h}_{i,\ell}

为了评估不同层隐藏状态捕捉到的信息类型，ELMo 分别在语义密集型和句法密集型任务上使用 biLM 不同层的表示进行测试：

语义任务：词义消歧（WSD）任务强调给定上下文下的词义。biLM 顶层在此任务上表现优于第一层。 句法任务：词性标注（POS tagging）任务旨在推断一个词在句子中的语法角色。使用 biLM 第一层比使用顶层能获得更高的准确率。

对比研究表明，句法信息在较低层表达得更好，而语义信息则由较高层捕捉。由于不同层倾向于携带不同类型的信息，将它们叠加在一起是有帮助的。

在下游任务中使用 ELMo#

与 CoVe 能帮助不同下游任务的方式类似，ELMo 嵌入向量被加入到特定任务模型的输入或较低层中。此外，对于某些任务（例如 SNLI 和 SQuAD，但不包括 SRL），将其加入到输出层也有帮助。

ELMo 带来的提升在有监督数据集较小的任务上最为显著。有了 ELMo，我们还能用少得多的标注数据达到相近的性能。

总结：语言模型预训练是无监督的，理论上可以无限扩大规模，因为无标注文本语料非常丰富。然而，它仍然依赖于为每个任务定制的模型，因此提升只是增量的，而为每个任务寻找一个好的模型架构仍然不是一件容易的事。

Cross-View Training#

在 ELMo 中，无监督预训练和特定任务学习是在两个独立模型、两个独立训练阶段中进行的。Cross-View Training（简称 CVT；Clark et al., 2018）将两者合并为一个统一的半监督学习过程，通过有标签数据的监督学习和无标签数据的辅助任务的无监督学习共同改进双向 LSTM 编码器的表示。

模型架构#

模型由一个两层双向 LSTM 编码器和一个主预测模块组成。在训练过程中，模型交替接收有标签和无标签的数据批次。

在有标签样本上，所有模型参数通过标准的监督学习进行更新，损失是标准的交叉熵。 在无标签样本上，主预测模块仍能产生“软”目标，尽管我们无法确切知道它们的准确性。在几个辅助任务中，预测器只能看到并处理输入的受限视图，例如只使用编码器单方向的隐藏状态表示。辅助任务的输出期望与主预测目标（针对完整输入视图）匹配。通过这种方式，编码器被迫将完整上下文的知识提炼到部分表示中。在此阶段，只有双向 LSTM 编码器进行反向传播，而主预测模块保持固定。损失是最小化辅助预测与主预测之间的距离。

多任务学习#

当同时训练多个任务时，CVT 会为额外任务增加几个额外的主预测模型。它们共享同一个句子表示编码器。 在有监督训练中，一旦随机选择一个任务，就更新其对应预测器和表示编码器的参数。 使用无标签数据样本时，编码器通过最小化每个任务的辅助输出与主预测之间的差异，在所有任务上联合优化。

多任务学习鼓励表示具有更好的泛化性，同时产生一个很好的副产品：来自无标签数据的“全任务标注”样本。考虑到跨任务标签很有用但相当稀缺，这些数据标签非常宝贵。

在下游任务中使用 CVT#

理论上主预测模块可以采用任何形式，通用的或任务特定的设计均可。CVT 论文中展示的例子同时包含了这两种情况。

在序列标注任务（针对每个 token 的分类）如 NER 或 POS tagging 中，预测器模块包含两个全连接层和一个 softmax 层，用于在输出上产生类别标签的概率分布。 对于每个 token \mathbf{x}_i，我们取其在两层中的对应隐藏状态 \mathbf{h}_1^{(i)} 和 \mathbf{h}_2^{(i)}：

\begin{aligned} p_\theta(y_i \mid \mathbf{x}_i) &= \text{NN}(\mathbf{h}^{(i)}) \\ &= \text{NN}([\mathbf{h}_1^{(i)}; \mathbf{h}_2^{(i)}]) \\ &= \text{softmax} \big( \mathbf{W}\cdot\text{ReLU}(\mathbf{W'}\cdot[\mathbf{h}_1^{(i)}; \mathbf{h}_2^{(i)}]) + \mathbf{b} \big) \end{aligned}

辅助任务只接收第一层的前向或后向 LSTM 状态。因为它们只能观察到部分上下文（左边或右边），所以必须像语言模型一样学习，在给定上下文的情况下预测下一个 token。前向和后向辅助任务各只使用一个方向，而未来和过去任务则分别在前向和后向方向上再往前走一步。

\begin{aligned} p_\theta^\text{fwd}(y_i \mid \mathbf{x}_i) &= \text{NN}^\text{fwd}(\overrightarrow{\mathbf{h}}^{(i)}) \\ p_\theta^\text{bwd}(y_i \mid \mathbf{x}_i) &= \text{NN}^\text{bwd}(\overleftarrow{\mathbf{h}}^{(i)}) \\ p_\theta^\text{future}(y_i \mid \mathbf{x}_i) &= \text{NN}^\text{future}(\overrightarrow{\mathbf{h}}^{(i-1)}) \\ p_\theta^\text{past}(y_i \mid \mathbf{x}_i) &= \text{NN}^\text{past}(\overleftarrow{\mathbf{h}}^{(i+1)}) \end{aligned}

请注意，如果主预测模块有 dropout，那么在用有标签数据训练时 dropout 层正常工作，但在用无标签数据训练并为辅助任务生成“软”目标时则不应用 dropout。

在机器翻译任务中，主预测模块被替换为带注意力机制的标准单向 LSTM 解码器。有两个辅助任务：(1) 对注意力权重向量施加 dropout，随机将某些值置零；(2) 预测目标序列中的未来词。辅助任务要匹配的主预测是使用固定主解码器在输入序列上通过 集束搜索 生成的最佳预测目标序列。

ULMFiT#

使用生成式预训练语言模型 + 特定任务微调的想法最早在 ULMFiT（Howard &amp; Ruder, 2018）中被探索，其直接受 ImageNet 预训练在计算机视觉任务上取得成功的启发。其基础模型是 AWD-LSTM。

ULMFiT 通过以下三个步骤在下游语言分类任务上取得良好的迁移学习效果：

通用语言模型预训练：在 Wikipedia 文本上进行。 目标任务语言模型微调：ULMFiT 提出了两种训练技巧来稳定微调过程，见下文。
区分性微调（Discriminative fine-tuning）的动机是语言模型的不同层会捕捉不同类型的信息（见上文讨论）。ULMFiT 提出对每一层使用不同的学习率 \{\eta^1, \dots, \eta^\ell, \dots, \eta^L\}，其中 \eta 是第一层的基础学习率，\eta^\ell 是第 \ell 层的使用率，总共有 L 层。 斜三角学习率（Slanted triangular learning rates, STLR）是一种特殊的学习率调度策略：先线性增加学习率，再线性衰减。增加阶段较短，以便模型快速收敛到适合当前任务的参数空间，而衰减阶段较长，以获得更好的微调效果。
目标任务分类器微调：在预训练语言模型后添加两个标准的前馈层，并在最后进行 softmax 归一化来预测目标标签分布。
Concat pooling 从隐藏状态的历史中提取最大池化和平均池化结果，并将其与最终隐藏状态拼接起来。 渐进解冻（Gradual unfreezing）通过从最后一层开始逐步解冻模型层来避免灾难性遗忘。首先解冻最后一层并微调一个 epoch，然后解冻下一层，重复这个过程直到所有层都被微调。

GPT#

延续 ELMo 的类似思路，OpenAI GPT（全称 Generative Pre-training Transformer，Radford et al., 2018）通过在一个巨型自由文本语料集合上训练，将无监督语言模型扩展到了更大的规模。尽管有相似之处，GPT 与 ELMo 存在两个主要区别。

模型架构不同：ELMo 使用浅层拼接的独立训练的从左到右和从右到左的多层 LSTM，而 GPT 是一个多层 Transformer Decoder。 在下游任务中使用上下文嵌入的方式不同：ELMo 将嵌入作为额外特征输入到为特定任务定制的模型中，而 GPT 则是对所有终端任务微调同一个基础模型。

用 Transformer Decoder 作为语言模型#

与 原始 Transformer 架构相比，Transformer Decoder 模型舍弃了编码器部分，因此只有一个单独的输入句子，而不是两个独立的源序列和目标序列。

该模型在输入序列的嵌入上应用多个 Transformer 块。每个块包含一个带掩码的多头自注意力层和一个逐点前馈层。最终输出在经过 softmax 归一化后产生目标 token 的概率分布。

损失函数是负对数似然，与 ELMo 相同，但没有反向计算。假设大小为 k 的上下文窗口位于目标词之前，则损失函数如下：

\mathcal{L}_\text{LM} = -\sum_{i} \log p(x_i\mid x_{i-k}, \dots, x_{i-1})

字节对编码#

字节对编码（BPE）用于对输入序列进行编码。BPE 最初在 20 世纪 90 年代被提出作为一种数据压缩算法，后来被用于解决机器翻译中的开放词汇问题，因为翻译到新语言时很容易遇到稀有词和未知词。基于“稀有词和未知词通常可以分解为多个子词”的直觉，BPE 通过迭代且贪心地合并频繁出现的字符对来找到最佳的词分割方式。

有监督微调#

OpenAI GPT 提出的最实质性的升级是摆脱特定任务模型，直接使用预训练的语言模型！

以分类任务为例。假设在标注数据集中，每个输入有 n 个 token \mathbf{x} = (x_1, \dots, x_n)，以及一个标签 y。GPT 首先通过预训练的 Transformer Decoder 处理输入序列 \mathbf{x}，最后一个 token x_n 在最后一层的输出是 \mathbf{h}_L^{(n)}。然后只需要一个新的可训练权重矩阵 \mathbf{W}_y，就能预测类别标签的分布。
