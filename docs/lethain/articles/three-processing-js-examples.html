Processing.js 三个示例

2008-05-14 · 阅读原文

过去几天我一直在使用 Processing.js 的 JavaScript API 开发几个项目。这三个项目都主要围绕如何通过 HTML UI 控件（主要是文本框和按钮）来与图形进行交互和控制。所有代码都可以从演示页面直接获取，采用知识共享署名许可协议，但如果需要，我也可以改用更宽松的许可协议。

如果有任何问题，欢迎随时告诉我。

气泡（Bubbles）

这是一个非常简单的应用，只会绘制气泡。（注意：我不小心加了一个帧率限制，其实不应该有，因为它每次点击后只会渲染一次。）通过一系列文本框，用户可以自定义气泡的颜色范围、背景颜色、气泡数量以及画布尺寸。在非测试版浏览器中运行效果很好（在当前正式版的 Camino 中也能正常工作）。

超级空间（Superspace）

另一个简单应用，展示了按钮如何与 Processing.js 程序进行交互。画面中会有矩形在一个部分受限的区域内快乐地弹跳。在非测试版浏览器中运行正常（同样指当前正式版的 Camino）。

Processed 塔防

这是我目前用 Processing.js 做的最复杂的例子，目标是做一款塔防类型的游戏。目前上线的版本是我昨天写的，还有不少地方需要完善，但已经具备了一些有趣的功能。目前还不能真正“玩”，但可以随意摆弄。你可以建造炮塔、点击炮塔查看射程、手动生成敌人（目前还不会自动生成）、分数/金钱/生命值等实时更新、敌人会走向出口，到达后会扣除生命，以及发射导弹（点击“发射小型导弹”，然后把鼠标移入画布，鼠标周围会出现射程提示圈）等等。用户界面还算有趣，但肯定需要进一步打磨。

代码方面，我在最初三四个小时的快速开发后进行了重构，整体设计比较灵活。我之后可能需要专门写一篇博客来介绍其中一些有趣的实现细节。接下来的任务是让炮塔能够自主发射并造成伤害，以及实现敌人的自动生成。在此之后还有很多工作要做，比如给敌人的移动增加一些随机抖动、为各种行为添加简单动画（敌人死亡、发射导弹）、支持多种炮塔等等。

这个例子在 Camino 中可以运行，但速度很慢而且卡顿严重，基本整个界面都会卡成一团。不过在 FireFox 3 Beta 5 中运行非常流畅。

总之，这些示例欢迎大家学习、忽视、修改或者随意使用。祝玩得开心。
