Processing.js 三个示例

2008-05-14 · 阅读原文

过去几天，我一直在使用 Processing.js 的 JavaScript API 开发几个项目。这三个项目都主要通过 HTML UI 控件（主要是文本框和按钮）来与图形进行交互和控制。所有代码都可以直接从演示页面获取，采用知识共享署名许可协议，但如果需要，我也可以将其重新授权为更宽松的许可。

如果有任何问题，欢迎随时告诉我。

气泡（Bubbles）

这是一个非常简单的应用，只是用来绘制气泡。（注意：我不小心在里面加了帧率限制，其实不应该有，因为它实际上每次点击只渲染一次。）用户可以通过一系列文本框自定义气泡的颜色范围、背景颜色、气泡数量以及画布尺寸。在非测试版浏览器中运行效果很好（在当前正式版的 Camino 中也能正常工作）。

超级空间（Superspace）

另一个简单的应用，展示了按钮如何与 Processing.js 程序进行交互。画面中会显示一些矩形在一个半受限的区域内欢快地弹跳。在非测试版浏览器中运行良好（同样指当前正式版的 Camino）。

加工塔防（Processed Tower Defense）

这是我目前用 Processing.js 做的最复杂的一个示例，算是一款向塔防类游戏致敬的作品。现在线上版本是我昨天刚写的，虽然还有不少工作要做，但已经具备了一些有趣的功能。目前还不能真正“玩”它，但你可以随意摆弄。你可以建造炮塔、点击炮塔查看其射程、手动生成敌人（目前还不能自动生成）、分数/金钱/生命值等会实时更新、敌人会走向出口，到达后会扣除生命，以及可以发射导弹（点击“发射小型导弹”，然后把鼠标移到画布内，鼠标周围会出现射程半径提示），还有其他一些小功能。用户界面还算有趣，但肯定需要进一步打磨。

代码方面，我在最初三四个小时的快速开发后进行了重构，整体设计还是比较灵活的。我之后需要单独写一篇文章来分享其中一些有趣的实现细节。接下来要做的功能包括让炮塔自动开火并造成伤害，以及敌人自动生成。除此之外还有很多工作，比如给敌人的移动增加一些随机抖动、为各种事件添加简单动画（敌人死亡、发射导弹）、支持多种炮塔等等。

这个示例在 Camino 中可以运行，但速度很慢而且卡顿严重，基本上用户界面会变成一团糟。不过在 FireFox 3 B5 中运行非常流畅。

总之，这些示例希望大家可以从中学习、忽略、修改或随意使用。祝玩得开心。
