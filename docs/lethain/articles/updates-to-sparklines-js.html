Sparklines.js 更新说明

2008-06-30 · 阅读原文

今天花了些时间在 Sparklines.js 上，完成了几项不错的改进。

  1. There is now a public repository on github, where others can contribute.
  2. There is also a merged and minified library for download, sparklines.min.js.
  3. Charts are no longer constrained to start their y axis at an absolute value of zero. This idea wasn't obviously bad due to the example data I chose, but its viability became pretty limited as I played with different data sets.Instead, it is possible to start at zero, or to start at the minimum value. You can switch between the two easily. If you want to scale from min to max, you would do:
var opts = {'scale_from_zero':false};
var data = [1,2,3,4,5,6];
new Sparkline("canvas_id",data,opts);

图表不再强制要求 y 轴从绝对值 0 开始。此前由于示例数据的原因，这个限制看起来问题不大，但随着尝试不同数据集，其适用性变得十分有限。现在可以选择从 0 开始，或从数据最小值开始，且两者之间可以轻松切换。如果你想让图表从最小值缩放到最大值，可以这样写：

var opts = {'scale_from_zero':true};
var data = [1,2,3,4,5,6];
new Sparkline("canvas_id",data,opts);

目前默认仍为从 0 缩放到最大值，因为条形图从最小值到最大值缩放时，数据可读性会变得很差。不过我计划在不久的将来让折线 sparkline 默认采用从最小值到最大值的缩放方式（而条形 sparkline 将继续保持现有的从 0 到最大值的行为）。

此外，我还计划支持自定义设置缩放窗口的顶部和底部数值，这将使 sparkline 能更好地适配所展示的具体数据集。

关于 Sparklines.js 的博客更新可能不会太多，除非出现特别有意思的改进。如果你对这个项目感兴趣，请留意关注 GitHub 仓库。

更新 1

好的，这个行为现在已经修复，并且具备了足够的灵活性，可以满足我能想到的任何使用场景。默认情况下，折线 sparkline 从最小值缩放到最大值，条形 sparkline 从 0 缩放到最大值。不过，你也可以自行设置任意顶部和底部数值（如果需要，也可以让条形 sparkline 切换回从最小值到最大值的缩放方式）。

将折线 sparkline 从 0 缩放到最大值的效果如下：

var opts = {'scale_from':0};
var data = [1,2,3,4,5,6];
new Sparkline("canvas_id",data,opts);

将条形 sparkline 从最小值缩放到最大值的效果如下：

var opts = {'scale_from':undefined};
var data = [1,2,3,4,5,6];
new BarSparkline("canvas_id",data,opts);

将折线 sparkline 从 50 缩放到 150 也很简单：

var opts = {'scale_from':50,'scale_to':150};
var data = [1,2,3,4,5,6];
new Sparkline("canvas_id",data,opts);

具体功能在文档的“缩放数据”部分有更详细的说明。

更新 2

现在应该已经能在 Internet Explorer 中正常工作了，但我目前没有机器进行实际测试。它需要 excanvas.js 库，该库现已加入仓库（以及项目页面）。如果有人能在 IE 中验证其是否正常运行，我将不胜感激。
