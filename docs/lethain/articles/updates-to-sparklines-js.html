Sparklines.js 更新说明

2008-06-30 · 阅读原文

今天花了些时间在 Sparklines.js 上，取得了几项不错的进展。

现在已在 GitHub 上建立了公开仓库，欢迎其他人一起贡献。此外还提供了一个合并并压缩后的库文件供下载：sparklines.min.js。图表不再强制要求 y 轴从绝对零值开始。 这个限制在之前选用的示例数据中看起来问题不大，但随着尝试不同数据集，其局限性就变得非常明显。现在可以选择从零开始，也可以从最小值开始，并且可以轻松在这两种模式之间切换。如果你想让图表从最小值缩放到最大值，可以这样写：

另一方面，如果你希望从零缩放到最大值，则可以这样写：

目前默认仍然是从零缩放到最大值，因为条形图从最小值到最大值缩放时，数据可读性会变得非常糟糕。不过我打算在不久的将来让折线 Sparkline 默认采用从最小值到最大值的缩放方式（而条形 Sparkline 将继续保持当前的从零到最大值行为）。

此外，我还计划支持自定义缩放窗口的顶部和底部数值，以便根据具体数据集对 Sparkline 进行进一步适配。

除非出现特别有趣的更新，今后在这个博客上关于 Sparklines.js 的文章可能不会太多。如果你对这个项目感兴趣，建议持续关注 GitHub 仓库。
