Python 和 Flask 中的 HMAC SHA256 签名

2019-11-06 · 阅读原文

我最近在研究 Slack API，稍后会写一篇更详细的文章。其中集成过程中需要生成 HMAC SHA256 签名来验证请求是否来自 Slack。我在网上没找到太多有用的资料，有些像 hmac 模块的官方文档也没有提供示例。这里给以后遇到同样问题的朋友们一些快速参考。

感谢 Joe Kampschmidt 的文章，他很好地讲解了签名相关内容。

第一步是改造你的测试应用，让它能捕获完整的请求头和原始请求体，以便验证自己的实现是否正确。

如果你使用 Flask 作为服务器，获取原始请求体稍微有点麻烦。因为当 Content-Type 是 application/x-www-form-urlencoded 时，Flask 会自动把数据转换成字典，而不是原始字符串。这种转换导致我们很难直接拿到原始字符串。

幸运的是，你可以使用 Request.get_data 来获取原始请求体，但必须在调用 Request.form 之前进行。实际上你可以先调用 Request.get_data，之后再调用 Request.form，只要注意调用顺序就行。

def recall_post(request):
    # must not call request.form here
    headers = request.headers()
    data = request.get_data()
    print(headers)
    print(data)


    # calling request.form is fine now
    request.form
    return "%s %s" % (headers, data)

当你拿到请求头和原始数据后，就可以测试生成签名并与 Slack 发送的签名进行对比。你需要从传入请求中提取的值包括：


timestamp = request.headers['X-Slack-Request-Timestamp']
expected_sig = request.headers['X-Slack-Signature']

你还需要前往 Slack 仪表盘中的 Application 页面获取 Signing Secret。拿到这些信息以及通过 Request.get_data 获取的原始 POST 请求体后，就可以用它们来测试生成自己的签名了。

import hmac, hashlib

body = b'token=etc&team_id=etc&...'
timestamp = b'100000000000'
base = 'v0:%s:%s' % (timestamp.decode('utf-8'), body.decode('utf-8'))
secret = b'1234'
computed = hmac.new(secret, base.encode('utf-8'),
                    digestmod=hashlib.sha256).hexdigest()
sig = 'v0=%s' % (computed,)

print(sig)

如果使用真实数据，最终生成的签名应该与 X-Slack-Signature 请求头中 Slack 提供的签名完全一致。

把以上内容整合起来，服务器端的验证函数大致如下：

def verify(request,secret):
    body = request.get_data()
    timestamp = request.headers['X-Slack-Request-Timestamp']
    sig_basestring = 'v0:%s:%s' % (timestamp, body.decode('utf-8'))
    computed_sha = hmac.new(secret,
                            sig_basestring.encode('utf-8'),
                            digestmod=hashlib.sha256).hexdigest()
    my_sig = 'v0=%s' % (computed_sha,)
    slack_sig = request.headers['X-Slack-Signature']
    if my_sig != slack_sig:
        err_str = "my_sig %s does not equal slack_sig %s" % \
                   (my_sig, slack_sig))
        raise Exception(err_str)

def recall_post(request):
    signing_secret = b'your secret from some config tool'
    verify(request, signing_secret)
    return "Signatures match, yay."

现在，只要你在处理函数中调用 verify，就能确信收到的请求确实来自 Slack。希望这篇文章能帮到大家，节省一点时间！
