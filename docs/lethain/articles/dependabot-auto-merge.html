自动合并 Dependabot PR

2025-12-18 · 阅读原文

软件开发中一个反复出现的主题就是修复安全问题。 目前大多数代码托管服务都提供了相当不错的漏洞报告功能，但很多组织仍然难以及时应用这些修复。 上周我们在讨论如何降低这个流程的负担时，我突然想到：能不能直接自动合并 GitHub Dependabot 提交的拉取请求呢？

结果证明，[答案是可以]，而且效果还不错。 你可以控制想要自动合并的更新类型（补丁更新、小版本更新、大版本更新等），它也会尊重你设置的自动化检查。 如果你有完善的 CI/CD 流程，会强制运行代码 lint、类型检查和测试，那么这个方案会工作得特别好。 如果你还没有，那么这将是一个非常有效的机制——虽然可能会让你经历一番折腾，但最终能帮你建立起良好的代码 lint、类型检查和测试体系。
