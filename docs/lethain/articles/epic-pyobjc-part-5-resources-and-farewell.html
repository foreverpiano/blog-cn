那么……我尽量不让你失望。

PyObjC 示例代码

要深入理解 PyObjC 中的某个具体概念，最好的方法之一就是研究那些优秀的示例项目。这些示例在你的 Mac 上已经预装好了，路径为 /Developer/Examples/Python/PyObjC/。需要注意的一点是，部分 PyObjC 示例可能略显过时，它们偶尔会使用已废弃的 NibClassBuilder.AutoBaseClass 作为基类，而不是显式地继承一个真实的类（如 NSObject 等）。但如果忽略这一点，其余的实现细节仍然极具参考价值。

Objective-C

我最初是用 PyObjC 来开发 Cocoa 应用的，直到后来才学习 Objective-C。在用纯 Objective-C 开发了几个应用之后，我依然认为 PyObjC 是更好的选择，但任何 Cocoa 开发者都不会后悔让自己精通 Objective-C。

最显而易见的原因是，如果你只依赖 PyObjC 的文档，那你就把自己关进了一个非常狭小且不那么愉快的盒子里。除此之外，你还可以用 Objective-C 来优化那些对性能要求极高的代码部分；同时，当你不再依赖 Python 自带的“电池”时，也能更深入地了解 Cocoa 库中那些丰富而强大的功能。

  • Apple 官方的《The Objective-C 2.0 Programming Language》是一本深入介绍 ObjC 2.0 的好资料。

Core Data

我在本教程第二部分曾简要提及 Core Data，它确实是一个非常出色的工具。尽管并非所有项目都适合使用它，但一旦项目与之契合，它就能与 Cocoa bindings 以及各种控制器（NSObjectController 和 NSArrayController 等）相结合，帮你完成数据类型的 schema 创建、数据连接、数据增删、数据显示等几乎所有工作——你基本上可以用它们构建整个应用。

  • The Apple Documentation's high level overview of Core Data is good for getting your feet slightly damp.
  • CocoaDevCentral's excellent introduction to implementing a Core Data application will have you actually going through the motions (lots of InterfaceBuilder goodness) of using Core Data. Its in Objective-C, but you won't find a better introduction.
  • The Apple Documentation's thorough introduction and discussion of the many minutiae of Core Data. The writing style is less accessible than a security vault, but when you need to know the details this is the best place to look.

Cocoa Bindings

我们在教程中花了大量篇幅介绍 Cocoa bindings，但总有更多技巧值得学习，以便进一步减少应用所需的代码量。

  • CocoaDevCentral's Intro to Bindings. It might seem like I'm recommending everything on CocoaDevCentral indiscriminately, but I worked through all the material there when I learning Objective C, and its uniformly excellent stuff.
  • Apple Documentation's Introduction to Cocoa Bindings is the gateway to Apple's myriad resources on Cocoa Bindings.
  • NSObjectController Class Reference.
  • NSArrayController Class Reference.

开始一个项目，从悬崖上跳下去

归根结底，提升 PyObjC 使用水平的最好方法和学习其他任何东西都一样：开启一个有野心的项目，然后把它真正做出来。当你遇到棘手的问题时，不要为了回避困难而重新设计应用。正面迎接它们，一边做一边把细节问题搞清楚。
