PyObjC 示例代码

要深入理解 PyObjC 中的某个具体概念，最好的方法之一就是研究那些优秀的示例项目。这些示例已经安装在你的 Mac 上，路径为 /Developer/Examples/Python/PyObjC/。需要注意的一点是，其中部分示例可能有些过时。具体来说，它们偶尔会使用 NibClassBuilder.AutoBaseClass 作为基类，而不是显式地继承一个真实的类（比如 NSObject 等），这种做法现在已被废弃。不过如果忽略这一点，其余的实现细节仍然非常有参考价值。

Objective-C

我最初是用 PyObjC 开始开发 Cocoa 应用的，直到后来才学习了 Objective-C。在用纯 Objective-C 写了几款应用之后，我依然认为 PyObjC 是更好的选择，但任何 Cocoa 开发者都不会后悔让自己熟悉 Objective-C。

最显而易见的原因是，如果你只依赖 PyObjC 的文档，就会把自己关在一个非常狭小且不怎么愉快的盒子里。除此之外，你还可以用 Objective-C 来优化那些对性能要求较高的代码部分；同时，当你不再依赖 Python 自带的“电池”时，也能更深入地了解 Cocoa 库中那些丰富而强大的功能。

Apple 官方的《The Objective-C 2.0 Programming Language》是一本深入介绍 ObjC 2.0 的好教程。

Core Data

我在教程第二部分简单提到过 Core Data，它真是一个非常出色的开发工具。虽然并非所有项目都适用，但只要场景合适，它结合 Cocoa bindings 以及各种 Controller（比如 NSObjectController 和 NSArrayController），就能帮你完成数据类型的 schema 创建、数据连接、数据的增删改查、数据显示等几乎所有工作——你基本上可以用它们构建起整个应用。

Apple 文档中对 Core Data 的高层概述适合初次接触，让你稍微沾点水。CocoaDevCentral 上那篇优秀的 Core Data 应用实现教程会手把手带你实际操作（里面有大量 Interface Builder 的精彩内容）。虽然它是 Objective-C 版本的，但你找不到比它更好的入门资料了。Apple 文档中对 Core Data 全面而详尽的介绍和对各种细节的讨论，虽然文风像银行保险库一样不太亲切，但在你需要深入了解具体细节时，这里是最好的去处。

Cocoa Bindings

我们在教程中花了大量篇幅介绍 Cocoa bindings，但总有更多技巧值得学习，以便进一步减少应用所需的代码量。

CocoaDevCentral 的《Bindings 入门》。你可能会觉得我对 CocoaDevCentral 的内容过于无差别推荐，但我在学习 Objective-C 时确实把那里的所有材料都认真学了一遍，而且每一篇都是极好的内容。Apple 文档的《Cocoa Bindings 简介》是你通往 Apple 大量 Cocoa Bindings 资源的入口。NSObjectController 类参考文档。NSArrayController 类参考文档。

开始一个项目，从悬崖上跳下去

归根结底，提升 PyObjC 使用水平的唯一方法，和其他任何事情都一样：启动一个有野心的项目，然后让它真正跑起来。当你遇到困难时，不要为了躲避问题而重新设计应用。直面它们，在前进的过程中把细节一一搞清楚。
