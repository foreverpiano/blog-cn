两面 Django 第 7 部分：PyFacebook 和 FBJS Ajax

2007-12-17 · 阅读原文
  • 你可以在此处找到该项目的在线版本详情，包括网页和 Facebook 两种界面。现在的在线版本也已加入我们将在本节实现的酷炫 Ajax 投票功能。

现在我们已经完成了 Facebook 应用的大部分功能，只需为它添加一点 Ajax 功能就可以发布了。如果你之前没有跟进，可以下载[我们已开发代码的快照][polling6]。

通常在这个阶段我们会开始 urls → views → templates 的开发流程，但实际上我们在网页应用中已经实现了相关的 urls 和 views。让两个应用相互依赖显得有点不优雅，更干净的做法是创建一个第三方应用来存放所有通用或共享的组件（我喜欢把这个第三方应用叫做 api）。

唤醒记忆

让我们快速看一下正在复用的 urls 和 views。首先来看从网页应用中复用的 URL。

urlpatterns = patterns('',
    (r'^vote/$', 'polling.web.views.vote')
)

再回忆一下 polling.web.views.vote 这个视图的样子：

def vote(request):
    results = {'success':False}
    if request.method == u'GET':
        GET = request.GET
        if GET.has_key(u'pk') and GET.has_key(u'vote'):
            pk = int(GET[u'pk'])
            vote = GET[u'vote']
            poll = Poll.objects.get(pk=pk)
            if vote == u"up":
                poll.up()
            elif vote == u"down":
                poll.down()
            results = {'success':True}
    json = simplejson.dumps(results)
    return HttpResponse(json, mimetype='application/json')

所以，我们基本上是想向“www.ourserver.com/vote/”发送一个 GET 请求，并附带 pk 和 vote 两个参数。其中 vote 参数的值应该是 up 或 down。

但这里有个小问题。FaceBook Javascript（稍后会详细介绍）不支持发送 GET 请求。因此我们必须改用 POST 请求，而我们的 vote() 函数目前无法处理 POST 请求。所以，我们需要对 polling/web/views.py 做一些小改动。

emacs polling/web/views.py

并把 vote() 修改成下面这样：

def vote(request):
    results = {'success':False}
    if request.method == u'GET':
        data = request.GET
    elif request.method == u'POST':
        data = request.POST
    if data.has_key(u'pk') and data.has_key(u'vote'):
        pk = int(data[u'pk'])
        vote = data[u'vote']
        poll = Poll.objects.get(pk=pk)
        if vote == u"up":
            poll.up()
        elif vote == u"down":
            poll.down()
        results = {'success':True}
    json = simplejson.dumps(results)
    return HttpResponse(json, mimetype='application/json')

这段代码写得有点别扭，你可能更喜欢改写成：

def vote(request):
    results = {'success':False}
    if request.REQUEST.has_key(u'pk') and request.REQUEST.has_key(u'vote'):
        pk = int(request.REQUEST[u'pk'])
        vote = request.REQUEST[u'vote']
        poll = Poll.objects.get(pk=pk)
        if vote == u"up":
            poll.up()
        elif vote == u"down":
            poll.down()
        results = {'success':True}
    json = simplejson.dumps(results)
    return HttpResponse(json, mimetype='application/json')

request 的 REQUEST 属性会先查找 POST 属性，再查找 GET 属性。因此它正是我们当前场景下想要的。不过，使用 REQUEST 还是有些不被推荐（它不够显式）。在某些时候，选择哪一种就成了一个每个人都需要自己回答的哲学问题。

不管怎样，让我们保存 views.py 并继续。

FaceBook JavaScript

首先，你可能想快速浏览一下 Facebook Javascript 文档，特别是关于 FBJS Ajax 对象的文档。

FBJS 本质上是在一个安全沙箱中运行的 JavaScript。大部分情况下它的行为与标准 JavaScript 相同，但有些功能就是无法使用。另一个区别是 FBJS 通过其命名空间内已有的对象实例来暴露某些功能。我们将会使用其中两个暴露的对象。

第一个是 Dialog 对象。它是 Facebook 风格的、用于向用户发起简单交互的方式。我们将用它来完成和 JQuery 示例中 alert() 一样的功能（即通知用户操作成功）。

用于创建对话框的 FBJS 代码如下：

var successful = "True";
var d = new Dialog(Dialog.DIALOG_POP);
d.showMessage("Ajax", "The operation was " + successful);

除了 Dialog 对象，我们还会使用另一个 FBJS 对象——Ajax 对象。开发者维基将其描述为“一个非常强大的 AJAX 对象”，那就让我们来看看它的强大之处吧。

事实证明，Ajax 对象与你从 JQuery、Prototype 或 MochiKit 获得的简化版 Ajax 功能非常相似。

发送一个简单的 POST 请求如下所示：

var a = new Ajax();
// Can also be Ajax.RAW or Ajax.FBML
a.responseType = Ajax.JSON;
// If you want to require login
a.requireLogin = true;
var p = { "one":10, "name":"Jack" };
a.post('http://www.abc.com/d/', p);

简单到不能再简单了。现在让我们把 FBJS 投入使用。

编辑 detail.fbml 模板

我们即将编辑 polling/templates/fb/detail.fbml 模板。让我们快速打开它：

emacs polling/templates/fb/detail.fbml

一开始（在我们添加任何 Ajax 功能之前），它的样子是这样的：

{% load facebook %}
<fb:dashboard>
	<fb:create-button href="{% fburl '/create/' %}">Create a new poll</fb:create-button>
</fb:dashboard>
<fb:tabs>
  <fb:tab-item href="{% fburl '/' %}" title='All Polls'/>
</fb:tabs>
<div class="poll">
  <p> Score for "{ { poll.question }}" is { { poll.score }}!</p>
  <p>Do you <span id="up">agree</span> or <span id="down">disagree</span>?</p>
</div>

现在我们先来编写一个 JavaScript 函数，根据传入的参数为对象投赞成或反对票：

function vote(pk, voteUp) {
  if (voteUp == true)
    typ = "up";
  else
    typ = "down";
  var ajax = new Ajax();
  ajax.responseType = Ajax.JSON;
  ajax.requireLogin = true;
  var params = { "pk":pk, "vote":typ };
  ajax.post('http://krit.willarson.com/vote/', params);
}

好了，现在我们只需要修改模板，让它使用我们刚刚编写的 vote() 函数。在 detail.fbml 模板中，我们将重写 id 为 poll 的 html div。修改之后它将变成：

<div class="poll">
  <p> Score for "{ { poll.question }}" is { { poll.score }}!</p>
  <p>
    Do you
    <a href="#" onclick="vote({ { poll.pk }}, true)">agree</a>
    or
    <a href="#" onclick="vote({ { poll.pk }}, false)">disagree</a>?
  </p>
</div>

注意我们仍然可以使用“通过 Django 模板定制 JavaScript”这个方便技巧。

很好。现在的代码可以工作了，但还有一个小问题：验证它是否工作起来比较麻烦（必须手动刷新当前页面）。所以作为小小的改进，让我们使用 Dialog 对象来通知用户投票是否成功。

让我们稍微修改一下 vote() 函数，现在它看起来是这样的：

function vote(pk, voteUp) {
  if (voteUp == true)
    typ = "up";
  else
    typ = "down";
  var ajax = new Ajax();
  ajax.ondone = function(data) {
    var d = new Dialog(Dialog.DIALOG_POP);
    if (data.success == true)
      msg = "Your vote was successful!";
    else
      msg = "Your vote failed. :(";
    d.showMessage("Voting Result", msg);
  }
  ajax.responseType = Ajax.JSON;
  var params = { "pk":pk, "vote":typ };
  ajax.post('http://krit.willarson.com/vote/', params);
}

我们给 ajax 的 ondone 字段赋了一个匿名函数。任何赋给该字段的方法都会接收一个参数：Ajax 请求返回的内容。该内容格式是在创建 Ajax 对象时指定的（可以是 raw、json 或 fbml）。

经过这些修改，我们的 Facebook 应用的 Ajax 功能也完成了。
