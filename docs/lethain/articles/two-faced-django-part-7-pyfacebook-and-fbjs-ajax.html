FaceBook JavaScript

首先，你可能想快速浏览一下 Facebook Javascript 文档，特别是关于 FBJS Ajax 对象的文档。

FBJS 本质上是在安全沙箱中运行的 Javascript。大部分情况下它和标准 Javascript 的行为一致，但有些功能就是无法使用。另一个区别是 FBJS 通过其命名空间内的一些对象实例来暴露功能。我们将会用到其中两个暴露的对象。

第一个是 Dialog 对象。它是 Facebook 风格的、用于向用户索取简单交互的方式。我们将用它来完成和之前 JQuery 示例中 alert() 相同的功能（即通知用户操作成功）。
