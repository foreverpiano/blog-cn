PHP 中的简单单元测试

2009-02-01 · 阅读原文

如果说 Perl 是互联网界的瑞士军刀电锯，那么 PHP 可能就是你姑妈 Girda 因为舍不得扔掉、却又心怀愧疚送给你的那套银餐具里的钝黄油刀。当然，你永远别想用它砍倒红杉，但当你要涂黄油的时候，黄油刀也有它的用武之地。今天我们要涂的“黄油”，就是小型 PHP 项目中的单元测试。

只要你的编程语言支持将函数作为参数传递，搭建一个轻量级的单元测试环境就非常简单。幸运的是，PHP 可以做到。例如，下面是一个不算精巧的 map 函数实现：

<?php
function my_echo($x) {
    echo "my_echo: $x";
}
function map($func, $lst) {
$mapped = array();
foreach($lst as $item) {
$mapped[] = $func($item);
}
return $mapped;
}
map("my_echo", array('a','b','c'));
?>

考虑到这一点，我们来看看基本的单元测试主要包含哪些内容：

  • Comparing actual and expected values.
  • Defining testcases.
  • Running testcases.
  • Reporting results.

强调“基础”二字，我们可以用极低的成本实现上述所有功能：

<?php
$verbose = $_GET['verbose'];
$pass = 0;
$fail = 0;
function assert_($a, $b) {
if ($a != $b) {
echo "<p class=&quot;error&quot;>error: $a != $b<?p>";
global $fail;
$fail += 1;
} else {
global $pass;
$pass += 1;
echo '<span>.</span>';
}
}
function test_x() {
assert_(1,2);
assert_("yes","yes");
}
function test_y() {
assert_(count(array(1,2,3)), strlen("abc"));
}
$tests = array('text_x','text_y');
foreach($tests as $test) {
set_up();
if ($verbose) { echo "<p>$test</p>"; }
$test();
tear_down();
}
echo "<p>Passed $pass tests. Failed $fail tests.</p>";
?>

如果你对依赖全局状态感到不舒服，或者觉得它难以扩展，我们可以利用 PHP5 的面向对象风格稍作改进（只是会牺牲一些简洁性）。

<?php
class SimpleTest {
  public $passed;
  public $failed;
  public $current;
  public $msgs;
public function __construct() {
$this->passed = 0;
$this->failed = 0;
$this->msgs = array();
}
public function assert($a,$b) {
if ($a == $b) {
$this->passed++;
echo '<span>.</span>';
} else {
$this->failed++;
echo '<span>X</span>';
$this->msgs[] = "$this->current: $a != $b";
}
}
public function run_tests($tests) {
foreach($tests as $test) {
$this->current = $test;
$test($this);
}
foreach($msgs as $msg) {
echo "<p>$msg</p>";
}
echo "<p>$this->passed passed tests, and $this->failed failed tests.</p>";
}
}
function test_math($st) {
$st->assert(1*2,2);
$st->assert(5+0,5);
}
function test_strings($st) {
$st->assert("test","test");
$st->assert(strlen("test"),4);
}
$st = new SimpleTest();
$st->run_tests(array("test_math", "test_strings");
?>

如果你想玩点过度设计，从这里再往前一步就能得到一个灵活且可扩展的单元测试框架。首先，我们可以重写 run_tests 方法，让它扫描所有用户定义的函数，找出那些以 test_ 开头的函数并执行它们。

<?php
public function run_tests() {
    $all_funcs = get_defined_functions();
    $user_funcs = $all_funcs['user'];
    foreach($user_funcs as $func) {
      if (strpos($func, "test_") === 0) {
        $this->current = $func;
        $func($this);
      }
    }
}
?>

无论使用哪种方式，运行测试都简单到只需刷新页面（或者在命令行中执行）。这个练习彻底把我对 PHP 的偏见从心理垃圾桶里拖了出来（放进了一个编程语言的半途收容所）。用 Python 写出的等价代码给我的感觉要愉快得多，但两者之间的差距并不像我曾经想象的那么巨大。
