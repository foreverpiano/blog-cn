使用 django-userskins 让用户自定义网站样式

2008-10-27 · 阅读原文

在我正在开发的一个 Django 项目中，我想允许用户从若干套皮肤中选择一款，以个性化网站的界面（类似于 Twitter 新推出的换肤功能），于是决定开发一个可插拔的 Django 应用来实现这个需求。

django-userskins 就这样诞生了。

自述文件（readme）对实现细节已经介绍得相当详尽，不过我还是在这里简单说明几点。

尽可能减少数据库访问次数

我认为尽量避免数据库查询非常重要，因为如果用户换肤功能导致网站加载明显变慢，那就失去了意义。我的方案是使用 cookie 进行持久化，当已认证用户没有对应 cookie 时，才会去数据库查询其皮肤偏好并重新设置 cookie。因此，每个用户只会在清理浏览器 cookie 后，才需要访问一次数据库。

此外，django-userskins 还提供了一个完全不访问数据库的选项，这种情况下将仅通过 cookie 来保存用户的皮肤偏好。

节省带宽

另一个我认为很重要的问题是尽可能节省带宽。为此，我不喜欢那种把自定义样式表直接插入模板的做法，因为它无法利用缓存、压缩和长期过期策略，而且每次渲染模板都要重新发送样式内容。

django-userskins 则允许你为每种皮肤指定要加载的 CSS 文件。一个简单的配置如下：

USERSKINS_DEFAULT = "light"
USERSKINS_DETAILS = {
    'light':'light.css',
    'dark':'dark.css',
}

这个配置会被 userskin 模板标签使用……

{% load userskins %}
<head>
<title>Yadayada</title>
{% userskin %}
</head>

最终渲染出类似下面的 HTML：

<head>
<title>Yadayada</title>
<link rel="stylesheet" href="http://127.0.0.1:8000/media/light.css">
</head>

更让人兴奋的是（至少对我来说），django-userskins 可以与 django-compress 很好地集成。你的配置文件大致会是这样：

COMPRESS = True
COMPRESS_VERSION = True
COMPRESS_CSS = {
    'light':{
        'source_filenames':('css/base.css','css/skins/light.css'),
        'output_filename':'css/light_skin.r?.css',
    },
    'dark':{
        'source_filenames':('css/base.css','css/skins/dark.css'),
        'output_filename':'css/dark_skin.r?.css',
    },
}
USERSKINS_DEFAULT = "light"
# USERSKINS_DETAILS is not used when integrating with django-compress
USERSKINS_USE_COMPRESS_GROUPS = True

模板标签的使用方式完全不变，但会输出经过压缩、合并并带版本号的皮肤 CSS 文件。

{% load userskins %}
<head>
<title>Yadayada</title>
{% userskin %}
</head>

通过 django-compress 和 django-userskins 的组合，你可以在支持用户换肤的同时，不必在每个页面多发送额外数据，而且（配合 far-future-expires 头部）甚至不需要额外发起一次 HTTP 请求来获取皮肤的 CSS 文件。再结合最小化的数据库访问设计，django-userskins 可以在对网站性能和带宽影响极小的情况下投入使用。

已认证用户和匿名用户均可使用皮肤

django-userskins 的另一个优点是，未登录的用户也可以选择皮肤（通过 cookie 持久化）。设置用户 cookie 的代码可以非常简单（比如你在侧边栏提供了一个皮肤列表，用户点击链接即可切换皮肤）：

from django.conf.urls.defaults import *
from django.http import HttpResponseRedirect
from userskins.models import SkinPreference
def dark_skin(request):
hrr = HttpResponseRedirect("/")
hrr.set_cookie("userskins", "dark")
if request.user.is_authenticated():
try:
sp = SkinPreference.objects.get(user=request.user)
sp.skin = "dark"
sp.save()
except SkinPreference.ObjectDoesNotExist:
sp = SkinPreference.objects.create(user=request.user,
skin="dark")
return hrr
def light_skin(request):
hrr = HttpResponseRedirect("/")
hrr.set_cookie("userskins", "light")
if request.user.is_authenticated():
try:
sp = SkinPreference.objects.get(user=request.user)
sp.skin = "dark"
sp.save()
except SkinPreference.ObjectDoesNotExist:
sp = SkinPreference.objects.create(user=request.user,
skin="light")
return hrr
urlpatterns = patterns(
'',
(r'^skin/dark/$', dark_skin),
(r'^skin/light/$', light_skin),
)

如果你的网站不需要已认证用户，那么选择视图还可以写得更简短：

def light_skin(request):
    hrr = HttpResponseRedirect("/")
    hrr.set_cookie("userskins", "light")
    return hrr
