使用 django-userskins 让用户自定义网站样式

2008-10-27 · 阅读原文

在我正在开发的一个 Django 项目中，我想让用户从若干种皮肤中进行选择，以个性化网站的界面（类似于 Twitter 新推出的皮肤切换功能），于是决定开发一个可插拔的 Django 应用来实现这个需求。

django-userskins 就这样诞生了。

自述文件（README）对实现细节已经讲得比较详尽，不过我还是在这里简单说明几点。

尽可能减少数据库访问次数

我认为尽量避免数据库查询非常重要，因为如果允许用户选择皮肤却导致网站加载变慢，那就得不偿失了。我的方案是使用 Cookie 来保持状态：如果已认证用户没有对应的 Cookie，就去数据库查一下他们的皮肤偏好并重新设置 Cookie。这样每个用户只需要在清除浏览器 Cookie 后才会访问一次数据库。

此外，django-userskins 还提供了一个完全不访问数据库的选项，这种情况下仅通过 Cookie 来存储用户的皮肤偏好。

节约带宽

另一个我很重视的问题是尽可能节约带宽。为此，我不太喜欢那种把自定义样式表直接插入模板的做法，因为它无法利用缓存、压缩或 far-future-expires 机制，而且每次渲染模板都要重新发送样式内容。
