Python 处理大型 CSV 和 XML 文件

2009-01-22 · 阅读原文

和大多数人一样，我从未意识到自己会需要处理大型文件。 我知道会有一些几兆字节的数据文件，但 我从未想到自己会求着 Perl 处理几百兆字节的 XML，更没想到这周我会让 Python 把 6.4 GB 的 CSV 转换成 6.5 GB 的 XML。

几次内存溢出的经历会告诉你，处理大型文件的关键其实很简单：使用把一切当作数据流来处理的代码。 对于输入，从磁盘分块读取；对于输出，频繁写入磁盘，让系统内存保持轻松无负担。

当你自己读写文件时，这件事做对其实比想象中容易……

……比做错要容易得多……

……至少在简单情况下是这样。

性能表现

虽然我的脚本生成的 XML 元素种类与上面的例子不同，但复杂度并没有增加，性能也相当不错。将 6.4 GB 的 CSV 文件处理成 6.5 GB 的 XML 文件花费了 19 到 24 分钟，也就是说它大约每秒能读-处理-写 5 兆字节的数据。

从原始速度来看，这算不上特别惊人，但用 Perl 的 XML::Twig 做类似的操作（实际上是 XML 到 XML 而不是 CSV 到 XML）时，处理一个约 100 兆的文件就要花 8 分钟，所以我对 Python 标准库的质量以及它处理大文件的能力还是相当满意的。

标准库的广度和深度真的让 Python 成为编写这类简单一次性脚本的乐趣所在。 要是它能有 Perl 那样更易用的正则表达式语法就好了……
