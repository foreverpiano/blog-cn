Cocoa 拖拽文本到 Dock 图标

2008-08-06 · 阅读原文

我花了整个下午的时间，试图实现一个看起来应该非常简单的功能：让 Cocoa 应用程序能够接受拖拽到其 Dock 图标上的文本（以及应用程序图标，虽然这不是我的主要关注点）。让它接受文件相对简单，我也没费多少功夫就让它能接受 txt 文件，但要让它接受选中的文本字符串，却是完全另一回事。

在反复组合搜索关键词并尝试各种想法后，我终于找到了两个关键资源：

  1. A subsection of the Cocoa Scripting Guide that detailed the open content Apple Event sent by Mac OS.
  2. The documentation for providing a Systems Service.

如果我是 Cocoa 编程档案里的热心幽灵，我就会把你们丢在这里自己去拼凑，但我不至于那么残忍，所以我们还是来更仔细地看看具体细节。我当时使用的是 PyObjC，因此我会先给出 Python 示例，但也会把核心部分移植到 Objective-C。

在 AppDelegate 中添加代码

首先，你需要在应用程序的委托中创建一个单向系统服务的实现。一个使用 NSLog 记录传入文本的简单服务看起来像这样：

def doString_userData_error_(self,pboard,userData,error):
    pboardString = pboard.stringForType_(NSStringPboardType)
    NSLog(u"%s" % pboardString)

然后你需要在应用程序委托的 applicationDidFinishLaunching: 方法中注册这个服务：

def applicationDidFinishLaunching_(self,sender):
    NSApp.setServicesProvider_(self)

把它们合在一起，大概是这样的：

把这段代码移植到 Objective-C 相当直接。两个方法实现大致如下：

-(void)applicationDidFinishLaunching:(NSNotification *)aNotification {
    [NSApp setServicesProvider:self];
}
-(void)doString:(NSPasteboard )pboard userData:(NSString )userData error:(NSString **)error {
NSString * pboardString = [pboard stringForType:NSStringPboardType];
NSLog(@"%@",pboardString);
}

修改 Info.plist

最后你需要做的是在 Info.plist 文件中添加几个简单的设置来注册你的系统服务。首先，打开 Info.plist 文件进行编辑。然后添加一个名为 Services 的新键（自动补全应该能帮到你），其值是一个数组。

在 Services 键对应的数组中，Xcode 会创建一个直观地命名为“Item 1”的键。Item 1 的值同样是一个数组。它已经创建了一个名为 Menu 的键，下面有一个名为 default 的子项。default 的值应该是一个直观的服务名称，比如“Search dictionary”或“Add to list”，具体取决于你的服务功能。

现在，你只需要再为 Item 1 添加两个子项就完成了。首先是 Instance method name 键，其值对应上面代码中的 doString。其次是 Send Types 键，它的值是一个数组，第一个子项 Item 1 的值应为 NSStringPboardType。

如果上面的解释还不够清晰，这里有一张图片可以帮助说明。

现在构建你的应用程序，选中一些文本并将其拖到 Dock 中的应用图标上，它应该会友好地亮起，愉快地接收你的文本。
