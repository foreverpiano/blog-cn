Cocoa 拖拽文本到 Dock 图标

2008-08-06 · 阅读原文

我花了整个下午的时间，试图完成一件看似非常简单的事情：让 Cocoa 应用程序能够接受拖拽到其 Dock 图标上的文本（以及应用程序图标，虽然这不是我的主要关注点）。让它接受文件非常容易，我也没费多少功夫就让它能接受 txt 文件，但要让它接受高亮选中的文本字符串，却是完全另一回事。

在重新组合搜索关键词并尝试各种想法之后，我终于找到了两个关键资源：

Cocoa Scripting Guide 中关于 Mac OS 发送的 open content Apple Event 的小节，以及提供系统服务的文档。

如果我是 Cocoa 编程档案里的乐于助人的幽灵，我就会把你留在这里，让你自己把它们拼凑起来，但我没那么残忍，所以我们来更仔细地看看细节。我当时使用的是 PyObjC，因此我会先给出 Python 示例，然后再把核心部分移植到 Objective-C。

在 AppDelegate 中添加代码

首先，你需要在应用程序的 delegate 中创建一个单向系统服务的实现。一个简单的、使用 NSLog 输出传入文本的服务看起来像这样：

def doString_userData_error_(self,pboard,userData,error):
    pboardString = pboard.stringForType_(NSStringPboardType)
    NSLog(u"%s" % pboardString)

然后你需要在应用程序 delegate 的 applicationDidFinishLaunching: 方法中注册这个服务：

def applicationDidFinishLaunching_(self,sender):
    NSApp.setServicesProvider_(self)

把它们组合起来后看起来是这样的：

将这段代码移植到 Objective-C 相当直接。两个方法实现大致如下：

-(void)applicationDidFinishLaunching:(NSNotification *)aNotification {
    [NSApp setServicesProvider:self];
}
-(void)doString:(NSPasteboard )pboard userData:(NSString )userData error:(NSString **)error {
NSString * pboardString = [pboard stringForType:NSStringPboardType];
NSLog(@"%@",pboardString);
}

修改 Info.plist

最后你需要做的是在 Info.plist 文件中添加几个简单的设置来注册你的系统服务。首先，打开 Info.plist 文件进行编辑，然后添加一个名为 Services 的新键（自动补全应该能帮到你），其值是一个数组。

在 Services 键对应的数组中，Xcode 会创建一个名为 Item 1 的键（非常直观）。Item 1 的值也是一个数组。它已经创建了一个名为 Menu 的键，Menu 下面有一个名为 default 的子项。default 的值应该是一个直观的服务名称，比如可能是“Search dictionary”或“Add to list”，具体取决于你的服务要做什么。

现在，你只需要再为 Item 1 添加两个子项就完成了。首先是 Instance method name 键，其值应为上面代码中的 doString。其次是 Send Types 键，其值是一个数组，数组中的第一个 Item 1 的值为 NSStringPboardType。

如果上面的解释还不够完美，这里有一张图片可以帮助澄清。

现在，当你构建应用程序后，选中一些文本并将其拖拽到 Dock 中的应用图标上，它应该会友好地亮起，愉快地接收你的文本。
