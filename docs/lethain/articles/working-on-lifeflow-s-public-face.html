改进 LifeFlow 的对外形象

2008-06-11 · 阅读原文

最近对 LifeFlow 的工作重点放在提升博客对访客的可用性上。0.90 版本主要致力于改善写作者的使用体验，所以这次能重新专注于更直接面向用户的外观部分，感觉十分令人振奋。

我首先着手的是让 LifeFlow 生成符合标准的标记。此前我一直以 HTML4.01 Strict 为目标，但后来决定直接跳到 XHTML，只花了大约半小时在各个模板中查找未转义的换行和水平线，就顺利通过了验证。

有一件事我已经想做很久了，就是把评论直接嵌入到文章列表中。之前那个（相当丑陋的）首页算是朝这个方向迈出的第一步，但那一步太过保守且摇摆不定。这次的结果我还挺喜欢的。现在当你浏览文章列表时，就能直接在列表视图中看到最新的三条评论。

我认为这不仅看起来更舒服，也让读者能更方便地获取内容。此外，我还让分页按钮更加显眼，并为首页也添加了分页支持（首页会分页显示所有文章，而 Flow 页面仍只对其包含的文章进行分页）。

接下来，我对 RSS 页面一直不太满意——它虽然传递了必要的信息，但看起来就像是 XML 文档和一堆换行标签之间发生战争后的惨烈现场。

现在同样的信息被精简成了两段更短、更易浏览的文字。

我还尝试改进归档页面，它长期以来都给人一种“临时附加”的感觉。首先，我在顶部添加了面包屑导航，让归档的浏览更加便捷。其次，我在归档列表视图中增加了更多信息，这应该能让用户更容易发现感兴趣的内容，也更容易找到某篇具体文章。

除了这些改动，我还清理了模板，特别是彻底重构了之前控制 LifeFlow Editor 中文章编辑的那套短视的 template/url/view 三层结构。从我最近的文章就能明显看出来，我最近正处于 LifeFlow 开发的冲刺阶段，所以接下来的一两周还会有一波开发高潮，之后我会把注意力转向其他项目，开发节奏会暂时放缓。

我非常希望听到大家对 LifeFlow 设计的反馈——哪些地方做得不错，哪些地方确实需要改进以提升博客的易用性。哦，对了，还有最后一处改动：评论现在会以合理的顺序显示（采用我们期望的、符合逻辑的嵌套线程顺序），而不是之前那种线程混杂、首尾倒错的混乱状态。我终于不再把它当成“特性”，而是承认那就是一个 bug，并把它彻底修复了。

祝好，期待大家的任何反馈！

最后补一句。我已经把修改推送到了托管 lethain.com 的 VPS 上，同时把 VPS 上的 Django 源码更新到了最新版本。虽然中间遇到了一些奇怪的错误需要处理，但现在使用最新代码一切运行正常。
