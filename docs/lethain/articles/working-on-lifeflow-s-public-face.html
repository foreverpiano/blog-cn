改进 LifeFlow 的对外界面

2008-06-11 · 阅读原文

最近对 LifeFlow 的工作重点放在提升博客对访客的可用性上。0.90 版本主要致力于改善作者的写作体验，因此现在能重新专注于对外可见的部分，感觉十分 refreshing。

我首先着手的是让 LifeFlow 生成符合标准的标记。此前我一直以 HTML4.01 Strict 为目标，但后来决定直接跳到 XHTML，只花了大约半小时在各个模板中查找未转义的换行和水平分隔线，就顺利通过了验证。

有一件事我已经想做很久了，就是将评论内联到文章列表中。老版本（相当丑陋）的首页算是朝这个方向迈出的第一步，但那一步实在太过谨慎和犹豫。这次我对结果还算满意。现在当你浏览文章列表时，就能直接在列表中看到三条最新的评论。

我认为这样不仅看起来更美观，也让读者能更方便地获取内容。此外，我把分页按钮做得更加醒目，并为首页也添加了分页支持（首页会分页显示所有文章，而 Flow 页面仍只分页显示其所包含的文章）。

接下来，我对 RSS 页面一直不太满意。虽然它能传递必要的信息，但外观就像是 XML 文档和一大堆换行标签惨烈交战的战场。

现在同样的信息被压缩成了更简洁、易于浏览的两段文字。

我还一直在改进归档页面，它以前给人一种临时拼凑的感觉。首先，我在顶部添加了面包屑导航，让浏览归档更加方便。其次，我在归档列表视图中增加了更多信息，这样既更容易发现感兴趣的内容，也更容易找到特定文章。

除了这些改动，我还清理了模板，特别是彻底重构了之前控制 LifeFlow Editor 中文章编辑的那个短视的 template/url/view 三层结构。从我最近的文章就能明显看出，我最近对 LifeFlow 的开发进入了一阵狂热期，所以接下来的一两周会有一波开发冲刺，之后我会把注意力转向其他项目，开发节奏也会相应放缓。

我非常希望听到大家对 LifeFlow 设计的反馈——哪些部分做得不错，哪些地方确实需要改进以提升博客的可用性。对了，顺便说一下最后一个改动：评论现在会以合理的顺序显示（采用我们期待的、符合逻辑的 threaded 评论排序），而不是之前那种 threaded 与 first-last 混杂的混乱顺序。我终于不再自欺欺人地把那当作一个“功能”，而是承认它是个 bug，并且已经把它修复了。

保重，期待大家的反馈！

最后补充一句。我已经把修改推送到了托管 lethain.com 的 VPS 上，同时也将 VPS 上的 Django 源码更新到了 head 版本。虽然中间遇到了一些奇怪的错误需要处理，但现在使用 head 版本一切正常。
