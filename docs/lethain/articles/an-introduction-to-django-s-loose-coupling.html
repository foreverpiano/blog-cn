Django 松耦合设计简介

2008-07-22 · 阅读原文

Django 的核心设计理念之一就是松耦合。这既是 Django 最优秀的地方之一，也需要一定的时间和实践，才能真正理解它的价值以及如何加以利用。本系列短教程将首先简要说明 Django 松耦合理念的含义，以及它对使用 Django 开发项目的开发者有何优势，随后会通过几个小型示例项目，展示如何替换 Django 技术栈中的各个组件。

它的含义

松耦合是指 Django 功能栈中的各个组件尽可能保持独立。例如，Django 的模板语言非常适合渲染模型（model）中的内容，但同样可以轻松用来渲染其他类型的 Python 对象。Django ORM 让数据库的配置和访问变得简单，但你也可以选择使用 SQLAlchemy 来代替。

这种设计让 Django 应用更容易与遗留系统集成，但更重要的是，它允许你使用自己熟悉的工具，以及最适合当前具体问题的工具。许多刚接触 Django 的开发者常常不喜欢 Django 工具链中的某些部分，并建议让 Django 的行为更接近他们熟悉的框架和工具。然而，Django 的解决方案既极其简单又极其强大：如果你更喜欢其他工具，那就直接使用它们。

Django 并不是一个从天而降、要统治你整个项目的巨型工具，它提供了一组相互协作的工具，同时也非常乐意与你自己选择的工具配合。从 Ruby on Rails 或其他极具主见（opinionated）的框架转过来的开发者，可能已经习惯遵循框架的最佳实践，以避免与一个“自以为比你更了解你的项目”的框架对抗。但在使用 Django 时，你将重新回到驾驶座上。1
