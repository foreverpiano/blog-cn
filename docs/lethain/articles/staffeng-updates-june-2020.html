StaffEng 更新，2020 年 6 月

2020-06-23 · 阅读原文

我正在休为期四周的育儿假（之后 Laurel 和我会换班，她会先接手一段时间，等她回去工作后我再继续休假）。在学习如何换尿布、识别宝宝的饥饿信号、适应持续睡眠不足的生活，以及开始 的同时，我也想推进几个拖了很久的项目，其中之一就是 StaffEng。黑人的命也是命。

已经发生的变化：

staffeng.com 现在是一个由 Gatsby 构建、托管在 Github Pages 上的网站，不再是运行在 Google Cloud Function 上的 Python 服务。它更稳定、速度更快，也更容易维护。lethain/staff-eng 这个 GitHub 仓库已经转为公开仓库，今后大家可以直接通过提交 Pull Request 来分享自己的故事，而不用再像以前那样通过 Google Doc 提交。这也意味着如果你对网站的可用性有意见（比如我怎么都搞不定某些 iPad 尺寸下的显示问题），现在可以直接提交修复。StaffEng 新增了一个「指南」板块，大致列出了我计划在较长时间内撰写的资源主题，或许最终会集结成书，但同时也会一直免费开放在 StaffEng 网站上。

没有改变的事：

依然非常欢迎更多人分享自己晋升到 Staff-plus 工程师角色的经历，特别是 BIPOC 和女性朋友，她们通往这些职位的道路往往充满挑战。我相信提供一系列真实的故事，能帮助整个行业意识到我们在让这类职位更公平可及方面还有很多工作要做。我也相信，提供观点鲜明、注重实操的 Staff-plus 角色指南，仍然是推动行业向更包容、决策更明智的方向发展的一种有效方式。

现在这些琐碎的维护工作已经完成，希望我能尽快上线更多故事，同时也会写一些文章来提炼和总结从中学到的经验！
