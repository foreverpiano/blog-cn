对 Systems & Papers 的反思

2018-04-14 · 阅读原文

大约一年前，我快速搭建了一个名为 Systems & Papers 的网站，今天早些时候把对应的 GitHub 仓库设为了公开。

这个项目的核心想法是将 Project Euler「边做边学」的模式与相关的软件工程论文结合起来，让大家能更轻松地接触到基础设施工程领域的一些重要理念。对我个人来说，这也是一个深入学习 Ruby 的项目——Ruby 在我当前工作中使用非常广泛，而我之前并没有太多实际使用经验。

我把迁移到了一篇博客文章中，同时也将 [Redis 问题](/redis-protocol/) 和 问题也转成了博客文章。我最喜欢的一些技术论文。用程序化方式重构 Ruby 代码

这也是一次很好的机会，让我能更深入地了解 RunKit。它提供了一个动态原型开发环境，对于「通过 HTTP API 提交简单解决方案」这类场景非常高效。

总体来说，这个项目很有趣，但现在我很高兴能取消域名的自动续费，释放 Kubernetes 集群的一些空间，然后开启下一个新项目。
