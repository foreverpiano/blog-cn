系统与论文的思考

2018-04-14 · 阅读原文

大约一年前，我搭建了一个简易网站 Systems & Papers，今天早些时候将其 GitHub 仓库公开。

大致想法是将 Project Euler 的“边做边学”模式与相关的软件工程论文结合起来，让大家更容易接触到基础设施工程领域的一些重要理念。这也是我用来熟悉 Ruby 的一个项目——Ruby 在我工作中使用非常频繁，但之前我并没有怎么用过。

我把迁移到了一篇博客文章中，同时也将 [Redis 问题](/redis-protocol/) 和 问题转化成了博客文章。我最喜欢的一些技术论文。以编程方式重构 Ruby 代码

这也是一个很好的机会，让我能更深入地熟悉 RunKit。它提供了一个动态原型开发环境，对于通过 HTTP API 提交简单问题解答这类场景非常高效。

总的来说，这是个很有趣的项目，但现在我很高兴能取消域名的自动续费，释放 Kubernetes 集群的一些空间，然后开启下一个项目。
