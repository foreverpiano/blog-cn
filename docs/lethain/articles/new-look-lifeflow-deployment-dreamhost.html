LifeFlow 新外观，在 Dreamhost 上的部署

2007-07-12 · 阅读原文

昨天完成 LifeFlow 大部分核心编程工作后，我觉得是时候彻底改变它那过于通用的外观了。很长一段时间里，这个网站和 LifeFlow 都紧密结合在一起，随着时间推移，程序代码层面已经解耦，而现在外观层面也终于独立出来了。Django 应用的外观主要由模板文件和媒体文件（css、图片、javascript 等）来决定。

LifeFlow 现在拥有了自己独立的外观，而 lethain.com 也有了属于自己的样子。你可以去我的 Dreamhost 站点看看 LifeFlow 的新模样。它是一个相当标准的博客，但真正重要的是：把一个 LifeFlow 网站的外观彻底改头换面只花了大约三十分钟。所有的改动都是对 HTML 和 CSS 做的一些小调整，并不需要很深的编程经验。

另一个消息是，在 Dreamhost 上部署 LifeFlow 确实是可行的。不过我当时记录下来的操作说明恐怕不太好直接套用：我在 Dreamhost 账户上的环境经过了大量个性化定制。

总之，去看看那个站点吧，你会看到一个全新安装的 lifeflow 是什么样子（我额外加了一篇文章和一个项目以作展示）。今晚我应该就能把安装说明准备好（不过主要是写给有 Django 使用经验的朋友看的）。
