一个在列表中显示相邻元素的过滤器

2009-01-20 · 阅读原文

当你没有花太多时间去思考它们时，有时很容易忽略那些显而易见的 UI 模式。这一点最近在我对博客做一些小调整时让我感触颇深。

在上一次重新设计中，我希望尽可能把重点放在文章本身——模仿书籍和报纸的呈现方式——其中一部分工作就是去掉侧边栏。我尽可能删除了冗余的信息，但最终还是到了一个地步：剩下的每样东西似乎都太重要，无法割舍。

我扩展了页头，尽可能塞入更多内容，但知道没有足够空间放下所有我想放的东西。于是我决定尝试让页头内容具有上下文相关性。具体来说，我把页头分成了五个区域。

受限于 A、B、C 三个区域的空间限制，很明显我无法放入所有想要的内容；我需要稍微节省一些。我决定先采用一个简单的策略，之后再逐步优化：

  1. Always show additional nav links in slot C.
  2. If an article has a related series, show it in slot A.
  3. Backfill empty slots with related tags.
  4. Backfill an empty slot with recent entries.
  5. Backfill an empty slot with random entries.

这意味着导航页面（如 Life 页面或首页）将始终显示最近和随机文章，而单篇文章则会显示相当相关的文章（同一系列的文章和拥有相同标签的文章的混合）。虽然规则很简单，但它们确实能把相关内容呈现出来。

（我正在考虑把随机文章替换为按评论量排名的前五篇文章，这也许能更好地暴露有趣的内容。）

由于 C 槽里有五个导航链接，我决定在 A 和 B 槽中也最多显示五篇文章。然后我有好几个月都想不明白：如果一个系列的文章超过五篇，该怎么处理呢？

在公司里实现完半打搜索原型之后，我意识到这个问题的模式其实早就存在，而且就在每个搜索引擎的结果页 UI 里。

更具体地说，有趣的是当你到达不再显示第一页结果的某一页时会发生什么。

啊，就是它：如果一个系列超过五篇文章，我只需要显示当前文章、前两篇和后两篇。等我终于看明白时，真是恍然大悟。

把这个概念实现为一个模板过滤器相当简单。

from django import template
register = template.Library()
def nearby(lst, obj, count=5):
lst = list(lst)
l = len(lst)
try:
pos = lst.index(obj)
except ValueError:
pos = 0
dist = count / 2
if pos <= dist:
return lst[:count]
if pos >= l - dist:
return lst[l-count:]
else:
return lst[pos-dist:pos+dist+1]
register.filter('nearby', nearby)

以下是在模板中的用法示例（假设模板上下文中有一个名为 object 的文章对象和一个名为 series 的文章列表）。

<h1>{ { object.title }}</h1>
<ol class="series">
{% for entry in series|nearby:object %}
<li>{ { entry.title }}</li>
{% endfor %}
</ol>

我只能感慨，自己怎么花了这么长时间才想明白这个。
