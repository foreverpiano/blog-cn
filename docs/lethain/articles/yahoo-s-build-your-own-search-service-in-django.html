用 Django 构建自己的 Yahoo 搜索服务

2008-07-10 · 阅读原文

在本教程中，我们将构建一个简单的 Django 应用，并将其与 Yahoo BOSS 搜索框架集成。更具体地说，我们将使用 BOSS Mashup Framework。

首先，让我们来回答最紧迫的问题：Yahoo BOSS 到底是什么？BOSS 是“Build Your Own Search Service”（构建你自己的搜索服务）的缩写，它为我们提供了一个相当底层的接口，不仅可以搜索我们自己的网站，还能搜索几乎任何内容。我们即将使用的 BOSS Mashup Framework 对所有开发者开放，并且几乎没有任何限制。

细节说明

首先让我们把所有琐碎的配置工作处理完。虽然内容不少，但都不难。这里需要提前说明的是，BOSS Mashup Framework 需要 Python 2.5，如果使用之前的版本则需要进行一些修改。

注册一个 BOSS App ID。 创建一个新的 Django 项目，我们将其命名为 my_search。 django-admin.py startproject my_search 在 my_search 中创建一个 Django 应用，我们将其命名为 yahoo_search。 python2.5 manage.py startapp yahoo_search 下载用于控制 BOSS 的 Python 库。 将其解压到 my_search/yahoo_search 文件夹中，并重命名为 boss。 unzip boss_mashup_framework_0.1.zip rm boss_mashup_framework_0.1.zip mv boss_mashup_framework_0.1 boss Yahoo 在打包方面做得不是特别好，无法做到即装即用，因此我们需要几个步骤来构建这个框架。（不过，这些子步骤几乎直接来自附带的 README 文件，所以他们并非没有提供文档，只是配置过程确实有点麻烦。）为 Yahoo 辩护一句，我认为他们打包“糟糕”的原因是可能遇到了不兼容的许可证问题。 如果你还没有安装 Simple JSON，请先安装它。你可以在 Python2.5 交互环境中输入 import simplejson 来检查是否已安装。 如果没有安装，请下载 Simple JSON，然后安装它。 python2.5 setup.py build python2.5 setup.py install 创建文件夹 my_search/yahoo_search/boss/deps/。 下载 dict2xml 和 xml2dict，并将它们解压到 deps 文件夹中，删除 .tgz 文件，然后返回 boss 目录。 tar -xzvf dict2xml.tgz tar -xzvf xml2dict.tgz rm *.tgz cd .. 现在我们可以最终构建这个框架了。 python2.5 setup.py build python2.5 setup.py install 接下来，我们需要更新 boss/config.json 中的设置。我只修改了前三个设置：appid、email 和 org。其中 appid 是你注册 BOSS 时获得的那一个。 在 boss 目录中运行以下命令来检查一切是否正常： python2.5 examples/ex3.py 从现在开始，我们的操作将与 README 略有不同：我们要把 example 和 yos 移动到 yahoo_search 目录中，将 config.json 移动到 my_search 目录，并删除其他所有内容（当然，你可以保留 examples 文件夹以供自己参考）。 mv config.json ../../ mv yos ../ mv examples ../ cd .. rm -r boss

好了，现在配置工作全部完成，我们可以开始构建一个使用 BOSS Mashup Framework 的简单 Django 应用了。

需要注意的一点是，Yahoo 提供的辅助库依赖于 config.json 位于 Python 运行的根目录。这在开发环境中是成立的，但在部署服务器上可能并非如此。我认为最好的解决方案是将 config.json 的内容添加到项目的 settings.py 文件中，并修改 yos/boss/ysearch.py 文件，让它使用 django.conf.settings 来加载配置，而不是从磁盘读取。
