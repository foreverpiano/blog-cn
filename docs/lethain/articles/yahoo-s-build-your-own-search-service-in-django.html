用 Django 构建你自己的 Yahoo 搜索服务

2008-07-10 · 阅读原文

在本教程中，我们将构建一个简单的 Django 应用，并将其与 Yahoo BOSS 搜索框架集成。更具体地说，我们将使用 BOSS Mashup Framework。

首先，让我们来回答最紧迫的问题：Yahoo BOSS 到底是什么？BOSS 是“Build Your Own Search Service”（构建你自己的搜索服务）的缩写，它为我们提供了一个相对底层的 Yahoo 搜索引擎接口，不仅可以搜索自己的网站，还几乎能搜索任何内容。我们即将使用的 BOSS Mashup Framework 对所有开发者开放，并且几乎没有任何限制。

繁琐的细节

首先让我们把所有琐碎的配置工作处理掉。虽然内容不少，但都不难。作为提醒，我要指出 BOSS Mashup Framework 需要 Python 2.5，如果不做一些修改的话，它无法在之前的版本上运行。

定义我们的应用

现在所有准备工作都已就绪，我们需要明确这个应用要做什么。首先（别担心，这将是一个多篇系列教程，我们会逐步构建一个更有趣的应用），我们要做的非常简单：根据表单提交的结果来搜索 Yahoo 新闻。

是的，就是这么简单。等我们做出能正常运行的东西之后，再逐步增加趣味性。

URL 配置

首先让我们编辑项目的 urls.py，把 yahoo_search 应用的 URL 包含进来。my_search/urls.py 应该看起来像这样：

from django.conf.urls.defaults import *
urlpatterns = patterns('',
    (r'^', include('my_search.yahoo_search.urls')),
)

不过，我们还没有创建 my_search/yahoo_search/urls.py，所以现在赶紧来创建它。

from django.conf.urls.defaults import *
urlpatterns = patterns('',
    (r'^$', 'my_search.yahoo_search.views.index'),
)

从 urlpatterns 可以看出，我们只有一个名为 index 的视图，它将负责处理所有事情。

index 视图

现在我们要编写 index 视图，它将为我们处理一切。首先打开 my_search/yahoo_search/views.py，让我们先导入所有需要的模块。

from django.shortcuts import render_to_response
from django import newforms as forms
from yos.boss import ysearch
from yos.yql import db

我们将使用 render_to_response 来渲染模板，用 newforms 来获取用户的搜索词，用 ysearch 从 BOSS 获取数据，用 db 将获取的结果格式化为更易管理的数据结构。

编写搜索函数

现在让我们编写一个简单的搜索函数，用于查询 BOSS。

def search(str):
    data = ysearch.search(str,vertical="news",count=10)
    news = db.create(data=data)
    return news.rows

简短的题外话

如果你想搜索 Yahoo 的网页结果而不是新闻，只需将这一行

data = ysearch.search(str,vertical="news",count=10)

data = ysearch.search(str,count=10)

search 函数返回的数据是一个字典列表，结构如下：

搜索函数非常基础，但对于这个应用的初始版本已经足够了。让我们继续前进。

一个简单的表单

接下来我们需要创建一个非常简单的表单，用于向用户询问搜索关键词。

class SearchForm(forms.Form):
    search_terms = forms.CharField(max_length=200)

目前我们只需要这么多，继续吧。（我说过它很简单。）

真正实现 index 视图

好的，现在让我们暂停一下，想想 index 视图需要完成什么工作。

  1. It needs to check if there are any incoming POST parameters.
  2. If there are POST parameters, it needs to validate them using SearchForm, and then use search to put together the results.
  3. It needs to use render_to_response to render a template contain a SearchForm, and any search results (if applicable).

好的，把这些翻译成 Python 代码，我们就得到了 index 函数：

def index(request):
    results = None
    if request.method == "POST":
        form = SearchForm(request.POST)
        if form.is_valid():
            search_terms = form.cleaned_data['search_terms']
            results = search(search_terms)
    else:
        form = SearchForm()
    return render_to_response('yahoo_search/index.html', 
                              {'form': form,'results': results})

诚然，我们还没有编写 index.html 模板，这是我们接下来的任务。除此之外，这是一个相当标准的 Django 视图。

完善 index.html 模板

首先，我们需要为 yahoo_search 应用创建模板目录。在 my_search/yahoo_search 目录中执行：

mkdir templates
mkdir templates/yahoo_search

然后创建 templates/yahoo_search/index.html 文件，并用编辑器打开它。这将是一个简单的模板，只包含一个搜索输入框和结果列表。

它看起来会像这样：

</head>

</span>

下载文件压缩包

如果你没有跟着操作，或者你的代码运行异常，你可以下载所有这些文件的压缩包。只需将其解压到某处，在 my_search/config.json 中填写前三项内容（你的 BOSS appid、email 和 org），然后你就可以在下一步中运行这个应用了。

2008年7月12日更新：遗憾的是，由于 BOSS 库的构建方式，仅仅复制 yos 文件夹是不够的，你需要按照上面列出的 BOSS Framework 安装步骤（第 6 步）进行操作。具体来说，你需要完成这些步骤，最后执行：

python2.5 setup.py build
python2.5 setup.py install

这确实有点麻烦，我会看看能否清理一下，让过程更简单。

看看它如何运行

现在我们已经完成了应用的构建，让我们启动它吧。

python2.5 manage.py runserver

访问 http://127.0.0.1:8000/，你会看到一个友好的搜索框在等待你。输入一个搜索词，按下回车，瞧，你就会看到结果列表。我搜索了“iPhone”，得到的结果页面如下：

需要注意的一点是，Yahoo 提供的辅助库依赖于 config.json 位于运行 Python 的基础目录中。这在你的开发环境中是成立的，但在部署服务器上可能并非如此。我认为最好的解决方案是将 config.json 的内容添加到项目的 settings.py 文件中，并修改 yos/boss/ysearch.py 文件，让它使用 django.conf.settings 来加载配置，而不是从磁盘读取。
