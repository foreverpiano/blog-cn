我的 2025 年桌面设置

2025-06-07 · 阅读原文

从 2020 年开始，我就一直在完善自己的桌面设置，现在终于觉得基本到位了。我不认为自己的桌面布置有多新颖，肯定还有更好的搭配方式。但自从加入 CalDigit TS5 Plus 之后，它终于能完全按照我的预期工作了，这一步我等了很久。

我对桌面的要求是：

  1. Has support for 2-3 Mac laptops
  2. Has support for a Windows gaming desktop with a dedicated GPU
  3. Has a dedicated microphone
  4. Has good enough lighting
  5. Is not too messy
  6. I can switch between any laptop and desktop with a single Thunderbolt cable

历史上最大的痛点一直是最后一项，以前切换设备需要插拔两根线——一根 Thunderbolt 和一根独显视频线，而有了这款新扩展坞后，终于只需要一根线就能搞定。

文中展示的设备以及我对每件产品的简短评价如下：

  1. UPLIFT v2 升降桌 —— 这是我使用的升降桌。因为桌面物品较多，同时又希望保持极简感，所以选择了 72" x 30" 的尺寸。2020 年下单时，唯一能快速发货的是竹面版，所以就选了它。
  2. CalDigit TS5 Plus Dock —— 这就是一直缺失的那块拼图，它提供了三个 Thunderbolt 端口和一个 DisplayPort。我把外接显卡直接接在 DisplayPort 上，然后通过切换 Thunderbolt 线来决定当前激活的是哪台电脑。它还有足够的 USB-A 端口，可以接无线键盘和鼠标的适配器，避免在不同电脑间重新配对，减少切换设备的摩擦。
  3. Apple Studio Display —— 我曾尝试过独立音箱和摄像头，但对我来说把这些功能集成在显示器里，能有效减少桌面上的物件。Studio Display 的屏幕、音箱和摄像头对我而言都足够优秀。虽然我知道在每个维度上都能找到更好的，但实际使用中我从不会想到这些，也没遇到过任何问题。不过，我原本希望能同时去掉独立麦克风，但它的收音质量对我来说不够理想——因为我经常参加视频会议和录制播客。
  4. Beelink GTi Ultra & EX Pro Docking Station —— 这是我的 Windows 迷你主机和扩展坞，支持外接 GPU。Beelink 本身有点让人恼火，据我观察他们在 Windows 11 上做了一些比较奇怪的定制补丁，但总体上作为一台专用游戏机用得很顺手，做工和体积控制都非常出色。
  5. MSI Gaming RTX 4070 Ti Super 16G Graphics Card —— 今年年初买的，当时想找一张有现货、性能也够用的卡，能用上一两代都不需要再大笔花钱去买 50 系列（何况其中有些型号看起来也不是 40 系列的明显升级）。
  6. Hexcal Studio —— 这是一体式的工作站/显示器支架/理线系统，还带灯光等功能。我总体上挺喜欢，但它并不完美，比如它的 Qi 无线充电器理论上能用，但充电速度太慢，实际上等于不能用。这东西确实太贵了，而且不能完全满足需求，所以我不太推荐。不过既然已经买了，也就不想再换了。
  7. Audio-Technica AT2020USB 心形指向电容 USB 麦克风 —— 这支麦克风我已经用了六年，质量非常好，当时大概花了 120 美元左右。现在已经停产了，但应该有更新的替代型号。我把它安装在一个悬臂支架上。
  8. LUME CUBE Edge 2.0 LED 台灯 —— 我买了两个，用于录制时的补光。其实我并不太喜欢一直开着它们，因为我讨厌直视灯光，但需要确保光线正确的时候还是会用到。
  9. Logitech MX Keys Advanced Wireless Illuminated Keyboard for Mac —— 这款键盘用着很顺手，而且是 USB-C 接口，我可以从 Hexcal 引一根带电的 USB-C 线，同时给键盘、鼠标、手机和耳机充电。
  10. Logitech MX Master 3S Wireless Mouse —— 这个系列的鼠标我用了很久，一两年前特意买了这个版本，为的是把所有设备的充电口都统一成 USB-C。
  11. 笔记本支架 —— 我不太记得是从哪里买的，可能来自 Etsy。当时很难找到能同时支撑三台笔记本而不是两台的支架。在找到这个之前，我用的是这个双笔记本支架，也还不错。
  12. Laptops —— 这是我的个人和工作的 MacBook。

这是桌面左侧稍近一点的细节。

现在，我对这套设置已经没有什么不满的地方了，未来几年应该也不会再做大的改动。额外说一句，我的办公室里挂着几件“专业艺术品”，都代表着我骄傲的经历。从左到右依次是：《An Elegant Puzzle》的封面、一幅完全基于 2014 年万圣夜 Uber 行程数据绘制的旧金山地图，以及《The Engineering Executive’s Primer》的封面。可能有点自恋，但我喜欢时不时回忆一下这些成就。
