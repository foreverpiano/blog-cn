双面 Django（上）：构建一个同时存在于 Facebook 和 Web 的项目

2007-12-04 · 阅读原文
你可以在这里找到该项目的在线演示版本，包括 Web 和 Facebook 两种界面。

最近我花了很多时间研究 Django 和 PyFacebook。虽然网上有一个还算不错的 PyFacebook 入门教程，但从邮件列表里的一些评论来看，大家似乎更需要一篇更全面、循序渐进的实战指南。

本系列文章将以 Django 官方教程那种清晰的步步为营风格，带你一步步构建一个 Django 应用，让它既能作为普通的 Web 应用运行，又能作为 Facebook 应用运行。Web 和 Facebook 两个界面将共享同一个数据库、使用相同的模型，因此使用其中一种界面的用户也能与另一种界面进行交互。

此外，本着资本主义的创业精神，我们打算抢占 Django 官方教程的地盘，打造一个更大更好的玩具级投票应用。此刻，硅谷的风险投资家们正因为这些投票应用可能给他们的钱包带来的冲击而瑟瑟发抖——或者类似这样的梗。

接下来，让我们看看在接下来一到三个小时内我们将完成什么：

构建 Web 应用和 Facebook 应用将共享的模型。使用 generic views 尽可能少写代码。使用 HTML 和 FBML（Facebook Markup Language）两种模板来渲染内容。使用 Facebook 的 JavaScript 和 jQuery 库实现 Ajax。使用 Django 测试框架在 Web 开发中实践测试驱动开发（TDD）。使用 newforms 来验证和表示数据。

本系列遗憾地不会覆盖以下内容：

如何把命令行指令改成适用于 Windows 的版本（我手头没有 Windows 机器可供测试）。如何在服务器上配置 mod_python 或其他部署方式。

本教程内容跨度较大，但不用担心，它并不要求你有太多先备知识。只要你有终端、Python 和 Subversion，我们就能一起完成这个旅程。
