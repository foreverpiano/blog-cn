OS X 文本框编码问题（可能如此）

2009-04-01 · 阅读原文

今天早些时候，我正在扫描一些税务文件，通过 USB 连接 HP 多功能一体机扫描时，我可怜的 MacBook 突然死机了。我一直不太喜欢这台一体机（主要抱怨：没有无线连接，软件也一般）。

我只好按住电源键强制重启，然后重新开机。结果……登录后又卡住了。一两分钟后系统时间突然变空白，即使再等四五分钟也没有任何变化。于是我只好再次强制重启。还是同样的问题。然后我又强制重启了一次，这次没有登录而是直接重启，接着又关机而不是登录，再重新开机。我等了几分钟（我怀疑是 Entourage 的问题……但这个判断可能并不准确）让初始程序启动后，终于可以使用机器了。只是……只是……只是出现了一个小问题。

所以，我是遇到某种数据损坏了吗？这是我多年以来无意中下载到的第一个病毒吗？这个问题真的很令人困惑。在桌面本身（不是通过 Finder 查看）文件名都显示正常，Mail.app 中邮件正文也正常，但上传并附加到邮件中的文件名却显示错误（我不愿意说是文件损坏，因为似乎只是显示出错，文件本身并没有问题）。

我目前运行的是 OS X 10.5.5（每次尝试升级到 10.5.6 都会一直卡住），这个系统是我大约七个月前干净安装的。硬盘还有 25GB 可用空间（原来总共只有 120GB）。我的 MacBook 大约用了 2.5 年。有什么想法吗？

哦，对了，我打字的时候肯定正在备份数据。;)

按照 JD Hollis 的建议，我运行了磁盘工具，磁盘看起来没问题。奇怪的是，这个问题对于那些可以关闭并重新启动的程序已经自行解决了，基本上只剩下 Finder 还显示乱码。似乎 10.5.6 本来应该修复这个问题，而我之前通过系统更新程序下载的 10.5.6 更新可能存在缺陷。乐观地看，这个问题很快就会消失。更详细地说，这个问题似乎与 IRIS 字符识别软件、HP 扫描仪软件和 OS X 10.5.5 有关。
比如，当你上传一个文档时，可以旋转第一页来校正对齐，但之后就无法对后续页面进行任何额外编辑，而且也不会记住你在第一页所做的编辑。真是够了。
