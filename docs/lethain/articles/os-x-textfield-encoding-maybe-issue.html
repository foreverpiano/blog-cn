OS X 文本框编码问题（可能如此）

2009-04-01 · 阅读原文

今天早些时候，我正在扫描一些税务文件，通过 USB 连接 HP 多功能一体机扫描时，我可怜的 MacBook 突然死机了。我一直不太喜欢这台一体机（主要抱怨：没有无线连接，软件也一般）。

我只好按住电源键强制重启，然后重新开机。结果……登录后又卡住了。一两分钟后系统时间突然变空白，即使再等四五分钟也没有任何变化。于是我只好再次强制重启。还是同样的问题。然后我又强制重启了一次，这次没有登录而是直接重启，接着又关机而不是登录，再重新开机。我等了几分钟（我怀疑是 Entourage 的问题……但这个判断可能并不准确）让初始程序启动后，终于可以使用机器了。只是……只是……只是出现了一个小问题。

所以，我是遇到某种数据损坏了吗？这是我多年以来无意中下载到的第一个病毒吗？这个问题真的很令人困惑。在桌面本身（不是通过 Finder 查看）文件名都显示正常，Mail.app 中邮件正文也正常，但上传并附加到邮件中的文件名却显示错误（我不愿意说是文件损坏，因为似乎只是显示出错，文件本身并没有问题）。

我目前运行的是 OS X 10.5.5（每次尝试升级到 10.5.6 都会一直卡住），这个系统是我大约七个月前干净安装的。硬盘还有 25GB 可用空间（原来总共只有 120GB）。我的 MacBook 大约用了 2.5 年。有什么想法吗？

哦，对了，我打字的时候肯定正在备份数据。;)

  • At JD Hollis' suggestion I ran Disk Utility, and the disk looks ok.
  • Oddly enough the problem has cleared itself up for programs I can close and relaunch, which basically means only Finder is still garbled.
  • It seems that 10.5.6 is supposed to fix this issue, and that my previous 10.5.6 update downloaded by system updater was flawed in some way. Optimistically this problem will go away soon. For more detail, it seemed to be an issue with the IRIS character recognition software, HP Scanner software and OS X 10.5.5.
  1. 比如，当你上传一个文档时，可以旋转第一页来校正对齐，但之后就无法对后续页面进行任何额外编辑，而且也不会记住你在第一页所做的编辑。真是够了。
