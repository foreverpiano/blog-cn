OS X 文本框编码问题（也许）

2009-04-01 · 阅读原文

今天早些时候，我正在扫描一些税务文件，通过 USB 连接 HP 多功能一体机进行扫描的过程中，我那可怜的小 MacBook 突然死机了。我一直不太喜欢这台一体机（主要吐槽点：没有无线连接，软件也一般）。

我只好按住电源键强制重启，然后重新开机。结果登录后又卡住了。一两分钟后系统时间显示变为空白，即使再等四五分钟也没有任何变化。于是我只好再次强制重启。还是老样子。然后我又硬重启了一次，这次没有登录而是直接重启，接着我没有登录就直接关机，再次开机。我等了几分钟（我怪罪于 Entourage……但这个判断可能不准确）让初始程序启动后，总算能正常使用机器了。不过……不过……不过，还是有一个小问题。

那么，我是遇到某种数据损坏了吗？这是我多年以来无意中下载的第一个病毒吗？这个问题真的很奇怪。在桌面本身（不是通过 Finder 查看）上，文件名都显示正常。Mail.app 中的邮件正文也正确，但上传并附加到邮件中的文件名却显示错误（我不太想说是“损坏”，因为其实只有显示出了问题，文件本身并没有损坏）。

我运行的是 OS X 10.5.5（每次尝试升级到 10.5.6 的时候都会一直卡住），这个系统是我大约七个月前干净安装的。硬盘还有 25 GB 可用空间（一开始总共只有 120 GB）。我的 MacBook 已经用了大约 2.5 年。有何高见？

哦，对了，我一边打字一边已经在备份数据了。;)

按照 JD Hollis 的建议，我运行了 Disk Utility，磁盘看起来没问题。奇怪的是，这个问题对于那些可以关闭并重新启动的程序已经自行解决了，也就是说现在只有 Finder 还显示混乱。似乎 10.5.6 应该能修复这个问题，而我之前通过系统更新下载的 10.5.6 版本可能存在缺陷。乐观地看，这个问题应该很快就会消失。更详细地说，这个问题似乎与 IRIS 字符识别软件、HP 扫描软件和 OS X 10.5.5 有关。
