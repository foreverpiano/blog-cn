在 Python 中去除 XML 中的非法字符

2009-01-25 · 阅读原文

上周我用 Python 做了大量的 XML 生成工作，却一直找不到一个纯 Python 脚本，能够在不安装额外包的情况下从文件中去除非法 XML 实体（在没有 root 权限的机器上，安装额外包会很麻烦）。

这个脚本是一个简单的命令行工具，它接受一个文件作为输入，去除 XML 中不合法的 ASCII 实体（以及你指定的其他任何字符），并将处理后的结果输出到标准输出。

如果你想额外指定需要移除的字符，可以在命令行中使用 -c 参数。

该脚本对输入和输出都采用流式处理，因此即使处理极大文件也能顺利完成（曾在超过 6GB、包含 4200 多万行的文本文件上测试过）。目前的速度对于大多数场景来说已经“足够快”了。下面是在一个 101MB 的文件中，从 867072 行里去除 60552 个字符的实际表现：

time ./strip_xml_entities.py < data.txt > clean.txt 2> log.txt
real 0m19.242s
user 0m6.991s
sys	 0m1.407s

如果需要更高的性能，还有一些优化的空间，但目前已有三分之二的时间都花在系统 IO 上，所以性能提升的空间已经不大了。
