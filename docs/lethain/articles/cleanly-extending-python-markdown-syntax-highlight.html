干净优雅地扩展 Python Markdown 以支持语法高亮

2008-01-09 · 阅读原文

当我刚开始搭建自己的博客时，最先着手的事情之一就是为文章添加代码语法高亮功能。我甚至还为此写过一篇比较粗糙的文章。

整个挑战的核心在于扩展 Markdown，让它支持一种能标记需要高亮代码块的语法。我到现在依然很喜欢自己选择的语法：

def add(a, b):
    return a + b

它并不花哨，但足以完成任务。然而，我第一次尝试扩展 Python-Markdown 来正确渲染这种语法时，写得相当糟糕。虽然它能跑，也确实能用，但它在运行过程中严重破坏了整个 Python-Markdown 库。

在某些情况下这或许可以原谅，但 Python-Markdown 的开发者已经特意设计了良好的扩展机制……所以我当时感觉挺糟心的。随着我持续投入精力改进博客软件，我决定是时候解决之前留下的这个烂摊子了。

让我们开始吧。
