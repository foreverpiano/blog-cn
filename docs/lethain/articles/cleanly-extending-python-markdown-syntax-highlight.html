优雅地扩展 Python Markdown 以实现语法高亮

2008-01-09 · 阅读原文

当我开始搭建自己的博客时，最先着手的事情之一就是为文章添加代码语法高亮功能。我甚至为此写过一篇比较粗糙的文章。

整个问题的核心在于扩展 Markdown，使其支持一种能够标记需要高亮代码块的语法。我至今仍很满意自己当时选择的语法：

def add(a, b):
    return a + b

它并不花哨，但足以完成任务。然而，我第一次尝试扩展 Python-Markdown 来正确渲染这种语法时，写得相当糟糕。虽然它能工作，效果也还行，但它几乎把整个 Python-Markdown 库都搅得一团糟。

在某些情况下这或许可以原谅，但 Python-Markdown 的开发者特意将它设计成易于扩展的……所以我对此感到有些愧疚。由于最近在博客软件上投入了很多精力，我决定是时候修正之前的愚蠢行为了。

让我们开始动手吧。

第一步：获取一份新的 Markdown

我之前修改过的 Markdown 副本已经残破不堪，所以我需要一份全新的。同时你最好也顺便安装一份 Pygments。

easy_install pygments

第二步：动手写代码

Markdown 库中有一个功能完整的示例（搜索 FOOTNOTE 即可跳转到它），这非常有用。每当遇到困惑时，就去参考它寻求指导。

现在我们需要创建一个新模块来存放我们的代码。它不应该（也不适合）与 markdown.py 放在同一个文件中。我把它命名为 code.py，因为我把它放在了一个叫 markup 的文件夹里。如果你把它放在名称不那么明确的文件夹中，可能需要取一个更好的名字。

你首先需要编写的是一个预处理器。预处理器需要定义一个函数：

def run(self, lines):
    # do things
    return lines

Markdown 库会按 "\n" 分割所有行，然后把结果传给你。如果你想把文本当作一个整体来处理，就得自己重新拼接：

blob = u"\n".join(lines)

所以我们的类将命名为 CodeBlockPreprocessor（很抓眼球吧），它将包含以下 run 方法：

def run (self, lines):
    new_lines = []
    seen_start = False
    lang = None
    block = []
    for line in lines:
        if line.startswith("@@") is True and seen_start is False:
            lang = line.strip("@@ ")
            seen_start = True
        elif line.startswith("@@") is True and seen_start is True:
            lexer = get_lexer_by_name(lang)
            content = "\n".join(block)
            highlighted = highlight(content, lexer, HtmlFormatter())
            new_lines.append("\n%s\n" % (highlighted))
            lang = None
            block = []
            seen_start = False
        elif seen_start is True:
            block.append(line)
        else:
            new_lines.append(line)
    return new_lines

我们逐行遍历，寻找代码块的起始标记（一行开头连续的两个 @ 符号）。找到后就忽略后续内容，直到遇到结束标记（如果没有结束标记，那么起始标记之后的所有内容都会被丢弃……虽然有点粗糙，但也能防止不该出现的内容混进来）。然后我们使用 Pygments 对起始和结束标记之间的代码进行着色，使用起始行指定的 lexer（例如 @@ ruby 就使用 ruby，@@ html+django 就使用 html+django）。

完成 run 方法之后，我们只需再写一些通用代码，很快就能得到一个干净的 Python-Markdown 扩展。

首先我们需要在文件顶部引入一些模块：

import re
from ddmarkup import markdown
from pygments import highlight
from pygments.formatters import HtmlFormatter
from pygments.lexers import get_lexer_by_name

然后我们要编写一个简单的类，用来注册我们的新预处理器。

class CodeExtension :
    def extendMarkdown(self, md):
        index = md.preprocessors.index(markdown.HTML_BLOCK_PREPROCESSOR)
        preprocessor = CodeBlockPreprocessor()
        preprocessor.md = md
        md.preprocessors.insert(index, preprocessor)

这可能是最简单的类了。它接收一个 Markdown 类的实例，然后将 CodeBlockPreprocessor 的实例添加到其预处理器列表中（放在 HTML_BLOCK_PREPROCESSOR 之前）。

最后，我们需要写一个函数来使用新的预处理器调用 markdown。

def render(text):
    md = markdown.Markdown()
    codeExtension = CodeExtension()
    codeExtension.extendMarkdown(md)
    md.source = text
    return unicode(md)

我们创建一个 Markdown 实例，添加我们的扩展，然后就可以渲染了。如果需要，我们也可以让它支持从命令行接收参数：

if __name__ == '__main__':
    print render(file(sys.argv[1]).read())

虽然第一次修改 Python-Markdown 时感觉费力不讨好，但它实际上是一个设计精良的库，也是“如何设计便于他人干净扩展的库”的好范例。有空的时候读读它的源码吧。
