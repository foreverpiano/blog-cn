干净地扩展 Python Markdown 以实现语法高亮

2008-01-09 · 阅读原文

当我最初开始搭建自己的博客时，最先着手的事情之一就是为文章添加代码语法高亮功能。我甚至为此写过一篇比较粗糙的文章。

整个挑战的核心在于如何扩展 Markdown，让它支持一种能标明代码块需要高亮的语法。我至今仍然很喜欢自己选择的这种语法：

def add(a, b):
    return a + b

def add(a, b):
    return a + b

它并不花哨，但足以完成任务。然而，我第一次尝试扩展 Python-Markdown 来正确渲染这种语法时，写得相当糟糕。虽然它确实能工作，效果也还凑合，但它在运行过程中把整个 Python-Markdown 库搞得乱七八糟。

在某些情况下这或许可以原谅，但 Python-Markdown 的实现者已经特意让它变得易于扩展……所以我对此感到有些心虚。随着我越来越多地改进自己的博客软件，我决定现在是时候修正之前的愚蠢行为了。

让我们开始吧。

第一步：获取一份新的 Markdown 副本

我之前修改过的 Markdown 副本已经残破不堪，所以我必须重新获取一份全新的。你同时也应该顺便安装一份 pygments。

easy_install pygments

第二步：动手写代码

Markdown 库中有一个功能完整的示例（搜索 FOOTNOTE 就能跳转到它），这非常有帮助。每当你感到困惑时，就去参考那个示例。

现在我们需要新建一个模块来存放我们的代码。它不应该（也不适合）和 markdown.py 放在同一个文件中。我把它命名为 code.py，并放在一个叫 markup 的文件夹里。如果你把它放在名称不那么明确的文件夹中，可能需要起一个更好的名字。

你首先需要编写的是一个 preprocessor。Preprocessor 需要定义一个函数：

def run(self, lines):
    # do things
    return lines

Markdown 库会按照 "\n" 分割所有行，然后把结果传给你。如果你想把文本当作一个整体来处理，就得自己重新拼接：

blob = u"\n".join(lines)

所以我们的类将命名为 CodeBlockPreprocessor（挺好记的，对吧），它将包含以下 run 方法：

def run (self, lines):
    new_lines = []
    seen_start = False
    lang = None
    block = []
    for line in lines:
        if line.startswith("@@") is True and seen_start is False:
            lang = line.strip("@@ ")
            seen_start = True
        elif line.startswith("@@") is True and seen_start is True:
            lexer = get_lexer_by_name(lang)
            content = "\n".join(block)
            highlighted = highlight(content, lexer, HtmlFormatter())
            new_lines.append("\n%s\n" % (highlighted))
            lang = None
            block = []
            seen_start = False
        elif seen_start is True:
            block.append(line)
        else:
            new_lines.append(line)
    return new_lines

我们遍历所有行，寻找代码块的开始标记（即一行开头连续的两个 @ 符号）。找到之后就忽略后续文本，直到遇到结束标记（如果没有结束标记，那么开始标记之后的所有内容都会被丢弃……虽然有点粗暴，但也不会让不想要的内容混进来）。然后我们使用 Pygments 对开始和结束标记之间的代码进行着色，使用的 lexer 由代码块开始那一行指定（例如 @@ ruby 会使用 ruby lexer，@@ html+django 则使用 html+django）。

完成 run 方法之后，我们只需再写一些通用的代码，很快就能得到一个干净的 Python-Markdown 扩展。

首先我们需要在文件顶部进行一些引入：

import re
from ddmarkup import markdown
from pygments import highlight
from pygments.formatters import HtmlFormatter
from pygments.lexers import get_lexer_by_name

然后我们需要编写一个简单的类，用来管理我们新加入的 preprocessor。

class CodeExtension :
    def extendMarkdown(self, md):
        index = md.preprocessors.index(markdown.HTML_BLOCK_PREPROCESSOR)
        preprocessor = CodeBlockPreprocessor()
        preprocessor.md = md
        md.preprocessors.insert(index, preprocessor)

这个类非常简单。你接收一个 Markdown 类的实例，然后把 CodeBlockPreprocessor 的实例添加到它的 preprocessor 列表中（放在 HTML_BLOCK_PREPROCESSOR 之前）。

最后，我们需要写一个函数，用我们新的 preprocessor 来调用 markdown。

def render(text):
    md = markdown.Markdown()
    codeExtension = CodeExtension()
    codeExtension.extendMarkdown(md)
    md.source = text
    return unicode(md)

我们创建一个 Markdown 实例，添加我们的扩展，然后就开始渲染。如果需要，我们也可以让它接受命令行参数：

if __name__ == '__main__':
    print render(file(sys.argv[1]).read())

虽然第一次修改 Python-Markdown 时感觉付出的努力大于收获，但它实际上是一个设计非常优秀的库，也是“如何设计易于被他人干净扩展的库”的好范例。有空的时候读读它的源码吧。
