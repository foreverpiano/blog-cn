Processing.js 的使用方法

2008-05-26 · 阅读原文

最近 John Resig 推出了 Processing.js。这个有趣的项目可以将 Processing 代码直接在网页浏览器中运行。下面先简单聊聊为什么我觉得它很有趣，之后再说明它的用法（或者说尝试说明一下）。

为什么 Processing.js 很有趣？

对这个问题的答案有很多，但这里我只说两点。

首先，Processing 的理念和做法非常出色，但我一直觉得 Java 的语法用起来相当麻烦。很早之前我就希望能有一种 Ruby 或 Python 风格的语法。后来发现它支持 JavaScript，我感到非常高兴。Processing 的目标是让人能轻松创建简单的程序，我认为用 JavaScript 比 Java 更能实现这个梦想。当然你也可以继续使用标准的 Processing 语法，但用 JavaScript 来写类似 Processing 的代码真的非常有趣。第二个理由正如 _why 所说，Java Applet 可能会逐渐从互联网上消失。虽然对我来说 Applet 似乎永远不会完全消失，但它的使用频率应该会越来越低。
