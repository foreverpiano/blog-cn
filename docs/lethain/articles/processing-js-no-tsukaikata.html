Processing.js 的使用方法

2008-05-26 · 阅读原文

最近 John Resig 发布了 Processing.js。这个有趣的项目可以让 Processing 代码直接在网页浏览器中运行。下面先简单说明为什么我觉得它很有意思，然后再介绍它的用法（或者说试着说明一下）。

为什么 Processing.js 很有意思？

对于这个问题有很多答案，但这里只说两点。

首先，Processing 的理念和做法非常棒，但我一直觉得 Java 的语法用起来相当麻烦。很早以前我就希望能有类似 Ruby 或 Python 那样的语法。后来发现它支持 JavaScript，让我感到有些高兴。Processing 的目标是让编程尽可能简单，我认为用 JavaScript 比用 Java 更能实现这个梦想。当然也可以使用标准的 Processing 语法，但用 JavaScript 来写类似 Processing 的代码真的非常有趣。第二个理由，正如 _why 所说，Java Applet 可能会逐渐从互联网上消失。虽然对我来说 Applet 似乎永远不会彻底消失，但它的使用频率应该会越来越少。

下载

Processing.js 入门非常简单，但一开始需要下载一两个文件。首先，下载 Processing.js。然后，再准备一个新的网页浏览器。Firefox、WebKit 或 Opera 都可以使用。（其实这个例子在旧浏览器中也能正常运行。）

准备工作

文件都准备好后，现在就可以开始编程前的设置了。

新建一个文件夹，取个类似“Processing”的名字。将下载好的 Processing.js 文件放入这个文件夹中。在同一个文件夹里再创建一个新文件，命名为“init.js”。

准备工作完成后，在 init.js 文件中加入以下代码。

window.onload = function()
{
  var canvas = document.getElementsByTagName("canvas");
  for ( var i = 0; i < canvas.length; i++ )
  {
    Processing( canvas[i], canvas[i].previousSibling.textContent );
  }
};

（“init.js”的代码是由 John Resig 编写的，并非我所写。）

接下来只需要创建一个简单的 HTML 文件就行了。

Processing.js 的使用方法

使用 Processing.js 最麻烦的部分其实是编写普通的 Processing 代码。完成后，可以把它嵌入到一个普通的 HTML 页面中就结束了。这个 HTML 页面做好之后可以重复使用，以后制作新的 Processing.js 程序时，就只需要专注于编写 Processing 代码本身。

那么，下面我们来创建这个重要的 HTML 页面。在之前的文件夹中新建一个名为“test.html”的文件，并加入以下 HTML 内容。

<html>
  <head>
    <title>一つのProcessing.jsの例</title>
    <script type="text/javascript" src="processing.js"></script>
    <script type="text/javascript" src="init.js"></script>
  </head>
  <body>
    <h1>一つのProcessing.jsの例</h1>
    <script type="application/processing">
    </script><canvas></canvas>
  </body>
</html>

请注意 type 为“application/processing”的 script 标签的位置。它就是用来放入 Processing 代码的地方。接下来，我从示例页面中选择了一个 Processing 代码示例。我选择了“Setup and Draw”这个例子，它的代码是

void setup() 
{
  size(200, 200);  //　サイズはいつも最初だ
  stroke(255);     // 線の書く色は白い
  frameRate(30);
}
float y = 100;
void draw() 
{ 
  background(0);   // バックグラウンドの色は黒い
  y = y - 1; 
  if (y < 0) { y = height; } 
  line(0, y, width, y);  
}

然后把这段代码加入到前面的 HTML 文件中。加入后，文件内容应该像下面这样。

<html> <head>
<title>一つProcessing.jsの例</title>
<script type="text/javascript" src="processing.js"></script>
<script type="text/javascript" src="init.js"></script>
</head>
<body>
<h1>一つProcessing.jsの例</h1>
<script type="application/processing">
void setup() 
{
  size(300, 300);
  stroke(255);
  frameRate(90);
}
float y = 100;
void draw() 
{ 
  background(0);
  y = y - 1; 
  if (y < 0) { y = height; } 
  line(0, y, width, y);  
}
</script><canvas></canvas>
</body> </html>

接着用网页浏览器打开看看，应该能看到和示例一样的结果。是不是相当简单又有趣呢？

最后的感想

今后大家可以用它来制作各种自己喜欢的游戏和绘图作品，用一段时间后，我相信 Processing.js 会成为一个非常好的工具。如果有关于 Processing 的问题，可以到它的官网查找各种资料。很抱歉，前面提到“Why Processing.js is interesting”的第一个理由完全没有详细说明。那部分我已经用英文写好了，接下来很快就会翻译成日文。

如果有任何问题、疑问或意见，欢迎随时给我发邮件。

比如，如果把 PHP（或 Ruby 等）与 Processing.js 结合起来使用，应该能做出既有趣又漂亮的程序。
