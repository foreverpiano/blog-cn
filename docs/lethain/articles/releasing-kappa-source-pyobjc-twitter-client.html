发布 Kappa 源代码（PyObjC Twitter 客户端）

2008-10-23 · 阅读原文

今天早上我发布了 Kappa 的源代码，这是一款基于 PyObjC 的 macOS Twitter 客户端。它已经成为我日常使用的默认 Twitter 客户端，倒不是因为它特别优秀，而是因为 Twitter 客户端的需求其实相当有限。我尝试在用户界面上做了一些有创意的设计（支持用正则表达式过滤推文、用进度条显示下次获取推文的时间、前后台不同显示模式等），但总体来说这些功能的实际价值有限，甚至可能适得其反。

欢迎大家随意玩耍，如果有兴趣也可以贡献代码。由于基础功能都已经实现（除了让链接可点击这一点，我一直没来得及做），你应该可以很容易地基于它打造一个个性化 Twitter 客户端。

希望这些代码能对你有所帮助。
