施事被动语态

2026-03-29 · 阅读原文

你应该在某个阶段学过被动语态——句子中动作的执行者不明确。例如，“我的软件没有编译成功”。这就是被动语态的一个典型例子。不过，你可能并不了解这套规则的全部细节，因为下面这些被动语态的句子，你或许就认不出来了：

  • Claude made an error in my writeup.
  • ChatGPT messed up the commitment.
  • Gemini didn’t write tests.

你可能觉得这些是主动句，但它们实际上是“施事被动语态”的例子。这里的规则是：只要句子的动作执行者是一个模型，那就是被动句。很抱歉，如果你的语法老师从未教过这条规则，但现在情况就是这样。

这是一个重要的语法区分。因为我越来越常看到有人说“Claude犯了个错误”，却没有意识到他们写出了模糊、几乎不符合语法规范的句子——连小学老师都会打回的句子。所以，请追求更高的标准。用主动语态写作，避免任何形式的被动表达。
