Erlang Brush for SyntaxHighlighter

2009-09-15 · 阅读原文

在 Pitance 首次公开展示之后，Luke Hatcher 指出的初期缺陷之一就是缺少语法高亮。我当时认为这很难实现，因为我不知道有任何基于 Erlang 的词法分析和格式化包，这让事情变得相当棘手。

而 Luke 则认为这相当简单。

带着这次交流的想法，我研究了 SyntaxHighlighter，这是一个基于 JavaScript 的代码高亮工具。它非常适合我的需求，但缺少 Erlang 词法分析器（这里所说的 lexer 用得比较宽松，因为它其实只是一组正则表达式）。

我找到了 Steve Gilham 提供的一个现成的 Erlang brush（SyntaxHighlighter 对 lexer 的称呼），但在实际使用中遇到了一些问题（可能是因为他的版本基于 SyntaxHighlighter 1？也可能是命名空间不同？又或者是我复制粘贴时出了错？），于是我自己重新写了一个版本。

你可以在这里看到高亮后的模板示例。

SyntaxHighlighter.brushes.Erlang = function() {
    this.regexList = [
        { regex: /&lt;|\&gt;/gm ,css: 'plain' },
        { regex: /[a-z](a-zA-Z0-9)*/gm, css: "color2"},
        { regex: /%(.*)$/gm, css: "comments"},
        { regex: /"(.*)"/gm, css: "string"},
        { regex: /[A-Z](\w*)/gm, css: "value"},
        { regex: /\??[A-Z][A-Z0-9]+/gm, css: 'keyword' }
    ];
}
SyntaxHighlighter.brushes.Erlang.prototype = new SyntaxHighlighter.Highlighter();
SyntaxHighlighter.brushes.Erlang.aliases = ['erlang', 'erl'];

你可以从 Pitance 获取最新版本的 Erlang brush。

  1. Pitance 从头到尾都是用 Erlang 开发的，在合理范围内，我也希望能一直保持这种状态。
