使用 Automator 水平缩放图片

2008-09-22 · 阅读原文

我以前的网站设计存在一个问题，就是我用 CSS 来缩放所有图片的大小，而不是确保它们实际就很合适。我想摆脱这种做法，于是把那些 CSS 都去掉了。

但我仍然面临根本性的问题：图片没有被正确缩放。我解决这个问题的第一个尝试是使用 Python Imaging Library，即 PIL。

不幸的是，如果你使用预编译版本，PIL 经常无法检测到 jpeg 编码库。我的 OSX 笔记本和 Ubuntu 服务器都无法处理 jpeg 图片，除非重新编译源代码。

因为当时我只想睡觉，脑子已经不太想继续思考。幸运的是，Automator 及其所见即所得的操作方式帮了我大忙。

虽然 Automator 默认可以缩放图片，但它只能垂直缩放，这不是我想要的效果。盯着它看了几秒钟后，我想出了一个狡猾（或者说在意料之中）的办法：先将图片旋转 90 度，然后垂直缩放，最后再旋转 -90 度。

虽然这个方法让人感觉哪里不太对劲，但它确实有效，而且效果惊人地好。于是我创建了一个名为 Size-For-Blog 的工作流，并把它放在了桌面上。

在此之前我一直忽略 Automator，因为我隐约记得六年级时曾经用 AppleScript 做了一个看起来像硬盘的图标，点击它就会运行关机脚本，我以为 Automator 也差不多那么“有用”。

不过，嘿，它还挺有帮助的。我不确定它是否能帮上我日常工作的忙，但从现在起，我至少会先去看看它是否适用。
