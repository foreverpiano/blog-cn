使用 Automator 水平缩放图片

2008-09-22 · 阅读原文

我以前的网站设计存在一个问题，那就是我用 CSS 来缩放所有图片的大小，而不是确保它们原本就尺寸合适。我想摆脱这种做法，于是把所有相关的 CSS 都去掉了。

但我仍然面临最根本的问题：图片没有被正确缩放。我解决这个问题的第一个思路是使用 Python Imaging Library（PIL）。

不幸的是，如果你使用预编译版本，PIL 常常无法检测到 jpeg 编码库。我的 OSX 笔记本和 Ubuntu 服务器如果不重新编译源代码，都无法处理 jpeg 图片。

因为当时只想赶紧睡觉，我实在没精力再深入思考。幸运的是，Automator 及其简单易用的点击式操作拯救了我。

虽然 Automator 默认可以缩放图片，但它只会垂直缩放，这不是我想要的效果。盯着它看了几秒后，我想出了一个狡猾（其实是必然会想到的）方案：先将图片旋转 90 度，然后垂直缩放，最后再旋转 -90 度。

虽然总觉得这种做法哪里不太对劲，但它确实有效，而且效果惊人地好。于是我做了一个名为 Size-For-Blog 的工作流，直接放在了桌面上。

在此之前我一直没怎么关注 Automator，因为我隐约记得六年级时曾经用 AppleScript 做了一个看起来像硬盘的图标，点击它就会运行关机脚本，我以为这个工具也就那么点用处。

不过，嘿，它其实挺好用的。我不确定它能否成为我日常任务的得力助手，但从今往后，我至少会先看看它是否能帮上忙。
