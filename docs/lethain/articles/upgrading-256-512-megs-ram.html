从 256 兆升级到 512 兆内存

2007-12-16 · 阅读原文

最终运行 Apache2 加 mod_python 的确不是个对 256 兆内存特别友好的进程。我终于升级到了 512 兆的虚拟服务器。现在运行 top 命令看到还有空闲内存，感觉怪怪的却又很兴奋。经过这次升级，我相当有信心本站最近的不稳定问题应该结束了。

不过我还是会继续关注 Apache 的错误日志，以防有什么更阴险的问题在暗中作祟。

更新 1

我也开始进一步优化 Apache2 的配置。按照我的搭建教程，我现在是用 nginx 前端代理，后面跑带 mod_python 的 Apache2。我做的第一个改动是将“KeepAlive”设为“Off”。因为我不通过 Apache 提供任何静态文件，所以关闭 KeepAlive 有很多理由，却几乎找不到打开它的必要。于是……现在它被关闭了。
