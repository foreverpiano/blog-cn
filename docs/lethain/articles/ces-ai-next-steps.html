使用本书与 LLM 的其他想法

2025-03-15 · 阅读原文

能走到《Crafting Engineering Strategy 的 AI 伴侣》这最后一章，说明你已经和 LLM 共同撰写并修改了一份工程策略。我们还通过上下文学习示例和 Model Context Protocol 服务器，让 LLM 为复杂、特定领域的任务做好准备，比如构建系统模型或 Wardley 地图。

目前还剩下两个最重要的问题需要探讨：

今后你应该如何实际使用这本为 LLM 优化的《Crafting Engineering Strategy》？“LLM 优化版图书”这个概念本身是否真正有价值？

这两个问题正是评估这个项目成败的关键，也将决定这种格式是否代表了图书出版方式的一次有意义的进步，还是仅仅是一个注定被遗忘的临时 hack。

本章是《The AI Companion to Crafting Engineering Strategy》的草稿章节，主要讨论如何在 LLM 中使用《Crafting Engineering Strategy》，来起草、完善和改进工程策略。

在实践中使用 LLM 优化版图书

把过去二十年学到的知识写下来后，一个很大的好处是，我可以将这些内容加载到任何 LLM 的上下文窗口中，从而显著提升模型生成的质量。如今，我所有与 LLM 相关的工作都在一个上下文丰富的项目中进行，以此改善生成结果；而涉及策略相关的话题时，就意味着要把这本书包含在内。

这种做法——在进行策略工作时，让本书自然地出现在你的上下文窗口中——是我认为能长期从中获益的最佳建议。当然，除此之外，当你正在积极制定下一份工程策略时，也要充分利用本书提供的技巧和示例。

在组织内部还值得尝试以下几种实验：

将其用作策略教练或导师，按照 如何提升战略能力？ 中描述的方式指导你的策略实践；把现有的策略改写为格式一致、易于阅读的版本；从 Architecture Decision Records 中识别反复出现的主题和话题，将其纳入持久的策略而非反复重述；总结你组织当前的策略高度（strategy altitudes），以便围绕“哪些决策应该在哪个层面做出”展开结构化讨论。

根据你组织当前的写作文化，其中某些做法的效果会比其他更好。尽管如此，当你逐一试验时，我相信你还会发现更多机会。

LLM 优化版图书是噱头吗？

许多作者担心 LLM 会窃取他们的作品和生计。这并非抽象的担忧，而是非常现实的问题：我们已经看到许多网站的搜索流量在下降，因为人们直接从 LLM 获取答案。这些 LLM 接受过那些网站内容的训练，却没有为作者的使用支付任何报酬。

上世纪90年代万维网搜索变得普及时，也曾出现过关于合理使用（fair use）的类似争论。最终法院确定了网络爬虫背景下合理使用的具体界限，随着网站学会利用搜索引擎带来的流量，这场辩论逐渐平息。原有的现状没有被维持，报纸行业发生了不可逆转的变化，但新的平衡最终得以建立。今天，LLM 也处于类似的时刻：作者们既需要发现 LLM 所代表的机会，同时也要面对它们可能彻底改变图书阅读和销售方式的现实。

与 O'Reilly 合作发布《Crafting Engineering Strategy》的 LLM 优化版以及这部 AI Companion，本质上是一次联合实验，试图找出真正可行的路径。目前购买 LLM 优化版图书的市场几乎不存在，但这确实是一些我认识的最有思想的人反复提到却感到棘手的问题，而我认为这种方式能很好地解决它。

这个未来最极端的版本是，人们把自己的全部藏书都存放在一个个人图书馆中，该图书馆可供代表他们运行的 LLM 代理访问。另一种愿景则是人类的阅读行为变化不大，大部分时候仍是“人替人阅读”。虽然我无法确定明年或下一个十年我们会生活在哪种场景中，但我最好的猜测是两者兼而有之。

尽管这种方法仍有不足，但我个人今天已经从中受益，也希望它能让你更容易为组织撰写出有效的工程策略。
