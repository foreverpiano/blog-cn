直观呈现文字结构

2009-02-10 · 阅读原文

正如你可能已经读过好几遍的那样，最近我彻底迷上了 Processing。只需一两个小时就能拼凑出简单的草图，有时它们最终看起来还挺惊艳的。

下面是一个非常早期的草图——从非常基础的层面——来呈现文字。每个单词都定义了一个进入动画的帧和一个退出动画的帧，这使得创建动态笔记变得相当轻松。下面的这个草图还非常有限，但我打算给它加上一些润色：

背景由页面上已有的文字决定（即“情绪着色”）。支持文字逐渐淡出，而不是直接消失。支持可预测的文字着色（同一单词的所有出现都使用相同颜色，并且能够为每个单词选择颜色）。

之后我会找一些有趣的演讲，用这个工具来绘制它们，看看效果如何……

此浏览器没有 Java 插件。请在此获取最新版 Java 插件。
