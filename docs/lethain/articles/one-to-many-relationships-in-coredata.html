在 Core Data 中建立一对多关系

2008-02-24 · 阅读原文

最近我一直在使用 Core Data，并且越来越喜欢它。它与 Cocoa Bindings 结合使用时，简直是一个极其强大的工具。但在查找示例和文档来弄清楚如何管理实体之间的关系时，我确实遇到了一点挫折。我最终还是搞明白了，但这个过程（对 Cocoa 新手来说）足够令人困惑，因此值得提供一个比当前文档中更清晰明确的例子。下面是一个在已存在实体的一对多关系中添加新实体实例的示例。

本例所使用的 Core Data 模型中包含两个实体：curriculum 和 lessonPlan。实际上它们还包含一些其他信息，但关键之处在于 curriculum 与 lessonPlan 之间是一对多关系。（这个应用的名称是 StrictlyEducation，我知道这个名字可能不算特别有创意。）

以下是完整的 StrictlyEducation_AppDelegate.h 文件。

#import <Cocoa/Cocoa.h>
@interface StrictlyEducation_AppDelegate : NSObject
{
IBOutlet NSWindow window;
IBOutlet NSArrayController curriculums;
IBOutlet NSArrayController lessonPlans;
NSPersistentStoreCoordinator persistentStoreCoordinator;
NSManagedObjectModel managedObjectModel;
NSManagedObjectContext managedObjectContext;
}
- (NSPersistentStoreCoordinator )persistentStoreCoordinator;
- (NSManagedObjectModel )managedObjectModel;
- (NSManagedObjectContext *)managedObjectContext;
- (IBAction)saveAction:sender;
- (IBAction)addLessonPlan:sender;
@end

下面是 addLessonPlan:sender 方法的实现，我正是在这个方法中创建新的 lessonPlan 记录，并将其关联到 curriculum 与 lessonPlans 之间的一对多关系中。

- (IBAction)addLessonPlan:(id)sender {
    NSManagedObjectContext *context = [self managedObjectContext];
    NSArray * selectedArray = [curriculums selectedObjects];
    NSManagedObject * selected = [selectedArray objectAtIndex:0];
    id lessonPlan = [NSEntityDescription insertNewObjectForEntityForName:@"LessonPlan" inManagedObjectContext:context];
    NSMutableSet * lessonPlansSet = [selected mutableSetValueForKey:@"lessonPlans"];
    [lessonPlansSet addObject:lessonPlan];
    [lessonPlanSet setValue:lessonPlansSet forKey:@"lessonPlans"];
    [context processPendingChanges];
}
首先，你需要获取 NSManagedObjectContext，幸运的是 AppDelegate 可以通过调用 managedObjectContext 方法很方便地提供它。接下来，你询问主要的 NSArrayController 当前选中的对象（使用 selectedObjects 方法），在本例中表格被设置为始终只允许单选，因此我们知道返回的 NSArray 中只会包含一个对象。然后我们使用稍显冗长的 insertNewObjectForEntityName:inManagedObjectContext: 方法创建一个新的 lessonPlan 实例。第四步，我们将这个新的 lessonPlan 添加到 selected（它是一个 curriculum）对象的 lessonPlans 关系中。最后，我们让上下文保存这些新改动，并释放不再需要的 lessonPlan 和 lessonPlansSet 变量。

我不会说它很简单，但有了具体的例子之后，确实是可以轻松实现的。
