在 CoreData 中建立一对多关系

2008-02-24 · 阅读原文

最近我开始使用 CoreData，并且越来越喜欢它。配合 Cocoa Bindings 使用时，它简直是一个极其强大的工具。但我在查找示例和文档来弄清楚如何管理实体间关系的过程中，确实遇到了一些令人沮丧的困难。我最终还是搞明白了，但整个过程（对 Cocoa 新手来说）足够让人困惑，因此有必要提供一个比当前文档更清晰明确的示例。下面这个例子展示了如何在已有的实体上添加一个具有一对多关系的实体新实例。

本示例所使用的 Core Data 模型中包含两个实体：curriculum 和 lessonPlan。实际上它们还包含一些其他信息，但关键在于 curriculum 与 lessonPlan 之间存在一对多的关系。（这个应用的名称是 StrictlyEducation，我知道这个名字可能不算特别有创意。）

首先，你需要获取 NSManagedObjectContext，AppDelegate 很乐意通过 managedObjectContext 方法来帮你完成这件事。接下来，你向主要的 NSArrayController 查询它当前选中的对象（使用 selectedObjects 方法），在本例中表格被设置为始终只允许单选，因此我们知道返回的 NSArray 中只会有一个对象。然后，我们使用稍显冗长的 insertNewObjectForEntityName:inManagedObjectContext: 方法来创建一个新的 lessonPlan 实例。第四步，我们将这个新的 lessonPlan 添加到 selected（它是一个 curriculum）的 lessonPlans 关系中。最后，我们通知 context 保存这些新的更改，并释放现在不再需要的 lessonPlan 和 lessonPlansSet 变量。
