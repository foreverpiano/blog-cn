一个利用 Notion 文档作为 Prompt 来评论其他 Notion 文档的 Agent。

2025-07-20 · 阅读原文

上周末，我写了一篇关于 的文章。 那个方案效果还不错，但不算特别好。 这个周末我花了一些时间，把这个想法升级到了下一个层次， 开发了一个运行在 AWS Lambda 上的 Agent。 这其中最重要的是，它让我能够借助 Agent 的工具调用能力， 同时支持页面级别和块级别的评论。总体而言，我认为这个方案表现非常出色。通过 OpenAI 和 Zapier 在 Notion 文档中添加评论

这个项目主要由 Claude Code 完成， 因此我觉得代码质量其实比较一般， 但你可以在 GitHub 上的 lethain:basic_notion-agent 仓库看到完整的可运行实现。 安装和配置说明也在那里。

观看我在 YouTube 上录制的这个项目的快速演示。

截图

为了让你对最终使用体验有个直观感受，这里放几张截图。 首先，你需要在 Notion 文档中创建一个 Prompt。

接着，它就会在文档内的各个块上提供行内评论。

它还会为整个文档提供一条总结性评论 （当然，如果你只想要行内评论，这个功能也是可以关闭的）。

我特别喜欢的一个功能是，这个 Agent 能感知文档中已有的评论、是谁写的， 并且会针对这些评论进行回复。

总的来说，这是一个有趣的小项目，经过足够的 Prompt 调优后，效果出奇地好—— 几乎所有 Agent 在 prompt 调优到位后都是如此。
