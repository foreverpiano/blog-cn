在 Clojure 中写入文件

2009-11-16 · 阅读原文

刚开始学习 Clojure 时，我花了不少功夫才搞清楚如何从文件中读取数据，而理解如何写入文件则需要更多的探索。下面给出了一些在 Clojure 中写入文件的实用方法，首先使用 clojure.contrib.duck-streams，然后介绍如何直接使用 java.io.BufferedWriter。

clojure.contrib.duck-streams/spit

duck-streams.spit 可以看作是 Clojure 核心函数 slurp 的对应写入版本。 对于简单操作和小文件来说，spit 可能是最好的选择。

user> (require 'clojure.contrib.duck-streams)
nil                          
user> (clojure.contrib.duck-streams/spit "output.txt" "test")
nil

这段代码会创建一个 output.txt 文件，其内容为“test”。此外还有 append-spit 变体，可以将字符串追加到文件末尾。

user> (require 'clojure.contrib.duck-streams)
nil                          
user> (clojure.contrib.duck-streams/append-spit "output.txt" "test")
nil

这些函数非常实用，但请记住，你需要先安装 clojure.contrib 才能使用它们。

clojure.contrib.duck-streams/write-lines

如果要以流式方式写入文件，duck-streams 再次提供了最简单的方法 —— write-lines。

user> (require 'clojure.contrib.duck-streams)
nil   
user> (clojure.contrib.duck-streams/write-lines "output.txt" 
                                                (list 1 2 3 4))
nil

遗憾的是，并不是所有人都会立刻安装 clojure-contrib，因此我们来看看如何在不使用 duck-streams 的情况下写入文件。

java.io.BufferedWriter

当 Clojure 核心和贡献库无法满足需求时（或者我们不想安装贡献库），下一步就该转向 Java 的解决方案了：在本例中就是使用 java.io.BufferedWriter。

最简单的情况下，java.io.BufferedWriter 可以帮我们实现与 duck-streams.spit 相同的功能。

(ns tokenize
  (:import (java.io BufferedWriter FileWriter)))
(defn spit2 [file-name data]
(with-open [wtr (BufferedWriter. (FileWriter.	file-name))]
(.write wtr	data)))
(spit2 "output.txt" "this is some data…\n")

然而，spit2 和 slurp 一样存在缺陷，需要将整个文件内容加载到内存中，而不能以流的方式处理数据。我们也可以使用 BufferedWriter 来实现更高效的写入方式。

(ns tokenize
  (:import (java.io BufferedWriter FileWriter)))
(defn write-lines2 [file-name lines]
(with-open [wtr (BufferedWriter. (FileWriter. file-name))]
(doseq [line lines] (.write	wtr line))))
(write-lines2 "output2.txt" (list "a\n" "b" "c" "d\n" "e\n"))

上面四种方法（duck-streams.spit、duck-streams.write-lines、spit2 或 write-lines2）应该能够满足你大部分的文件写入需求。接下来值得考虑的场景是：一个系统从文件中惰性读取数据，执行某些处理后，再惰性地将结果写入文件。希望这一部分的内容一两天内就能准备好。
