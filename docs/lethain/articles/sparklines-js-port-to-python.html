Sparklines.js 的 Python 移植版

2008-09-13 · 阅读原文

既然现在似乎是我发布那些被遗弃代码的季节，我想干脆也把我之前做的一个 Sparklines.js 到 Python 的移植版本一起放出来。这个版本基本完成，但远谈不上完美。

你可以在这里下载该文件。

它使用 PIL 将 Sparklines 渲染为图像文件。大多数情况下它生成的 Sparklines 都丑得可怕，虽然 API 和 Sparklines.js 相当接近，但也并非完全一致。你可以说我是在一时兴起、毫无价值的情况下发布它的。它最初的目的是为了支持一个 Web 服务，该服务会使用 Sparklines.js 为网站用户动态生成 Sparklines，然后允许用户通过 Python 库导出一个图像文件副本。它实际用在这个目的上效果还不错（API 略有不同，但可以在你应用的逻辑中轻松修正），只是 Python 库生成的图像实在太丑了（这并非完全是玩笑，我当时正在开发的一个 Web 应用原型确实就是这么做的）。

不管怎样，我认为这种糟糕的外观并非无法克服，只是需要多花点心思去打磨，仅此而已。

移植过程中的感受

Python 版本有 270 行代码，而 JavaScript 版本大约有 320 行。由于我有先设计 JavaScript 库、再实现 Python 版本的优势，我认为这有力地说明了 Python 和 JavaScript 在表达力上的相对差异。另一方面，在 Python 中子类化时我不需要去查阅参考资料，这点是 JavaScript 做不到的。

整个移植过程实际花的时间比我预想的要长一些，主要原因是 PIL 文档存在模糊不清或缺失的地方。也可能是因为我自己的不足。不管怎样，符合 Python 习惯用法和符合 JavaScript 习惯用法之间的差异，比人们想象的要多。

希望这个移植多少能派上用场。我没有太多维护它的打算，但如果你有问题，我会尽力帮忙。
