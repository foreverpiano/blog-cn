Sparklines.js 的 Python 移植版

2008-09-13 · 阅读原文

既然现在似乎是我发布废弃代码的季节，我想我也可以顺便放出之前做的一个 Sparklines.js 到 Python 的移植版本——虽然基本完成，但远称不上完美。

你可以在这里下载该文件。

它使用 PIL 将 Sparklines 渲染为图像文件。大多数情况下生成的 Sparklines 都丑得可怕，虽然 API 与 Sparklines.js 相当接近，但并不完全一致。你可以说我是在一时兴起、毫无理由地发布它。它最初的目的是为了支持一个 Web 服务，该服务会通过 Sparklines.js 为网站用户动态生成 Sparklines，然后允许用户使用这个 Python 库导出一份图像文件。它实际上很好地实现了这个目的（API 略有不同，但在应用程序逻辑中很容易修正），唯一的缺点就是 Python 库生成的图像实在太丑了（这并不是吹牛，我当时正在开发的一个 Web 应用原型确实就是这么做的）。

不管怎样，我认为这种难看的外观并非无法克服，只是需要投入一点精力去打磨而已。

移植过程中的感受

Python 版本有 270 行代码，而 JavaScript 版本大约 320 行。由于我先设计了 JavaScript 库，然后才实现 Python 版本，我认为这相当有力地说明了 Python 和 JavaScript 在表达力上的差异。另一方面，在 Python 中子类化时我不需要查阅参考资料，而 JavaScript 就做不到这一点。

整个移植实际花的时间比我预想的要长一些，主要原因是 PIL 文档存在模糊不清或缺失的地方。当然也可能是我自己的问题。无论如何，符合 Python 习惯用法和符合 JavaScript 习惯用法之间的差异比人们想象的要多。

希望这个移植版能对你有点用处。我并不打算长期维护它，但如果你有问题，我会尽力提供帮助。
