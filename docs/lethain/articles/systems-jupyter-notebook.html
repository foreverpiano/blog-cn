在 Jupyter Notebook 中进行系统动力学建模

2018-09-30 · 阅读原文

几周前我发布了 systems 库的 0.0.1 版本，今天我又推出了 0.0.2 版本。这次更新几乎完全专注于让它在 Jupyter Notebook 工作流中更好地运行。Jupyter Notebook 依然是我发现的最适合进行迭代探索的工具之一。

这篇文章将一步步介绍如何在 Jupyter Notebook 中运行 systems 库。（你也可以在 Github 上看到最终的 Notebook 示例。）

安装与设置

第一步是安装 Jupyter 和 systems：

mkdir jupyter
cd jupyter
python3 -m venv ./env
source ./env/bin/activate
pip install jupyter systems

安装完成后，你可以通过以下命令创建一个 Notebook：

jupyter notebook

这应该会在你的浏览器中打开一个新标签页，指向你的 Jupyter Notebooks。你也可以通过 localhost:8888/tree 访问。

接下来创建一个新的 Notebook，给它起一个合适的名字，比如“systems exploration”之类的。

最后一步，通过在第一个代码单元格中输入以下代码来验证安装是否成功。

from systems.parse import parse
from systems.viz import as_dot
from IPython.core.display import HTML

然后点击 Run 按钮运行代码（如果是第一次运行 Jupyter，可能会花一些时间）。如果运行失败，请查看之前运行 jupyter notebook 的终端窗口，查看错误信息，并在继续之前解决这些问题。

例如，在我的电脑上，我需要先升级 prompt_toolkit 才能继续，但大多数用户应该不会遇到这个问题。

pip install --upgrade prompt_toolkit

假设一切已经正常运行，接下来就可以开始迭代构建模型了。

创建模型

这里使用的示例与相同，因为本文的重点是展示如何使用 Jupyter。用 Systems 库建模招聘漏斗

Notebook 的第一个单元格应该用来导入所需的依赖包：

from systems.parse import parse
from systems.viz import as_dot
from IPython.core.display import HTML

第二个单元格应该包含一个多行字符串，其中定义你的模型并进行解析。理论上你可以把模型定义和解析放在不同的单元格中，但我认为把它们放在一起更好，这样如果你的规格定义有问题，可以立即看到错误提示。

spec = """
[Candidate] > Recruiters(3, 7) @ 1
[Candidate] > Prospect         @ Recruiters * 3
Prospect    > Screen           @ 0.5
Screen      > Onsite           @ 0.5
# yeah and some more, eliding for example
"""
model = parse(spec)

然后你可以将模型渲染为图表：

as_dot(model)

对于较大的系统，你可以通过以下方式将从左到右的布局改为从上到下：

as_dot(model, rankdir="TB")

你还可以运行模型，并将结果以内联 HTML 表格的形式展示：

results = model.run(rounds=10)
rendered = model.render_html(results)
HTML(rendered)

把这些部分组合起来后，你就可以开始了！可以根据需要随意进行迭代。

如何绘制图表？

如果你想为输出结果绘制图表，也是很容易实现的。下面是一个使用 Bokeh 的简单示例。首先需要安装 bokeh：

pip install bokeh

然后你需要重启 Kernel，既可以通过 Notebook 中的 Kernel 菜单，也可以通过终止 Notebook 进程后重新启动。之后创建一个新的单元格，加入一些额外的导入和配置：

from bokeh.plotting import figure, output_notebook, show
output_notebook()

接着你就可以像这样渲染一条折线图：

col = "Offer"
x = list(range(len(results)))
y = [row[col] for row in results]
p = figure(title=col)
p.line(x, y)
show(p)

这会输出一个非常简单的图表，但如果你想做出更有趣的效果，可以参考 Bokeh 的官方文档继续探索！

你可以在 Github 上看到完整的示例 Notebook。
