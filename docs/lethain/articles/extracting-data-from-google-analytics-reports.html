从 Google Analytics 报告中提取数据

2008-09-11 · 阅读原文

几个月前，我和优秀的 J.D. Hollis 合作一个项目，最终编写了一个简单的 Python 脚本，用于解析导出的 Google Analytics 数据。虽然那个项目遇到了一些障碍，但这个脚本本身相当实用，于是我决定以 MIT 许可协议将其开源发布。

你可以从它的 GitHub 仓库下载 gareports_reader.py，或者直接下载整个项目文件夹的 zip 压缩包。

缘由

有时候你需要创建 Google Analytics 网页界面没有提供的自定义可视化图表，或者运行自定义的计算。你当然可以通过下载 CSV 格式的数据来实现，但导出的 CSV 数据集内容比较匮乏。另一方面，XML 数据集信息极其丰富，但要弄清楚如何正确解析 XML 并提取数据却相当困难。

gareports_reader.py 负责处理解析和提取工作，让你能够用简单的 Python 数据结构（列表、datetime 和字典）来操作这些数据。

使用方法

首先登录 Google Analytics，然后选择你想要下载的数据时间范围。

接着点击导出，并选择 XML 文件格式。

局限性

目前它仅支持 Dashboard 报告（即首页显示的报告）。扩展它以支持其他报告其实相当简单，但由于首页已经提供了极其丰富的数据集（每天的 search、unique、pageviews、newvisits、avgpageviews、direct、visists、visitors、boundrate、newvisitors、referral 和 timeonsite 等数值），对我当时的需求来说已经足够了。
