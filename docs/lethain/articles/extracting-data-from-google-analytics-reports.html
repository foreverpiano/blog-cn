从 Google Analytics 报告中提取数据

2008-09-11 · 阅读原文

几个月前，我和优秀的 J.D. Hollis 合作一个项目，当时写了一个简单的 Python 脚本，用于解析导出的 Google Analytics 数据。虽然那个项目遇到了一些阻碍，但这个脚本本身还是很有用的，于是我决定以 MIT 许可将其开源发布。

你可以从它的 GitHub 仓库下载 gareports_reader.py，也可以直接下载整个项目文件夹的 zip 压缩包。

理由

有时候你想创建自定义的可视化图表，或运行 Google Analytics 网页界面所没有的自定义计算。你确实可以通过下载 CSV 格式的数据来实现，但导出的 CSV 数据集内容相当有限。另一方面，XML 数据集信息非常丰富，但要弄清楚如何正确解析 XML 并提取数据却并不容易。

gareports_reader.py 负责处理解析和提取工作，让你可以用简单的 Python 数据结构（列表、日期时间和字典）来操作这些数据。

使用方法

首先登录 Google Analytics，然后选择你要下载的数据时间范围。

接着选择导出，并选用 XML 文件格式。

然后进入一个同时包含 gareports_reader.py 和你导出的数据文件的文件夹。

wills-macbook:gareports_reader will$ ls
Analytics_www.lethain.com_20080811-20080910_(DashboardReport).xml
LICENSE
gareports_reader.py

我通常会把 XML 文件重命名为更容易输入的名字。

mv Analytics_www.lethain.com_20080811-20080910_(DashboardReport).xml lethain.xml

接着启动 Python 解释器（应该能在 2.4 上运行，但记不太清了，可以肯定的是它能在 2.5 上正常运行）。

>>> from gareports_reader import GoogleAnalyticsReportParser
>>> fin = open('lethain.xml','r')
>>> data = GoogleAnalyticsReportParser(fin.read())
>>> fin.close()
>>> dir(data)
['__class__', '__delattr__', '__dict__', '__doc__', '__getattribute__', '__hash__', '__init__', '__module__', '__new__', '__reduce__', '__reduce_ex__', '__repr__', '__setattr__', '__str__', '__weakref__', 'contents', 'dates', 'domain', 'end', 'et', 'known_report_types', 'pageviews', 'parse_dashboard', 'start', 'type']
>>> data.domain
'www.lethain.com'
>>> data.start
datetime.datetime(2008, 8, 11, 0, 0)
>>> data.end
datetime.datetime(2008, 9, 10, 0, 0)

上面可以看到一些基本功能，但真正有价值的内容都在 dates 这个字段里。dates 是一个按时间顺序排列的列表，每个元素都是一个二元组（一个 datetime 对象和一个字典），形式如下：

>>> data.dates[0]
(datetime.datetime(2008, 8, 11, 0, 0), {'Search': '237.0', 'Unique': '963.0', 'Pageviews': '1100.0', 'NewVisits': '0.7579365079365079', 'AvgPageviews': '1.4550264550264551', 'Direct': '93.0', 'Visits': '756.0', 'Visitors': '690.0', 'BounceRate': '0.8293650793650794', 'NewVisitors': '0.7579365079365079', 'Referral': '426.0', 'TimeOnSite': '86.744708994709'})

因此，我们可以这样创建一个每天页面浏览量的列表，然后这样计算总数：

>>> pageviews = [ x[1]['Pageviews'] for x in data.dates ]
>>> reduce(lambda a,b: float(a) + float(b), pageviews)
38557.0

你还可以计算平均页面浏览量……

>>> total = reduce(lambda a,b: float(a) + float(b), pageviews) 
>>> qty = len(pageviews)
>>> total / qty
1285.2333333333333

请注意，所有数值都是以字符串形式存储的，所以在使用前需要先转换成浮点数。

总之，gareports_reader.py 让 Google Analytics 的数据变得非常易于访问，你可以据此创建自己感兴趣的图表并进行各种计算。

限制

目前它只支持 Dashboard 报告（即首页显示的那个报告）。要扩展它支持其他报告其实相当简单，但由于首页已经提供了非常丰富的数据集（每天的 search、unique、pageviews、newvisits、avgpageviews、direct、visists、visitors、boundrate、newvisitors、referral 和 timeonsite 等数值），对我当时的需求来说已经足够了。
