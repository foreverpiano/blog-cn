BossArray：像列表一样处理 Yahoo 搜索结果

2008-07-28 · 阅读原文

已经很久没有做一些纯粹为了自己兴趣的小型趣味项目了。这个想法我在脑子里盘算了几个星期，终于抽出几块时间把它实现了出来。我很高兴地宣布 boss_array.py 诞生了，它是对 Yahoo BOSS Mashup Framework 的一个友好封装，让搜索结果可以像普通 Python 列表一样使用。我们先来看一个例子。

这里有几个很方便的功能：

创建 BossArray 时只需指定一次查询条件，之后它就会记住你的搜索关键词；可以通过 len() 函数轻松获取搜索结果总数；允许一次性获取超过 50 条结果（搜索 API 单次查询最多返回 50 条，但 BossArray 会自动把大请求拆分成多个查询，目前是顺序执行，所以如果一次性获取非常多的结果可能会稍慢）；所有搜索结果都会被 BossArray 缓存。这意味着如果你先获取 x[0:20]，再获取 x[5] 时就不会再发起 HTTP 请求。如果你尝试获取 x[5:15]，同样会使用缓存的结果。这种机制在更复杂的情况下也能很好地工作，例如：>>> _ = x[0:50] >>> _ = x[100:150] >>> _ = x[0:200] BossArray 会智能地处理这种情况：在最后一次 x[0:200] 的查询中，它会复用已缓存的 0-50 和 100-150 的结果，只需要额外发起两次查询来填充 50-100 和 150-200 的缺失部分。
