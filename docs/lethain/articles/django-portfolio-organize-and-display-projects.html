Django-Portfolio：整理并展示你的项目作品

2008-12-29 · 阅读原文

无论你是顾问、承包商、爱好者还是学生，只要你是一名程序员（或设计师、作者等等），你就一定有自己的项目。如果你是一名有个人网站的程序员，那你很可能已经花了不少时间，反复编写那些用来美观展示和组织项目的样板代码。不过，以后不用再这样了。

Kevin Fricovsky 和我都一直在思考如何更好地展示个人项目，于是就有了 django-portfolio。它是一个可插拔、可复用的 Django 应用，专门用于展示、分组和整理个人项目。在过去几周里，它已经逐渐成型（Kevin 的 GitHub 仓库是官方仓库，但目前我的 fork 版本功能更完整一些）。

第一个可实际运行的示例——以及几张截图——就在这里，它正驱动着我的“项目”专区（你甚至可以看到用 django-portfolio 展示它自己的项目页面）。

功能特点

  1. Group projects by categories (one to many).
  2. Assign tags to projects (many to many).
  3. View list of projects grouped by either category or tag.
  4. Assign 0+ files and images per project.
  5. Example project using jQuery to click through all images (example here).
  6. Optional pull quotes (example here).
  7. Simple, resuable, still malleable for your input and changes.

未来计划

  1. Integration with repositories.Build zip/tar of repository on demand.Pull the project's README and render it for project detail page.
  2. Management command to resize all images. (I'm just using an automator script for this currently... not great but workable.)

欢迎随时把你的想法告诉 Kevin 或我，也可以直接 fork 这个仓库。
