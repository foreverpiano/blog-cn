Django-Portfolio：整理与展示你的项目

2008-12-29 · 阅读原文

无论你是咨询顾问、承包商、业余爱好者还是学生，只要你是一名程序员（或者设计师、作者等等），你都会有自己的项目。如果你是一名有个人网站的程序员，那么你很可能已经花了不少时间，反复编写样板代码来漂亮地展示和组织你的项目。但现在，不需要再这样了。

Kevin Fricovsky 和我一直都在思考如何更好地展示个人项目，这个想法逐渐成型为 django-portfolio。它是一个可插拔、可复用的应用，用于展示、分组和组织个人项目。在过去几周里，它已经开始变得充实起来（Kevin 的 GitHub 仓库是官方仓库，但目前我的 fork 版本稍稍领先一些）。

第一个可实际使用的例子——以及几张截图——就在这里，它正驱动着我的“项目”专栏（你甚至可以看到用 django-portfolio 自身来展示 django-portfolio 项目页面的效果）。

功能特性

按分类对项目进行分组（一对多）。为项目分配标签（多对多）。查看按分类或标签分组的项目列表。为每个项目关联 0 个或多个文件和图片。使用 jQuery 点击浏览所有图片的项目示例（可在此查看）。可选的引用摘录（可在此查看）。简单、可复用，仍具有足够的灵活性，欢迎你提出意见和修改。

未来想法

与代码仓库集成。按需生成仓库的 zip/tar 压缩包。拉取项目的 README 并在项目详情页渲染。调整所有图片尺寸的管理命令。（我目前使用的是一个 automator 脚本……不是特别优雅，但还能用。）

如果你有任何想法，欢迎告诉 Kevin 或我，或者直接 fork 这个仓库。
