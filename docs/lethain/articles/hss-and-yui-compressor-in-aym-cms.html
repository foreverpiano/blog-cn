AYM CMS 中的 HSS 和 YUI Compressor

2008-10-19 · 阅读原文

不久前我写过一篇关于 AYM CMS 的文章，它是一个基于 Django 的项目，用于生成复杂的静态网站（顺便说一下，它也是 Resume Interactivity Provider 的驱动引擎）。后来我开始经常在工作和个人项目中使用它，并做了一些有用的改进。

你可以从 Github 获取最新版本。

HSS 集成

当我编写较长的 CSS 文件时，常常希望能使用变量。现在借助这个小巧精致的项目，我终于可以实现了。（你也可以。）

在 AYM CMS 中使用 HSS 非常简单：

下载 HSS 程序。 执行 chmod +x hss 使其可运行。 在 settings.py 中设置 HSS_PATH 指向 hss 的路径。如果把它移到项目同一目录下，配置如下：HSS_PATH = "./hss" 在 static/ 目录中随意编写 .hss 文件。 运行 python build.py 时，这些文件会被编译成同名的 .css 文件。例如 my_style.hss 将生成 my_style.css。

忽略无用文件

这与其说是一个新功能，不如说是修复了之前的疏漏。以前类似 something.css~ 或 .#tmfile.css# 之类的垃圾文件经常会混进 deploy/static/ 目录，现在这种情况不会再发生了。
