AYM CMS 中的 HSS 和 YUI Compressor

2008-10-19 · 阅读原文

前段时间我介绍过 AYM CMS，这是一个基于 Django 的项目，用于生成复杂的静态网站（顺便说一下，它也是 Resume Interactivity Provider 的底层引擎）。后来我开始经常在工作和个人项目中使用它，并做了一些实用的改进。

你可以在 Github 上获取最新版本。

YUI Compressor 集成

现在所有 .js 和 .css 文件都会通过 YUI Compressor 进行压缩，前提是在 settings.py 中正确设置了 YUI_COMPRESSOR 的路径。如果你把 jar 包放在和 build.py 脚本相同的目录下，只需添加以下配置：

YUI_COMPRESSOR = u"yuicompressor-2.3.6.jar"

如果你不想压缩文件，将该值设为 None 即可。

YUI_COMPRESSOR = None

HSS 集成

当我编写较长的 CSS 文件时，常常希望能使用变量，现在借助这个精巧的小项目，我终于可以实现了。（你也可以。）

在 AYM CMS 中使用 HSS 非常简单：

chmod +x hss

HSS_PATH = "./hss"
下载 HSS 程序。将其设置为可执行文件。在 settings.py 中设置 HSS_PATH 指向 hss 的位置。如果你把它放到项目所在目录，配置如下：在 static/ 目录中随意编写 .hss 文件。运行 python build.py 时，这些文件会被编译成同名的 .css 文件。例如 my_style.hss 将生成 my_style.css。

简单介绍一下为什么要使用 HSS，因为它允许你这样写代码：

var colorOne = #AAAAAA;
var colorTwo = #FFFFFF;
var titleCSS = { font-size: 2.5em; color: #ABACAD; }
var colorThree = #BBBBBB;
var font = "Georgia";
body {
font-family: $font;
}
#head {
color: $colorOne;
.title {
$titleCSS;
}
a {
color: $colorTwo;
}
}
#foot {
color: $colorOne;
.title {
$titleCSS;
}
a {
color: $colorThree;
}
}

上面这段代码会被编译成符合你预期的 CSS 文件。

如果你不想使用 HSS，只需在 settings.py 中将其值设为 None 即可。

HSS_PATH = None

在 AYM CMS 中使用 CleverCSS

我还为 AYM CMS 接入了 CleverCSS 支持，构建脚本运行后会将 static/ 目录中的 CleverCSS 文件转换为 deploy/static/ 目录下标准的 .css 文件。

CleverCSS 和 HSS 功能类似，但它更偏向 Python 风格，同时还有其他一些巧妙的设计。你可能会更喜欢其中某一个，两者任选即可。CleverCSS 最大的优点是安装比 HSS 简单得多：

sudo easy_install CleverCSS

配置需要在 settings.py 中设置两个选项：

USE_CLEVER_CSS = True
CLEVER_CSS_EXT = ".ccss"

默认情况下它只将 .ccss 文件视为 CleverCSS，因为如果对普通 CSS 文件运行 CleverCSS 处理，脚本会出错。但如果你只使用 CleverCSS，也可以把该值改成 .css。

请注意，由构建脚本生成的文件扩展名始终是 .css，无论原始文件是什么扩展名。

忽略无用文件

这与其说是一个新功能，不如说是对之前疏漏的修复。以前像 something.css~ 或 .#tmfile.css# 之类的垃圾文件经常会混进 deploy/static/ 目录，现在这种情况不会再发生了。
