我在 Carta 学到的东西

2025-05-23 · 阅读原文

今天是我在 Carta 的最后一天，过去两年我有幸担任他们的 CTO。在那里工作让我学到了很多，我想用整理这些收获来为我的 Carta 篇章画上句号。（我正要去往新的地方，一两周内等与新团队敲定沟通方案后，就会分享相关消息。）

我在 Carta 学到的最重要的事情是：

深入细节——如果用批判的眼光审视我过去的领导风格，我认为最大的问题就是我太习惯在高度抽象的层面工作。利用他人的专业知识来填补自己的空白是一项宝贵的技能，但——和任何单一方法一样——如果使用过于频繁，就会变得局限。Carta“内部领导风格”的一个优点，就是要求领导者深入细节来获取信息并推动节奏。我在那里练习的方法，后来形成了策略测试：避免瀑布式策略陷阱，通过迭代优化。和培养领域专长：亲身实践，动手去做。这两篇文章。完善我的工程战略方法——在过去18个月里，我写了一本关于工程战略的书（所有文章都在 #eng-strategy-book 中），初始章节下个月会通过 O’Reilly 提前发布。希望这本书能在大约10月正式出版。加入 Carta 之前，我已经有了关于如何做工程战略的核心论点，但 Carta 给我提供了许多复杂项目来实践，还有优秀的人一起协作：特别感谢 Dan、Shawna 和 Vogl！关于这个项目的更多内容将在未来几周分享。提炼核心。——在我工作过的每个地方，团队都很难理解高管的意思。在每种情况下，高管确实可以表达得更清晰，但把这些问题框定为“高管需要修复”的问题并不特别有建设性。当然，他们可以沟通得更好，但这种框定会让你感到无能为力，而实际上你拥有很大的力量去理解那些令人困惑的沟通。毕竟，即使是优秀的沟通者有时也会表达不清。有意义地采用 LLM——一年前，我根据当时的经验写下了如何在你的产品中使用大语言模型（LLM）的笔记。从那以后，我们又学到了更多，LLM 本身也有了显著进步。Carta 使用 LLM 处理真实、影响业务的流程已经超过一年。这种应用还在继续扩展到解决更复杂的内部流程，更令人兴奋的是，它正在创造全新的产品能力，这些能力应该会在未来几个月内更广泛地推出（目前仅向小范围 beta 组发布）。这是我第一次以高级领导角色经历重大技术转型（因为我在职业生涯早期时，移动互联网才从新鲜事物变成普遍商品）。那种“必须更快采用”的巨大压力，以及“它究竟是意义重大的变革还是短暂热潮”的巨大不确定性，过程非常有趣，也如何采用大语言模型（LLMs）？。多维度权衡——Henry Ward 经常说的一句话是“每个人都是对的，只是高度不同。”这个想法深深触动了我，它与有价值的权衡是多维度的。和多层上下文。的理念非常契合，我发现这些理念能显著改善那些需要做出大量复杂决策的人的决策质量。在 Carta 工作，让这些想法从我直觉感知的东西，变成了我能清晰阐述的内容。导航者——我认为 Carta 最成功的工程战略之一是推出 Navigator 项目，它确保最资深的工程师能直接获得上下文和代表权，而不是完全依赖工程管理层的间接代表。Carta 的工程经理都很优秀，但当讨论跨越多个层级时，总会有信息损失。Navigator 项目可能不完全适合特别小的公司，但我认为任何拥有100-150名以上工程师的公司都会从类似机制中受益。如何打造软件质量——我对软件质量的思考多年来有了很大演进，但 Carta 特别帮助我弄清楚，为什么有些软件从数据或并发角度几乎没有规模，却仍然极其难以构建。我把这类系统称为“高本质复杂性”，它们 deserve 更多对其复杂性的认可，即使它们在基础设施扩展方面的复杂性很低。塑造工程组织成本——几年前，我写过自己管理基础设施成本的心智模型。在 Carta，我有机会进一步完善关于工程人力成本的思考，其中大部分想法都融入了驾驭私募股权所有权战略，以及工程组织层级结构模型。三个最大的杠杆是（1）“N-1 回填”，（2）要求晋升到最高级别时必须有明确的业务理由，以及（3）将招聘转向成本更优的地区。这些都不是能激发人的振奋话题，但它们对组织的长期稳定都至关重要。向董事会和高管解释工程成本——同样，我终于对如何用董事会熟悉的语言来呈现研发投资有了清晰的认识，上市公司可比分析。，并且知道如何快速完成，而不需要依赖任何手动维护的内部数据集。还有很多较小的收获，比如用于将同事引导到合适渠道的没有错误的门。、如何以能说服高管的方式如何获得更多人力。、关于人们在漫长职业生涯中动机如何演变的不可或缺 / 事业心重 / 第二幕动机（以及我个人职业使命——推动行业发展），为什么摩擦不等于速度。，尽管很多人把它当成一回事。

我还学到了很多关于风险投资、基金管理、股本表、非社交网络产品、运营多业务线公司以及各种运营模式的内容。如何在不泄露内部细节的前提下，把这些学习成果提炼成有趣的分享，过程有点太痛苦，所以我暂时省略了。也许在四五年后，当我的上下文足够过时，其中一些内容会变得可以分享。

作为结束语，我只想说，我非常感谢在 Carta 共事过的所有人。从管理团队（Ali、April、Charly、Davis、Henry、Jeff、Nicole、Vrushali），到我的直接下属（Adi、Ciera、Dan、Dave、Jasmine、Javier、Jayesh、Karen、Madhuri、Sam、Shawna），再到 Navigators（你们有很多人）。人永远是最好的部分，在 Carta 也绝对如此。
