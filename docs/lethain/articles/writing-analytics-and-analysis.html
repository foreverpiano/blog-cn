写作、数据与洞察

2011-04-10 · 阅读原文

你要么靠数据驱动，要么靠直觉行事。

如果你拥有敏锐的直觉和强大的团队，那么你会做得非常出色。但问题的关键在于：直觉无法脱离数据来衡量。因此，即使你确实在做出优秀的决策，你本质上仍是在靠自我感觉行事。

这一关键点在利用数据理解流量和使用情况时同样成立：如果你对数据使用有良好的直觉，你会做得很好；否则，你就需要关于“数据使用”的数据。

这确实是个两难困境。不如让我们来谈谈数据分析。

将数据分析作为读者的阅读语境

互联网上的内容创作者往往与读者之间存在完全的信息不对称：作者无所不知，而读者一无所知。对于那些思考过这种状况的出版者，我猜很多人更喜欢这种不对称——因为“在互联网上，没人知道你是一条狗”，他们也不想让别人知道自己投入了多少时间去写那些很少有人阅读的内容。（对职业出版者来说，还有竞争层面的考量。）

最近我逐渐形成一个假设：与读者分享有用的分析数据，能为他们正在阅读的内容提供语境，从而改善他们的阅读体验。

正如知道一篇文章是四年前发布的可能是个警示信号一样，知道自己是某篇文章的早期读者，也能提醒你这可能是一个粗糙的版本或不受欢迎的来源。如果能看到这个网站过去一周的页面浏览量，你的阅读体验是否会因此改变？

如果你还能看到主要流量来源和热门内容呢？上周末我为这个博客 hastily 拼凑了一个分析系统，并开始在 /analytics/ 页面公开这些数据以及更多信息。

如果你主要想了解单篇内容的全生命周期（研究内容是否被传播，无疑是业余出版者最有趣的工作之一），你就需用另一种视角来分析数据。基于此，这个网站上每篇文章的分析数据，都可以通过在原 URL 前加上 /analytics/ 来查看。

例如：

构建可扩展系统的架构导论

会变成

/analytics/introduction-to-architecting-systems-for-scale/

目前你可以看到一些汇总统计、近期的每日浏览量，以及该内容的顶级流量来源。未来可能还会添加更多功能。

我还计划将这些信息逐步融入右侧栏模块中，但目前仍处于思考实验的阶段。

数据来源

这些分析数据来自三个渠道。首先是 Google Analytics 四年的历史存档。其次，我从 Nginx 访问日志中提取了自从我[不使用 Google Analytics 重新上线这个博客](Irrational Exuberance’s Third Rebirth)以来的数据。最后，我还添加了实时事件追踪，覆盖从昨天部署追踪机制以来的所有行为。

访问日志解析器和实时事件解析器共用了一些基本机制来过滤自动化流量，这些机制目前效果不错，成功让流量水平在从 Google Analytics 切换到自制系统后保持稳定。具体的机制包括：

一个需要忽略的用户代理黑名单；忽略所有用户代理中大小写不敏感匹配“bot”字符串的请求；每个 IP 每分钟只统计第一次行为，即使漏掉某个机器人，其突发行为的影响也会被大大减轻。（这是通过 Redis 的 watch、multi、exec 命令以及检查时间桶 key 是否存在来实现的。）

那些不在黑名单中、用户代理不包含 bot、且将请求限制在每个 IP 每分钟一次的自动化行为，仍然会被统计。但我追求的是方向正确的分析数据，以便研究内容的传播和使用情况，并不太在意是否有少量自动化流量混进来。

四年的数据

在整合多个数据源的过程中，我制作了几张图表，展示这个博客至今的整体情况。

首先是从一开始的每日页面浏览量。

这张图最让我印象深刻的是，在我两年前不再频繁写作之后（恰逢工作开始变得繁重，并且此后一直如此），流量依然表现出惊人的韧性。

接下来是热门流量来源，没有太多意外。

在我上次频繁写作的时候，我的感觉是，只有社交新闻聚合网站（特别是我所处领域的 Reddit Programming 和 Hacker News）才能带来流量高峰。

查看最近一篇文章的分析数据后，我很好奇 Twitter 和 Facebook 是否能在细分技术内容领域与聚合网站一较高下。（我的假设是，有相当一部分直接流量来自没有设置 referrer 的原生 Twitter 客户端，但很难下定论。）

将过去四年的流量累加，Google Analytics 显示这些内容总共获得了约 120 万次有效页面浏览。如果我更积极地投放广告（假设每次点击 0.1 美元，点击率 1%），我本可以赚到 1200 美元。

考虑到写作所花费的时间，这其实是一笔相当糟糕的交易。但这个博客确实帮我拿到了第一份开发工作——稍微换个角度衡量，它已经带来了巨大的回报。

未来在召唤

有了这些分析数据，我非常期待开始尝试不同的内容形式（、等等），以及不同的主题（Redis、架构、Python 等等）！使用 Flot.js 结合 Digg Streaming API别逼我为你的观点辩护

最重要的是，我很高兴能重新开始写作。
