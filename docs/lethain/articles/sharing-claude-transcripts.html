分享 Claude 对话记录

2026-01-10 · 阅读原文

我支持 在 Imprint 推动 AI 采用 的核心前提之一是，采用程度取决于能否轻松发现什么是可行的、什么是好的。正因如此，我们驱动 Agent 的内部 Prompt 都存储在一个共享的 Notion 数据库中，但这也引出了一个问题：我们最先进的 Prompt 工程和交互其实发生在 Claude Code 里，而这些内容却很难被看到。

幸运的是，Simon Willison 之前写过一个工具 claude-code-transcripts，可以从 Claude Code 中提取对话记录。我们将其接入内部系统，构建了一个 Claude Code 会话的内部仓库，并通过 Cloudflare Pages 提供了一个查看器（并通过 Cloudflare 认证接入我们的 SSO）。

这套方案包含三个部分。首先是一个所有页面的索引。

这个页面会链接到由 Simon 的工具生成的对话记录。

最后，我们有一个名为 imp 的内部 CLI，已部署在每一台笔记本电脑上，现在新增了一个命令 imp claude share-session。它会打开 claude-code-transcripts，让你选择想要的会话，然后将其合并到中央仓库中。

整个过程只花了一两个小时，也算是一次关于涌现式流程设计的实验。短期内，我很享受让公司里最重度的 Claude Code 用户分享他们的会话，这样我就能从中挑选出值得推广的最佳实践。
