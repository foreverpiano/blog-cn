分享 Claude 对话记录

2026-01-10 · 阅读原文

我支持 推动 Imprint 的 AI 采用 的核心前提之一是：采用效果取决于能否轻松发现什么可行、什么优秀。这也是为什么我们会把驱动 Agent 的内部 Prompt 都存放在一个共享的 Notion 数据库里，但这也引出了另一个问题：我们最先进的 Prompt 工程和交互其实发生在 Claude Code 中，而这些内容却很难被看到。

幸运的是，Simon Willison 之前写过一个工具 claude-code-transcripts，可以用来提取 Claude Code 的对话记录。我们把它接入了内部的 Claude Code 会话仓库，并在 Cloudflare Pages 上搭建了一个查看器（通过 Cloudflare 认证后接入我们的 SSO）。

这套方案包含三个部分。首先是一个所有页面的索引。

这个索引页面会链接到由 Simon 的工具生成的对话记录。

最后，我们有一个名为 imp 的内部 CLI工具，在每台笔记本上都可以使用。它新增了一个命令 imp claude share-session，能打开 claude-code-transcripts，让你选择想要的会话，然后将其合并到中央仓库中。

整个过程大概只花了一两个小时，也算是一次关于“涌现式流程设计”的小实验。短期内，我很享受让公司里最 heavy 的 Claude Code 用户分享他们的会话，然后从中精选出值得推广的最佳实践。
