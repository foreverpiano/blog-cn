《非理性繁荣》的第四次降临

2014-03-24 · 阅读原文

虽然我自己很难相信（我知道没人会在意），但距离我这个可怜的网站，已经整整过去快三年了。它从 Blueprint CSS 换成带 Reset 的自定义 CSS，现在又换成了 Bootstrap。对于转向 Bootstrap，我的心情有些复杂，毕竟它已经变得太过流行，但它确实能让人非常轻松地做出一个可用的布局。《非理性繁荣》的第三次重生

第三版是我五年博客生涯的集大成之作，包含三百多篇文章，以及在 Digg 负责故事详情页时积累的、对内容优化的种种思考。

前端被重写，尽可能把注意力集中在内容本身；后端也彻底重构，追求极致的速度、实时收集使用数据，并根据这些数据推荐最好的内容。

老实说，我对第三版相当满意，当时 @mtrier 甚至公开表示「再访问这个博客终于不会闪瞎我的狗眼了」，算是极高的赞誉。只是后来有一些小的渲染问题开始不断烦扰我，我很想把它再收拾得干净一点。

对我来说，核心问题只有两个：

能不能让「写作」——也就是这个博客存在的根本意义——得到更多的强调？能不能消除那些让我看起来像疯了一样的视觉怪癖？

这就是这次的更新——显然没有偏离此前版本或 Bootstrap 本身太多。

在我看来，这次改进主要有以下几点：

对比度更合理：文章标题拥有最高对比度，能第一时间吸引目光。以前 header 和标签对比度反而更高，尽管它们没那么重要。右侧边栏的视觉权重也降低了。响应式：现在在绝大多数屏幕尺寸下都能正常显示，这要感谢 @segdeha 之前指出它渲染得有多糟糕。减少了色彩种类：之前的颜色虽然有种温暖的感觉，但也比较两极分化。现在彻底抛弃了。将「Projects」和「Resume」改成「Github」和「LinkedIn」，并新增了「Twitter」。同时删掉了「About」页面，那个页面从一开始就相当误导。

我还把 willarson.com 301 重定向到了 lethain.com，原因不言自明。

关于那些颜色，我还能说什么呢？我当时还年轻，充满乐观。而且那个页面我已经快三年没更新过了，这本身就说明我不太可能继续维护它。

完成这些改动，再加上清理我在互联网上的各种存在（换上几个月前新拍的头像、更新各种资料、合并一些拖了很久的 Pull Request 等等），我开始觉得自己像一个崭新的我。
