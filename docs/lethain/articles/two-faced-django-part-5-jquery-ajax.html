双面 Django 第 5 部分：JQuery Ajax

2007-12-11 · 阅读原文

最近我们花了很多时间在一起，你可能在想，我是不是打算在完全没有涉及 Ajax 的情况下就结束这个系列。这是一个非常合理的担忧。不过请放心，本教程的这一部分将介绍如何使用 JQuery 在我们的 Web 应用中实现 Ajax 投票。如果你没有跟上前面的文章，请下载我们项目当前进度的快照。

为 Web 应用添加 JQuery

我们需要做的第一件事是下载 JQuery。我建议下载未压缩版本，因为当你不需要阅读被压缩混淆过的 Javascript 时，调试会变得愉快得多……

var x = m45(k32, a32);
n41(x);

那是什么意思？我完全不清楚。但如果你想知道，可以下载上面链接的压缩版库，而不是未压缩版本。

下载完库之后，你需要把它移动到 polling/media/web/ 文件夹中。为了简单起见，我们将把它重命名为“jquery.js”。

mv jquery-1.2.1.js jquery.js

现在我们只需要修改 polling/templates/web/base.html 文件来引入 JQuery 库。首先打开这个文件

emacs templates/web/base.html

现在我们要把模板顶部的代码从

<html> <head>
<title>{% block title %}A Generic Title{% endblock %}</title>
</head>

<html> <head>
<script type="text/javascript" src="/media/web/jquery.js"></script>
<title>{% block title %}A Generic Title{% endblock %}</title>
</head>

完成了一项待办任务。还有几项要继续。

为 Ajax 添加 URL

继续打开 Web 应用的 urls.py。它位于 polling/web/urls.py。

emacs web/urls.py

在设计 URL 时，你可能会考虑使用类似这样的形式：

(r'^poll/(?P<id>\d+)/vote/up/$', 'polling.web.views.vote_up'),
(r'^poll/(?P<id>\d+)/vote/down/$', 'polling.web.views.down_down'),

这样你就可以向 /poll/4/vote/up/ 发送 Ajax（虽然我其实只是指异步）请求来为投票 4 投赞成票，向 /poll/13/vote/down/ 发送 Ajax 请求来为投票 13 投反对票。这是一种完全合理的方式来组织你的 URL。

在本教程中，我们将采用另一种方式：

(r'^vote/$', 'polling.web.views.vote'),

我们不再那么依赖所请求的 URL，而是更多地依赖随请求一起传递的 GET 参数。为什么这样更好？嗯，它确实能让我们只写一个视图而不是两个（尽管那个视图会比两个视图更复杂一些），但真正的优势有点刻意：它给了我们一个机会来展示如何用 Django 模板重写 Javascript 代码片段。

你的 web/urls.py 现在应该像这样：

from django.conf.urls.defaults import *
from polling.core.models import *
polls = Poll.objects.all()
urlpatterns = patterns('',
    (r'^$', 'django.views.generic.list_detail.object_list', 
     dict(template_name='web/poll_list.html', queryset=polls)),
    (r'^poll/(?P<object_id>\d+)/$', 'django.views.generic.list_detail.object_detail',
     dict(template_name='web/poll_detail.html', queryset=polls)),
    (r'^create/$', 'polling.web.views.create'),
    (r'^vote/$', 'polling.web.views.vote')
)

现在我们需要在 web/views.py 文件中编写那个讨厌的 vote 视图。

编写 vote 视图

刚才我提到，我们将通过 GET 请求发送数据来与 vote 视图通信。我们首先需要确定的是，我们期望接收哪些数据，以及如何标记它们？

我们需要两部分数据：

要投票的 poll 的主键，以及它应该是赞成票还是反对票。

因为我脑子比较简单，我们将把这些需求转换成两个键：'pk' 和 'vote'，我们期望 'pk' 是一个代表 poll 主键的整数，并且 'vote' 的值应该是 'up' 或 'down'。

经过这个高度民主的设计讨论后，我们准备开始编写视图。首先打开 web/views.py 文件。

emacs web/views.py

我们需要做的第一件事是导入 simplejson：

from django.utils import simplejson

并且把导入 HttpResponseRedirect 的那一行从

from django.http import HttpResponseRedirect

from django.http import HttpResponse, HttpResponseRedirect

现在我们需要编写 vote 视图。在看代码之前，我们先规划一下它应该如何工作：

检查请求是否是 GET 类型。如果不是 GET 类型，则失败。如果是 GET 类型，则检查是否存在 'pk' 和 'vote' 参数。如果其中一个或两个参数不存在，则失败。如果两者都存在，则获取对应的 poll，并根据 'vote' 的值进行赞成或反对投票。

好的，现在来看看用 Python 怎么写。

def vote(request):
    results = {'success':False}
    if request.method == u'GET':
        GET = request.GET
        if GET.has_key(u'pk') and GET.has_key(u'vote'):
            pk = int(GET[u'pk'])
            vote = GET[u'vote']
            poll = Poll.objects.get(pk=pk)
            if vote == u"up":
                poll.up()
            elif vote == u"down":
                poll.down()
            results = {'success':True}
    json = simplejson.dumps(results)
    return HttpResponse(json, mimetype='application/json')

你首先会注意到，我们在函数的第一行给 result 设置了一个默认值。这不是必须的，但它意味着我们只需要在一个地方设置它，而且函数只有一个出口（这使得跟踪函数逻辑更容易，如果出问题也更容易调试）。

接下来你会注意到的（因为……它是第二行）是：

if request.method == u'GET':

这是 Django 推荐的判断当前请求类型的方式。另一个常见的使用场景是处理 POST 请求（我们在上一个教程部分编写创建新 poll 的视图时就这么做过）。

注意我们使用 *has_key()* 方法来检查 QuerySet（一个类似于 Python 字典但比它略快的 Django 类）中是否包含我们关心的两个键 'pk' 和 'vote'。最后要提的两点是，我们在这里到处使用 unicode 字符串，这是因为 Django 现在在内部使用 unicode 字符串，所以所有你要比较的内容都会是 unicode。由于你的应用将来很可能遇到非 ASCII 数据，所以统一使用 unicode 是明智的。

最后一部分是关于 simplejson 的。Simplejson 是一个将基本 Python 数据结构序列化为 JSON 的库，因此它是最容易与 Javascript 通信的方式。simplejson.dumps() 函数接受一个基本的 Python 数据结构，并返回一个表示它的 JSON 字符串。

好了。这就是我们的视图。现在我们只需要在某个模板中注入一些 JQuery Javascript 代码，我们就完成了。

使用 JQuery 实现投票

现在我们只需要用 JQuery 写几行 Javascript 来避免大多数麻烦。继续打开 polling/templates/web/poll_detail.html。

emacs templates/web/poll_detail.html

现在我们直接内联几行 Javascript（我把它放在 id 为 'upvote' 和 'downvote' 的 span 所在的段落正上方）。

<script>
function vote(kind) {
  $.getJSON("/vote/", { pk:{ { object.pk }}, vote: kind }, function(json){
    alert("Was successful?: " + json['success']);
  });
}
function addClickHandlers() {
  $("#upvote").click( function() { vote("up") });
  $("#downvote").click( function() { vote("down") });
}
$(document).ready(addClickHandlers);
</script>

vote() 函数用于进行赞成或反对投票，注意我们如何创建一个包含 'pk' 和 'vote' 值的哈希表（类似于 Python 字典）。这些就是随我们的 GET 请求一起传递给位于 '/vote/' URL 的 Django 服务器的参数。其中最有趣的部分是 {{ object.pk }} 这段代码。我们在这里使用 Django 模板语言实时修改 Javascript。这是一个很方便的技巧。

其他有趣的地方不分先后：

$("#upvote") 是 JQuery 选择 id 为 'upvote' 元素的方式；$(document).ready(callThisFunc); 是 JQuery 用于在网页中的 DOM 元素创建完成后加载 Javascript 的技巧（用大白话说，就是在 HTML 元素实际存在可以被修改时调用 Javascript）。$("someelement").click(callThisFunc); 替代了标准的 Javascript ele.onclick = someFunc，JQuery 将一个函数作为参数传递给 click 函数。这是 JQuery 理念的延续——函数应该始终返回有用的值，因此你可以将调用链式地写在一起。

好了。所以，我们的 templates/web/poll_detail.html 整体应该看起来像这样：

{% extends "web/base.html" %}
{% block title %} Poll: { { object.question }} {% endblock %}
{% block body %}
<div id="poll">
  <p>We have a question for you. { { object.question }}
  <p> So far we have { { object.up_votes }} upvotes and { { object.down_votes }} downvotes, for an overall vote of { { object.score }}! </p>
  <script>
  function vote(kind) {
    $.getJSON("/vote/", { pk:{ { object.pk }}, vote: kind }, function(json){
      alert("Was successful?: " + json['success']);
    });
  }
  function addClickHandlers() {
    $("#upvote").click( function() { vote("up") });
    $("#downvote").click( function() { vote("down") });
 }
 $(document).ready(addClickHandlers);
  </script>
  <p> Do you <span id="upvote">agree</span> or <span id="downvote">disagree</span>? </p>
</div>
{% endblock %}

现在我们只需要确认它能正常工作，然后就完成了。

验证我们的进度

首先，我们启动开发服务器：

python manage.py runserver

然后导航到投票列表（除非你还没创建任何 poll，那么先去这里创建一个）。点击任意一个 poll，你应该会被带到该 poll 的详情页。

现在点击屏幕底部标有“agree”或“disagree”的文字。它应该会弹出一个 Javascript 警告，显示类似“Was successful?: True”的内容。如果你看一下上面的 Javascript 代码，可以注意到 JQuery 正在反序列化返回的 JSON 对象，我们正在检查其中的 'success' 键（这是我们在 polling/web/views.py 的 vote 视图中返回的）。

分数在这个页面不会实时更新，你需要返回到投票列表才能看到更新后的分数。（如果有人在弄清楚如何动态更新页面时遇到困难，我可以再写一篇教程来介绍，但那至少需要一个真正的请求 :) 我们当前代码的快照可以在这里下载。
