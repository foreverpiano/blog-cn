消灭英雄，停止蛮干

2012-11-25 · 阅读原文

项目发布已经延误了十八个月，公司收入大幅下滑，核心人员纷纷离职，新人不断填补空缺。该怎么办？嗯，更努力地工作！

这管用吗？

当然不管用。除非你的问题是大家根本没有努力，否则“更努力工作”的口号只会培养出一批英雄程序员，他们的英雄行径让非英雄们难以做出有意义的贡献。随后，当这些新英雄在 burnout（倦怠）中自我牺牲后，你将面临三个极其棘手的问题：

你培养了一批心怀不满、精疲力竭的英雄；你和你的英雄们疏远了其他所有人；你的项目依然彻底完蛋。

这是许多成长型公司反复陷入的模式，在大公司内部的项目中也很常见。只要你看到管理层绝望、团队拼命苦干，“更努力干”的幽灵就可能已经悄然降临。

某个阴雨天，你走进办公室，老板要找你谈话。他需要你完成自己的项目，同时还要你把同事的项目也干完，还不能让那位同事感到难堪，因为项目所有权依然归他，你只是去“帮忙完成”（别忘了你还有自己的本职工作）。

几周后，网站每隔几天就崩溃一次，公司急需上线新版本。老板又跑来告诉你，他非常信任你，需要你同时接管两边的活。你是个好人，这听起来是个好机会，而且你确信自己能比目前负责的人做得更好，于是你答应了。

恭喜！你已经成为一名英雄程序员。

你现在同时负责五个完全不同的项目，努力不让太多人感到不快，却发现很难让大家真正参与进来。似乎其他人并没有像你这么拼命，这让人有些沮丧——你每周工作七十小时，周六晚上还 constantly 被呼叫。

其他开发者很高兴你站出来解决那些让他们也感到恐惧的问题，但情况并不乐观。有几个人因为你突然升高的地位而暗暗不满，而大多数人只是不知道该如何再做贡献——因为你和你的英雄同伴们正在重写现有系统、排查崩溃、挑最容易的胜利果实。他们还有什么可做的呢？

日复一日，周复一周，英雄与非英雄之间的隔阂越来越深，朝着不可避免的灾难滑去。

要解决“英雄程序员”问题，你的选择很有限：要么消灭滋生英雄的环境，要么等着英雄自己 burnout（ burnout）而死。

他们是真正难以维护的存在，因为他们的存在会降低周围人的效能，换来的只是短期生产力爆发——靠长时间工作和最小化的沟通成本（之所以最小化，是因为大多数其他人已经没什么可做的了）。

这些长时间工作会烧尽你的英雄，然后他们要么辞职，要么被你塞到某个角落里，对你怒目而视，同时回想起自己曾经的拼命工作和关键贡献，最终却落得在这个角落里瞪着你。

你可以尝试挽救英雄，但从一开始就充满不确定性，修复也需要时间。他们可能会恨你一阵子，而且很可能应该恨你——因为是你用笨拙粗暴的方式试图解决当前问题，才把他们塑造成了英雄。

系统思考的一个观察是：虽然人类倾向于把事件解读为因果关系，但很多问题其实更适合用一系列“存量”的增长和减少来描述，这些存量受流入和流出影响而变化。沙尘暴并不是由一个农民或一年的过度耕作造成的，而是多年系统性滥用土地的结果。

存量与流量模型在理解项目和团队失败上特别有价值。项目是一个冲刺一个冲刺地落后，技术债务是在几个月里慢慢把项目勒死的。

项目是慢慢失败的，修复它们也需要时间。

疯狂工作几周或一个月，可能让人感觉付出了巨大努力和能量，但几乎不可能快速抵消过去几个月糟糕实施或管理决策所积累的赤字。

如果拼命工作和培养英雄不管用，那什么管用呢？

你应对破败系统的方式，取决于你是否有权制定政策。如果你当初制定了方向，并且有足够的影响力改变方向，那么重置其实很简单：站起来，为自己卷入的这场惨败承担责任。

承担 blame（指责）是痛苦的，而且只能在群体中奏效几次。之后人们就不会再信任你能带领他们走向成功了，这也合理——因为那时你已经多次把大家带偏。公平就是公平。

如果承担损失不能让你看起来光鲜，至少获得 closure（了结）是有疗愈作用的。团队将有机会开始 healing（疗愈）——当进度被重置、目标被调整之后。如果你没有改变政策的 leverage（影响力）——这不一定需要直接权力，影响力本身就很强大——你就无法启动疗愈，但你可以帮助团队更快地到达重置点（类似于艾萨克·阿西莫夫《基地》系列中，基地的目标是加速并最小化银河帝国崩溃的过程）。

如果没有决策权，你的工具就是退后一步，让破败的系统在自身重量下崩塌。一个存在深刻缺陷的系统无法靠创可贴拯救，却很容易吸收你的幸福感来稍稍延长它的寿命。退后一步，你能保存自己的精力，避免进入英雄模式把别人推开而制造裂痕，也能在重置真正发生后，准备好参与到一个新的——希望是更健康的——系统中。

这是一个非常令人不舒服的过程。如果你是一个勤奋、忠诚的人，这可能深深违背你的本性。它当然也违背我的本性，但我相信，在这种情况下，遵循本性对自己和周围的人都是有害的。

项目总是会失败，人总是会犯错。通常，我们正是因为不肯承认失误，才让情况变得更糟。如果我们能迅速承认错误，在把自己累垮之前及时止损，那么我们就能从错误中学习并进步。

消灭你的英雄，停止蛮干。不要把自己困在错误里，从中学习，然后继续前进。
