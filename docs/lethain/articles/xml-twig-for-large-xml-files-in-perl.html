使用 XML::Twig 处理大型 XML 文件（Perl）

2008-11-20 · 阅读原文

上周我还在用 XML::Simple 做一些简单的 XML 处理任务。这周我需要做同样的事情，但文件大小从 11KB 变成了 80 多 MB，我遇到了之前从未处理过的一类问题：真正的大文件。

你可能会觉得，一个自称专业的开发者应该早就经历过这种痛苦，但我没有。这其实是一组很有趣的问题，因为它会让你开始认真思考时间和空间的约束。出于好奇，我首先尝试直接运行之前写的 XML::Simple 脚本。结果就是等待很长时间、消耗大量内存，然后放弃。问题在于 XML::Simple 既不使用 SAX，也不使用 DOM 来处理 XML 文件，而是采用用户友好的“转换为原生数据结构”的方式。虽然在可行的情况下这是我最喜欢的方式，但在面对需要读-改-写的 20 万+ 元素时，就如同开着 Barbie 电动玩具车去参加拆车大赛一样不自量力。

于是我把库从 XML::Simple 换成了 XML::Twig，这次切换非常愉快。处理这个 80MB 文件不再需要“很长时间”，而是大约五分钟就能读入并写出（如果进行大量处理的话还会再多花几分钟）；七分钟比“永远完成不了”要好太多了。内存消耗也相当合理，处理 80MB 文件时一开始大约占用 10MB，随着脚本运行时间延长会慢慢增加到 20MB 左右，CPU 使用率则稳定在一个核心的接近 100%。
