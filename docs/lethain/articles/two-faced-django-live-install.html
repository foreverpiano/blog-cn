两面派 Django：在线安装

2007-12-16 · 阅读原文

本应用现在已经提供了在线运行的 Django 安装版本。你可以访问其网页界面，也可以访问对应的 FaceBook 应用。如果感觉响应缓慢或不灵敏，很可能是因为它运行在 Dreamhost 上——这个主机对 Django 并不友好（但它确实很方便用来部署这种一次性的演示应用）。

目前除 JQuery 相关功能外，其他一切都已正常运行。JQuery 在我本地机器上可以正常工作，只是还需要对 Dreamhost 的配置再做一些调整。（在共享主机上配置这些东西，细节上真的很折腾。）

附注：willarson.com 子域名名称的来历，是因为我正好有一个尚未使用的子域名，它已经预先修改了运行 Python fcgi 所需的权限（Dreamhost 需要技术人员手动编辑子域名的权限才能支持）。

更新一

现在 JQuery 功能也已经可以正常使用了。显然这个网站对用户非常不友好，因为它没有任何反向链接或非手动导航方式。抱歉！它只是一个示例而已！

更新二
