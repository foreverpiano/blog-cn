两面派 Django：在线安装

2007-12-16 · 阅读原文

这个应用现在已经有了在线运行的 Django 安装。你可以访问它的网页界面，也可以访问 FaceBook 应用。如果感觉响应缓慢或不灵敏，很可能是因为它运行在 Dreamhost 上——这个主机对 Django 并不太友好（不过它倒是很方便地让这样一个一次性应用上线）。

目前除了 JQuery 相关的功能外，其他一切都已正常运行。JQuery 在我本地机器上可以正常工作，只是还需要在 Dreamhost 的配置上再多调整一下。（在共享主机上搭建这些东西，细节处理简直就是一场恶梦。）

附注：willarson.com 子域名的命名缘由是，我恰好有一个尚未使用的子域名，它已经修改过权限，可以运行 Python fcgi（这需要 Dreamhost 的技术人员对你的子域名权限进行一次调整才能实现）。
