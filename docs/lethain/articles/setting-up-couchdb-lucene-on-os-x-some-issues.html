在 OS X 上安装 CouchDB-Lucene

2009-02-06 · 阅读原文

以下是我在 OS X 上安装 CouchDB-Lucene 时整理的步骤。你可以在标准的 OS X 10.5 系统上逐字照着这些步骤操作，10.4 系统应该也可以。

在 Linux 系统上的安装过程大体相似，但具体细节会有所不同。而 Windows 系统则基本没戏。

哦，这里顺便提一下那两个值得喜爱的项目：无模式数据库 CouchDB 和全文搜索引擎 Lucene。

这是本文的第二个版本，更新为使用 Robert Newson 的 couchdb-lucene 分支，该分支比 Paul Davis 的版本更新。

svn co http://svn.apache.org/repos/asf/couchdb/trunk couchdb

port install automake autoconf libtool help2man
port install icu erlang spidermonkey curl

cd couchdb
./bootstrap
./configure
make && sudo make install

sudo cp etc/couchdb/local.ini /usr/local/etc/couchdb/

sudo /usr/local/var/bin/couchdb

sudo port install git

cd ~/git/
git clone git://github.com/rnewson/couchdb-lucene.git

  1. Checkout CouchDB from SVN.
  2. Make sure you have requirements.
  3. Build that sucker.
  4. If you happen to have tried installing couchdb-lucene a month ago and given up in a fit of anger, then you may have a broken local.ini file laying around on your system. (Conceivably you might have had an alternative path to failure.)In that case, replace your current local.ini with a copy in the CouchDB source.

  6. Install Git if you don't already have it installed.Or you can use the git-osx-installer.
  7. Clone the couchdb-lucene project. (I like to keep all of my git repositories in ~/git/, but it's just a personal thing.)
  8. Now we beg OS X to let us use Java 1.6. This step isn't possible for people on PowerPCs, and possibly those using 10.4 or earlier. When it opens, drag 1.6 to the top in the bottom half of the screen (sorry, hard to describe the convoluted UI more precisely than that). Then exit. No, it doesn't tell you that it changed anything or confirm that it saved.
