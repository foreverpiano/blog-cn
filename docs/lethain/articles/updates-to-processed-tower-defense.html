Processed Tower Defense 更新

2008-05-28 · 阅读原文

John Resig 非常慷慨地提到了 Processed Tower Defense，于是我决定今天下午稍作庆祝，补上了两个最重要且缺失的功能：炮塔升级和多种类型的敌人。

先去玩一会儿吧，如果你对细节感兴趣，再回来继续看。

敌人类型

现在一共有四种敌人：Normal、Fiz、Buzz 和 FizBuzz。如果你是一名程序员，可能已经猜到它们会在什么时候出现；如果不是，那这只是个小小的玩笑而已。FizBuzz 会在能被 15 整除的波次出现，Buzz 会在能被 5 整除但不能被 15 整除的波次出现，Fiz 会在能被 3 整除但不能被 15 整除的波次出现，而 Normal 则出现在所有其他波次。

以下是这些新敌人类型的区别：

var FizCreep = function(wave) {
  var fc = Creep(wave);
  fc.color = color(0,255,255);
  fc.size = fc.size * 1.3;
  fc.hp = fc.hp * 2;
  fc.value = fc.value * 1.5;
  fc.speed = fc.speed * 0.75;
  return fc;
};
var BuzzCreep = function(wave) {
var bc = Creep(wave);
bc.color = color(100,150,50);
bc.speed = bc.speed  1.5;
bc.hp = bc.hp  .75;
bc.size = bc.size  0.9;
bc.value = bc.value  1.25;
return bc;
};
var FizBuzzCreep = function(wave) {
var fbc = Creep(wave);
fbc.color = color(255,100,150);
fbc.size = fbc.size  1.5;
fbc.hp = fbc.hp  10;
fbc.value = fbc.value * 10;
return fbc;
}

简单来说，Fiz 血量很高但移动缓慢；Buzz 速度很快但血量较低；而 FizBuzz 则是极其耐打的 Boss。它们各自也有专属的出怪代码：

var FizCreepWave = function(settings) {
  var fcw = CreepWave(settings);
  fcw.spawn_creep = function() { FizCreep(this.wave);  }
  SET.creep_variety = "Fiz Creeps";
  return fcw;
};
var BuzzCreepWave = function(settings) {
var fcw = CreepWave(settings);
fcw.spawn_creep = function() { BuzzCreep(this.wave);  }
SET.creep_variety = "Buzz Creeps";
return fcw;
};
var FizBuzzCreepWave = function(settings) {
var fcw = CreepWave(settings);
fcw.remaining = 1;
fcw.spawn_creep = function() { FizBuzzCreep(this.wave);  }
SET.creep_variety = "FizBuzz Creeps";
return fcw;
};

基本上就是对原有 CreepWave 的样板式扩展，只是 FizBuzzCreepWave 每次只生成一个敌人（因为它实在太难杀死了）。

炮塔升级

炮塔升级的实现稍微麻烦一些，主要是因为我大量使用 HTML 控件来绘制界面（这是由于 canvas 的文本渲染支持有限）。不管怎样，它现在已经可以正常使用了。想要升级炮塔时，点击它，然后使用右侧（在其当前属性下方）出现的升级按钮即可。

两种炮塔的升级方式略有不同。先来看看 Missile Tower。

mt.upgrade = function() {
  if (SET.gold >= this.upgrade_cost) {
    SET.gold -= this.upgrade_cost;
    this.upgrade_cost = this.upgrade_cost * 2;
    this.damage = this.damage * 1.5;
    this.set_range(this.range + 0.5);
  }
}

它的射速完全没有提升，但每次升级射程都会大幅增加。虽然伤害提升速度不如 Laser Tower 快，但由于其初始伤害就是后者的十倍，所以实际上影响不大。

接下来是 Laser Tower 的升级情况。

lt.upgrade = function() {
  if (SET.gold >= this.upgrade_cost) {
    SET.gold -= this.upgrade_cost;
    this.upgrade_cost = this.upgrade_cost * 1.5;
    this.damage = this.damage * 2.0;
    this.set_range(this.range + 0.25);
    this.reload_rate = this.reload_rate - 10;
  }
}

Laser Tower 的伤害提升非常快，射程也会略有增加。此外，每次升级其装填时间会减少 10 毫秒（初始装填时间为 250 毫秒），这是一个很实用的改进。如果你能把一座 Laser Tower 升级 25 次，那么它每次渲染循环都会发射一发激光。不过由于游戏帧率只有 60 FPS，实际上只需要升级 24 次就能达到其最大有效射速。

未来计划

其实我一开始并没打算继续开发 PTD，但这个游戏目前确实比较单调，我想让那些不幸发现它的人能玩得稍微开心一点。再强调一次，我目前并没有明确的继续开发计划，但如果有人特别感兴趣的话，也许会继续做下去。

以下是一些我可能会实现的特性（不分先后顺序）：

  1. More tower types. Probably something involving small ellipses (gattling?) and large ellipses (cannon). Also some of the tactical towers wouldn't be so hard to implement (slowing, damage over time, tower enhancers, etc), and would add some interest to the game as well.
  2. More types of creep waves. Release the creeps faster sometimes. Sometimes have a fix of creep types.
  3. Vary the number of entrance squares, doubling or tripling the number of creeps.
  4. More arcade type elements, such as a powerful tower that must be player controlled, etc.
  5. It would be nice to have a high score board, although it would be hopelessly impossible to trust, since anyone with FireFox would be able to open the console and just submit a score. You can get relatively tricky about these things, calclating the expected score from number of towers/remaining gold and so on, but regardless of the level of sophistication of the anti-cheating I can't imagine passing the "five minute glance" test by a JavaScript programmer. This is certainly one of the disadvantages of development a JavaScript game.
  6. Pathfinding AI for the creeps. It would be nice if the creeps occasionally did more than walk in a straight line.
  7. I'd really enjoy having support for displaying multiple tower killzones at once. See the full coverage of your towers.

总之，希望现在的游戏比之前有趣一些。
