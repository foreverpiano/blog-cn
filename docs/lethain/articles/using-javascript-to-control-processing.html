使用 Javascript 控制 Processing

2008-05-11 · 阅读原文

在之前的一篇文章中，我提到过 Processing.js 最吸引人的特性之一，就是能够编写类似 Processing 的代码，但使用 Javascript 而不是 Java 1.3 语法来实现逻辑部分。不过我当时没有给出具体示例，所以今天早上我决定做一个简单的例子，就是下面这个。

改进 Javascript 版本

正如我之前简单提到的，Processing 代码特别简洁的原因在于它内置的一些魔法。在 Processing 中，我们定义了 draw 方法，但并没有在任何地方显式调用它（Processing 已经知道该怎么处理）。我们使用 frameRate 来定义帧率，但使用该帧率的循环是在幕后创建的。Processing 并不会纠结于保持命名空间干净，它只是尽量让事情变得简单1。

Javascript 版本没有这些魔法，因此会更加冗长和杂乱。意识到这一点后，我们需要退一步思考：是想要实现一些方便的魔法，还是坚持可靠的可预测性。我个人认为，Processing 的全部魅力就在于它的魔法——让任何人都能轻松写出令人印象深刻的东西——所以我的答案是：“是的，请给我那些魔法把戏。”

结束思考

虽然我完全支持将 Javascript 作为控制语言，但我不确定其带来的好处是否值得分散开发者对 Processing 的知识掌握，也不确定这些想象中的好处是否值得去编写一个库，为 Processing.js 提供一个更具魔力的接口层。用这种方式编写的程序无法与 Processing 桌面版程序一起使用，这当然是一种损失，但它也并非没有一些补偿性的好处。
