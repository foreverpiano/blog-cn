从 Django 数据转储中提取模型

2007-07-13 · 阅读原文

在对模型进行了一系列破坏性修改后，我在 Django 项目中导出的旧数据几乎无法优雅地重新导入到 Postgres 中。于是我写了一个简单的脚本，它可以读取数据转储文件并整理其中包含的模型。

最终结果是一个名为 extracted 的文件夹，其中为数据转储中包含的每个应用（app）创建一个子文件夹。每个应用文件夹下再为其中包含的每个模型创建一个子文件夹。每个模型文件夹内则包含若干文件（文件名即该记录的主键），每个文件保存一条模型数据。

extracted -> admin
        -> auth
        -> blog          -> entry
                         -> language
                         -> tag              -> 1.xml
                                             -> 2.xml
                                             ...
                         ...
        -> flatpges
        ...

使用方法非常简单：

python model_extract.py yourdatadump.xml

这会在当前目录下创建一个名为 extracted 的文件夹。它不会覆盖已存在的同名文件夹（这是功能而非 bug），因此如果文件夹已存在，你需要先将其删除。

你可以从[这里][modelextract]获取该文件。使用它需要安装 BeautifulSoup，可以通过以下命令轻松完成

easy_install BeautifulSoup
