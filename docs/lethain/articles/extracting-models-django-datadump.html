从 Django 数据导出文件中提取模型

2007-07-13 · 阅读原文

在对模型进行了一系列破坏性修改后，我在 Django 项目中导出的旧数据几乎无法顺利恢复到 Postgres 中。于是我写了一个简短的脚本，它可以读取数据导出文件，并将其中包含的模型整理出来。

最终结果是一个名为 extracted 的文件夹，其中为数据导出文件中包含的每个应用（app）创建一个子文件夹。每个应用文件夹下，再为其中包含的每个模型创建一个子文件夹。每个模型文件夹内则包含若干文件，每个文件的文件名是对应模型的主键，文件内容则是该模型实例的数据。

extracted -> admin
        -> auth
        -> blog          -> entry
                         -> language
                         -> tag              -> 1.xml
                                             -> 2.xml
                                             ...
                         ...
        -> flatpges
        ...
