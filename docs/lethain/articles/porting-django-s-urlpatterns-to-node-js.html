将 Django 的 urlpatterns 移植到 Node.js

2010-03-06 · 阅读原文

我正在构思一个新的个人小项目，打算用 Node.js 来实现。（主要是因为它部署起来极其简单，而且在空闲时不会像我平时用的 Apache2 + mod_wsgi 配置部署 Django 那样消耗资源。）

我对[这篇博客文章中介绍的配置思路][boldr]颇为满意，但希望再多融入一些 Django 的风格，于是就把 [urlpatterns.py 的 URL 分发模式][urlpatten]移植了过来。结果发现实现起来相当容易。

使用这个 dispatcher 之后，我就能编写一个 views.js 文件，它会把正则表达式从 URL 中提取的匹配结果作为参数传递给对应的函数。

exports.index = function(req, res) {
    res.writeHead(200, {'Content-Type': 'text/html'});
    res.write('index.html');
    res.close();
};
exports.project = function(req, res, project) {
res.writeHead(200, {'Content-Type': 'text/html'});
res.write('project.html: ' + project);
res.close();
};

下面是包含模式匹配器和 dispatcher 的核心文件。

var http = require("http"),
    url = require("url"),
    views = require("./views"),
    port = 8000;
require("../underscore/underscore");
var patterns = [
[/^/project/([\w-_])/$/, views.project],
[/^/$/, views.index]
];
http.createServer(function(req, res) {
req.addListener('end', function() {
var path = url.parse(req.url).pathname,
match = _.detect(patterns, function(pattern) {
return pattern[0].exec(path);
});
if (match) {
var p = [req, res].concat((match[0].exec(path)).slice(1));
match[1].apply(this, p);
} else {
res.writeHead(404, {'Content-Type': 'text/html'});
res.write('No matching pattern found');
res.close();
}
});
}).listen(port);

总的来说，这是一个很不错的小巧方案。我正在尝试结合 Mu，可能今晚或明天会发布一个微框架，不过很可能也没比其他人已经花时间打造的那些东西多出多少价值。唉，就这样吧。
