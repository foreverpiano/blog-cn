平台会变，但酷 URI 永不变。

2022-04-25 · 阅读原文

最近 Twitter 董事会接受了 Elon Musk 的收购要约，这一消息让不少人开始讨论是否要离开 Twitter。从长远来看，2006 年成立的 Twitter 还是一家年轻的公司，但互联网格局已大不相同。在过去的 16 年里，它已成为许多科技从业者（以及其他领域人士）的重要平台。Twitter 对在线内容创作者尤其重要，它已成为许多作者最有效的传播渠道。这对自出版并自行营销的作者来说无疑是事实，我也听过出版社在合同中要求作者必须活跃在 Twitter 上，甚至部分根据作者的 Twitter 粉丝数量来筛选潜在作者。

我希望 Twitter 能继续作为一个充满活力、有效的讨论场所和内容分发渠道，但这也提醒我们：即使是最优秀的平台也不会永远存在。Tumblr 和 Flickr 曾是许多活跃社区的家园，后来却都被 Yahoo! 收购而逐渐衰落。MySpace 在被收购后也同样淡出舞台。。Facebook 虽然还在，但早期驱动其应用生态的 API 早已消失。就连 Twitter 自身，也从鼓励丰富、以 API 为中心的开发者生态，转向暗中关闭大部分 API 使用。Digg 团队如何被 acquihire（收购人才）

你当然可以说这些平台并非真正的内容或分发平台，但很难在看到如今订阅通讯的宠儿 Substack 时，不联想到昔日博客宠儿 Medium 那日益不可预测的付费墙。理论上你可以每五六年就换一次平台，但酷 URI 不会改变，而更换平台会严重损害内容的发现和分发。

对于那些投入大量时间在网上创作内容的人来说，这最终意味着你需要拥有自己的内容，拥有将读者连接到内容的 DNS 记录，并拥有自己的邮件列表。只要你控制这些接口，你就可以在更换平台时不影响可发现性。当然，这需要一些工作，但这个博客在过去 15 年里已经迁移了五次，从 Dreamhost 到 Linode，再到 AWS、GCP，最后到 Github Pages，据我所知所有的 URI 依然有效。如果我当初把读者直接引到 Medium 或 Github 的域名上，就无法如此干净地完成这些迁移（顺便说一句，当我开始写作时这些平台还不存在，但这不是这里的重点）。

最重要的 URI 之一，就是你的 RSS feed 所在的地址。RSS 作为分发机制的重要性已不如十年前，但 RSS 订阅者往往是最有价值的读者，因为他们当中包括那些 。如何成为科技领域的影响者

很长一段时间里，我坚定地相信 RSS 就足够了，但当我开始着手发布 时，最终还是开通了邮件列表。即使到现在，这个列表规模也不算特别大，但仍有超过 6000 人，即便 Twitter 明天就消失，我也能直接触达他们（Staff Engineer 的邮件列表稍大一些，Infrastructure Engineer 的列表则是全新的，还非常小）。这也是一群高度参与的读者，他们更有可能回复邮件分享自己的想法。我不太情愿地意识到，URI 和邮件才是持久的接口与协议，它们将远比任何一个平台的巅峰期都要长久（不过，想象一下 Gmail 突然关停的那种混乱，我确实后悔还没有把邮箱迁移到自己的域名下，这或许是今年值得做的项目）。精美的谜题：工程管理之道

如果你打算写作跨越数十年，那就必须拥有通往自己内容的接口。你当然应该去尝试那些来来去去的其他平台——它们常常会变成非凡的社区，拥有极好的分发能力——但它们永远不会成为持久的家园。
