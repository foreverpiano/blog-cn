使用 newforms 向用户提问

在我们的 Polling 项目中，我们要允许用户创建新的投票，并且需要一种简单的方式来询问用户想要创建的投票内容。使用 Django.newforms 模块是一个简单的方法。

首先，进入 Polling 项目目录，我们将创建一个新文件 core/forms.py，用于存放我们的表单。

emacs core/forms.py

现在让我们为这个文件添加导入语句：

from django import newforms as forms
from polling.core.models import Poll

接下来我们来创建一个简单的表单，它只包含一个字段，即要询问的问题。代码如下：

class PollForm(forms.Form):
    question = forms.CharField(max_length=200)

好吧，这确实是一个非常简单的例子（抱歉！），但我们希望它能做得更多：我们想要验证问题是否唯一，如果不唯一则添加错误信息。我们通过在 PollForm 类中添加一个 clean_question 方法来实现这一点。得益于一些元编程的魔法，Django 会自动查找这个方法名，并在验证 question 字段时调用它进行额外的校验。

实现这段功能的代码如下：

def clean_question(self):
    question = self.cleaned_data['question']
    count = Poll.objects.filter(question=question).count()
    if count != 0:
        raise forms.ValidationError('The question "%s" is already in use.' % question)
    return question

编写表单的部分就这么多。但在我们继续之前，还需要编写一些测试。让我们打开 core/tests.py 文件，在导入部分添加下面这行：

from polling.core.forms import PollForm

然后我们创建一个新的 unittest.TestCase：

class CoreFormTest(unittest.TestCase):
    "Test the forms contained in the 'core' app."
    def test_PollForm(self):
        pass

确保一切正常……

python manage.py test

测试通过了，现在我们来完善 *test_PollForm* 这个单元测试。

def test_PollForm(self):
    f = PollForm()
    self.assertEquals(False, f.is_valid())
    data = {}
    f = PollForm(data)
    self.assertEquals(False, f.is_valid())
    self.assertEquals([u'This field is required.'], f.errors['question'])
    data = {"question":"Is this valid?"}
    f = PollForm(data)
    self.assertEquals(True, f.is_valid())
    self.assertEquals("Is this valid?", f.cleaned_data['question'])
    u = User(name="Will L")
    u.save()
    p = Poll(question="Is it real?", creator=u)
    p.save()
    data = {"question":"Is it real?"}
    f = PollForm(data)
    # should be false because Poll with this question already
    # exists in our database
    self.assertEquals(False, f.is_valid())
    self.assertEquals([u'The question "Is it real?" is already in use.'], f.errors['question'])
    p.delete()
    u.delete()

和之前的测试一样，我们先进行一些基本的健全性检查，以确保我们理解自己在做什么，并且 Django 没有出什么问题。确认这一点后，我们开始测试表单在预期情况下是否有效或无效，以及是否能正确报告我们期望的错误信息。

现在运行这些测试……

python manage.py test

看起来一切依然正常。非常好。
