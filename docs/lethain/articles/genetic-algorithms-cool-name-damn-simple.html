遗传算法：酷炫的名字 & 极其简单。

2009-01-02 · 阅读原文

遗传算法是一种听起来很神秘的技术，诞生于一个同样神秘的领域——人工智能（artificial intelligence）。这就是给事物起名不当所带来的问题。当这个领域被命名为人工智能时，它的本意是利用数学方法人工创造出智能的表象，但自命不凡的研究者和艾萨克·阿西莫夫却把它重新定义成了机器人。

遗传算法这个名字听起来确实很复杂，还带有一丝魔幻色彩，但实际上，它却是你在人工智能领域能遇到的最简单、最直观的概念之一。

遗传算法能做什么？

简单来说，遗传算法擅长优化。它能为一个问题找到更好的答案，但无法解决全新的问题。给定一辆车的定义，它也许能造出一辆更好的车，但永远不会给你变出一架飞机。

我更喜欢“遗传编程”这个词！

我也是——它听起来好多了——但遗憾的是，用哪个名字并不是个人喜好问题，它们指的是两种不同的技术。遗传算法关注的是优化，而遗传编程则是利用遗传算法的技术，从编程语言的原始汤中构建出计算机程序。

想象一下，你花了过去十年时间试图用 Scheme 写一个“Hello World”程序，却始终无法跨越这道巨大的障碍。但假如你足够聪明，整理出了一份包含大量命令和字符串的清单，使得其中某些组合就能把“Hello World”打印到标准输出。那么你就可以不断混合搭配这些命令和字符串，最终有可能生成“Hello World”，就像无数只猴子随机打字——只要给它们无穷长的时间——最终能重新写出莎士比亚的作品一样。有点像，但不完全一样。

所以，遗传算法是一系列优化技术的集合，而遗传编程则是一种解决你已经知道答案的问题的新颖方法。好吧，这么说并不公平。我们会在另一篇文章中更深入地探讨它，目前只需记住它们不是一回事就行了。

解决方案的组成要素

在遗传算法中，每一个建议的解都被称为一个个体（individual）。在我们当前的问题中，每一个包含 N 个数字的列表就是一个个体。

所有个体的集合被称为我们的种群（population）。

接下来我们需要一种方法来判断每个解决方案的有效程度，即评估每个个体的适应度（fitness）。顾名思义，我们称之为适应度函数（fitness function）。对于我们的问题，我们希望适应度是某个体数字之和与目标数字 X 之间距离的函数。

进化

这就是遗传算法的“秘密酱料”——“秘密”指的是其实相当明显，“酱料”就是酱料的意思。想象一群麋鹿被一群狼无情地猎杀。每过一代，最弱的麋鹿被狼吃掉，而最强壮的麋鹿则繁殖后代。把这些想法稍微抽象一下，我们就可以实现进化机制了。

对于每一代，我们会根据适应度函数选出表现最好的一部分个体。这些高性能个体将成为下一代的父母。我们还会随机选择一些表现较差的个体作为父母，因为我们希望促进遗传多样性。抛开比喻，优化算法的一个危险在于陷入局部最优，从而无法找到全局最优。通过引入一些表现不那么优秀的个体，我们降低了陷入局部最优的可能性。 将父母结合在一起，繁殖出新的个体，将种群补充到期望的大小（如果你从 100 个个体的种群中保留前 20 个，那么就需要通过繁殖创造 80 个新孩子）。在我们的例子中，繁殖非常简单：从父亲那里取前 N/2 个数字，从母亲那里取后 N/2 个数字。 >>> father = [1,2,3,4,5,6] >>> mother = [10,20,30,40,50,60] >>> child = father[:3] + mother[3:] >>> child [1,2,3,40,50,60] 允许一个父母多次繁殖，但一个父母不应该同时既是父亲又是母亲。 将父母和子女合并，构成下一代的种群。 最后，我们对种群中一小部分随机个体进行变异。这意味着每个个体都有一定概率被随机修改。 >>> from random import random, randint >>> chance_to_mutate = 0.01 >>> for i in population: ... if chance_to_mutate > random(): ... place_to_modify = randint(0,len(i)) ... i[place_to_modify] = randint(min(i), max(i)) ... 这一步——就像引入表现不太好的个体一样——是为了促进遗传多样性，即避免陷入局部最优。
