遗传算法：酷炫的名字 & 简单得要命。

2009-01-02 · 阅读原文

遗传算法是听起来颇为神秘的人工智能（artificial intelligence）领域里的一项技术。这就是给事物起名时经常遇到的问题。当这个领域被命名为“人工智能”时，它的本意是利用数学方法人工制造出智能的表象，但自命不凡的研究者和艾萨克·阿西莫夫却把它重新定义成了机器人。

遗传算法这个名字听起来确实有些复杂，还带点神秘的魔力，但实际上，它却是你在人工智能领域能遇到的最简单、最直观的概念之一。

遗传算法能做什么？

一句话：优化。它们可以为一个问题找到更好的答案，但不能解决全新的问题。给定一辆汽车的定义，它们也许能造出一辆更好的汽车，但永远不会给你变出一架飞机。

我更喜欢“遗传编程”这个词！

我也是——它听起来顺耳多了——但可惜的是，用哪个名字并不是个人喜好问题，它们指的是两种不同的技术。遗传算法关注的是优化，而遗传编程则是利用遗传算法的技术，从最基本的编程语言“汤”中构建出计算机程序。

想象一下，你花了过去十年时间试图用 Scheme 写一个“Hello World”程序，却始终无法跨越这个巨大的障碍。但假设你足够聪明，整理出了一份包含大量命令和字符串的清单，其中某些组合就能把“Hello World”打印到标准输出。那么你就可以把这些命令和字符串混搭起来，最终有可能生成“Hello World”，就像无数只猴子随机打字——只要给它们足够长的时间——最终能再现莎士比亚的作品一样。差不多是这个意思。

所以，如果说遗传算法是一系列优化技术的集合，那么遗传编程则是针对那些你已经知道答案的问题的一种新颖的求解方法。好了好了，这个描述并不完全公平。我们会在另一篇文章中更深入地探讨它，目前暂且记住它们不是一回事就好。

定义一个待优化的问题

现在我们要用 Python 实现一个使用遗传算法的简单例子。我们要优化的一个非常简单的问题是：生成一个包含 N 个数字的列表，使这些数字相加的结果等于 X。

如果我们设定 N = 5 且 X = 200，那么以下这些都是合适的解。

lst = [40,40,40,40,40]
lst = [50,50,50,25,25]
lst = [200,0,0,0,0]

（有人告诉我，在文章里随机冒出一句“很简单，对吧？”并不会有什么帮助。不然我早就毫无意义地在这里加上一句了。）

解决方案的组成要素

在遗传算法中，每个被提出的解决方案都被称为一个个体（individual）。在我们当前的问题里，每一个包含 N 个数字的列表就是一个个体。

>>> from random import randint
>>> def individual(length, min, max):
...     'Create a member of the population.'
...     return [ randint(min,max) for x in xrange(length) ]
... 
>>> individual(5,0,100)
[79, 0, 20, 47, 40]
>>> individual(5,0,100)
[64, 1, 25, 84, 87]

所有个体的集合被称为我们的种群（population）。

>>> def population(count, length, min, max):
...     """
...     Create a number of individuals (i.e. a population).
... 
...     count: the number of individuals in the population
...     length: the number of values per individual
...     min: the min possible value in an individual's list of values
...     max: the max possible value in an individual's list of values
... 
...     """
...     return [ individual(length, min, max) for x in xrange(count) ]
... 
>>> population(3,5,0,100)
[[51, 55, 73, 0, 80], [3, 47, 18, 65, 55], [17, 64, 77, 43, 48]]

接下来我们需要一种方法来判断每个解决方案的有效程度，即评估每个个体的适应度（fitness）。不出所料，我们把它叫做适应度函数（fitness function）。对于我们的问题，我们希望适应度是某个个体的数字总和与目标数字 X 之间的距离的函数。

我们可以这样实现适应度函数：

>>> from operator import add
>>> def fitness(individual, target):
...     """
...     Determine the fitness of an individual. Lower is better.
... 
...     individual: the individual to evaluate
...     target: the sum of numbers that individuals are aiming for
...     """
...     sum = reduce(add, individual, 0)
...     return abs(target-sum)
... 
>>> x = individual(5,0,100)
>>> fitness(x, 200)
165

老实说，我更希望用较高的适应度分数来表示个体更优，而不是像现在这样——完美的个体适应度为 0，而且数值越大越差。唉，不管怎样，在阅读下面的代码时请记住这个细节。

另外，写一个计算种群平均适应度的函数也很有帮助。

>>> def grade(pop, target):
...     'Find average fitness for a population.'
...     summed = reduce(add, (fitness(x, target) for x in pop), 0)
...     return summed / (len(pop) * 1.0)
...
>>> x = population(3,5,0,100)
>>> target = 200
>>> grade(x, target)
116

现在我们只需要一种方法来进化我们的种群，让它从一代推进到下一代。

进化

这就是遗传算法的“秘方”，其中“秘”指的是其实相当明显，“方”就真的是配方了。想象一群麋鹿被一群狼无情地猎杀。在每一代中，最弱的麋鹿会被狼吃掉，而最强壮的麋鹿则会繁殖后代。把这些想法抽象一下，我们就能实现进化的机制。

>>> father = [1,2,3,4,5,6]
>>> mother = [10,20,30,40,50,60]
>>> child = father[:3] + mother[3:]
>>> child
[1,2,3,40,50,60]

>>> from random import random, randint
>>> chance_to_mutate = 0.01
>>> for i in population:
...     if chance_to_mutate > random():
...         place_to_modify = randint(0,len(i))
...         i[place_to_modify] = randint(min(i), max(i))
...
  1. For each generation we'll take a portion of the best performing individuals as judged by our fitness function. These high-performers will be the parents of the next generation.We'll also randomly select some lesser performing individuals to be parents, because we want to promote genetic diversity. Abandoning the metaphor, one of the dangers of optimization algorithms is getting stuck at a local maximum and consequently being unable to find the real maximum. By including some individuals who are not performing as well, we decrease our likelihood of getting stuck.
  2. Breed together parents to repopulate the population to its desired size (if you take the top 20 individuals in a population of 100, then you'd need to create 80 new children via breeding). In our case, breeding is pretty basic: take the first N/2 digits from the father and the last N/2 digits from the mother.It's okay to have one parent breed multiple times, but one parent should never be both the father and mother of a child.
  3. Merge together the parents and children to constitute the next generation's population.
  4. Finally we mutate a small random portion of the population. What this means is to have a probability of randomly modifying each individual.This--just like taking individuals who are not performing particularly well--is to encourage genetic diversity, i.e. avoid getting stuck at local maxima.

把以上所有内容组合起来，进化一代的代码可以这样实现：

"""
# Example usage
from genetic import *
target = 371
p_count = 100
i_length = 6
i_min = 0
i_max = 100
p = population(p_count, i_length, i_min, i_max)
fitness_history = [grade(p, target),]
for i in xrange(100):
    p = evolve(p, target)
    fitness_history.append(grade(p, target))
for datum in fitness_history:
   print datum
"""
from random import randint, random
from operator import add
def individual(length, min, max):
'Create a member of the population.'
return [ randint(min,max) for x in xrange(length) ]
def population(count, length, min, max):
"""
    Create a number of individuals (i.e. a population).
    count: the number of individuals in the population
    length: the number of values per individual
    min: the minimum possible value in an individual's list of values
    max: the maximum possible value in an individual's list of values
    """
return [ individual(length, min, max) for x in xrange(count) ]
def fitness(individual, target):
"""
    Determine the fitness of an individual. Higher is better.
    individual: the individual to evaluate
    target: the target number individuals are aiming for
    """
sum = reduce(add, individual, 0)
return abs(target-sum)
def grade(pop, target):
'Find average fitness for a population.'
summed = reduce(add, (fitness(x, target) for x in pop))
return summed / (len(pop) * 1.0)
def evolve(pop, target, retain=0.2, random_select=0.05, mutate=0.01):
graded = [ (fitness(x, target), x) for x in pop]
graded = [ x[1] for x in sorted(graded)]
retain_length = int(len(graded)*retain)
parents = graded[:retain_length]
# randomly add other individuals to
# promote genetic diversity
for individual in graded[retain_length:]:
if random_select > random():
parents.append(individual)
# mutate some individuals
for individual in parents:
if mutate > random():
pos_to_mutate = randint(0, len(individual)-1)
# this mutation is not ideal, because it
# restricts the range of possible values,
# but the function is unaware of the min/max
# values used to create the individuals,
individual[pos_to_mutate] = randint(
min(individual), max(individual))
# crossover parents to create children
parents_length = len(parents)
desired_length = len(pop) - parents_length
children = []
while len(children) < desired_length:
male = randint(0, parents_length-1)
female = randint(0, parents_length-1)
if male != female:
male = parents[male]
female = parents[female]
half = len(male) / 2
child = male[:half] + female[half:]
children.append(child)     
parents.extend(children)
return parents
