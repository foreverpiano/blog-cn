遗传算法：超酷的名字 & 简单得要命。

2009-01-02 · 阅读原文

遗传算法是听起来颇为神秘的人工智能（artificial intelligence）领域里一种神秘的技术。这就是给事物起名不当所带来的问题。当这个领域被命名为“artificial intelligence”时，它的本意是用数学方法人工创造出智能的表象，但自命不凡的研究者和艾萨克·阿西莫夫却把它重新定义成了机器人。

“遗传算法”这个名字听起来确实有点复杂，还带点魔幻色彩，但实际上，它却是你在人工智能领域能遇到的最简单、最直观的概念之一。

遗传算法能做什么？

一句话，遗传算法擅长优化。它能为一个问题找到更好的答案，但无法解决全新的问题。给定一辆车的定义，它也许能造出一辆更好的车，但永远不会给你变出一架飞机。

我更喜欢“遗传编程”这个说法！

我也是——它听起来顺耳多了——但可惜，选择用哪个名字不是个人偏好问题，它们指的是不同的技术。遗传算法主要用于优化，而遗传编程则是利用遗传算法的思想，从原始的编程语言材料中构建出计算机程序。

想象一下，你花了过去十年时间试图用 Scheme 语言写一个“Hello World”程序，却始终无法跨过这道巨大的门槛。但假如你足够聪明，事先准备了一大堆命令和字符串，使得其中某些组合就能把“Hello World”打印到标准输出。那么你就可以不断混合搭配这些命令和字符串，最终很可能生成“Hello World”，就像猴子随机打字一样——只要给它们足够长的时间——最终能打出莎士比亚的作品。大致就是这个意思。

所以，如果说遗传算法是一系列优化技术的集合，那么遗传编程则是用来解决那些“你已经知道答案的问题”的一种新奇方法。好吧，这个描述并不完全公平。我们会在另一篇文章中更深入地探讨它，目前就先记住它们不是同一回事。

定义一个要优化的问题

现在我们要用 Python 实现一个简单的遗传算法示例。我们要优化的是一个非常简单的问题：生成一个包含 N 个数字的列表，使这些数字相加的结果等于 X。

如果我们设定 N = 5 且 X = 200，那么以下这些都是合适的解。

lst = [40,40,40,40,40]
lst = [50,50,50,25,25]
lst = [200,0,0,0,0]

（有人告诉我，在文章里随机冒出一句“很简单，对吧？”的做法并不可取。否则我刚才就多此一举地加上一句了。）

解决方案的组成要素

在遗传算法中，每一个被提出的解决方案都叫做一个个体（individual）。在我们当前的问题里，每一个包含 N 个数字的列表就是一个个体。

>>> from random import randint
>>> def individual(length, min, max):
...     'Create a member of the population.'
...     return [ randint(min,max) for x in xrange(length) ]
... 
>>> individual(5,0,100)
[79, 0, 20, 47, 40]
>>> individual(5,0,100)
[64, 1, 25, 84, 87]

所有个体的集合被称为我们的种群（population）。

>>> def population(count, length, min, max):
...     """
...     Create a number of individuals (i.e. a population).
... 
...     count: the number of individuals in the population
...     length: the number of values per individual
...     min: the min possible value in an individual's list of values
...     max: the max possible value in an individual's list of values
... 
...     """
...     return [ individual(length, min, max) for x in xrange(count) ]
... 
>>> population(3,5,0,100)
[[51, 55, 73, 0, 80], [3, 47, 18, 65, 55], [17, 64, 77, 43, 48]]

接下来我们需要一种方法来判断每个解决方案的有效程度，即评估每个个体的适应度（fitness）。顺理成章地，我们把它叫做适应度函数（fitness function）。对于我们的问题来说，适应度应该是个体数字总和与目标数字 X 之间差距的函数。

我们可以这样实现适应度函数：

>>> from operator import add
>>> def fitness(individual, target):
...     """
...     Determine the fitness of an individual. Lower is better.
... 
...     individual: the individual to evaluate
...     target: the sum of numbers that individuals are aiming for
...     """
...     sum = reduce(add, individual, 0)
...     return abs(target-sum)
... 
>>> x = individual(5,0,100)
>>> fitness(x, 200)
165

老实说，我更希望适应度分数越高代表个体越优秀，而不是像现在这样——完美适应的个体适应度为 0，而且数值越大越差。哎，不管怎样，在看代码的时候请记住这个细节。

另外，写一个计算种群平均适应度的函数也很有帮助。

>>> def grade(pop, target):
...     'Find average fitness for a population.'
...     summed = reduce(add, (fitness(x, target) for x in pop), 0)
...     return summed / (len(pop) * 1.0)
...
>>> x = population(3,5,0,100)
>>> target = 200
>>> grade(x, target)
116

现在我们只需要一种让种群进化的方法，即让种群从一代演进到下一代。

进化

这就是遗传算法的秘密武器——所谓“秘密”其实相当明显，“武器”也就是配料的意思。想象一群麋鹿被一群狼无情地猎杀。每过一代，最弱的麋鹿被狼吃掉，而最强壮的麋鹿则繁殖后代。将这些想法抽象一下，我们就能实现进化机制。

>>> father = [1,2,3,4,5,6]
>>> mother = [10,20,30,40,50,60]
>>> child = father[:3] + mother[3:]
>>> child
[1,2,3,40,50,60]

>>> from random import random, randint
>>> chance_to_mutate = 0.01
>>> for i in population:
...     if chance_to_mutate > random():
...         place_to_modify = randint(0,len(i))
...         i[place_to_modify] = randint(min(i), max(i))
...
在每一代，我们会根据适应度函数选出一部分表现最好的个体作为下一代的父母。我们还会随机选择一些表现较差的个体作为父母，因为我们希望促进基因多样性。抛开比喻，优化算法的一个危险就是陷入局部最优，从而无法找到全局最优。通过引入一些表现不佳的个体，我们可以降低陷入局部最优的风险。 将父母组合起来繁殖后代，使种群规模恢复到预期大小（如果你从 100 个个体的种群中保留前 20 名，就需要通过繁殖产生 80 个新孩子）。 在我们的例子里，繁殖过程非常简单：从父亲那里取前 N/2 个数字，从母亲那里取后 N/2 个数字。 允许一个父本多次繁殖，但一个个体不能同时既是父亲又是母亲。 将父母和子女合并，构成下一代的种群。 最后，我们对种群中一小部分随机个体进行变异。这意味着每个个体都有一定概率被随机修改。 这一步——就像保留表现不佳的个体一样——是为了促进基因多样性，避免陷入局部最优。

完整代码

"""
# Example usage
from genetic import *
target = 371
p_count = 100
i_length = 6
i_min = 0
i_max = 100
p = population(p_count, i_length, i_min, i_max)
fitness_history = [grade(p, target),]
for i in xrange(100):
    p = evolve(p, target)
    fitness_history.append(grade(p, target))
for datum in fitness_history:
   print datum
"""
from random import randint, random
from operator import add
def individual(length, min, max):
'Create a member of the population.'
return [ randint(min,max) for x in xrange(length) ]
def population(count, length, min, max):
"""
    Create a number of individuals (i.e. a population).
    count: the number of individuals in the population
    length: the number of values per individual
    min: the minimum possible value in an individual's list of values
    max: the maximum possible value in an individual's list of values
    """
return [ individual(length, min, max) for x in xrange(count) ]
def fitness(individual, target):
"""
    Determine the fitness of an individual. Higher is better.
    individual: the individual to evaluate
    target: the target number individuals are aiming for
    """
sum = reduce(add, individual, 0)
return abs(target-sum)
def grade(pop, target):
'Find average fitness for a population.'
summed = reduce(add, (fitness(x, target) for x in pop))
return summed / (len(pop) * 1.0)
def evolve(pop, target, retain=0.2, random_select=0.05, mutate=0.01):
graded = [ (fitness(x, target), x) for x in pop]
graded = [ x[1] for x in sorted(graded)]
retain_length = int(len(graded)*retain)
parents = graded[:retain_length]
# randomly add other individuals to
# promote genetic diversity
for individual in graded[retain_length:]:
if random_select > random():
parents.append(individual)
# mutate some individuals
for individual in parents:
if mutate > random():
pos_to_mutate = randint(0, len(individual)-1)
# this mutation is not ideal, because it
# restricts the range of possible values,
# but the function is unaware of the min/max
# values used to create the individuals,
individual[pos_to_mutate] = randint(
min(individual), max(individual))
# crossover parents to create children
parents_length = len(parents)
desired_length = len(pop) - parents_length
children = []
while len(children) < desired_length:
male = randint(0, parents_length-1)
female = randint(0, parents_length-1)
if male != female:
male = parents[male]
female = parents[female]
half = len(male) / 2
child = male[:half] + female[half:]
children.append(child)     
parents.extend(children)
return parents
