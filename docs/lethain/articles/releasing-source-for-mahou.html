公开 Mahou 的源代码

2008-10-16 · 阅读原文

在意识到自己永远不会有时间继续开发 Mahou 之后，我决定将源代码公开出来供大家共同使用。目前代码已托管在 GitHub 上。

这是一个相当简单的 webapp，使用 Cappuccino 框架构建用户界面，Yahoo! BOSS Mashup Framework 处理搜索结果，并通过 Google App Engine 进行托管和部署。我希望它能为那些寻找 Cappuccino 示例代码的开发者提供帮助，因为它包含了大量对 CPCollectionView 和 CPCollectionViewItem 的自定义子类实现。

入门应该相当简单。首先克隆 Git 仓库。

git clone git://github.com/lethain/mahou.git

然后更新配置文件，填入真实的值。具体来说，你需要提供 appid、email 和 org 的值。（这些是 Yahoo! BOSS 的配置值，与 Google App Engine 无关。）

最后，更新 app.yaml 文件，将其中的 application 标识符替换为你自己在 Google App Engine 上的真实应用标识。

如果有任何问题，欢迎随时告诉我。
