Processing.js 入门指南

2008-05-10 · 阅读原文

最近 John Resig 发布了 Processing.js。这是一个非常有趣的项目，它允许在浏览器中直接运行 Processing 代码。本文将快速介绍为什么值得尝试这个项目，并以一个入门教程作为结尾。

为什么 Processing.js 如此重要？

我认为（至少）有两点原因，让 Processing.js 的出现显得尤为重要。

第一点是，Processing 的理念和语法一直让人觉得不太匹配。用代码绘制草图的想法非常诱人，我认为这个概念完美体现了 Processing 的精髓。然而，用 Java 1.3 的语法来绘制草图，就好像用一支快要干掉的马克笔写信：虽然能做到，但很难沉浸在创作的乐趣之中。Processing.js 将 Processing 的大部分功能暴露给 JavaScript，这意味着那些更熟悉 JavaScript 而不是 Java 1.3 的人，可以用自己更喜欢的语言来了解 Processing。第二点原因是“它将彻底淘汰 Java Applet”。虽然我没有 Why 那么乐观——即使经过核冬天，我依然相信 Applet 能和蟑螂一起幸存下来——但对于工具箱极为匮乏的这个细分领域，Processing.js 确实是一把趁手的锤子。

总结

至此，你已经可以随心所欲地进行各种实验了。你可以修改 test.html 中的代码内容，然后在浏览器中刷新页面；如果你想更深入地了解 Processing 语言，可以访问 Processing 官网。

我意识到，本文完全没有涉及 Processing.js 的两大亮点之一——即你可以从 JavaScript 中访问 Processing 的大部分功能。我希望在不久的将来能花些时间重写一些示例，让它们更多地依赖 JavaScript 而非 Processing 来处理应用逻辑，如果最终结果足够有趣值得分享，或许会写成另一篇文章。
