让静态网站重新“动”起来；AYM CMS

2008-09-15 · 阅读原文

写完上一篇博文后，我决定听从自己的建议，制作了一个模板项目文件夹，专门用于通过 build.py 构建脚本创建这类静态 CMS 网站。

你可以在这里下载模板的 zip 压缩包，也可以在这里克隆 GitHub 仓库。

我决定叫它 AYM CMS，其中 AYM 可以代表 “Ain't Yo Momma's”（可不是你妈妈的那套）。或者也可以是 “All Your Mess”（你的一团乱麻）。或者别的什么都行。我们就按 Git 的玩法来吧——它代表你想让它代表的任何含义。它简短好打，这一点似乎最重要……

AYM CMS 能为你提供什么

<a href="{ { image.image }}">
    <img src="{ { image.thumbnail }}" alt="{ { image.filename }}">
</a>
{% endfor %}
{% with images_dict.my_pic as image %}
<img src="{ { image.thumbnail }}">
{% endwith %}

{% load aym %}
<p> I love templates. </p>
{% markdown %}
Render this **content all in Markdown**.
>> Writing in Markdown is quicker than
>> writing in HTML.

Or at least that is my opinion.
What about you?
{% endmarkdown %}
使用 Django 模板的全部能力来构建你的静态网站。从模板继承、默认的 Django 模板标签和过滤器，到添加你自己的自定义标签/过滤器，都可以随意使用。所有放在 images/ 目录下的图片都会自动生成缩略图。它还会把所有图片加载成一个列表和一个字典，并注入到模板上下文中供渲染使用。只要把文件放入 static/ 目录，它们就会被一并复制到 deploy/static 文件夹，同时保留子文件夹结构。提供了两个自定义模板标签，让编写静态内容变得更快、更强大：markdown 和 syntax。markdown 会把包裹的文本渲染为 Markdown 格式，使用方法如下：

syntax 则使用 Pygments 为包裹的文本添加代码语法高亮，使用方法是：

{% load aym %}
<p> blah blah blah </p>
{% syntax objc %}
[obj addObject:[NSNumber numberWithInt:53]];
return [obj autorelease];
{% endsyntax %}

通过在 settings.py 文件中的 PAGES_TO_RENDER 列表添加条目，即可为你的网站增加更多页面。这意味着你只会渲染自己需要的模板，不会有多余的半成品模板散落在网站里。

你可以在 settings.py 和 build.py 中添加自定义的模板渲染上下文。这为轻松定制和编写节省时间的脚本打开了大门——无论是复制额外资源、从其他数据源注入数据，还是你那巧妙头脑能想到的几乎任何事情。

如果 AYM CMS 使用中遇到任何问题，欢迎告诉我。它的目标是成为一个通用的构建脚本，用于创建复杂的静态网站。我认为它对解决这类问题已经非常足够了（如果我再大胆一点，甚至可以说是一个很好的解决方案）。

我知道现在大家都在追捧华丽的动态网站，但我想我们大多数人手里还是维护着一些静态网站（或者在开发更复杂系统时先搭一个临时的静态站点）。AYM CMS 能很好地服务于这个虽小却重要的细分领域。

如果你有任何问题、抱怨或建议，欢迎告诉我。
