如何在 PyObjC 中使用 Selector

2008-08-19 · 阅读原文

最近我在开发一个 PyObjC 项目时遇到一个稍显复杂的情况。我希望安排一个操作，让它在稍后执行，除非满足特定条件，那时我需要取消这个已安排的操作。

如果用纯 Python 编写，我可以使用 Timer 类来实现这个功能。

from random import random
from threading import Timer
def disp():
print "Couldn't find in time."
timer = Timer(15.0,disp)
timer.start()
while 1:
if random() > 0.9:
timer.cancel()
print "Found!"
break

但当时我的思维还停留在 Objective-C 模式，所以立刻就想到了使用 NSTimer。NSTimer 创建新实例的方法定义如下1：

+scheduledTimerWithTimeInterval:target:selector:userInfo:repeats:

没问题，我们可以直接用熟悉的 PyObjC 规则进行转换。

NSTimer.scheduledTimerWithTimeInterval_target_selector_userInfo_repeats_(delay,target,selector,userInfo,repeats)

大多数参数都很好理解，但有一个地方让我不太确定：如何在 PyObjC 中创建 selector？其实非常简单，只是需要一点小技巧。

现在看起来都挺合理，对吧？不过，可能有一个小地方完全让人摸不着头脑？如果我可以直言不讳的话，signature='v@:' 这部分看起来有点神奇，甚至（我敢说）有些随意。不过幸运的是，这是一个很容易掌握的小魔法。

第一部分 v 表示该方法返回 void——即不返回任何值，第二部分 @: 表示它是一个实例方法。因为我的对象没有接受任何参数，所以就只有这些了。

但如果方法需要接受一些参数，也很容易处理。签名 v@:@fi 表示该方法接受三个参数：@ 代表对象，f 代表 float，i 代表整数。你也可以用这些相同的符号来代替 v，以指定返回值的类型。例如，考虑下面这个 Python 方法：

class MyClass(object):
    def my_method(self,x_int,y_int,z_obj):
        print x_int + y_int
        return z_obj

在 Python 中为该方法创建 selector 的写法如下：

import objc
s = objc.selector(my_method,signature="@@:ii@")

确实有点别扭，但有了 v、@、i 和 f 这四个神奇的符号，就没什么难以克服的了。
