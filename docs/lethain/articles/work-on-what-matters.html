专注于真正重要的事。

2020-09-10 · 阅读原文

我们的一生时间有限，在这有限的生命倒计时中，我们会将一部分时间投入到工作上。即使是最以事业为重的人，生活中也会有许多工作以外的事情：支持家人、照顾孩子、锻炼身体、做导师或被指导、培养兴趣爱好等等。这是一个丰富人生的标志，但其副作用是，随着职业生涯的深入，你用于工作的时间会变得越来越稀缺。

如果你仍在职业生涯中不断前进，那么即便可用于工作的时间在减少，周围对你产生影响的期望却会持续增长。在一段时间内，你可以尝试减少睡眠，或者放弃那些让你感到完整所需的非工作活动，但你最终会发现，工作对你做出的牺牲并不会给予回报，而是保持一种冷漠。只有通过四十年的职业生涯，你才能实现长期的可持续发展。

事实上，掌控节奏已成为维持长期成功职业生涯的核心挑战：越来越高的职位要求你完成越来越多的事情，而且要在越来越少的时间内完成。这两个约束之间的空间会随着你职位升高而变得越来越窄，但如果你采取有意识的方法，它仍然是可以行走的。

首先我们来讨论几种常见的容易让人跌倒的方式：零食式工作、自我炫耀，以及追逐幻影。然后我们会进入正题：如何专注于真正重要的事情？

避免零食式工作

Hunter Walk 建议大家在安排工作优先级时要避免“snacking”（零食式工作）。如果你所在的是一个运转良好的组织，那么在某个阶段，你将无法再找到既高影响力又轻松的工作。这时候你面临两个选择：向右转向困难但高影响力的工作，或是向下转向轻松但低影响力的工作。后一种选择——轻松且低影响力——就是 Walk 所说的“snacking”。

当你很忙碌时，这些“零食”会给人一种成就感，让它们在心理上感到有回报，但你不太可能从中学到什么，别人很可能同样有能力完成它们（对其中一些来说，这可能还是很好的培养机会），而且与去做更高影响力的事情相比，机会成本巨大。

花一点时间做“零食”来保持自己在重大成就之间的动力是可以的，但你必须诚实地评估自己在高影响力工作和低影响力工作上分别投入了多少时间。在高级职位上，你更有可能自主决定自己的工作内容，如果你没有刻意追踪自己的工作，很容易就会发现自己几乎没有在做高影响力的事情。

停止自我炫耀

如果说“snacking”是指做轻松且低影响力工作的广义类别，那么其中有一个特别诱人的子集，我称之为“preening”（自我炫耀）。Preening 就是去做低影响力但高可见度的工作。许多公司强烈地将高可见度与高影响力混为一谈，以至于无法区分自我炫耀和真正的影响力，这就是为什么在一些公司里，你会看到最资深的工程师把大部分时间花在价值可疑、却经常在公司会议上被表彰的工作上。

如果你从短期职业发展角度来看，那么针对当前组织在评估影响力上的病态进行优化就是最优路径：去尽情地自我炫耀吧。然而，如果你考虑的是如何在的情况下发展自己，或者如何在多个组织中取得成功，那么在有价值的工作与自我成长之间取得平衡就重要得多。与公司复杂性共同成长

这也是你在选择公司时需要考虑的重要因素！深入了解一家公司重视什么，并确保它与你希望的个人成长方向一致。如果一家公司的领导层全是那些把精力放在表现出来的紧迫感或效忠行为上的人，那么当你在公司里的成功取决于这些行为时，就不要感到惊讶。

更糟糕的是，要成为一个成功的“preener”，你需要对关于你真实影响力的批评几乎免疫，而如果你的精力被转移到自我炫耀上，你真正的工作就会受损。通常这意味着你必须是某位高层领导出于虚荣而聘请的人，或者要按照公司认为领导者应该表现的方式来包装自己。如果你不是这样的人，那么你试图用自己的良好判断力换取公司成功的尝试最终还是会失败：你会因为缺乏真正的影响力而被追责，而那些符合公司对领导者外在期望的人，却能不知怎地一路向上。

停止追逐幻影

许多人会认为，公司作为理性的优化者，应该会避免在低影响力、高投入的项目上花费太多时间。不幸的是，情况并非总是如此。新来的高级领导加入公司后，立即推动，这种情况出奇地常见。前公司留下的“幽灵”强烈影响着他们对新公司的理解，以至于他们把熟悉的事物误判为本质重要的事。大型迁移

作为一名高级领导，你必须控制自己的 ego，避免在无意义的工作上进行大规模投入。这可能会比想象中更具挑战性，尤其是在招聘过程中你反复被告诉，你是被雇来修复某个严重问题的——你是新来的救世主，你的直觉当然是对的！花时间先理解现状，再去改变它，总是会让你的勤奋得到回报。

我最近和一个人讨论，他认为新的高级领导会故意推动重大变革，即使他们怀疑这些努力会失败。这些变革会让组织越来越依赖新领导，同时也确保任何取得的好结果都被直接归功于新领导，而不是他们的团队。如果这就是你的领导方式，请知道你很糟糕，并花时间自我提升，直到整个公司的福祉和成功对你来说，比被视为不可或缺的人更加重要。

存在性问题

现在你已经不再吃零食、炫耀自己或追逐幻影，那么寻找重要工作的第一个地方，就是看看你的公司是否正面临存在性风险。公司运行在一场永恒的中，在未来的成功与活到未来成为现在之间取得平衡。如果你即将输掉其中一轮，那么永远要把注意力放在那里。使用迭代淘汰赛来进行时间线权衡

资金耗尽————可能是最明显的问题，但并非所有存在性问题都是财务上的，比如 Twitter 的“失败鲸”稳定性挑战，或是适应 Covid-19 疫情带来的转变。Digg v4 发布：源于迫切的乐观。

如果你的公司正在发生严重的问题，那就是你应该投入的地方。如果这个问题得不到解决，其他一切都无关紧要。

在有空间和关注的地方工作

存在性问题通常不是最有效投入努力的地方，但当围墙在你周围崩塌时，效率就不是优先考虑的事了。你应该蜂拥到存在性问题上，但如果一个问题不是存在性的，那么你就应该怀疑是否要把自己的努力加入到大家已经高度关注的地方。人们常常会追逐领导层的首要任务，但因为有那么多人在那里寻求影响力，往往很难产生有意义的影响。

相反，最有效的工作地点，是那些对公司很重要，但仍有足够空间让你真正开展工作的地方。哪些是未来会变得至关重要的优先事项，你可以提前做好出色的工作？哪些领域目前表现尚可，但有了你的支持就能变得卓越？

有时候你会发现值得关注的工作，但组织却无法给予关注，通常是因为其领导层不重视这类工作。在一些公司里这是开发者工具工作，在另一些公司里是包容性工作，而在大多数公司里则是“glue work”（胶水工作）。

这类没人关注的工作几乎总是有大量空间，因此你能在初期取得快速进展，这看起来是个很好的投入机会。然而，在某个时刻，这项工作会需要支持，而要为一个公司天生倾向于忽视或贬低的工作获得支持，是非常具有挑战性的。你早期的胜利会慢慢被冷漠和错位所侵蚀，你最初的影响力最终会被时间的流沙所掩埋。

这是否意味着你不应该做包容性工作？不，这不是我想让你得出的结论。有时候，一个组织不关注的领域是如此重要，以至于你会想要倡导它开始重视。教会一家公司重视它原本不在乎的事情，是你能做的最艰难的工作之一，而且常常会失败，因此你应该尽量少做，但也不能完全不做。作为一名高级领导，你的道德义务超越了最大化公司在感知层面的影响力，但认识到你面对的是什么，并相应地安排我们的努力，这一点很重要。

培养成长

一个经常被投资不足（也就是说有很多空间可以工作），同时又具有高度杠杆效应的领域，就是培养你周围的团队。招聘流程中有很多人参与，通常集中在优化上，但入职引导、导师制和教练指导在许多公司却被完全忽视，尽管它们对公司工程速度的影响至少和。你的招聘漏斗超级增长时代的生产力

如果你每周哪怕只拿出几个小时来培养周围的团队，那么很可能，在你的技术规格和 pull request 早已被遗忘很久之后，这将成为你的遗产。

编辑

有数量惊人的项目，离成功只差一个小改动、一个能解锁新机会的快速修改，或者一次能达成共识的谈话。我把做这些小改动、快速修改和简短对话视为“编辑”团队的做法。

凭借你在组织中的特权、你在公司内建立的关系，以及从经验中获得的预见能力，你往往只需投入最少的一点努力，就能改变一个项目的结果，而这正是你能做的最有价值的工作之一。

它特别有价值，因为它快速、简单，对你和被帮助的人都极具激励性，而且如果做得好，影响巨大。（另外，如果做得不好也会让人非常泄气，所以你的方法很重要！）

完成事情

一种特殊的“编辑”形式是，帮助完成一个自己无法彻底收尾的项目。通常你会遇到一个职业早期但已经很能干的工程师，他们已经在做这项工作，却无法获得足够的支持，或者不知道如何将项目调整到可完成的范围。令人惊讶的是，指导一位队友如何微调项目使其变得可完成，然后借用你的特权去推动那些关键的阻力点，往往能把一个长达六个月的苦战，变成两个星期的高效冲刺，而且影响几乎完全相同。

我们只有在完成项目时才能获得价值，而把一个项目推过终点线的那一刻，就是它从风险转变为杠杆的魔法时刻。花在完成工作上的时间，永远是值得的。

只有你能做的事

最后一类重要工作，是那种只有你才能完成的事情。当然，有些工作你比别人做得更快或更好，但更重要的是那些如果你不做就根本不会发生的工作。

这类工作是你特别擅长的事情和你真正关心的事情的交集。它可能是，可能是说服一位优秀候选人加入，可能是改变 CEO 对如何偿还技术债务的看法，也可能是设计一个精妙的 API。探索的量级。

不管是什么，那些如果你不做就不会发生的事情，是你专注于重要工作的最大机会，而且这类工作的范围会随着你职业生涯的深入而变得既更窄又更深。

为什么这很重要

如果你在职业生涯二十年后去面试一个新职位，面试你的人不会知道你在任何一个具体项目上的真实影响，也不会知道你对所任职公司的真正贡献。相反，你会发现自己被一系列惊人主观的指标所评判：你的声望、你曾获得的头衔和公司的声望、你的非公开口碑，以及你在面试过程中的表现。

如果你把职业生涯都花在吃零食、自我炫耀或追逐幻影上，那么你过去所做的事情被你所面试的公司重视的可能性虽然存在，但相对较低。相反，对你职业生涯唯一可行的长期押注，就是去做真正重要的事、能让你自身成长的事，并转向那些重视真正专业知识的公司。
