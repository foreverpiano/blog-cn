专注于重要的事。

2020-09-10 · 阅读原文

每个人的生命时间都是有限的，在这有限的倒计时中，我们会把一部分时间投入到工作中。即使是最以事业为重的人，生活中也会有许多工作以外的事情：照顾家人、养育子女、锻炼身体、担当导师与被导师、培养爱好等等。这些都是丰富人生的标志，但随之而来的副作用是，随着职业生涯的深入，你用于工作的时间会变得越来越少。

如果你仍在职业道路上持续前进，那么即便可用于工作的时间不断减少，周围对你产生影响的期望却会持续增长。在一段时间内，你可以尝试减少睡眠，或放弃那些让你感到完整的非工作活动，但最终你会发现，工作对你所做的牺牲始终保持着一种冷漠的无动于衷，而不是给予回报。只有通过四十年职业生涯，你才能实现长期的自我可持续。

的确，掌控节奏成了维持成功职业生涯的核心挑战：越来越高级的职位要求你完成越来越多的事，而且要用越来越少的时间。这两个约束之间的边缘会随着你走得更远而变得越来越窄，但只要你采取有意识的方法，它仍然是可以行走的。

首先我们来讨论几种常见的让自己绊倒的方式：零食式工作、自我炫耀，以及追逐幻影。然后我们会进入真正有价值的部分：如何去专注于真正重要的事？

避免零食式工作

Hunter Walk 建议大家在安排工作优先级时要避免“零食式工作”。如果你身处一个运转良好的组织，总有一天你会把那些高影响且容易做的事做完。这时你面临两个选择：要么向右转，去做困难但高影响的事；要么向下转，去做容易但低影响的事。后一种选择——容易且低影响——就是 Walk 所说的“零食式工作”。

当你很忙碌时，这些零食会给你一种成就感，让它们在心理上很有回报，但你不太可能从中学到多少东西，别人很可能也同样能完成这些事（对其中一些来说甚至是很好的培养机会），而且相对于去做更高影响的事，这里面存在着巨大的机会成本。

花一点时间做零食来维持自己在重大成就之间的动力是可以的，但你必须诚实地看待自己到底把多少时间花在了高影响工作上，又有多少花在了低影响工作上。在高级职位上，你更可能自主决定自己的工作内容，如果你不刻意追踪自己的工作，就很容易发现自己几乎没做什么高影响的事。

停止自我炫耀

如果说“零食式工作”是做容易且低影响工作的宽泛类别，那么其中有一个特别诱人的子集，我称之为“自我炫耀”。自我炫耀是指做低影响但高可见度的工作。许多公司把高可见度和高影响强烈地混为一谈，以至于无法区分炫耀和真正的影响力，这就是为什么在一些公司里，你会看到最资深的工程师把大部分时间花在价值可疑、却经常在公司会议上被表彰的工作上。

如果你只从短期职业发展来看，那么针对你当前组织在评估影响力上的病态进行优化就是最优路径：去尽情炫耀吧。然而，如果你思考的是如何在的情况下发展自己，或是跨多个组织取得成功，那么在有价值的工作与自我成长之间取得平衡就重要得多。与公司 complexity 共同成长

这也是你在选择公司时需要考虑的重要因素！深入了解一家公司真正重视什么，确保它与你期望的个人成长方向一致。如果一家公司的领导层全都是把精力放在表面绩效或效忠行为上，那么当你在公司里的成功取决于这些行为时，就不要感到惊讶。

更糟糕的是，要成为一个成功的炫耀者，你需要几乎对任何针对你真实影响力的批评免疫，而如果你把精力转移到炫耀上，你真正的工作就会受到损害。通常这意味着你必须是某位高级领导的虚荣招聘对象，或者以公司认为领导者应有的样子来包装自己。如果那不是你，那么你试图用自己的良好判断力去交换公司成功的尝试最终还是会失败：你会被追究缺乏真实影响力的责任，而那些符合公司对领导者外在期待的人，却会莫名其妙地继续向上爬。

停止追逐幻影

很多人会假设公司作为理性的优化者，会避免在低影响高投入的项目上浪费太多时间。不幸的是，情况并不总是如此。新来的高级领导加入公司后，立刻推动的情况 surprisingly 常见。前任环境留下的幽灵牢牢地抓住了他们对新公司的理解，以至于他们把熟悉的事物误判为本质。大型迁移

作为高级领导，你必须控制住自己的 ego，避免在大规模上投入到毫无意义的工作中。当你在招聘过程中反复被告诉说，你是被雇来修复某个严重问题的——你是新来的救世主，你的直觉当然是对的！——这其实会变得 surprisingly 困难。在做出改变之前花时间理解现状，总会让你的 diligence 得到成果的回报。

我最近和一个人讨论，他认为新的高级领导即使怀疑这些重大变革会失败，也会故意推动它们。这些变革会让组织越来越依赖新领导，同时也确保任何取得成功的事都会直接归功于新领导，而不是他们的团队。如果这就是你的领导方式，请知道你很糟糕，并且花时间好好反思自己，直到整个公司的福祉和成功对你来说，比被视为不可或缺的人更重要。

存在性问题

现在你已经不再吃零食、不再炫耀、不再追逐幻影，那么寻找重要工作的第一个地方，就是去探索你的公司是否正面临存在性风险。公司处于一场永恒的中，在未来的成功与活到未来成为现在之间寻求平衡。如果你即将输掉其中一轮，那就永远把注意力放在那里。使用迭代淘汰赛来进行时间线权衡

资金耗尽（）可能是最明显的问题，但并非所有存在性问题都是财务上的，比如 Twitter 的“失败鲸”稳定性挑战，或是适应 Covid-19 疫情带来的转变。Digg v4 发布：源于迫切的乐观。

如果你的公司正在发生什么危急的事，那就是你应该投入的地方。如果这个问题得不到解决，其他一切都不重要。

在有空间和关注的地方工作

存在性问题通常不是投入努力最高效的地方，但在四周墙壁都在倒塌时，效率就不是优先级了。你应该蜂拥去解决存在性问题，但如果一个问题不是存在性的，那么你就应该对在大家都已聚焦的地方投入努力保持怀疑。人们常常去追逐领导层的首要任务，但因为有太多人在那里试图做出影响，往往很难产生有意义的影响。

相反，最有效的工作地点，是那些对公司重要但仍有足够空间让你真正开展工作的领域。哪些是未来会变得关键的优先级，而你现在就能提前做出出色的工作？哪些领域目前表现尚可，但有了你的支持就能变得出色？

有时候你会发现值得关注的工作，但组织却无法给予关注，通常是因为其领导层并不重视这类工作。在一些公司里这是开发者工具工作，在另一些公司里是包容性工作，而在大多数公司里则是“胶水工作”。

几乎总是存在大量空间去做这种没人关注的工作，所以你能在这个领域快速取得初期进展，这感觉像是一个很好的投入机会。然而，到了一定阶段，这项工作会需要支持，而要为一个公司天生倾向于忽视或贬低的工作获得支持是非常困难的。你早期的胜利会慢慢被冷漠和错位所侵蚀，你最初的影响力最终会被时间的沙子重新掩埋。

这是否意味着你不应该做包容性工作？不，这不是我想让你得出的结论。有时候，一个组织不重视的领域是如此重要，以至于你会想要倡导它开始关注。教会一家公司去重视它原本不在意的东西，是你能做的最难的工作之一，而且常常会失败，所以你应该尽量少做，但也不能完全不做。作为高级领导，你负有超越最大化公司感知影响力的道德义务，但认识到你面对的是什么，并相应地安排我们的努力也很重要。

培养成长

一个经常被投入不足（也就是有很多空间可以工作），同时又具有高度杠杆效应的领域，是培养你周围的团队。招聘有很多人参与，通常集中在优化上，但入职、导师指导和教练辅导在许多公司却完全被忽视，尽管它们对公司工程速度的影响至少和。你的招聘漏斗超高速增长时代的生产力

如果你开始每周甚至只拿出几个小时来发展你周围的团队，那么很可能，在你的技术规格和 pull request 早已被遗忘很久之后，这将成为你的遗产。

编辑

有数量惊人的项目，距离成功只差一个小小的改变、一个快速的修改就能打开新的机会，或者只差一次对话就能达成共识。我把做这些小的改变、快速的修改和简短的对话，视为在编辑团队的做法。

凭借你在组织中的特权、你在公司里建立的人脉，以及从经验中获得的预见能力，你常常能用最小的努力就改变一个项目的结果，而这正是你能做的最有价值的工作之一。

它特别有价值，因为它快、它容易、对你和被帮助的人都有很强的激励作用，而且如果做得好，影响巨大。（另外，如果做得不好，它也极具破坏性，所以你的方式很重要！）

完成事情

一种特殊的编辑工作是帮助完成一个自己无法彻底收尾的项目。你常常会遇到一个职业早期但很有才华的工程师，他们已经在做这项工作，却无法获得足够认同，或者不知道如何将项目重新界定为可完成的工作。令人惊讶的是，你只要教练队友如何调整项目使其变得可完成，然后借用你的特权去推动那些关键的摩擦点，就能把一个长达六个月的苦战变成两周的冲刺，而最终影响几乎完全一样。

我们只有在完成项目时才能获得价值，而把一个项目推过终点线，就是它从风险变成杠杆的魔法时刻。花在完成工作上的时间永远是值得的。

只有你能做的事

最后一类重要工作，是那种只有你才能完成的事。当然，有些工作你比别人做得更快或更好，但更重要的是那种如果你不做就根本不会发生的工作。

这类工作是你特别擅长的事和你真正关心的事的交集。它可能是，可能是说服一位优秀候选人加入，可能是改变 CEO 在如何偿还技术债上的想法，可能是精心设计一个有辨识度的 API。探索的量级

不管是什么，那些如果你不做就不会发生的事，是你去专注重要工作的最大机会，而且随着职业生涯的深入，这类工作的范围会变得既更窄、也更深。

为什么这很重要

如果你在职业生涯二十年后去面试一个新职位，面试你的人不会知道你在任何一个具体项目上的真实影响，也不会知道你对所任职公司的真正贡献。相反，你会发现自己被一系列 surprisingly 主观的指标所评判：你的声望、你拥有过的头衔和公司的声望、你的私下口碑，以及你在面试过程中的表现。

如果你把职业生涯花在吃零食、自我炫耀或追逐幻影上，那么你过去所做的事被你后续面试的公司重视的可能性虽然存在，但相对较低。相反，对职业生涯唯一可行的长期押注，就是去做真正重要的事、去做能发展自己的事，并转向那些重视真正专业能力的公司。
