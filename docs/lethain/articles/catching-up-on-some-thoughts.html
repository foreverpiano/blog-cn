追上一些想法

2008-03-10 · 阅读原文

坐在厨房里，一边洗碗一边用锅烧水煮饭，我忽然意识到今晚正是适合写作的夜晚。一个合适的时间，来向大家交代一下我现在身在何处，以及接下来要去往哪里。

坐在日本岐阜县的暖桌下，冬天终于开始退去。最近大多数日子气温升到了四十几华氏度，下了三个月的雪之后，天空终于记起了如何下雨。我意外地发现自己有多么想念雨声、雨的力量，还有雨后留下的气息，以及雷雨中那种平静安宁的感觉。我真的很高兴，又下雨了。

上周有几个早晨地上还覆着雪，但即使是冬天最后的温柔拉扯，似乎也将在接下来一两周内让位于春天。看着暴风雪变成泥泞的雪水，这种满足感，只有在雪已经纠缠了你整整三个月之后，才能真正体会。

话虽如此，天气还是相当寒冷，但早晨半冻住的水管发出的那种标志性嘎嘎声已经停止了，我还自十二月以来第一次把衣服挂在外面晾干。（从那以后我一直开车三十分钟去投币式洗衣店。）

高中生（我并不教他们）上周已经毕业了，我教的初三学生明天也要毕业。我并不特别难过，但他们确实是我工作中最喜欢的部分，所以对于他们即将永远从我的生活中溜走，我并非没有一些复杂的心情。其中四个人参加过演讲比赛，是我抵达日本后最早认识的四个学生，直到现在依然是我最了解的四个。他们的演讲主题是各自的梦想，内容有的比其他更震撼人心，但我很享受和他们一起工作的过程。

初三学生毕业后，学校接下来的一周半时间里就只剩下初一和初二的学生，总共大约180人，直到春假开始。然后他们会消失两周，同时消失的还有一些将被调到本地区其他学校的老师。目前还不知道谁会被调走，但我确定的是，我所在基地学校的指导老师即将结束她的教学生涯。她五十多岁，已经教了大约二十年书。她想去发展中国家做志愿教学，教日语或英语。虽然她是家里的主要经济支柱（丈夫是农民），而且有个十二岁的儿子，但她还是决定为自己和人生规划一个新的方向。

最终，人们会根据未来几年财务和家庭情况的结果，判断她是勇敢还是鲁莽。但无论结果如何，我都不会吝惜对她正在尝试的事情给予尊重。人类最可怕的景象之一，就是那些不快乐却下定决心什么都不改变的人；而最鼓舞人心的景象之一，则是那些尽管飞行 inherently 危险，却仍向往更高处的人。

我想这也关联到 JET Program 最令人不安的一个方面：太多人是因为恐惧而选择续约。这不是害怕教育委员会训斥他们，也不是担心世界会因为他们的离开而崩塌……他们只是不知道自己该做什么，于是就在虚线上签下名字，排队再干第二年或第三年。在续约期结束前，县政府（以及 CLAIR，这个政府的全国性机构）发了一封邮件，讨论了续约的好理由和坏理由。稍微简化一下，基本上就是：个人成长是留下的最好理由，而不确定性是离开的最好理由。

有条经常被重复的规则大概是：“愚蠢就是做同一件事两次，却期待得到不同的结果。”我认为这也适用于在 JET Program 续约第二年。有些人第一年过得相当不错，大体上很享受，对这些人来说第二年多半也会不错。另一方面，那些第一年过得很惨的人——除非发生了什么关键变化——第二年大概率也会同样惨淡。

最近每当续约的话题出现时（即使截止日期已经过去一个多月，这个话题还是经常被提起），住在我镇对面的那个狡猾的家伙就喜欢指出，我对整个过程大概没那么情绪化，因为“你不是在下飞机之前就已经铁了心不续约吗？”

诚然，飞往日本的航班并不特别舒服，尤其是坐在一个肥胖乘客旁边的时候，但我不能诚实地说自己那么早就下定了决心。如果要说我最初的想法，大概就是我知道自己热爱编程，而且不太敢期待自己会更热爱教英语。

接下来的几个月里，并没有发生太多事情改变这一点。而唯一两种可能让我认真考虑续约第二年的情况，要么是我的女朋友决定续约，要么是我弄丢了脑子里那个存放连贯英语的隔间的钥匙，直到回美国才能取出来。所以，不，决定不留第二年并不困难。有很多因素可以放在天平上衡量：我喜欢这个小镇，但不太喜欢这里的冬天；我喜欢工作中的同事，但不太喜欢这份工作本身；能拿到成人水平的工资很不错，但高级食材也只能治愈到一定程度。

不过说到底，这份工作就是不适合我。它还可以，我不喜欢的大部分事情我都可以更努力去改善，但到了某个时刻，你必须检查自己浇水壶上的刻度，决定要给哪些种子浇水。JET 有点像仙人掌，耐旱又顽强，但即使你每天照顾它，或者给它穿上锦缎，它依然是一株又丑又该死的仙人掌。

所以我转而去浇灌编程和写作，观察它们是否显露出生机。在小众圈子之外，把空闲时间花在编程和写作上显得有点奇怪，但到了某个时刻，你就是得去追逐自己的幸福，而不是接受别人递给你的东西。这就是我正在行走的道路。

在过去几个月里，而且随着每一周过去，这种想法变得更加清晰：我决定接下来的人生阶段要做一名独立软件开发者。但这可能稍微有些轻描淡写。我想以一人编程工作室起步，并把它发展成一家公司。过去的七个月帮助我磨砺了这个梦想，也让我尝到了对工作不满意是什么滋味。坦白说，我不想再有更多这样的感受。我想尽可能减少，越少越好。我看到的减少它的途径，就是驾驶自己的船只，驶向更甜美的地平线。希望这艘船能抵达，但与其等待电梯安装好，不如从通往天堂的楼梯上跌落。

总之，这就是我的梦想，我希望能尽可能多地带上其他人一起上路。这将会是一趟美好的旅程。
