Shoes Curious 在 OS X 10.4 下的怪异显示问题

2008-01-10 · 阅读原文

就在几天前，Why the Lucky Stiff 发表了一篇博客，介绍了 Shoes 的第一个命名版本，我对此感到非常兴奋。虽然我并不是一个狂热的 Ruby 开发者，但我必须承认，我非常喜欢 Shoes。我真的很享受用 Shoes 来制作简单的小应用程序。

正因如此，随着 Shoes Curious 的发布，我决定再用 Shoes 写一个程序，看看他们目前做得怎么样。

（编者注：同时写 Why 和 Shoes 真的让我大脑短路。Why 既可以是形容词也可以是名词。“Thats why!” 既可以是在公共场合看到 Why 时的惊讶感叹，也可能是一句干巴巴、写得很烂的句子，用来解释新版 Shoes 的发布。而 Shoes 是……是……同样让人头疼。）

我正在编写一个简短的小程序，狡猾地把它命名为 The Lazy Internet，它的功能是：当我没有网络连接时收集各种链接，等检测到有网络后再去下载它们。

这是一个简单的工具，但在我以前那些无法连接网络的日子里，我偶尔会非常希望自己有这样一个工具。

不过，在 OS X 上开发 Shoes 仍然充满风险。（我目前还在使用 OS X 10.4，这可能是问题的一部分，也可能不是。）最关键的问题是，用同一个 Shoes 解释器运行同一个 Shoes 程序，却会得到截然不同的结果。

下面是几张截图，展示了运行同一段代码后我得到的各种不同结果。（代码放在图片下方。如果我正淹死在我自己精心制作的汤里，请务必告诉我！）

源代码

QUEUED = []
DOWNLOADING = []
DOWNLOADED = []
BANDWIDTH_THROTTLE = 50
Shoes.app :title => "The Lazy Internet", 
  :width => 800, :height => 400 do
  background "071A17"
  stack :width => 780, :margin => 20 do
    flow :width => 1.0, :height => 40 do
      background "#071A17"
      @url = edit_line :width => 500, :margin_right => 50, :text => "http://"
      button "enqueue", :width => 100 do
        enqueue(@url.text)
        @url.text = "http://"
      end
    end
    stack :width => 1.0, :height => 100 do
      background "#A69561"
      @queued = para "queued downloads"
    end
    stack :width => 1.0, :height => 100 do
      background "#665C2C"
      @downloading = para "in progress downloads"
    end
    stack :width => 1.0, :height => 100 do
      background "#332E1E"
      @downloaded = para "finished downloads"
    end
  end
  def redraw_queued
    @queued.replace *(QUEUED.map { |url| url + "\n" })
  end
  def redraw_downloading
    @downloading.replace *(DOWNLOADING.map { |download| download + "\n" })
  end
  def redraw_downloaded
    @downloaded.replace *(DOWNLOADED.map { |download| download + "\n" })
  end
  def enqueue(url)
    QUEUED << url
    redraw_queued
  end
  def download
    dl = QUEUED[0]
    if dl != nil
      DOWNLOADING << dl
      QUEUED.delete dl
      redraw_queued
      redraw_downloading
    end
  end
  def complete(dl)
    DOWNLOADING.delete dl
    DOWNLOADED << dl
    redraw_downloaded
  end
  animate(8) do
    download
  end
end
