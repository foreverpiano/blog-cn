更梦幻的 Dream Server：使用 Nginx

2007-07-17 · 阅读原文

2009/2/13 本文更新版本（基于 Ubuntu Intrepid）可在此查看。

在我之前的配置中，使用 mod_proxy 的方式存在一些问题。请求首先到达 Apache，如果是媒体文件，Apache 会将请求转发给 Lighttpd，Lighttpd 把文件传回 Apache，最后再由 Apache 发送给客户端。显然，这简直是疯了。

因此我重新整理了指南，减少了那些灾难性的脑残操作。文章也进行了精简，所有关于安全的章节已被移除，你可以参考原始文章，但最好寻找更专业的服务器安全资源。

主要流程基本不变，现在我们将使用 Nginx 作为前端代理和静态媒体服务器，用带 mod_python 的 Apache2 作为后端处理 Django 请求。放弃 Lighttpd 改用 Nginx，主要是因为 Nginx 来自俄罗斯，显得更具异域风情。

另外，Lighttpd 还有一个烦人的内存泄漏问题。

最终效果

最终产物依然是一台 Ubuntu Feisty 服务器。它将使用 Nginx 作为前端（处理静态媒体，并将其他请求代理给 Apache2），Apache2 作为后端服务器。使用 memcached 进行缓存，Postgres 8.2 作为数据库。Django 仍是我们的首选框架。

接下来进入有趣的部分。

将 Ubuntu Dapper 升级到 Feisty

从 Ubuntu Dapper（SliceHost 当前提供的 Ubuntu 系统）升级到 Feisty 过程快速且无痛。你必须按顺序升级：直接跳到 Feisty 可能会导致系统不稳定。最后执行的 'lsb_release -a' 只是为了确认升级是否成功，它应该显示已安装 Feisty。
