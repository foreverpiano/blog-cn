实时输入 Slug 唯一性验证

2008-09-26 · 阅读原文

欢迎来到 Django、jQuery 和 Ajax 教程系列的第四篇也是最后一篇，它接续《Layers of Authentication》之后的内容。

因为这是最后一篇，我们打算做点快速又有趣的事情：让首页的 slug 字段在你输入时就能实时验证，通过将输入框的背景颜色变为红色（已被占用）或蓝色（可用）来提示。

让我们开始吧。

两个程序员、一条 URL 和一个视图

首先打开 notes/urls.py，添加以下 URL 配置：

(r'^slug_available/$', 'notes.views.slug_available'),

然后打开 notes/views.py，添加以下方法：

@login_required
def slug_available(request):
    if request.method == "GET":
        get = request.GET.copy()
        if get.has_key('slug'):
            slug_str = get['slug']
            if Note.objects.filter(slug=slug_str).count() == 0:
                return HttpResponse(slug_str)
            else:
                return HttpResponseServerError(slug_str)
    return HttpResponseServerError("Requires a slug field.")

我们通常用返回的数据来表示请求成功或失败，但使用 HTTP 响应码来区分成功和失败会更简单、更清晰，也（或许）更符合 HTTP 的设计理念。

这个视图在成功时会返回 200 响应码（因为使用了 HttpResponse），失败时返回 500 响应码（因为使用了 HttpResponseServerError）。我们通过在 500 响应中返回不同的文本内容来区分不同类型的失败。

除此之外，slug_available 这个视图相当直观，我们接下来把它集成到模板中。

集成到 notes/note_list.html

我们先从列表视图开始愉快地集成，请打开 notes/note_list.html 模板。

首先，我们来修正之前偷懒的地方，把这段代码里的所有内容都包裹在 <script></script> 标签中：

<script>
$(document).ready(function() {
// All other JavaScript here.
});
</script>

这是一个非常实用的 jQuery 模式，它能确保你的 JavaScript 在 DOM 完全加载并准备好被操作之后才执行。如果不使用它，可能会出现一些非常模糊且难以追踪的问题……所以，请务必使用它。

现在回到我们的任务：根据 slug 是否可用更新输入框的背景颜色。

效果如下（你需要把这段代码添加到 note_list.html 中 <script></script> 标签内的某个位置）：

$("#slug").keyup(function() {
    var slug = this.value;
    var complete = function(res, status) {
       if (status == "success") $("#slug").css('background-color','#A0A0FF');
       else $("#slug").css('background-color','#FFA0A0');
    }
    $.ajax({type:'GET', url:'/slug_available/', data:{'slug': slug }, complete:complete});
    });
});

如果愿意，我们可以把第一行内联进来，把代码压缩得更简洁一些。

$("#slug").keyup(function() {
  var complete = function(res, status) {
    if (status=="success") $("#slug").css('background-color','blue');
    else $("#slug").css('background-color','red');
  }
  $.get('/slug_available/',{'slug':this.value},complete:complete);
});

然后我们可以把整个回调函数也内联进去。

$("#slug").keyup(function() {
  $.get('/slug_available/',{'slug':this.value},complete:function(res, status) {
    if (status=="success") $("#slug").css('background-color','blue');
    else $("#slug").css('background-color','red');
  })});

这看起来是个不错的结束点。

至此我们就实现了一个实时输入的 slug 验证系统。这是我认为真正有价值的 Ajax 技术之一，它能有效地向用户传递额外信息，非常推荐在合适的应用场景中集成它。
