Freebase 黑客日与 Image Game

2009-07-12 · 阅读原文

昨天我参加了 Freebase Hackday 09，这是一次绝佳的机会，通过与实际打造它的工程师交流，让我对 Freebase 有了更多了解。此外，这也是我第一次接触 Freebase Apps，其核心就是 Acre：一个同时支持服务端和客户端 JavaScript 的 Web 应用开发平台。

听到又一个新的 Web 服务器（无意冒犯 YAWS），还带着自己的开发环境、模板语言和配套库，我多少觉得有点可怕。这不仅需要服务器、环境、IDE 和库的团队投入大量时间，也给每位尝试在其中开发的程序员带来了负担。最让我警惕的是，这类问题做起来特别有趣，而有趣的问题往往是最危险的。

不过就这个项目而言，我认为 Acre 的最终产品还是相当扎实的。虽然我可以对一些细节吹毛求疵，但只花了一两个小时上手尝试后，Acre 就让人觉得相当直观，其文档也足够充分。总体来说，这个环境还比较年轻，但看起来有潜力打磨成一个相当舒适的开发平台。（它让我想起很多 Bespin 的感觉。）

在这次黑客日上，其中一个建议项目与 Games With a Purpose 的思路类似，这正是我参与的方向。与 Peter Burns 以及几位超级热心的 Metaweb 成员合作，我们很快拼凑出了一个非常粗糙的概念，它的代号听起来有些误导——叫做 Image Game。

（抱歉在这个原型里还没有显示出处信息。我们在当天结束前进行闪电演讲演示时已经来不及了，但毫无疑问，出处信息会在图片加入到公开 Freebase 数据之前得到修正并正确标注。）

这类游戏的核心概念，就是利用用户空闲的时间来解决计算机难以处理的难题。Image Game 的具体想法是：找出 Freebase 中尚未关联图片的地点，然后向 Flickr API 查询可能的匹配结果（目前仅通过标签匹配，理想情况下后续会结合标签和地理标记一起判断），再让用户来判断哪张图片最适合对应地点。

这些投票结果随后会被 Metaweb 用于推理筛选合适的图片（例如需要若干不同用户对同一地点选择同一张图片等条件），最终用户提供的数据也可以进入公开的 Freebase 数据集中。

这是一次很有趣的活动，也是一个做起来相当开心的应用。希望未来几周内它能得到进一步打磨，但无论如何，我都 strongly 推荐大家参加下一次 Freebase Hackday。
