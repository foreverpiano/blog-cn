Freebase Hackday 和图像游戏

2009-07-12 · 阅读原文

昨天我参加了 Freebase Hackday 09，这是一次很好的机会，通过与真正构建它的工程师交流，来更深入地了解 Freebase。此外，这也是我第一次接触 Freebase Apps，其核心是 Acre：一个同时支持服务端和客户端 JavaScript 的 Web 应用开发平台。

当我听说又一个新的 Web 服务器（无意冒犯 YAWS）自带专属开发环境、模板语言和配套函数库时，心里多少有些不安。这需要服务器、环境、IDE 和函数库团队投入大量时间，同时也会给每位试图在其中开发的工程师带来负担。最让我警惕的是，这类问题通常都很有趣，而有趣的问题往往最危险。

不过在这种情况下，我认为 Acre 的最终产品还是相当不错的。虽然我可以挑出一些小毛病，但经过一两个小时的实际尝试，Acre 用起来相当直观，其文档也足够充分。总体来说，这个环境还比较年轻，但看起来有可能打磨成一个相当愉悦的开发平台。（它让我想起很多 Bespin 的感觉。）

在 Hackday 上，其中一个建议项目与 Games With a Purpose 的思路类似，这也是我选择参与的方向。在 Peter Burns 和几位非常热心的 Metawebbers 的帮助下，我们共同完成了一个非常粗糙的概念作品，它的代号听起来有些误导——Image Game。

（抱歉在这个原型中还没有显示作者署名。我们在当天结束前的闪电演讲前已经没时间了，但毫无疑问，在这些图片被加入到公开的 Freebase 数据之前，署名信息会被修正并包含在地点数据中。）

这类游戏的核心理念是利用用户空闲的时间来解决计算机难以处理的难题。Image Game 的具体概念是：找出 Freebase 中尚未关联图片的地点，然后向 Flickr API 查询可能的匹配图片（初期仅通过标签匹配实现，未来理想情况下会结合标签和地理标记），再让用户判断哪张图片最符合某个地点。

这些投票结果随后会被 Metaweb 用于推理，选择合适的图片（例如需要若干不同用户对某个地点和图片达成一致等），最终用户提供的数据也可以进入公开的 Freebase 数据库。

这是一次很有趣的活动，也是一个挺好玩的小应用。希望在未来几周内它能得到进一步打磨，但无论如何，我都强烈推荐大家参加下一次的 Freebase Hackday。
