基本结构应该已经很熟悉了：urlpatterns 定义了 URL 如何映射到视图函数，而视图（compute）则根据请求生成响应。但有几处发生了变化：

正则表达式现在可以匹配参数：\w 匹配字母或数字，\w+ 匹配一个或多个这样的字符，(?P<op>\w+) 则给这个序列起名为 op。这些都是普通的 Python re 模块的功能。Django 会把从正则表达式中提取的参数传递给视图函数：compute 会额外收到一个名为 op 的关键字参数。它永远是字符串类型，即使正则匹配的是数字（\d）。request.GET 是一个包含 GET 参数（a 和 b）的字典，同样也都是字符串。
