在 PyObjC 中写入 Application Support

2008-08-22 · 阅读原文

使用 PyObjC 编写 Cocoa 应用时，很容易养成在 .app 包内保存错误类型数据的坏习惯。例如，在我正在开发的一个应用中，我使用了一个 SQLite 数据库，并像下面这样从 .app 包内部访问它：

import os,sqlite3
def getDatabase(self):
    path = os.path.join(os.path.dirname(__file__),'my_dict.sqlite')
    return sqlite3.connect(path)

由于这个数据库包含的是不可变数据，因此将其存储在 .app 包内是合适的位置。然而，在同一个应用中，我还需要存储一些用户特定的数据。与不可变的数据库不同，用户特定数据的正确存储位置是 ~/Library/Application Support/ 的某个子文件夹中。

计算该文件夹的函数可以这样实现：

import os
from AppKit import *
from Foundation import *
def applicationSupportFolder(appname=u"MyAppNameHere"):
    paths = NSSearchPathForDirectoriesInDomains(NSApplicationSupportDirectory,NSUserDomainMask,True)
    basePath = (len(paths) > 0 and paths[0]) or NSTemporaryDirectory()
    fullPath = basePath.stringByAppendingPathComponent_(appname)
    if not os.path.exists(fullPath):
        os.mkdir(fullPath)
    return fullPath

这样我们就能为任意应用找到它的支持文件夹（只要知道应用名称即可），但我们可以进一步构建一个更实用的函数，在此基础上拼接出给定文件名的完整路径。

def pathForFilename(filename,appname=None):
    base = (appname and applicationSupportFolder(appname)) or applicationSupportFolder()
    return base.stringByAppendingPathComponent_(filename)

使用 pathForFilename 的方式如下：

path = pathForFilename('user_data.xml','my_app')
fin = open(path,'r')
prefs = SomeCustomPythonClass(fin.read())
