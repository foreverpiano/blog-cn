迁移“本周 Django”这个概念

2008-09-05 · 阅读原文

为了致敬 This Week In Django 全新改版，我花了些时间思考为什么这个绝妙的概念还没有在其他项目中流行起来。当然——Michael、Brian 和 Kevin 每周都要投入大量时间——但或许还有更深层的原因？

本周 iPhone 开发

背景音乐：任何能让剪影激烈舞动的流行金曲。

欢迎收看本周 iPhone 开发！我们为你准备了一期非常特别的节目。是的，没错。本周 Apple 有了一些关键进展。事实上，我采访过的一些工程师把这些变化称为“比我第一个孩子出生还要激动人心”。真的吗？那我们就开始聊聊这些变化吧……嗯，好吧。我很想聊。但法务部门明确表示，如果公开谈论这些内容，我们很可能会违反 NDA。对，还是这个问题。那我们聊聊本周的博客内容怎么样？嗯，法务部门对这个也不太放心，觉得我们可能会因此承担连带责任。好吧，这就是另一期《本周 iPhone 开发》。下周同一时间，我们继续为您带来同样精彩的内容！

本周 Google Chrome

背景音乐：和 Scala 编程语言宣传曲一样怪异且同样高制作水准的歌曲。

欢迎收看本周 Google Chrome！Google 居然他妈的做了一款浏览器。天哪，太惊人了。 除了是一款浏览器之外，它还拥有一些令人印象深刻的技术特性。 天哪，这也太牛了。Reddit Programming 社区都爱上 Google Chrome 了！Google 做浏览器啦！ 好吧，如果我们看看 John Resig 关于 Google Chrome 进程管理器的文章，就会发现 Chrome 确实有扎实的技术价值，并且可能会开启浏览器开发的新一轮热潮。 浏览器们已经在 CSS 渲染上投入了大量精力，我很高兴我们能重新回到一种更全面的浏览器开发思路，既关注直观、简洁的用户界面，也重视性能问题。 它就是个浏览器啊兄弟。我简直不敢相信我居然拿到了一款新浏览器！ 算了，我不干了。你比《Best in Show》里那个解说颜色的人还烦。

总之，经过一番思考后，似乎确实能找到一些原因，解释为什么 This Week in Django 的 brilliance 至今还没有传播到其他社区。
