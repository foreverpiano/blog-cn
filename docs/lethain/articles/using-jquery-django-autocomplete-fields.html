在 Django 中使用 jQuery 实现自动完成字段

2007-11-30 · 阅读原文

本文没有经过特别润色，阅读前需要具备一定的 Django 知识，但不需要有 jQuery 使用经验。

用 Django 配合 jQuery 实现 Ajax 其实很简单，但要做一个自动完成表单就稍微复杂一些。下面是一个完整 walkthrough。

我使用的是 Frank Vega 的 autocomplete 库。这个库比较简洁，但完全够用。先下载它的 JavaScript 和 CSS 文件。此外你还需要 jQuery 的 Dimensions 插件和 jQuery 本身。把这些文件都放到 media 文件夹下的 js 目录里，结构应该如下：

/media
    /js
        jquery-1.2.1.js
        dimensions.js
        autocomplete.js
        autocomplete.css

我们的模板

首先来写模板。我们会用到两个模板：一个基础模板用于加载 JavaScript 和 CSS 文件，另一个较小的模板可以在需要使用自动完成表单的地方引入。

<html lang=en>
  <head>
    <meta http-equiv="content-type" content="text/html; charset=UTF-8">
    <link type="text/css" rel="stylesheet" href="/media/js/autocomplete.css">
    <script type="text/javascript" src="/media/js/jquery-1.2.1.js"></script>
    <script type="text/javascript" src="/media/js/dimensions.js"></script>
    <script type="text/javascript" src="/media/js/autocomplete.js"></script>
    {% block extra_css %}{% endblock extra_css %}
    <title>{% block title %}books are social{% endblock title %}</title>
  </head>
  <body>
    {% block body %}
    {% endblock body %}
  </body>
</html>

较小的模板内容如下：

<script type="text/javascript" >
$(function(){
  setAutoComplete("bookSearchField", "bookResults", "/lookup/?query=");
});
</script>
<label for="bookSearchField">Book: </label>
<input type="text" id="bookSearchField" name="bookSearchField">

使用时，通过 {% include "path/to/lookup.html" %} 标签引入它（假设你把这个小片段保存为 lookup.html）。注意，这个较小的模板应该被包含在一个继承自上面 base 模板的大模板中，这样才能使用所需的 JavaScript 库。

URL 配置

接下来我们要创建一个简单的 urls.py 文件，用于处理前端的请求（记得把里面的项目名和应用名改成你自己的）：

from django.conf.urls.defaults import *
urlpatterns = patterns('project.app.views',
    (r'^/lookup/$', 'book_lookup'),
)

这部分可能需要根据你的实际情况稍作调整，但并没有用到 Django 教程之外的高级技巧。

模型

一个非常简单的 Book 模型，我们将通过它进行搜索。

class Book(models.Model):
    name = models.CharField(max_length=200)

视图

视图非常简洁，只需解析传入的 GET 请求，然后返回序列化后的数据即可。

from django.utils import simplejson
from django.http import HttpResponse
from project.app.models import Book
def user_lookup(request):
    # Default return list
    results = []
    if request.method == "GET":
        if request.GET.has_key(u'query'):
            value = request.GET[u'query']
            # Ignore queries shorter than length 3
            if len(value) > 2:
                model_results = Book.objects.filter(name__icontains=value)
                results = [ x.name for x in model_results ]
    json = simplejson.dumps(results)
    return HttpResponse(json, mimetype='application/json')

注意我们使用了 'name__icontains' 来按书名搜索。这在 SQL 中会翻译成 LIKE 查询，从性能角度看，这在大型数据库上会相当慢。这只是一个示例，并非生产环境质量的代码。

结束

使用 jQuery 实现简单自动完成功能就是这么简单。Django 确实让这类事情变得相当容易，只是在刚开始接触时可能会觉得有点困惑。
