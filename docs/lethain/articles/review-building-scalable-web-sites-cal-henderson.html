《构建可扩展网站》——Cal Henderson 著

2007-07-17 · 阅读原文

最近我花了很多时间阅读关于构建可扩展网站的相关资料。我在数据库领域里构建了一张张思维对照表，比较 PostgreSQL、Oracle 和 MySQL；我还在 Apache 的“坟墓”上跳舞，并试图得到 Memcached 的亲笔签名。所以，我对扩展还是了解一些的。

呼……我给大家一点时间，让你们恢复平静。

好吧，其实我对扩展并没有了解多少。这就是为什么我最近订购了 Cal Henderson 的《Building Scalable Web Sites》。这是一本书，那种用死掉的树做成的东西。更准确地说，它讨论的是一个快速发展的领域。Nginx 成了新的 Lighttpd，而 Lighttpd 曾经是新的 WebBrick。PostgreSQL 其实已经很快了。SQLite 做行级锁（好吧，这个是骗人的，SQLite 依然讨厌你和那些脏兮兮的并发操作）。

幸运的是，这本书的层次写得足够高，大部分内容都避免了立即过时。正如人们所预料的，它偶尔会因为一些具体细节而让自己显得过时，但还不至于失去价值。哦，对了，它的價值，我也该稍微谈谈。

这本书的价值在于，它对一系列广泛的话题都做了轻触式的介绍，读完之后能让你对扩展一个 Web 系统所涉及的相互关联的各个要素形成一个清晰的高层次印象。你可能已经了解数据库和 memcached，但你或许没有想过如何处理不符合标准的手机邮件，或者如何应对整个数据中心故障的问题。如果你已经思考过不符合标准的手机邮件或其他相对细节的扩展问题，那么这本书可能不会给你带来多少价值。它是一本概览书，一本写得很好的概览书，但归根结底还是一本概览。

《Building Scalable Web Sites》的理想读者是对扩展 Web 服务几乎一无所知的人。这本书能帮助你建立一个思考扩展问题的框架，这对不熟悉该领域的人来说具有巨大价值，但它并不会把这个框架填充得非常详尽。

至于我，我读得很享受，而且书写得也很好（虽然我因为里面出现《搏击俱乐部》的梗而扣了分——在当下，这类引用已经不太能被社会接受了）。我可能会把它塞在书架的某个角落……但我其实在考虑把它转手送人。除非我失忆，否则我不认为它会成为一本经常翻阅的参考书。公平地说，我也不认为任何一本书能在扩展领域达到 Knuth 的《计算机程序设计艺术》在算法领域所达到的地位（也就是让学生们普遍痛恨）。

所以，去找一本看看吧，翻翻目录，读一读那些看起来不熟悉的部分（第九章关于数据库垂直扩展和水平扩展的讨论特别值得一读），但除非你觉得扩展这个话题特别令人生畏，否则我不推荐你买一本。不过，如果你决定要买一本，可以在这里购买《Building Scalable Web Sites》。
