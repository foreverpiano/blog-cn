《构建可扩展网站》—— Cal Henderson 著

2007-07-17 · 阅读原文

最近我花了大量时间阅读关于构建可扩展网站的资料。我在数据库领域里构建了一张张心理对照图，比较 PostgreSQL、Oracle 和 MySQL；我还在 Apache 的坟头上跳舞，并试图讨到 Memcached 的签名。所以，我对扩展性还是了解一点的。

呼。我给大家一点时间，让你们缓过神来。

好吧，其实我对扩展性了解得并不多。这也是为什么我最近订购了 Cal Henderson 的《Building Scalable Web Sites》。这是一本书，那种用死掉的树做成的东西。更准确地说，它是一本关于一个快速演进领域的书。Nginx 成了新的 Lighttpd。Lighttpd 曾经是新的 WebBrick。PostgreSQL 其实已经很快了。SQLite 会做行级锁（好吧，这个是谎话，SQLite 依然讨厌你和你那些脏兮兮的并发操作）。

幸运的是，这本书的层次足够高，因此大多不会立刻过时。正如人们所料，它偶尔会因为一些具体细节而让自己显得有些落伍，但还不至于失去价值。哦，说到它的价值，我也应该谈谈这一点。

它的价值在于对众多主题都进行了浅尝辄止的触及，读完之后能让你对扩展一个 Web 系统所涉及的相互关联的各个部分形成一个良好的高层认知。你可能已经了解数据库和 memcached，但你或许从未想过如何处理不符合标准的移动设备邮件，或者如何应对整个数据中心故障的问题。如果你已经思考过不符合标准的移动邮件或其他较为细节的扩展问题，那么这本书对你来说可能价值不大。它是一本概览，一本写得相当不错的概览，但终究只是一本概览。

《Building Scalable Web Sites》的理想读者是对扩展 Web 服务几乎一无所知的人。这本书能帮助你建立一个思考扩展问题的框架，这对不熟悉该领域的人来说具有巨大价值，但它不会把这个框架填充得非常详尽。

至于我自己，我读得挺享受的，而且书写得也很好（尽管我要因为里面引用了《搏击俱乐部》而扣一点分，这种引用现在已经不能算是社会能接受的了）。我可能会把它塞在某个书架上……但我其实在考虑把它转手送人。除非我失忆，否则我不认为它会成为一本经常翻阅的参考书。公平地说，我也不认为任何一本书能在“扩展性”这个领域达到 Knuth 的《The Art of Computer Programming》在算法领域所达到的高度（也就是让学生们普遍痛恨的程度）。

所以，去找一本看看吧，看看目录，阅读那些你不熟悉的部分（第九章关于数据库垂直扩展和水平扩展的讨论特别值得一读），但我不会推荐你买一本，除非你觉得扩展性特别令人生畏。不过，如果你确实决定要买一本，可以在这里购买《Building Scalable Web Sites》。
