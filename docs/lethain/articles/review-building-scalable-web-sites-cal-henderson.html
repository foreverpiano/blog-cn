《Building Scalable Web Sites》—— Cal Henderson 著

2007-07-17 · 阅读原文

最近我花了大量时间阅读关于构建可扩展网站的相关资料。我在数据库领域里构建了 PostgreSQL、Oracle 和 MySQL 的心理对比图表；我踩着 Apache 的“坟墓”跳舞，并试图拿到 Memcached 的亲笔签名。所以，我对扩展性还是了解一些的。

呼……我给大家一点时间，让你们恢复平静。

好吧，其实我对扩展性的了解并不多。这也是为什么我最近订购了 Cal Henderson 的《Building Scalable Web Sites》。这是一本书，那种用死掉的树做成的东西。更准确地说，它讨论的是一个快速发展的领域。Nginx 是新一代的 Lighttpd，而 Lighttpd 曾经是新一代的 WebBrick。PostgreSQL 其实已经很快了。SQLite 支持行级锁（好吧，这个是谎话，SQLite 依然讨厌你和你那些脏兮兮的并发操作）。

幸运的是，这本书的写作层面足够高，因此在很大程度上避免了立即过时。正如人们可能预料的那样，它偶尔会因一些具体细节而显得有些落伍，但还不至于因此失去价值。哦，对了，关于它的价值，我也应该谈一谈。

这本书的价值在于它对一系列广泛主题进行了浅显易懂的介绍，通读之后能让你对扩展 Web 系统所涉及的相互关联的各个要素建立起一个良好的高层视图。你可能已经了解数据库和 Memcached，但或许从未想过如何处理不符合标准的移动端邮件，或者如何应对整个数据中心宕机的情况。如果你已经思考过不符合标准的移动邮件或其他相对细节的扩展问题，那么这本书对你来说可能价值不大。它是一本概览，一本写得不错的概览，但归根结底还是一本概览。

《Building Scalable Web Sites》的理想读者是对扩展 Web 服务几乎一无所知的人。这本书能帮助你建立一个思考扩展性的框架，这对不熟悉该领域的人来说具有巨大价值，但它不会对这个框架进行非常深入的细化。

至于我，我读得挺享受的，书也写得不错（不过我要扣一点分，因为里面有个《搏击俱乐部》的梗，在当下这已经不能算是能被社会接受的梗了）。我可能会把它塞在书架的某个角落……但我其实在考虑把它转手出去。除非我失忆，否则我不认为它会成为一本经常翻阅的参考书。公平地说，我不认为任何一本书能在扩展性领域达到 Knuth 的《The Art of Computer Programming》在算法领域所达到的地位（也就是让学生们普遍痛恨）。

所以，去找一本看看吧，看看目录，阅读那些你不熟悉的部分（第九章关于数据库垂直扩展和水平扩展的讨论特别值得一读），但我不建议你购买一本，除非你觉得扩展性这个话题特别令人生畏。不过，如果你决定要买一本，可以在这里购买《Building Scalable Web Sites》。
