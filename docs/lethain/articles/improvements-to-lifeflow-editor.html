LifeFlow Editor 的改进

2008-05-21 · 阅读原文

今天上班的空闲时间，我重新回忆了 LifeFlow 的工作原理，特别是对 LifeFlow Editor（LFE）进行了一番打磨。我平时就是用它来撰写文章，而不是通过 Django admin。但它之前还有一些粗糙的地方。我修复了几处问题，其中最重要的是终于实现了登录/登出功能，以后就不用再通过 Django admin 登录了，那种方式确实不够优雅。

我还改进了 LFE 中用于生成 slug 的 sluggify 函数，让它变得更强大，以后不用再跳转到 Django admin 去处理带标点符号的标题了（这其实是过去一个月里我唯一使用 Django admin 的场景，所以花三十秒扩展一下还是很值得的）。最后，我还为 LFE 添加了指定作者和关联翻译的支持。希望今晚能放出一篇新的翻译来庆祝一下。

LFE 仍然有一些工作要做，首先我要清理驱动它的那堆乱七八糟的 JavaScript 代码。我当时做的每一个决定当时看起来都还不错，但最终结果却变成了一堆“JavaScript 散居”，让后续开发显得比实际需要的更加 hack。目前它简直是“如何用 jQuery 把很多事情做得既不恰当又难以理解”的绝佳反面教材。另外，我真的得重新设计一下登出按钮，它现在在页面上方看起来太丑了……

我的目标是在八月初回美国之前发布 LifeFlow 0.99，所以大家可以期待这方面会有更多开发进度。完成后，它会保持在 0.99 版本并持续跟踪 Django SVN trunk，直到 Django 1.0（或者 2.0，或者最终叫什么版本）正式发布。那时我再把它整理打包成一个漂亮的 1.0 版本。
