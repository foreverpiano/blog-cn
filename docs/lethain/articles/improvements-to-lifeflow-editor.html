LifeFlow 编辑器的改进

2008-05-21 · 阅读原文

今天上班的空闲时间，我重新温习了 LifeFlow 的工作原理，特别是对 LifeFlow Editor 进行了一些优化。这个编辑器是我用来撰写文章的工具（而不是用 Django admin），但之前还存在一些粗糙的地方。我修复了几处问题，其中最重要的是终于实现了登录/登出功能，以后就不用再通过 Django admin 来登录了，那种方式之前确实不太优雅。

我还改进了用于生成 slug 的 sluggify 函数，现在它的功能更强大，以后就不需要再切换到 Django admin 去修正带标点符号的标题了（这其实是过去一个月里我唯一使用 Django admin 的场景，所以花三十秒扩展一下还是很值得的）。最后，我还为 LFE 添加了指定作者和关联翻译的功能。希望今晚就能发布一个新的翻译版本来庆祝一下。

LFE 仍然有一些工作要做，我接下来要做的第一件事就是清理驱动它的那一堆混乱的 JavaScript 代码。我当时做的每个决定似乎都还不错，但最终结果却变成了一堆 JavaScript“散居部落”，让后续开发感觉比实际需要的更 hack 一些。目前它堪称一个如何用 jQuery 不恰当或难以理解地实现各种功能的绝佳反面教材。另外，我真的需要重新设计一下登出按钮，它现在看起来有点丑……

我的目标是在八月初回美国之前发布 LifeFlow 0.99，所以这个领域接下来会有比较密集的开发。一旦完成，它会以 0.99 的版本跟随 Django SVN trunk 继续更新，直到 Django 1.0（或者 2.0，或者最终叫什么版本）正式发布，那时候我会把它清理打包成一个像样的 1.0 版本。
