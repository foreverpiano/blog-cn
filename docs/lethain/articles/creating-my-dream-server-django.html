搭建我的 Django 梦想服务器

2007-07-13 · 阅读原文

2009/2/13 本文使用 Ubuntu Intrepid 的更新版本可在此查看。

注意：本文已重新修改，使用 Nginx 作为 Apache2 的前端，而不是本文中展示的那种较为少见的配置。你可能更想查看修改后的版本。

当你在构建对自己很重要的东西时，你会希望把它建立在坚实的基础之上。最令人沮丧的事情，莫过于花费大量心血开发出一款优秀的软件，最后却跑在一个配置糟糕的服务器上。最近我决定不再忍受这种感觉，于是重新搭建了我的服务器，以下是我的详细步骤。

最终成品是一台运行 Ubuntu Feisty 的服务器，使用 Apache2 + mod_python 来提供 Django 应用，使用 lighttpd 来提供静态文件。它使用 memcached 作为缓存后端，并使用 PostgreSQL 8.2 作为数据库。按照这些步骤搭建的服务器目前正在运行这个博客——它正是一个 Django 应用。我是在 SliceHost 256MB 的 VPS 上完成安装的，这些步骤同样适用于任何 Ubuntu 服务器（对共享主机则不太适用）。

接下来进入有趣的部分。

配置 memcached

现在我们要来设置 memcached。这一步相当简单，它将为你的 Django 项目提供强大的缓存功能。第一步是：

class Entry(models.Model):
     title = models.CharField(maxlength=200)
     body = models.TextField()
     body_html = models.TextField(blank=True, null=True)
     use_markdown = models.BooleanField(default=True)

在 Ubuntu 中，www-data 是运行 Web 服务器的用户，这与其他发行版中的 apache 用户类似。使用 -u www-data 参数运行 memcached，意味着我们将以和 Web 服务器相同的用户身份运行它。11211 是 memcached 的默认端口，除非你要同时运行多个 memcached 实例，否则不建议修改。由于我的 SliceHost 只有 256MB 内存，而我的 Django 应用需要缓存的数据并不多，因此我选择了 32MB 的内存。你可能希望分配更多内存给 memcached，尤其是当你的 VPS 配置更高时。

接下来我们需要安装 python-memcached，它是 Python 的 memcached 客户端。还有一个叫 cmemcached 的替代库，速度是 python-memcached 的两倍，但我编译时遇到了麻烦（我认为是因为我从仓库而不是源码安装的 memcached）。python-memcached 安装起来非常简单：

禁用 root 账户的原因是，不应该让一个众所周知的用户名可以通过 SSH 直接访问。同时也不应该让它能被快速 su 切换。诚然，你的新账户仍然可以被访问，但至少它是你自己的账户，而不是一个广为人知的用户名。

完成

至此，你应该已经拥有了一个相当棒的 Django 服务器。你可能还想进一步加强安全性（我后续会研究一下并补充更多细节），但抛开安全不谈，我认为这个配置已经非常接近生产环境了。使用 mod_python 运行 Django，lighttpd 提供静态文件，memcached 负责缓存，Python 2.5（2.4 会更稳定一些，但目前 2.5 已经足够成熟），对我来说运行得非常好。
