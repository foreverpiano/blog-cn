打造我的 Django 梦幻服务器

2007-07-13 · 阅读原文

2009/2/13 本文针对 Ubuntu Intrepid 的更新版本可在此查看。

注意：本文已改版，使用 Nginx 作为 Apache2 的前端，而非本文中那种比较少见的配置。你可能更想查看改版后的内容。

当你在构建对自己很重要的东西时，你会希望把它建立在坚实的基础上。再没有什么比开发出一款优秀的软件，却跑在一个配置糟糕的服务器上更让人沮丧了。最近我决定不再忍受这种感觉，于是重新搭建了我的服务器，下面是我的操作记录。

最终成品是一台运行 Ubuntu Feisty 的服务器，使用 Apache2 + mod_python 来提供 Django 应用，lighttpd 负责提供静态文件。它使用 memcached 作为缓存后端，数据库则采用 Postgres 8.2。按照这些步骤搭建的机器实际上正在运行这个博客——一个 Django 应用。我是在 SliceHost 256MB 的 VPS 上完成安装的，这些步骤同样适用于任何 Ubuntu 服务器（对共享主机则不太适用）。

接下来进入有趣的部分。

在 Ubuntu 中，www-data 是运行 Web 服务器的用户，这与其他发行版中的 apache 用户类似。使用 -u www-data 参数运行 memcached，意味着我们将以和 Web 服务器相同的用户身份运行它。11211 是 memcached 的默认端口，除非你要同时运行多个 memcached 实例，否则不需要修改。由于我的 VPS 总内存只有 256MB，而且我的 Django 应用需要缓存的数据并不多，我选择了给 memcached 分配 32MB 内存。如果你的 VPS 内存更大，你可能希望分配更多内存给 memcached。

禁用 root 账户的思路是：避免使用一个众所周知且可通过 SSH 访问的用户名。同时也不希望别人能轻易通过 su 切换到 root。当然，你的新账户仍然可以被访问，但至少它是你自己的账户，而不是一个广为人知的用户名。
