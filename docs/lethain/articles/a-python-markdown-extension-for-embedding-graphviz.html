一个用于嵌入 Graphviz 的 Python-Markdown 扩展

2010-01-16 · 阅读原文

在我的写作中（包括这个博客上的公开文章和个人笔记），我最常使用的两个工具就是 Graphviz 和 Markdown。最近几天我一直想着如何把 Graphviz 图表嵌入到 Markdown 里，今天终于抽出几个小时快速实现了一个原型。

这个概念验证项目 python-markdown-graphviz 已发布在 Github 上。

我选择扩展 Python-Markdown，是因为这个博客所使用的自定义 Markdown 扩展（有人觉得有些随意）就是基于它开发的。

编写文档的语法非常简单：把 Graphviz 图表代码放在一个标签内，标签类型对应要使用的 Graphviz 可执行程序（dot、neato、lefty、dotty）。

* hi
* there
<dot>
digraph a {
    b -> c -> d
}
</dot>
## And a title
<neato>
digraph a {
    b -> c -> d
}
</neato>
This is some text

你可以自定义以下几个设置：

BINARY_PATH 是 dot、neato 等可执行程序的路径（默认不指定路径，即假设已在 $PATH 中）。FORMAT 是 Graphviz 生成的图片格式（默认为 png）。WRITE_IMGS_DIR 是图片的输出目录（默认为当前目录）。BASE_IMG_LINK_DIR 是生成图片链接的基础目录（默认为当前目录）。
