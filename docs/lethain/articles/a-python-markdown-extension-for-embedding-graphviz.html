一个用于嵌入 Graphviz 的 Python-Markdown 扩展

2010-01-16 · 阅读原文

在我的写作中（包括这个博客上的公开文章和个人笔记），我最常使用的两个工具就是 Graphviz 和 Markdown。最近几天我一直在考虑如何将 Graphviz 图表嵌入到 Markdown 中，今天终于抽出了几个小时快速实现了一个原型。

这个概念验证项目 python-markdown-graphviz 已发布在 Github 上。

我选择扩展 Python-Markdown，是因为这个博客所使用的自定义 Markdown 扩展（有人认为比较随意）就是基于它实现的。

书写文档的语法非常直观：将 Graphviz 图表代码放在一对标签内，标签类型对应具体的 Graphviz 可执行程序（dot、neato、lefty、dotty）。

* hi
* there
<dot>
digraph a {
    b -> c -> d
}
</dot>
## And a title
<neato>
digraph a {
    b -> c -> d
}
</neato>
This is some text

一个简单的使用示例（需要将 mdx_graphviz.py 放在 Python 路径下）：

import markdown
txt = "* this is some\n<dot>\ndigraph a {\n a -> b;\n}\n</dot>\nhi\n"
md = markdown.Markdown(extensions=['graphviz'])
print md.convert(txt)

你可以自定义以下几个设置：

BINARY_PATH 是 dot、neato 等可执行文件的路径（默认为空，即假定已在 $PATH 中）。FORMAT 是 Graphviz 生成图片的格式（默认为 png）。WRITE_IMGS_DIR 是图片的输出目录（默认为当前目录）。BASE_IMG_LINK_DIR 是生成图片链接的基础目录（默认为当前目录）。

修改默认设置的示例：

import markdown
txt = "* this is some\n<dot>\ndigraph a {\n a -> b;\n}\n</dot>\nhi\n"
md = markdown.Markdown(
    extensions=['graphviz'],
    extension_configs={'graphviz':
                           {'FORMAT':'gif'}
                       },
    )
print md.convert(txt)

这个扩展还有很大的改进空间，以下是一些想法：

使用图的名称（从 Graphviz 语法中提取）作为文件名，而不是纯数字文件名。支持指定图的尺寸，或者至少可以指定宽度并自动计算高度。

基本就是这些了。在后续使用过程中我可能会做一些改进，如果这个扩展对你有用，我也非常欢迎其他人一起完善它。
