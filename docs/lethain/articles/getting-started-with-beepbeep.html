BeepBeep 入门指南

2009-07-05 · 阅读原文

一位同事（得找找他隐藏的博客，好给他加上链接…… :)）转发了一封来自 Erlang 邮件列表关于 BeepBeep 的消息。这个项目看起来相当令人兴奋，因为它将我工作中正在使用但还需要更多练习的 Erlang，与熟悉的 Django 风味结合在了一起。

本教程将带你完成一个极其简单的 BeepBeep 应用的安装、创建以及（某种程度上、差不多、但也不是真的）部署。我不能保证你会立刻兴奋不已，但这将为后续更精彩的教程铺平道路。

请注意，本教程在很大程度上借鉴了 BeepBeep 的官方文档，没有这些文档就不可能完成。

在本教程中，我们将构建一个简单的网页应用，它会显示随机素数（看来我对网页应用的评判标准最近有点降低了），同时展示 BeepBeep 应用的基本组成部分。不再废话，让我们开始吧。

安装 BeepBeep

cd ~/git/
git clone git://github.com/dmitriid/beepbeep.git

cd beepbeep
make
  1. First, install Erlang. For OS X with Port this could be sudo port install erlang, for Debian systems it could be apt-get install erlang.
  2. Next, download the source code from the Git repository.(At the time of this tutorial's writing, the latest commit was 96fb57a58322aa9abd0340755f0c94d6501d223d from July 2nd, 2009. If you really want this tutorial to work without modification, I'd recommend using that version.)
  3. Third, we need to build the BeepBeep source code. (The Git repository is kind enough to come with its dependencies--MochiWeb and ErlyDTL--included.)Somewhat unusually, building the code worked on the first try, and didn't involve chasing down any hidden dependencies.

现在你已经完成了相当轻松的 BeepBeep 安装。

创建 BeepBeep 项目

框架安装完成后，下一步就是为我们的新项目创建基础结构。

./script/new_beep.erl Primes ../BB_Primes

cd ../BB_Primes/primes/
make
./stat_server.sh
  1. First, create the project scaffolding for the BB_Primes, the exceedingly unclever name for the project we're building.
  2. Now start the webserver for the new project.If you forget to make the code you'll get a fairly generic crash file, so double-check there first if something goes wrong.After successfully running the server, go to http://localhost:8000 to view the default BeepBeep application page.
  3. Now let's take a few minutes to take a look at the various files and folders that are created by the new_beep.erl script.deps contains the BeepBeep, MochiWeb and and ErlyDTL sources, which means you don't need to ensure those are in your Erlang path. Not too much to do here, although you might want to add other dependencies your project uses.ebin stores the compiled files generated by the Makefile. Not much to do here either.support contains include.mk, a helper file for make.www contains static files to be served by MochiWeb. (I must admit, I assumed a production environment using BeepBeep would involve hiding it behind Nginx/Lighttpd and only using it to serve dynamic content, but it seems that MochiWeb is a reasonable static file server as well.)views contains the templates used to render to your apps pages. These templates are written in the Django template language, compiled using ErlyDLT.src contains all the code for the application, including several pieces that will be unfamiliar to those without previous Erlang experiences.home_controller.erl is where your controller logic is defined. For simple applications, this is the only file in src that you'll need to edit.primes.app defines an OTP application.primes.erl defines the start and stop functions for primes.app.primes_deps.erl defines and locates dependencies (I haven't actually seen a X_deps.erl file before, a rather nice idea for reusable apps.)primes_app.erl starts and stops the primes_sup.erl supervisor application.primes_sup.erl defines the supervisor for primes.app.primes_web.erl defines the MochiWeb server for the app.

定制 BeepBeep 项目

在 BeepBeep 项目中，你主要会在三个位置进行修改。

  1. src/home_controller.erl is where URL patterns and behavior are defined. In Django terms, it serves as both the urls.py and views.py files for your project.
  2. views/ contains all templates, which are used by controllers to display content to users. In Django, this would be your templates/ folder.
  3. www/ contains all static media, akin to the media/ folder for most Django projects.

一般来说，我建议从一个简单的控制器开始，编写一个匹配的简单视图，然后在两者之间迭代，直到达到你想要的终点。最后再添加静态文件。

按照我自己的建议，首先打开 src/home_controller.erl。找到名为 index 的处理函数，它看起来像这样：

handle_request("index",[]) ->
    {render,"home/index.html",[{data,"Hello There From BeepBeep!"}]};

并将其修改为如下所示：

random_prime(N) ->
    % skipping the logic for finding
    % nth prime to keep things concise ;(
    101.
handle_request("index",[]) ->
N =	random:uniform(100),
SomePrime =	random_prime(N),
{render, "home/primes.html", [{prime, SomePrime}]};

接下来该处理我们的视图了。首先打开 views/base.html。

    {% block content %}{% endblock %}
  </body>

base.html 模板被用作其他模板的脚手架，是支持 Django“Don't Repeat Yourself（不要重复自己）”理念的一种简单方式。我们接下来会将其扩展为 home/primes.html 模板。

{% extends "../base.html" %}
{% block content %}
    <p>Prime is : { { prime }}</p>
{% endblock %}

部署

当前的启动脚本在当前的 shell 会话中运行，这对开发来说很好，但对于长期运行的进程来说就不太方便了。你可以对其进行很多改进（在另一个节点启动，使用 heart 运行等），但为了保持本教程的简单风格，只需用 detached 模式运行它即可，这样你就能保留自己的 shell 会话。

cp start-server.sh start-detached-server.sh
emacs start-detached-server.sh

然后将 start-detached-server.sh 修改为如下内容：

#!/bin/sh
cd `dirname $0`
exec erl -pa $PWD/ebin $PWD/deps/*/ebin -boot start_sasl </span>
-s reloader -s primes -detached

如果你希望在注销后进程仍然存在，可以使用 sudo -u 以一个持久的用户身份运行该进程（以 root 运行会有一些非常轻微的安全后果，但你可以使用 www-data 或自定义用户来运行你的 BeepBeep 应用）。

就是这样，一个非常简单的 BeepBeep 应用。诚然，本教程没有给你那种“5 分钟创建一个博客”的框架体验，但请继续关注，我保证下一个 BeepBeep 教程会精彩得多。
