在 Google App Engine 上部署 django-springsteen

2009-03-05 · 阅读原文

（可在此查看 django-springsteen 的在线示例。）

（另外，我已大幅简化了在 Google App Engine 上部署 django-springsteen 的流程，详见此处说明。不过你仍应阅读本文，以了解如何定制 Springsteen。）

Vik Singh 几个月前率先在 Google App Engine 上运行了 Yahoo! BOSS，但 django-springsteen 与 BOSS Mashup Framework 属于不同的“魔法”，因此希望你能容忍少许重复的内容。

本文将简要介绍如何利用 Springsteen 内置的对 Yahoo! BOSS、Twitter 和 Amazon 的支持，部署一个略具特色的专业搜索引擎。整个过程应该不会超过半小时。

from django.conf import settings

class ComputerAmazonSearch(AmazonProductService):
    _access_key = settings.AMAZON_ACCESS_KEY
    _topic = 'apple'

class AppleTwitterService(TwitterLinkSearchService):
    _qty = 3
    _topic = 'apple'

def search(request, timeout=2500, max_count=10):
    services = (ComputerAmazonSearch, AppleTwitterService, Web)
    return default_search(request, timeout, max_count, services)     

def ranking(query, results):
    query = query.lower()
    def rank(result):
        score = 0.0
        title = result['title'].lower()
        if title in query:
            score += 1.0
        return score

Now's a nice time to dip our toes into relevency.You want the most relevant results to bubble to the top (feel free to make a bubble sort pun), but naively stacking results from different services doesn't permit that unless all results from source A are more relevant than those from source B, all results from B are more relevant than those from source C and so on. Let's take a stab at a very simple relevency algorithm to address these problems.You can think of two kinds of relevency approachs:Scoring results on their individual merits. We might call this intrinsic relevance.Scoring results in regard to each other. We might call this contextual relevance.We're going to do a little bit of both here. First we're going to boost results which contain the query term in their title, and second we're going to punish the 2nd-Nth results from an already encountered domain.Place this code in views.py above the search function.And then update the search function to use this ranking function.Now our results are ranked using the above ranking function.
