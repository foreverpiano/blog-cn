使用 Django 开发服务器作为代理，减少痛苦

2008-09-30 · 阅读原文

在进行 Web 开发时，你偶尔会遇到这样的情况：正在开发新的用户界面，或者对网站进行重新设计，但又不能或不想完全替换现有的部分。可能是专横的 IT 部门要求所有开发服务器的重启都需要审批，或者你的新项目只是一个不同思路的快速原型，你不想在原型证明其价值之前花时间替换当前系统。

和往常一样，Django 在这种情况下成了一个得力的工具。通过一些最小的定制，你就可以使用 Django 开发服务器来处理特定的 URL 模式，并将剩余的请求透明地代理到另一台服务器。

为什么？

对于开发来说，Django 开发服务器确实是个福音。它不算快，但也够快了，而且代码修改后自动重启的功能能大大加速开发。你可以在现有平台之上透明地进行开发。当构建依赖于 RESTful API 的重 JavaScript 应用时，这一点尤其适用（因为你主要是在客户端实现新功能，而有了精心设计的 API，你就不需要修改服务端的代码）。特别是，这种方式允许你跨域使用基于 XMLHttpRequest 的 Ajax 功能，而浏览器不会阻止你。这是因为你是在本地请求 URL，代理会从远程主机获取内容，最后再返回给请求者，就像一切都发生在本地一样。这也意味着，当你最终将新的 UI 或功能集成到现有应用中时，不需要修改任何 URL。你不需要拥有主服务器的管理权限（也不需要具备构建它的能力或知识）。你不必等待服务器重启、缓存清空或设置重置。

如何实现？

使用 Django 作为代理非常简单。首先你需要安装 Django 和 Httplib2：

curl http://www.djangoproject.com/download/1.0/tarball/ > Django-1.0.tar.gz
tar xzvf Django-1.0.tar.gz
cd Django-1.0
sudo python setup.py install
sudo easy_install httplib2

接下来创建一个标准的 settings.py 文件。如果你只是要使用静态文件开发新的外观或界面，那么你的设置可以简单到像这样：

import os
ROOT_PATH = os.path.dirname(__file__)
# Change this to the domain where you
# want requests to be proxied to.
PROXY_DOMAIN = "127.0.0.1:5678"
DEBUG = True
TEMPLATE_DEBUG = DEBUG
ADMINS = ()
MANAGERS = ADMINS
TIME_ZONE = 'America/Chicago'
LANGUAGE_CODE = 'en-us'
SITE_ID = 1
USE_I18N = True
MEDIA_ROOT = os.path.join(ROOT_PATH, 'ui')
MEDIA_URL = 'http://127.0.0.1:8000/media/'
ADMIN_MEDIA_PREFIX = '/admin_media/'
SECRET_KEY = 'etcetcetc'
TEMPLATE_LOADERS = ()
MIDDLEWARE_CLASSES = ('django.middleware.common.CommonMiddleware',)
ROOT_URLCONF = 'proxy_server.urls'
TEMPLATE_DIRS = ()
INSTALLED_APPS = ()

然后你还需要编辑项目的 urls.py，这就是魔法的发生之处。

import httplib2
from urllib import urlencode
from django.conf.urls.defaults import *
from django.conf import settings
from django.http import HttpResponse
PROXY_FORMAT = u"http://%s/%s" % (settings.PROXY_DOMAIN, u"%s")
def proxy(request, url):
conn = httplib2.Http()
# optionally provide authentication for server
#conn.add_credentials('admin','admin-password')
if request.method == "GET":
url_ending = "%s?%s" % (url, urlencode(request.GET))
url = PROXY_FORMAT % url_ending
resp, content = conn.request(url, request.method)
return HttpResponse(content)
elif request.method == "POST":
url = PROXY_FORMAT % url
data = urlencode(request.POST)
resp, content = conn.request(url, request.method, data)
return HttpResponse(content)
urlpatterns = patterns('',               
(r'^media/(?P<path>.)$', 'django.views.static.serve', {'document_root': settings.MEDIA_ROOT }),
(r'^(?P<url>.)$', proxy),
)

你可能需要根据具体情况对 URL 做一些调整，但基本就是这样。
