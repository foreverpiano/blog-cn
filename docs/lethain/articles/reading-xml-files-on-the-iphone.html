在 iPhone 上读取 XML 文件

2008-11-30 · 阅读原文

当我开始开发第二个即将面向市场的 iPhone 游戏时，我所做的最重要的改进之一，就是从一开始就把配置信息和关卡细节都搬到了 XML 文件中。优秀游戏和平庸游戏之间的一个重要区别就在于灵活性，而将细节存储在 XML 文件中能带来极大的灵活性（最棒的是，你可以用 XML 设计关卡或内容格式，然后让非程序员来制作内容，而且以后添加新内容也非常容易）。

幸运的是，在 iPhone 上加载 XML 文件其实相当简单，只要掌握几个小技巧即可。
