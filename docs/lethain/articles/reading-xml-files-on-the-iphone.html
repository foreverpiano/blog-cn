在 iPhone 上读取 XML 文件

2008-11-30 · 阅读原文

当我开始开发第二个准备面向市场的 iPhone 游戏时，我做出的最重要的改进之一，就是从一开始就把配置和关卡细节都转移到了 XML 文件中。优秀游戏与平庸游戏之间的一个重要区别就在于灵活性，而将细节存储在 XML 文件中能带来多方面的灵活性（最棒的是，你可以用 XML 设计关卡或内容格式，然后让非程序员来制作内容，而且以后添加内容也非常容易）。

幸运的是，在 iPhone 上加载 XML 文件其实相当简单，只要掌握几个小技巧即可。

第一步是创建一个 plist 文件：

  1. Go to File and then select New File....
  2. Scroll to the bottom of the list of templates, and select Other.
  3. From the templates, select Property List.
  4. Name the properly list settings.plist, and save it in your project.
  5. Add whatever data you're interested in. For this example let's say that you leave Root as a dictionary, and give it three keys:An array with the key levels.A string with the key title.A number with the key version.

现在，无论你在代码的什么位置想要加载它，只需编写下面几行简单的代码：

NSString * fileName = @"settings.plist";
NSString * path = [[NSBundle mainBundle] bundlePath];
NSString * fullPath = [path stringByAppendingPathComponent:fileName];
NSDictionary * root = [[NSDictionary alloc] initWithContentsOfFile:fullPath];
NSArray  levels = [root objectForKey:@"levels"];
NSString  title = [root objectForKey:@"title"];
int version - [[root objectForKey:@"version"] intValue];
[root release];

需要注意的一个陷阱是：即使你把所有 XML 文件都放在项目文件夹中名为 xml 的目录下，也并不意味着应用构建完成后文件仍会处于名为 xml 的目录中。
