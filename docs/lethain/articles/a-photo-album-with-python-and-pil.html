使用 Python 和 PIL 制作相册

2010-01-04 · 阅读原文

周末突发奇想，我决定玩玩 Python Imaging Library（PIL），把任意一组照片组合成一个照片画廊。在 PIL 文档的帮助下，这个过程相当有趣。（完整代码已在 Github 上开放。）

我所编辑的照片全部来自我自己，内容出自几年前我写的那篇关于 Kamioka 的文章，那是我曾经生活过的小镇。

首先，我们先加载一张图片，然后不做任何修改直接保存。

>>> import Image
import Image
>>> img = Image.open("kamioka.png")
img = Image.open("kamioka.png")
>>> img.save("kam2.png")
img.save("kam2.png")

保存后的图片和原图完全一致，细心的读者应该还没见过原图吧。

老实说，没什么意思。接下来，我们尝试创建一个新图像，里面放两份第一张图片的副本。

def mirror(img, n=2):
    x,y = img.size
    mirror_img = Image.new("RGB", (x*n,y), "White")
    for i in range(0, n):
        mirror_img.paste(img, (i*x,0))
    return mirror_img

然后用它来生成包含两份副本的图像。

>>> img = Image.open("kamioka.png")
img = Image.open("kamioka.png")
>>> mirror(img).save("kam3.png")
mirror(img).save("kam3.png")

我们也可以用它来制作包含更多副本的图像。

>>> img = Image.open("kamioka.png")
img = Image.open("kamioka.png")
>>> mirror(img, n=5).save("kam3_2.png")
mirror(img).save("kam3_2.png")

下面是包含五份副本的版本。

现在，我们来尝试给图片加上边框，增加一点精致感。先从单色边框开始。

def border(img, width=10, color="White"):
    x,y = img.size
    bordered = Image.new("RGB", (x+(2*width), y+(2*width)), color)
    bordered.paste(img, (width, width))
    return bordered

这是一张带有白色边框的图片经过镜像处理后的效果。

>>> img = Image.open("kamioka.png")
img = Image.open("kamioka.png")
>>> mirror(border(img)).save("kam4.png")
mirror(border(img)).save("kam4.png")

我得承认这个边框确实挺寒酸的。边框函数可以进一步扩展，以便支持更多自定义。我们不再假设边框只有宽度和颜色，而是把边框描述为一个由（宽度，颜色）元组组成的列表。

def border(img, brdrs=[(2, "White"), (8, "Black"), (1, "Grey")]):
    x,y = img.size
    width = sum([ z[0] for z in borders ])
    bordered = Image.new("RGB", (x+(2*width), y+(2*width)), "Grey")
    offset = 0
    print offset
    for b_width, b_color in brdrs:
        bordered.paste(Image.new("RGB", (x+2*(width-offset),
            y+2*(width-offset)), b_color), (offset, offset))
        offset = offset + b_width
    bordered.paste(img, (offset, offset))
    return bordered

再次调用 border 函数，

>>> mirror(border(img)).save("kam5.png")
mirror(border(img)).save("kam5.png")

边框功能改进之后，接下来我们创建一个函数，它接收一组图片，并将它们整齐地排列显示出来。为了简化实现，我们做了以下妥协：

将所有图片缩放到相同高度；将较宽的图片拆分成块，其中最大块的宽度等于最窄原始图片的宽度；将图片均匀平铺。

首先，我们需要将所有图片的高度统一为最短图片的高度。

def normalize(imgs):
    "Normalize height for all images to shortest image."
    shortest = min([ x.size[1] for x in imgs ])
    resized = []
    for img in imgs:
        height_ratio = float(img.size[1]) / shortest
        new_width = img.size[0] * height_ratio
        img2 = img.resize((new_width, shortest), Image.ANTIALIAS)
        resized.append(img2)
    return resized

接下来，我们把较宽的图片分割成若干块，每一块的宽度都和最窄的图片一致。

def chunk(imgs):
    "Break images into chunks equal to size of smallest image."
    smallest = min([ x.size[0] for x in imgs ])
    height = imgs[0].size[1]
    chunked_imgs = []
    for img in imgs:
        parts = math.ceil((img.size[0] * 1.0) / smallest)
        for i in xrange(0, parts):
            box = (i*smallest, 0, (i+1)*smallest, height)
            img2 = img.crop(box)
            img2.load()
            chunked_imgs.append(img2)
    return chunked_imgs

第三步，我们需要把这些图片平铺到相册页面上。（注意，merge 函数假定输入的图片已经完成归一化和分块处理。）

def merge(imgs, per_row=4):
    "Format equally sized images into rows and columns."
    width = imgs[0].size[0]
    height = imgs[0].size[1]
    page_width = width * per_row
    page_height = height * math.ceil((1.0*len(imgs)) / 4)
    page = Image.new("RGB", (page_width, page_height), "White")
    column = 0
    row = 0
    for img in imgs:
        if column != 0 and column % per_row == 0:
            row = row + 1
            column = 0
        pos = (width*column, height*row)
        page.paste(img, pos)
        column = column + 1
    return page

最后，我们把这些函数调用封装到一个 album 函数中，让它们协同工作，并额外添加一个边框。

def album(imgs):
    imgs = normalize(imgs)
    imgs = chunk(imgs)
    imgs = [ border(x) for x in imgs ]
    return merge(imgs)

现在来创建第一个相册。

>>> album(imgs).save("album.png")
album(imgs).save("album.png")

这里我使用了 Kamioka 文章里的所有图片，它们碰巧尺寸已经一致。
