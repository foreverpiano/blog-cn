CTO/Staff+ 学习圈行为准则

2020-01-25 · 阅读原文

在尝试为 CTO、工程副总裁（VPs of Engineering）和 Staff+ 工程师组织若干学习圈的过程中，我参考了会议行为准则（Conference Code of Conduct），并将其调整以适用于学习圈。本行为准则采用知识共享署名 3.0 未本地化版本（Creative Commons Attribution 3.0 Unported License）发布，与其所依据的 CCC 采用的许可协议一致。

欢迎通过 lethain@gmail.com 向我提出建议。

概要

我们的学习小组致力于为所有人提供一个无骚扰的环境，我们不容忍以任何形式骚扰参与者。

我们为每个人创造发言和被倾听的空间。我们会留意自己发言的频率。如果我们已经说得比较多，就会让沉默自然出现，并让其他人有机会发言。

我们可能会讨论敏感话题，并遵循查塔姆规则（Chatham House Rule）：你可以分享你学到的内容，但未经当事人明确许可，不得透露信息来源。

虽然招聘会是经常讨论的话题，但我们聚在一起的目的不是相互招聘。参与者可以主动联系他人表达被聘用的意愿，但请不要主动发起针对其他成员的招聘讨论。

违反这些规则的参与者可能会被组织者酌情予以警告或开除。

详细说明

骚扰包括与以下方面相关的冒犯性言语评论：性别、性别认同与表达、年龄、性取向、残疾、外貌、体型、种族、民族、宗教、技术选择、在公共场合出现的性图像、故意恐吓、跟踪、尾随、骚扰性的摄影或录音、持续干扰谈话或其他活动、不适当的身体接触，以及不受欢迎的性关注。

被要求停止任何骚扰行为的参与者应立即遵守。如果参与者有骚扰行为，组织者可采取他们认为合适的任何行动，包括警告违规者或将其开除。如果您正遭受骚扰、注意到其他人正遭受骚扰，或有任何其他疑虑，请立即联系组织者。

我们为每个人创造发言和被倾听的空间。我们会留意自己发言的频率。如果我们已经说得比较多，就会让沉默自然出现，并让其他人有机会发言。

我们可能会讨论敏感话题，并遵循查塔姆规则（Chatham House Rule）：你可以分享你学到的内容，但未经当事人明确许可，不得透露信息来源。

虽然招聘会是经常讨论的话题，但我们聚在一起的目的不是相互招聘。参与者可以主动联系他人表达被聘用的意愿，但请不要主动发起针对其他成员的招聘讨论。

我们期望参与者在所有活动中都遵守这些规则。违反这些规则的参与者可能会被组织者酌情予以警告或开除。
