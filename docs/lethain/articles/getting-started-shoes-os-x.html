在 OS X 上开始使用 Shoes

2007-10-15 · 阅读原文

最近我又多玩了一阵 Ruby，也很想同时玩玩 GUI。我的 RSS 阅读器里关注 Why the Lucky Stiff 已经有一段时间了，一直在零散地阅读他目前的项目 Shoes——一个 Ruby 的 GUI 工具包。用了两三天后，我觉得值得一试。

什么是 Shoes？

从语法上讲，“What is Shoes?” 让我有点别扭，但在这里应该是正确的。不管怎样，Shoes 是一个极简的 Ruby 图形用户界面工具包，支持 OS X、Windows 和 Linux。该项目由 Why 一个人领导、启发、推动、执行和编写。你可以看看他在自己网站上的自我介绍，这会让你放心：“Why the lucky stiff 是一名初出茅庐的自由职业教授，他会英年早逝，不会留下任何持久的印象。”

Shoes 的理念是极简主义，深受互联网设计的影响。和大多数我接触过的 Ruby 项目一样，它并不是为了满足所有人的所有需求。它对自己的定位做出了明确的选择（这里认可的 buzzword 是“有主见的软件”），如果你想要一个简单、有趣且易于使用的工具包，就应该试试 Shoes。目前它还不够成熟，无法用于生产级项目，但用来在几分钟内为当前项目快速拼凑一个 GUI 非常棒。它也非常适合做原型设计。虽然在考虑这一点前我建议你先吃点盐（别太当真），但我认为它最终会成为一种非常愉快的途径，让你能随软件一起发布简单实用的 GUI。坦白说，Shoes 已经能做出一些相当令人印象深刻的图形效果。再过大概半年左右，它甚至可能会有正式的文档。

根据 Why 的说法，它还从 Processing 那里获得了一些灵感，比如让在程序中绘图和使用图形变得简单。然而，Processing 常常让我感到不适（它只允许受限地使用一种受限的编程语言，即 Java 1.5 之前版本），而 Shoes 并没有强加同样的尴尬限制。

本质上，Shoes 是一个小巧有趣的 GUI 工具包，值得投入几个小时去玩。它是我见过的最快创建实用 GUI 的方式，而且用起来还很直观。绝对值得花时间尝试。

准备使用 Shoes

你需要获取一份 Shoes 的副本。最简单的方法是访问这里，下载最新的快照。本教程使用的是 2007 年 9 月 6 日的快照。你也可以从 svn 代码库自己构建 Shoes，但目前没有这个必要（而且 Shoes 处于剧烈变动中，所以从代码库深处冒出来的东西会有一定的不确定性）。

解压包含 shoes 的 tar.gz 文件，你会得到一个闪亮的 Shoes.app 文件。把它扔进你的应用程序文件夹（其实不必非得这么做，但我下面的说明会假设它在那里）。

定位元素

使用糟糕工具构建 GUI 最痛苦的部分之一就是定位元素。Shoes 对这件事有一个非常灵活且强大的理念：stack 和 flow。Stack 是向下堆叠的容器，flow 是先向右、再向下的容器。Flow 就像书里的文字。Stack 就像日志文件里的条目。主 Shoes 窗口是一个 flow，而 stack 或 flow 里面可以包含任意数量的 stack 和 flow。

这个系统在大多数情况下工作得相当好，我想象随着 Shoes 越来越完善，它会越来越“如你所愿”，也更少出现不可预测的情况。即使现在也已经几乎很棒了，但因为一个好的 GUI 必须做到完美，我发现自己和这些 stack、flow 斗争的次数还是比我希望的要多。
