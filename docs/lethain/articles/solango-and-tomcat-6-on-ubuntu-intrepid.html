Solango 和 Tomcat 6 在 Ubuntu Intrepid 上的安装

2009-03-06 · 阅读原文

上周我花了一些时间在 VPS 上配置 Solango，为这个博客提供全文搜索功能（那么全文搜索在哪里呢？目前还在进行中）。我选择使用 Tomcat 和 Solr 的方案，结果过程比预想的要麻烦一些，主要是因为我对 Java 服务端生态不太熟悉。

如果你不特别在意性能优化，我建议不要按照这些步骤操作，而是直接使用 Solr 自带的 Jetty 服务器。Solango 的教程里对此有说明，不过你得读到最后才能发现这一点。话虽如此，如果你追求生产环境的性能，并且相信 Tomcat 比 Jetty 更出色，那就继续往下读吧。

本教程主要参考了以下资料：在 Ubuntu 上安装 Solr 的教程、Solango 的安装文档以及 Solango 官方教程。

（这些步骤无法直接应用于 OS X 系统。）
