Solango 和 Tomcat 6 在 Ubuntu Intrepid 上的安装

2009-03-06 · 阅读原文

上周我花了一些时间在 VPS 上配置 Solango，为这个博客提供全文搜索功能（不过全文搜索功能目前还在开发中）。我选择使用 Tomcat 和 Solr 的方案，结果过程比预想的要麻烦一些，主要是因为我对 Java 服务端生态不太熟悉。

如果你并不特别追求极致性能，我不建议按照本文的步骤操作，而是直接使用 Solr 自带的 Jetty 服务器。Solango 的官方教程里其实有说明，但你需要读到最后才能发现这一点。不过，如果你希望获得生产环境的性能，并且相信 Tomcat 比 Jetty 更出色，那就继续往下读吧。

本教程大量参考了《在 Ubuntu 上安装 Solr》的教程，以及 Solango 的安装文档和官方教程。

（本教程无法直接应用于 OS X 系统。）

  1. Retrieve Solango source from SVN.
  2. Add Solango to your Python path.
  3. Copy the solango/inital_settings.py file into your project folder and rename it as solr_settings.py.
  4. Add Solango to your project's INSTALLED_APPS setting in its settings.py file.
  5. At the end of your settings.py file, but before importing local_settings.py (if you do so), import everything from solr_settings.
  6. Next create a search.py file for your Django apps that you want to be searchable.   7. Create a Solr schema file in your local directory.Now move it into the the Solr configuration directory.
  8. Restart Tomcat.
  9. In a local_settings.py file override any of the Solango settings that don't fit your needs.Be careful to ensure that your server can write to the LOG_FILENAME file. If you followed the configuration from the Ubuntu & Django Almanac, you'll need to do this:(Only the first two sevens are important, the last digit can be anything depending on your preference.)
  10. Now we need to index content for search.If you get a raise ValueError, "Invalid or missing XML", then you need to stop and start Tomcat.
  11. Now it should be possible to start searching. Fire up your project's shell.And then perform some searches.
  12. From here you can reference the Solango tutorial if you're interested in using its pre-packaged search view, or start writing your own wrapper as desired.
