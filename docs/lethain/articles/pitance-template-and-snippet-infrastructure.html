Pitance：模板与代码片段基础设施

2009-09-13 · 阅读原文

过去几个月，我一直在开发一个令人兴奋的项目：Pitance。Pitance 是 Project Infrastructure and Templates Are Now Convenient for Everyone 的缩写，它是一个用于共享和管理项目模板与代码片段的基础设施。该基础设施包括一个网站、一个 HTTP/JSON API 以及一个命令行工具。

该项目位于 pitance.lethain.com，随时欢迎大家使用。

Pitance 快速入门

Pitance 的设计理念是尽可能简单上手。当然在这方面还有一些工作要做，但希望它能快速改进。

curl http://pitance.lethain.com/api/template/erlang_couchdb_app/ > erlang_couchdb_app.erl

curl http://pitance.lethain.com/api/template/erlang_couchdb_app/1/ > erlang_couchdb_app.erl

curl http://pitance.lethain.com/download/command-line/ > pitance.py

chmod +x pitance.py

./pitance.py template erlang_couchdb_app > erlang_couchdb_app.erl
# specific version
./pitance.py template erlang_couchdb_app 1 > erlang_couchdb_app.erl

echo "print 'This is my template'" > test_template.py
./pitance create python_test_template \
    --language python \ 
    --tags "test, useless" \
    --related_templates "erlang_test, ruby_test" \
    --author_email lethain@example.com # this is hidden from users, only visible to admin \
    --author "Will Larson" \
    --desc "This is a test for a Python template. Please ignore this." \
    < test_template.py

./pitance.py update python_test_template --tags "test2, test3" < test_template.py
首先，访问网站，通过搜索或浏览找到你感兴趣的模板。以本例来说，假设你对 erlang_couchdb_app 这个模板感兴趣，那么可以使用 cURL 下载它：你也可以获取特定版本的模板：或者，你可以使用命令行客户端，它能让操作更加简便。首先需要下载最新版本的客户端：然后为其添加执行权限：现在你就可以这样获取模板了：如果你安装了 simplejson（或者使用的 Python 版本自带 json 库），还可以用 pitance.py 来创建和更新模板：也就是说，你通过标准输入提供模板内容，并必须指定 language、author_email、author 和 desc 这几个参数。你可以选择性地指定 tags 和 related_templates 参数，它们接受逗号分隔的列表。创建模板后，你可以用类似方式更新它，但重要的一点是每次更新都必须重新提交模板内容，而其他参数则是可选的。这其实是命令行客户端的限制，而非 API 的限制，我希望很快能修复（主要是它会卡在等待标准输入那里……）。每次更新都会生成模板的新版本，但之前的版本仍可通过明确引用获取。这使得多人能够以 wiki 的方式协作维护模板，同时也保证你始终能获取自己偏好的版本。

未来开发计划

我对如何改进 Pitance 有大量想法，会根据用户反馈以及这个服务是否对更多人有价值，一步步地实现它们。

以下是一些想法（不分先后顺序）：

在模板创建和更新时推 Tweet。 在模板中支持变量，以便更容易定制（不过统一的命名规范加上搜索替换其实已经能实现这个需求）。 支持声明模板依赖关系，从而可以由多个模板组合构建多文件项目模板（这也可以作为第三方系统构建在现有 API 之上）。 命令行客户端还有改进空间。 网站的某些部分和搜索功能应该区分项目和项目版本（比如你搜索 erlang，结果返回 erlang_couchdb_app - 1 和 erlang_couchdb_app - 2，这显得有点傻）。 为网页添加语法高亮（遗憾的是，用 Erlang 实现这个功能让我暂时告别了长期钟爱的 Pygments）。

技术栈

技术栈已在“关于”页面有所介绍，其实很值得单独写一篇文章。简而言之，它基于 BeepBeep、CouchDB 和 Lucene，通过 couchdb-lucene 和 erlang_couchdb 进行整合。这是一个非常棒的开发栈。
