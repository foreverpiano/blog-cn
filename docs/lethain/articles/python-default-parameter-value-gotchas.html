Python 默认参数值的陷阱

2010-09-11 · 阅读原文

想象你有一个简单的 Python 函数，长这样：

>>> def x(a=[]):
...     return a
... 
>>> x()
[]

你知道对这个默认返回值进行破坏性操作会发生什么吗？

>>> x().append(1)
>>> x()
[1]
>>> x().append(2)
>>> x()
[1, 2]

好吧，现在你知道了。这个默认列表只会在函数定义时初始化一次，而不是每次调用都重新创建。请像躲避埃博拉病毒一样，千万不要写这样的代码。 替代方案可以考虑下面这两种写法：

# python 2.5+
def x(a=None):
    return a if a else []
# the old but at times reviled syntax
def x(a=None):
return a or []
# memory usage here is not ideal
def x(a=[]):
return a[:]

如果你从未遇到过这个问题，很可能是因为你一直遵守 Python 的惯例——不在没有明确说明的情况下对输入进行破坏性修改。如果你真的从来没这么做过，而且也不是因为不知道才没做过，那真是太棒了，先生或女士，衷心为你点赞。

感谢 Chris Goffinet 给我讲解这个问题。当时我在 PDB 中反复单步调试，看着一个本该为空的列表却带着内容进入了函数。
