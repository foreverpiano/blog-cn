一个用于加载 CouchDB 文档的命令行工具

2008-12-09 · 阅读原文

这个周末在使用 CouchDB 时，我发现自己既不满足于仅在 Futon 中创建内容，又不想为每次新尝试都编写一个全新的自定义脚本。我想要一个脚本，能够接受一个文件或目录，将其转换为 JSON，并上传到 CouchDB 中。

于是，我把它写了出来。

理由

在 Futon 中创建多行值并不特别直观，因此“先保存到另一个文件再粘贴”的备用方案并不理想。在实验过程中，我经常需要删除数据库，希望有一个快速简便的方式来加载示例数据和视图。我想要一种简单的方法来添加一次性数据，而无需编写用完即弃的代码（这正是命令行工具的完美应用场景）。用 Python 编写文档数据还能带来一些便利：良好的缩进和语法高亮让数据更清晰，通过 simplejson 轻松将数据结构转换为 JSON，既能验证 Python 数据结构的语法，也能确保输出的 JSON 有效。命令行工具之间的协作也比脚本好得多。

文件格式

该脚本支持四种可能的文件格式：

扩展名为 .py 的文件，内容为一个 Python dict。 { '_id':'123',"title":"hi","etc":"blah" } 扩展名为 .py 的文件，内容为一个包含多个 dict 的 Python list。 [ {'title':'a'}, {'title':'b'}] 扩展名为 .js 或 .json 的文件，内容为一个 JSON dict。 （嗯，简单的例子在结构上其实和 Python 示例完全相同。） 扩展名为 .js 或 .json 的文件，内容为一个包含多个 dict 的 JSON array。 （同样，这实际上和 Python list 示例完全相同。）

数组格式始终通过批量文档 API 发送（数组中的每个 dict 都是一个文档），而 dict 格式则始终通过 PUT API 来创建文档。

使用方法

使用方法相当直观。

python doc_utils.py database-name
python doc_utils.py db path/to/folder
python doc_utils.py db path/my_views.py
python doc_utils.py db --port=3432
python doc_utils.py db --hostname=example.com

上述选项的任意组合也都支持，因此你可以用来将任意路径的内容加载到任意 CouchDB 实例中。

下载

你可以在它的 GitHub 仓库获取源代码，也可以直接下载 zip 压缩包。
