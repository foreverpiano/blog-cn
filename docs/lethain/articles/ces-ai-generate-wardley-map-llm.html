使用 LLM 生成 Wardley Map

2025-03-15 · 阅读原文

在撰写《Crafting Engineering Strategy》前几章时，我曾考虑写一章专门讨论 GitLab 的战略。GitLab 有趣的地方在于它公开分享了大量自身运作方式的细节，因此我认为即使从未在那里工作过，也有可能为他们写出一份有趣的战略文档。

最终我决定不写那一章，但我确实创建了一份。这张 Wardley map 最终没有被收录在书的正式版本中，也没有采用针对 LLM 优化的格式，这使得它成为一个绝佳的测试案例——用来检验 LLM 是否能帮助我们生成一份有效的 Wardley map。Gitlab 战略的 Wardley 地图分析

这是《The AI Companion to Crafting Engineering Strategy》中的一章草稿，本章讨论如何在 LLM 中使用《Crafting Engineering Strategy》，来起草、完善和改进工程战略。

创建 Wardley map 的关键步骤之一是构建价值链（value chain），这在用 Wardley Mapping 完善策略一章中已有详细讨论。构建价值链绝对是 LLM 可以提供帮助的工作，但价值链本质上只是文本，因此我们已经介绍过适用于此类任务的有效提示模式。

然而，生成真正的 Wardley map 图像是我们尚未涉及的内容。因此，我们将从那篇被放弃章节中的用户和价值链（可在此 Gist 中获取）出发，目标是将其转化为一张 Wardley map。

我们首先上传 Wardley mapping 相关章节，并附上以图像形式呈现的已完成的 Wardley map。

这个项目仅包含 Wardley mapping 章节，而非整本书，目的是为项目上下文窗口留出更多空间来容纳图像。如果你使用 llm.py 并且所用的 LLM 拥有较大的上下文窗口，则可以像往常一样放入整本书。

项目设置完成后，我们使用用户和价值链（提醒一下，可在此获取），配合一段简短的提示来生成 Wardley map：

Create a wardley map image using the template
in this project these value chains:

{user and value chains text}

使用 ChatGPT 4o 后，它确实生成了一张 Wardley map 图——嗯，算是吧。

这张图表面上有很多类似 Wardley map 的特征，但它实际上完全不是一张 Wardley map。在 x 轴上每个正确拼写的标签旁边，图的其他位置都会出现一个毫无意义的词放在框里。我认为我们可以得出结论：直接通过图像生成功能并不是用 LLM 创建 Wardley map 的正确路径。

好吧，这次效果意外地糟糕。通常，当这种情况发生时，解决办法是把复杂性转移到工具上。最常见且有效的方式是创建一个领域特定语言（DSL），让 LLM 在它最喜欢的文本格式中工作，并把其他工作推给外部工具。这正是我们在中使用 systems library 和 systems-mcp server 所做的事情。使用 LLM 生成系统模型

为 Wardley map 创建一个 DSL 会是一项相当痛苦的工作。幸运的是，已经存在一个用于编写 Wardley map 的 DSL，即 Damon Skelhorn 开发的 OnlineWardleyMaps。（非常感谢 Ben Mosior，他的文章让我知道了 OnlineWardleyMaps。）

我创建了一个包含多个 Wardley map DSL 示例的文件，你可以将其加载到你的项目中。完成后，让我们重新执行上面的提示，这次在前面添加以下内容：

Create a wardley map for the below value,
using the OnlineWardleyMaps syntax.

{same value chains as above, omitted for brevity}

LLM 生成的输出如下，我将其粘贴到 OnlineWardleyMaps.com 中，成功生成了一个很有说服力的 Wardley map。

在我看来，这个结果相当出色。当然还有一些地方我需要调整，但这正是 Wardley map 的本质。能够快速得到一份可用的初稿极其有价值，因为对已存在的东西进行批评和迭代要容易得多。

总结

在本章中，我们体验了使用 LLM 解决复杂问题的推拉过程。我们第一次尝试通过图像方式生成 Wardley map，结果是一团无法使用的乱麻。随后我们制定了新的方法，利用已有的 OnlineWardleyMaps 格式，将问题转化为 LLM 非常擅长的 DSL 形式。

你现在可以快速写出一张复杂的 Wardley map，用一种易于分享的格式，而且无需自己去弄懂那个格式的繁杂细节。在我看来，这相当了不起。
