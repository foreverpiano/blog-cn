用 LLM 生成 Wardley Map

2025-03-15 · 阅读原文

在撰写《Crafting Engineering Strategy》前几章时，我曾考虑写一章专门讨论 GitLab 的战略。GitLab 的特别之处在于它公开分享了大量内部运作方式，因此我觉得即使从未在那工作，也有可能为他们写一份有趣的战略文档。

最终我决定不写那一章，但我确实制作了一张。这张 Wardley Map 最终没有被收录在书的正式版本中，也没有采用针对 LLM 优化的格式，这使它成为一个完美的测试案例——检验 LLM 是否能帮助我们生成一份有效的 Wardley Map。Gitlab 战略的 Wardley Mapping

这是《Crafting Engineering Strategy 的 AI 伴侣》中的一篇草稿章节，它讨论了如何在 LLM 中使用《Crafting Engineering Strategy》，来起草、完善和改进工程战略。

创建 Wardley Map 的关键步骤之一是构建价值链，正如使用 Wardley Mapping 优化策略一章中所讨论的那样。构建价值链绝对是 LLM 可以提供帮助的工作，但价值链本质上只是文本，因此我们已经介绍过适用于此的有效模式。

然而，生成真正的 Wardley Map 图像是我们尚未涉及的内容。因此，我们将从被舍弃章节中的用户和价值链开始（可在该 Gist 中获取），目标是将其转化为一张 Wardley Map。

我们首先上传 Wardley Mapping 的章节，以及以图像形式呈现的已完成的 Wardley Map。

这个项目仅包含 Wardley Mapping 章节，而非整本书，目的是为项目上下文窗口留出更多空间来容纳图像。如果你使用 llm.py 并选用具有大上下文窗口的 LLM，就可以按常规方式包含整本书。

项目设置完成后，我们使用用户和价值链（提醒一下，可在此获取），配合一段简短的提示来生成 Wardley Map：

Create a wardley map image using the template
in this project these value chains:

{user and value chains text}

使用 ChatGPT 4o，这生成了一个 Wardley Map 图表。嗯，算是吧。

这张图在表面上具有许多类似 Wardley Map 的特征，但它实际上完全不是一张 Wardley Map。在 x 轴上每一个正确拼写的标签旁边，都会出现地图其他位置某个框里毫无意义的词。我认为我们可以得出结论：直接生成图像并不是用 LLM 创建 Wardley Map 的可行路径。

好吧，这次结果意外地糟糕。通常遇到这种情况，秘诀是将复杂性转移到工具上。最常见的做法是创建一个特定领域的语言（DSL），让 LLM 在它们最喜欢的文本格式中工作，并将其他工作推给外部工具。这正是我们在中使用 systems library 和 systems-mcp server 所做的事情。使用 LLM 生成系统模型

为 Wardley Map 创建一个 DSL 将是一项相当繁琐的工作。幸运的是，已经存在一个用于编写 Wardley Map 的 DSL，即 Damon Skelhorn 的 OnlineWardleyMaps。（非常感谢 Ben Mosior，他的文章让我认识了 OnlineWardleyMaps。）

我创建了一个包含多个 Wardley Map DSL 示例的文件，你可以将其加载到你的项目中。完成之后，让我们重新执行上面的提示，这次在前面加上：

Create a wardley map for the below value,
using the OnlineWardleyMaps syntax.

{same value chains as above, omitted for brevity}

LLM 生成的输出如下，我将其加入 OnlineWardleyMaps.com，最终成功生成了一张很有说服力的 Wardley Map。

在我看来，这已经相当不错了。当然还有一些地方我愿意去调整，但这正是任何 Wardley Map 的本质。能快速得到一个可用的初稿极其有价值，因为批评和迭代一个已经存在的东西要容易得多。

总结

在本章中，我们体验了用 LLM 解决复杂问题的推拉过程。我们第一次尝试通过处理图像来创建 Wardley Map，结果是一团无法使用的混乱。随后我们制定了新的方法，利用已有的 OnlineWardleyMaps 格式，将问题转化为 LLM 特别擅长的 DSL 形式。

你现在可以快速写出一张复杂的 Wardley Map，用一种易于分享的格式，而且无需自己去掌握那个格式的繁琐细节。在我看来，这相当了不起。
