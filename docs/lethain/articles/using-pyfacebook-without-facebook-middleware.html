在不使用 Facebook middleware 的情况下使用 PyFacebook

2007-11-30 · 阅读原文

最近我一直在尝试使用 PyFacebook 来创建一个 Facebook 应用。在开发的早期阶段，我遇到了一个小难题：如何在不使用 PyFacebook middleware 的情况下，在 Django 中使用 PyFacebook？

这并不是一个无关紧要的问题，因为 PyFacebook middleware 对于那些不直接与 Facebook 通信的视图来说只是多余的负担，甚至对于某些直接与 Facebook 通信的视图（使用 FBJSM Ajax 对象发出的请求）也不太合适。

那么，废话不多说，让我们来看看如何在不使用 middleware 的情况下，在 Django 中使用 PyFacebook。

你需要将 PyFacebook 库导入到你的 views.py 文件中才能使用下面的示例。如果已经将 PyFacebook 库安装到 Python 路径中，导入方式如下：

import facebook.djangofb as facebook

将 Facebook 实例添加到 request 中

我们首先要解决的问题，是如何将 Facebook 实例添加到传递给视图的 request 中。

def add_fb_instance(request):
    # if already has a facebook instance, immediately return
    if getattr(request, 'facebook', None) is not None:
        return request
    # auth_token is other important possible param
    api_key = settings.FACEBOOK_API_KEY
    secret_key = settings.FACEBOOK_SECRET_KEY
    app_name = getattr(settings, 'FACEBOOK_APP_NAME', None)
    callback_path = getattr(settings, 'FACEBOOK_CALLBACK_PATH', None)
    internal = getattr(settings, 'FACEBOOK_INTERNAL', True)
    request.facebook = facebook.Facebook(
        api_key=api_key,
        secret_key=secret_key,
        app_name=app_name,
        callback_path=callback_path,
        internal=internal
        )

用法相当简单：

def canvas(request):
    add_fb_instance(request)
    fb = request.facebook
    # do whatever
    return direct_to_template(request, 'fb/canvas.fbml',
                              extra_context={'request':request})

add_fb_instance 会将一个 Facebook 实例添加到 request.facebook 中。由于这就是 PyFacebook middleware 所做的全部工作，我们已经重新实现了它的大部分功能。不过我们可能还想要更多功能，比如强制用户必须登录才能访问某个视图。

要求用户登录

要求用户登录我们的应用也非常简单。

def require_fb_login(request, next=None):
    if getattr(request, 'facebook', None) is None:
        add_fb_instance(request)
    fb = request.facebook
    if not fb.check_session(request):
        return fb.redirect(fb.get_login_url(next=next))

使用 require_fb_login 函数的方法如下：

def canvas(request):
    redirect = require_fb_login(request)
    if redirect is not None: return redirect
    user = get_fb_user(request.facebook)
    return direct_to_template(request, 'fb/canvas.fbml',
                              extra_context={'request':request, 'fbuser': user})

如果用户尚未登录，它会将用户重定向到应用的登录页面。请注意，如果 request 中还没有 Facebook 实例，它会自动添加一个。因此，显式调用 add_fb_instance(request) 并不是必需的（但建议还是调用一下，因为这样能更明确地表明已经向 request 中添加了 Facebook 实例）。

使用 Facebook 实例来完成一些操作

好了，现在我们已经把 Facebook 实例附加到 request 上了……但它们能为我们做什么呢？我们来看看。可以创建一个模型来存储已登录用户的信息，并使用 Facebook 实例来为模型填充一些数据。

让我们来创建模型：

class User(models.Model):
    facebook_id = models.IntegerField()
    name = models.CharField(blank=True, null=True, max_length=60)

一个简单的模型。现在，我们来写一个函数，它接收一个 Facebook 实例，获取或创建对应的 User 模型，并使用来自 Facebook 的数据填充 name 字段。

from django.shortcuts import get_object_or_404
def get_fb_user(facebook):
user, created = User.objects.get_or_create(facebook_id=int(facebook.uid))
# if the object is newly created
if created is True:
# get first and last name using FQL
query = "SELECT uid, first_name, last_name FROM user WHERE uid=%s" % facebook.uid
# FQL results a list of dicts, retrieve the first (and only) one
results = facebook.fql.query(query)[0]
user.name = "%s %s" % (results[u'first_name'], results[u'last_name'])
user.save()
return user

这里我们使用 Facebook Query Language（FQL）来获取信息。FQL 的优点在于你可以编写非常复杂的查询，而且上面这个例子就足以让你掌握如何通过 PyFacebook 获取其他数据：只需编写新的 FQL 查询，并以相同方式调用即可。

调用 facebook.fql.query(your_query) 会返回一个字典列表。由于我们调用的查询只会返回一条记录（用户的 user id），因此我们只取第一个结果，但在其他查询中，你可能需要更仔细地处理结果（通常是遍历所有结果）。

现在，让我们看看如何使用 get_fb_user 函数：

def my_view(request):
    add_fb_instance(request)
    user = get_fb_user(request.facebook)
    return direct_to_template(request, 'fb/canvas.fbml',
                              extra_context={'request':request, 'fbuser': user})

注意，我们需要在使用 request.facebook 实例获取用户之前，先调用 add_fb_instance（在调用 add_fb_instance 之前，该实例并不存在）。

将所有内容整合起来

好了，现在来看一个稍微复杂一点的例子，它综合使用了我们前面编写的所有功能，还有一些额外的小东西。

from django.shortcuts import get_object_or_404
def club(request, id):
add_fb_instance(request)
redirect = require_fb_login(request)
if redirect is not None: return redirect
user = get_fb_user(request.facebook)
club = get_object_or_404(Club, pk=int(id))
if user in club.admins.all():
is_admin = True
else:
is_admin = False
return direct_to_template(request, 'fb/club.fbml',
extra_context={'fbuser':user,
'club':club,
'is_admin':is_admin,
})

这个视图还向我们传递了一个 'id' 参数。因此 urls.py 大概是这样的：

from django.conf.urls.defaults import *
urlpatterns = patterns('bookface.fb.views',
(r'^$', 'canvas'),
(r'^club/(?P<id>\d+)/$', 'club'),
)

因为 URL 中的正则表达式只允许数字，所以我们可以直接对 id 调用 int() 函数（不过完全忽略错误处理仍然不是一个好主意）。

因此我们先给 request 添加一个 Facebook 实例，然后验证用户是否已登录到 Facebook。如果没有登录，就将他们重定向到我们应用的登录页面。接着我们获取与当前登录的 Facebook 用户关联的 User 实例。然后使用传入的 id 来获取或创建一个 club。

之后我们检查用户是否是该 club 的管理员之一。最后向模板渲染器传递大量额外上下文（user、club 以及用户是否为 club 管理员）。
