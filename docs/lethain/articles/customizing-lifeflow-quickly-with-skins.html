使用皮肤快速自定义 LifeFlow

2008-01-07 · 阅读原文

自定义 LifeFlow 的外观非常简单。

和这个：

从一种风格切换到另一种风格非常简单，这要归功于 LifeFlow 的皮肤概念……其他人称之为 CSS 文件，但管它呢，我们就先荒谬一下吧。不过在此之前，请注意所有随 LifeFlow 一起发布的皮肤均采用 Creative Commons Attribution 许可协议。

那么让我们来看看从第一个变成第二个需要做什么。

华丽的转变

只需要一行 Python 代码，将其放入托管 LifeFlow 的 Django 项目的 settings.py 文件中即可。

LIFEFLOW_CUSTOM_CSS = "/media/lifeflow/skins/lethain.css"

这个皮肤已包含在 LifeFlow 中（主要是作为示例供其他人修改以符合自己的喜好），但你可以轻松地将自己的 CSS 文件添加到 skins 目录，并修改路径指向它们而不是 lethain.css。

你可以在任何一份 SVN 代码检出中查看 lethain.css，它的代码很短，也可以直接贴在这里。

body {
    background-color: #613536;
}
ul {
    list-style: none;
}
div.heading {
    background-color: #363942;   
}
.heading a {
    color: #ff7f24;
}
div.content-main {
    background-color: #eeb4b4;
    overflow: hidden;
}
div.content-main-internal {
    padding-top: 18px;
    padding-left: 9px;
    padding-right: 9px;
}
div.content-sidebar {
    padding-top: 18px;
    margin-left: -10px;
    padding-right: 10px;
    background-color: #ff7f24;
}
a {
    text-decoration: none;
    color: #940505;
}
a:hover { 
    text-decoration: underline;
}

只是一些基本的 CSS 样式。模板中几乎所有的 HTML 元素都有命名，你只需打开一个模板，找出想要修改的 div 或其他元素的正确 class，然后在自定义的 CSS 文件中进行修改即可。

总之，我知道这篇介绍还可以写得更深入一些，我也相信一份详细的 LifeFlow 皮肤制作指南最终会问世，但现在这些内容应该足以帮助你入门了。

在不久的将来，我会开始提供更多的布局选择（比如单栏布局，将元内容放在底部而不是侧边栏等）：我希望让自定义 LifeFlow 成为一种愉快而舒适的体验。
