PHP中为文件添加版本号的几种方法

2009-07-28 · 阅读原文

最近在处理公司项目的前端部分，上周遇到了一个小难题：如何用最少的工作量，在 PHP 中实现静态文件的版本控制？

如果你之前没用过带版本号的静态文件，这其实是个非常实用的技巧。你可以配置 Apache、Lighttpd 或 Nginx，让浏览器知道某个文件（或者某个目录下的内容、特定后缀的文件等）在未来 5 分钟、3 天甚至 10 年内都不会发生变化。这相当于强烈建议浏览器对该文件进行缓存，不到指定时间就无需重新请求。这样能降低带宽消耗（减少文件发送量）、减轻服务器压力（每个页面浏览产生的 HTTP 请求更少），同时加快页面加载速度（同样得益于更少的 HTTP 请求）。

但这个做法有个尴尬的副作用：当你更新了文件内容后，用户不会主动重新加载，除非他们强制刷新页面或清空浏览器缓存（而这两件事并不常发生）。标准的解决办法是在文件名中加入版本号，比如把 styles.css 改成 styles-1.css，以后更新再变成 styles-231.css。回到我们的问题：如何在不手动修改代码的情况下，自动给文件加上最新的版本号呢？
