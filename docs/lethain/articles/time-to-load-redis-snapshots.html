在对 Redis 进行探究的过程中，我需要了解 Redis 节点在软崩溃或重启时对可用性的影响。Redis 支持可配置的磁盘快照功能，可以设定在一段时间内至少发生多少次修改后才更新磁盘快照。这样，你就可以根据自己愿意为之付出的性能代价，来尽可能多地保留数据。

接下来的问题是：重新加载这些快照需要多长时间？
