我所说的变体

我第一次使用这个变体时，正在开发一个需要部署到两个地方的应用：我的 VPS 和个人电脑。我希望把两套配置都放到版本控制里，同时又不需要每次更新代码后都去修改本地文件。

我的解决方案是这样的：

让 settings.py 包含所有共享的配置，并在文件末尾保留这几行： try: from local_settings import * except ImportError: pass 把开发环境的配置放在 devel_settings.py 中，把 VPS 的配置放在 vps_settings.py 中。 在每台开发机器上，创建一个 local_settings.py 文件，里面只包含一行代码。在我的开发服务器上，这一行是：from devel_settings import * 而在 VPS 上则是：from vps_settings import *

这样一来，我就可以轻松修改两套配置，并把它们都纳入版本控制，以便将来把项目部署到其他机器上。
