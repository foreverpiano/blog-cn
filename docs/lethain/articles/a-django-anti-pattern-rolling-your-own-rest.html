2008-06-13 · 阅读原文

上周我收到 Charlie O'Keefe 的一封邮件，其中谈到了 Django 在对 RESTful API 的原生支持上存在不足。我当时答应写一篇短博客来讨论这个话题，但一直没有成文。问题主要在于缺乏一个合适的库。并不是说完全没有库，实际上已经有好几个了，但至今还没有一个真正击中“甜蜜点”。

我觉得社区对此并没有特别焦虑，因为通常只需用少量视图函数就能轻松手写出所需的 RESTful 接口。这也是为什么很多重度使用 AJAX 的应用，最终都会出现一个“代码贫民窟”，专门用来实现该应用所需的那部分 RESTful API 子集：
