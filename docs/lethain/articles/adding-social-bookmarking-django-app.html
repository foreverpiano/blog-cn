为 Django 应用添加社交书签功能

2007-07-14 · 阅读原文

当你开发网站时，迟早会希望创建一些链接，让读者能够轻松地将你的内容提交到社交书签和新闻聚合服务中。幸运的是，为 Django 应用添加这个功能非常简单。

创建模板

模板是这个功能中最复杂的部分，但依然非常简单（这应该是个好兆头）。在模板中，我假设你使用的是通用视图（generic views），因此内容对象会被命名为 'object'。如果你使用的是自定义视图，可能用来存放内容的变量名称会有所不同。另外，请确保你的对象有一个 get_absolute_url 方法。

模板还需要能够访问当前 Site 对象，我们稍后会处理如何将 Site 传递给模板。

以下是模板代码：

{% with object.get_absolute_url|urlencode as obj_url %}
{% with object.title|urlencode as obj_title %}
{% with site.domain|urlencode as obj_domain %}
<span><strong> Social Links: </strong></span>
<span class="social"><a href="http://reddit.com/submit?url=http://{ { obj_domain }}{ { obj_url }}&title={ { obj_title }}"> Reddit </a></span>
<span class="social"><a href="http://del.icio.us/post?url={ { obj_domain }}{ { obj_url }}&title={ { obj_title }}"> Del.icio.us </a></span>
<span class="social"><a href="http://www.stumbleupon.com/submit?url={ { obj_domain }}{ { obj_url }}&title={ { obj_title }}"> StumbleUpon </a></span>
<span class="social"><a href="http://digg.com/submit?phase=2&url={ { obj_domain }}{ { obj_url }}&title={ { obj_title }}"> Digg </a></span>
{% endwith %}
{% endwith %}
{% endwith %}

你会注意到我们对所有构建的字符串都使用了 urlencode 过滤器，这一点非常重要，因为这些字符串将作为参数传递给社交网站的公共 API URL。

你需要将上面的模板片段包含在用于提交到社交网站的模板中。我通常使用 include 标签来引入它：

{% include "myapp/social_submit.html" %}

这会直接把社交书签代码注入到模板中（比手动复制粘贴到多个模板要方便得多）。

模板上下文

如前所述，我们还需要访问 Site 实例。因为我们没有其他方式来获取内容的完整 URL。我们使用 get_absolute_url 方法获取除域名之外的部分，但仍然需要 somehow 获取域名（这意味着你的 Site 中的域名需要是完整的域名，例如 www.lethain.com）。

编写上下文处理器也很简单。首先，在你的应用文件夹中创建一个新文件（我把它命名为 context.py），并添加以下内容：

from django.contrib.sites.models import Site
from django.conf import settings
def site_context(request):
site = Site.objects.get(pk=settings.SITE_ID)
return {
'site' : site,
}

然后在 settings.py 文件中添加以下配置：

TEMPLATE_CONTEXT_PROCESSORS = (
    "django.core.context_processors.auth",
    "django.core.context_processors.debug",
    "django.core.context_processors.i18n",
    "django.core.context_processors.media",
    "yourproject.yourapp.context.site_context",
    )

这样就完成了。如果你有任何问题，欢迎随时提问。
