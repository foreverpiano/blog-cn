Django 与 Ubuntu Intrepid 指南

2009-02-13 · 阅读原文

距离我第一次尝试搭建一个健康的 Django 部署环境已经过去一年多了（服务器对应 Ubuntu 版本的软件源停止维护，粗暴地提醒了我）。这段时间我学到了很多，也把最初的配置撑到了极限，但终究还是到了需要重新部署的时候——采用更合理的配置和更灵活的目录结构。

和上一次服务器搭建指南相比，有些东西保持不变：依然使用 Ubuntu、Memcached、Postgres，并且继续让 Nginx 作为 Apache2 前面的反向代理。同时也有不少变化：用 mod_wsgi 代替 mod_python，用 cmemcache 代替 python-memcached，采用更加清晰的目录布局，并引入 virtualenv，以便轻松托管多个项目和域名（包括一些只提供静态文件或 PHP 脚本的站点）。

这不仅仅是一次更新，我还加入了一些支线任务，比如把服务器当作远程 Git 仓库通过 SSH 使用，以及安装可插拔的 Django 库。最后，延续我之前教程的风格，我尽量把从一台裸的 Ubuntu Intrepid 服务器开始，到最终变成一台功能完善、支持多站点的 Django 服务器所需的所有操作步骤都列了出来。

如果你在操作中遇到任何问题，或者有改进建议，请告诉我！
