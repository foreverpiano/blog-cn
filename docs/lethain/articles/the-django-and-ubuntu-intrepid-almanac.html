Django 与 Ubuntu Intrepid 实用指南

2009-02-13 · 阅读原文

距离我第一次尝试搭建一个健康的 Django 部署环境已经过去一年多了（Ubuntu 仓库因为服务器版本停止支持而粗暴地提醒了我）。在这段时间里，我学到了许多，也把最初的配置拉伸到了极限，但最终还是需要一次全新的部署——采用更好的配置和更灵活的文件夹结构。

与我上次的服务器搭建指南相比，有几样东西保持不变：依然使用 Ubuntu、Memcached、Postgres，并且依然用 Nginx 作为 Apache2 前面的反向代理。同时也有不少变化：改用 mod_wsgi 而不是 mod_python，用 cmemcache 取代 python-memcached，采用更合理的文件夹布局，并引入 virtualenv，以便轻松托管多个项目和域名（包括一些只提供静态文件或 PHP 脚本的站点）。

这不仅仅是一次更新，我还加入了一些支线任务，比如把服务器当作通过 SSH 访问的远程 Git 仓库，以及安装可插拔的 Django 库。最后，秉承我之前教程的一贯作风，我力求把从一台裸的 Ubuntu Intrepid 服务器开始，把每一步必须敲下的命令都写出来，最终变成一台功能完备、深受 Django 喜爱的多站点服务器。

如果你在操作中遇到任何问题，或者有改进建议，请务必告诉我！
