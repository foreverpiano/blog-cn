我今天花了几个小时写了一个针对 OneManga.com 的 Python 网页抓取程序。该网站是一个在线漫画扫描资源的聚合站点。主要是因为我有时网络连接较慢，所以想要一种方便的方式来获取图片而不用花费太多精力。这也是一个很好地使用 BeautifulSoup 和 Httplib2 的实践机会。整个实现重点关注两个理念：易用性和友好性。易用性是指让用户能够轻松获取和操作可用数据；友好性则是指不会用不必要的请求去轰炸服务器。

再次出现了新信息，表明又发生了一次 HTTP 请求。从概览页面深入到第一个章节的页面列表，只用了三次 HTTP 请求，但从这里开始，获取每一页都需要一个 HTTP 请求，因此保持克制非常重要。由此可见，获取 Pluto 第一章的全部内容还需要额外 32 个请求。此外，这个库对 HTTP 请求的处理比较简单，没有实现并行，所以获取大量页面时可能会相当慢。
