vtt-compactor：让 VTT 文件少一些冗余。

2020-03-07 · 阅读原文

我正在做一个小型项目，需要采访多位工程师，记录他们成为 Staff Engineer 的经历以及日常工作内容。希望首批故事能在几周后发布，但让我意外的是，获取高质量的访谈记录竟然这么困难。

目前 Zoom 的会议录制功能非常出色，它生成的 VTT 格式文本转录质量已经“足够好”，可以直接拿来编辑成访谈稿。不过，这个格式稍微有点冗长，因为它原本是设计用于字幕的：

off script that I want to ask on but like, how do you measure
that a lot of people feel about it like that. I want to ask, there's

00:03:54.420 --> 00:03:58.560

And I've actually never heard anything quite like it before.

这导致我每次都要花大量时间手动删除这些元数据，才能开始真正重要的内容编辑工作。为了不让自己抓狂，我写了一个非常简单的 Python 脚本——vtt_compactor，使用方式如下：

python3 compact.py yourfile.rtt

它会生成如下输出：

actually never heard anything quite like it before.

虽然只是一个很小的改进，但它为每份转录节省了大约三十分钟的手动编辑时间，所以我决定把它分享出来。（老实说，如果我专注去做的话大概只需要十分钟就能完成，但这个过程实在太烦人了，导致我总是忍不住分心，结果花的时间反而更长。）
