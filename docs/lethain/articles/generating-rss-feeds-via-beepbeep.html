正如上面的例子所示，使用方式很简单——虽然略显啰嗦——但应该足以完成任务。在某些方面，我觉得它比 Django 的 syndication 框架更加灵活和直观，当然这也情有可原，因为后者的功能要丰富得多。我承认这并不是一个完全公平的比较。

如何为 BeepBeep 开发可重用的库，这也是我最近一直在思考的一个普遍话题。目前我的做法是，在合理范围内保持后端无关性，否则就统一使用 CouchDB 作为持久化方案。随着我继续将 BeepBeep 作为开发 Web 应用的基础平台，我可能会进一步完善这个方法（比如引入存储抽象层？）。
