书籍内保持一致链接的脚本

2025-04-06 · 阅读原文

在我撰写 #eng-strategy-book 的过程中，一直在编辑大量内容。 今天早上我想解决两个编辑问题。 首先，我想确保在各章节中均匀地引用各种策略（而非过度依赖其中某几个）。 其次，我想确保对其他章节的引用方式保持一致且标准化。

这两件事本质上都是从文件中收集 Markdown 链接，按文件或 URL 进行分组，然后以有用的形式输出分组结果。我决定尝试用一次性 Prompt 让 AI 帮我写这个脚本，而不是自己动手。Prompt 和输出结果（来自 ChatGPT 4.5）可以在这个 gist 中找到。

结果完全正确！输出的代码格式有点丑，我手动稍作调整，同时修改了正则表达式，让它捕获更少的前置内容，最终得到了这个脚本。虽然我是手动调整的，但我相信直接让 ChatGPT 修复会更快。不过无论如何，这些改动都很小。

总的来说，这是一个非常简单的脚本，我自己写大概需要三十分钟左右，而这次我只用了不到十分钟就完成了，剩下的二十分钟可以继续投入实际的编辑工作。

它对解决策略引用不均衡的问题也非常有帮助。 从输出可以看出，我最初对 Uber 迁移策略的引用多达 17 次，因为这是我最早为这本书记录的策略之一。

相反，关于 Stripe Sorbet 的策略只有三个链接，因为那是最后写完的两个章节之一。

在撰写各章节的过程中，我自然会更频繁地引用已经存在的策略，而较少提到尚未写完的策略，但这会让整本书读起来有些头重脚轻。这个脚本帮助我纠正了这种失衡。 这也是我在写《Staff Engineer》时没有做但后来希望做过的事情——我最终过多依赖了早期的案例，而对后期案例的提及明显不足。
