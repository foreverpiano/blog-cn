书籍内部统一链接的脚本

2025-04-06 · 阅读原文

在我撰写 #eng-strategy-book 的过程中，我一直在编辑大量内容。 今天早上我想解决两个编辑问题。 首先，我希望确保在各章节中对策略的引用保持均衡（不会过度依赖某几个策略）。 其次，我希望确保对其他章节的引用方式保持一致且标准化。

这两个问题本质上都是从文件中收集 Markdown 链接，按文件或 URL 进行分组，然后以实用的形式输出分组结果。我决定尝试用一次性 prompt 让 AI 帮我写这个脚本，而不是自己动手。prompt 和输出结果（来自 ChatGPT 4.5）可以在这个 gist 中找到。

结果非常成功！虽然输出的代码样式有点丑，我手动稍微调整了一下格式，并修改了正则表达式来减少捕获的前置内容，最终得到了现在的这个脚本。虽然我是手动调整的，但我相信直接让 ChatGPT 修复会更快。不过无论如何，这些都只是很小的改动。

总的来说，这是一个非常简单的脚本，我自己写大概需要三十分钟左右，但借助这种方式，我在不到十分钟内就完成了，剩下的二十分钟可以继续投入到实际的编辑工作中。

这个脚本对于解决策略引用不均衡的问题也非常有帮助。 从下面可以看到，我最初对 Uber 服务迁移策略的引用达到了 17 次，因为这是我为这本书最早记录的策略之一。

另一方面，关于 Stripe Sorbet 的策略只有 3 个链接，因为它属于我最后写完的两章之一。

在撰写各章节的过程中，我更频繁地引用已有的策略而非尚未写完的策略，这是很自然的，但这会让整本书读起来有些失衡，而这个脚本帮助我纠正了这种不均衡。 这也是我在写《Staff Engineer》时没有做但后来希望做过的事情，因为最终我过于依赖早期的案例，对后期案例的提及则相对较少。
