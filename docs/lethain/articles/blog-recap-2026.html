用 Remotion 创作数据可视化视频

2026-01-25 · 阅读原文

Remotion 最近颇受关注，于是我决定尝试一下 Claude Code 集成。我用不到 10 分钟就制作了几段视频，用来总结我博客上的数据。

首先是随时间推移发布的文章数量。我让 Claude 编写脚本生成这个数据集，然后通过一系列提示（prompt）来获得理想的可视化效果。整个过程相当直接，效果很好。如果我一开始就有更明确的目标，估计能更快做出满意的视频。

其次，这段视频展示了随时间变化的已发布博客文章、我当时最常用的标签，以及我在每段职业经历中发布的文章数量。

总的来说，看到 Claude 和 Remotion 结合能如此高效地生成相当复杂的视频，真是令人着迷。这绝对是我未来会再次使用的工具。
