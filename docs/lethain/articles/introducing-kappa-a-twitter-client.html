介绍 Kappa，一款 Twitter 客户端

2008-09-03 · 阅读原文

（如果您不想收到与我开发的软件相关的内容，请订阅 Code RSS feed，该订阅将仅包含教程和其他通用编程内容。）

今天我很高兴地宣布 Kappa 的 Alpha 版本。这是一款专为对数据和设计有着狂热兴趣的人打造的 Twitter 客户端。Kappa 这个名字来源于日本传说中生活在河流和湖泊中的水怪。虽然它们顽皮淘气，却是非常懂得尊重的生物，如果你向它鞠躬，它也会向你回礼。在鞠躬时，它们力量的源泉——水会从头顶倾泻而出，而旅行者就可以安心继续前行了。

你或许会想象这个故事和名字之间存在某种联系，但其实并没有。不过，为了弥补这种信任的落差，让我们来看看 Kappa 的功能特性吧。

Kappa 的迷人功能

在 Kappa 窗口顶部有一个进度条，用于显示距离上次更新和下次更新之间的时间。从此再也不用焦虑地猜测你的 Twitter 客户端上次是什么时候更新的。另一方面，如果你想立即刷新，只需点击进度指示器，Kappa 就会立刻更新推文。同样重要的还有顶部的搜索框，它支持使用正则表达式搜索所有本地存储的推文。例如，.*@ 可以搜索所有包含 @ 符号的消息，而 .*aba 则会找出包含“aba”字符串的推文。过滤器会同时搜索用户名和推文内容，当输入的文本是无效的正则表达式时，搜索框中的文字会变成红色。
所有获取的推文都会本地存储。这意味着即使没有互联网连接，你也可以在 Kappa 中舒适地浏览和搜索旧推文。说到获取推文，你可以通过“Feeds”菜单灵活组合，获取标准时间线（称为好友时间线）、公开时间线，以及发送给你的回复（例如 @lethain Kappa 为什么一直崩溃？）——无论对方是否已经是你的 Twitter 好友。Kappa 会尽量充分利用可用空间，所以当窗口不在最前端时，它会自动隐藏过滤框、发推文框甚至表格的列，为显示推文腾出更多空间。不过进度条仍然会显示，这样你就不用担心什么时候才能再次看到社交信息流了。
Kappa 允许你按时间、用户名和消息内容对列进行排序。虽然表面上看似没用，但这一功能与过滤器结合后，可以实现有趣且复杂的查询。

下载 Kappa

Kappa 仅能在 OS X 10.5 (Leopard) 上运行。对于使用其他平台或旧版 OS X 的用户：抱歉！

希望你下载 Kappa 并试用它。我必须强调，我是从昨天才开始开发 Kappa 的，所以它几乎肯定会存在一些 bug 和问题。如果遇到任何错误、问题或有想法，欢迎给我发邮件至 lethain@gmail.com。

Kappa 目前还不是（什么）

当你第一次打开 Kappa 时，可能会发现它在某些关键方面没有达到你的最低预期。这有三种可能的原因。

我主动决定不做这个功能（“我不喜欢那个。”）；我被动决定暂时不做（“我暂时还不做那个。”）；我还没想到这个点子（“……你说什么？”）。

目前为止，你可能想要的大多数功能都属于第二类，包括：

使用自定义视图而不是表格视图来显示推文。这引发了一系列相关抱怨：窗口较窄时难以看到完整的推文内容；难以看到完整的用户名；不显示用户头像；不显示用户位置。这些问题都源于目前尚未采用自定义视图。当然也有几点反驳理由：表格视图支持排序（对数据爱好者的 Twitter 客户端很有帮助）、支持列的重新排序（可按自己喜好定制），而且——或许最重要的是——表格视图已经实现了。我目前的思路是最终添加额外的列来显示所有需要的内容（主要是位置和图片），并允许用户在偏好设置面板中自定义显示哪些列。过滤框的位置目前有点让人苦恼，因为它是你启动应用时第一个注意到的元素，你的第一反应可能是把要发的推文输入到过滤框里。不过，我也还没找到明显更好的位置。一种可能的解决方案是让用户选择是否显示过滤器。随着 Kappa 的开发，我会继续重新思考这个问题。

目前我能想到的就是这些，但无疑还有其他需要解决的问题。下载 Kappa 试用一下吧，并尽情给我反馈你产生的任何想法。
