介绍 Kappa，一款 Twitter 客户端

2008-09-03 · 阅读原文

（如果您不想收到与我开发的软件相关的内容，请订阅 Code RSS feed，该订阅将仅包含教程和其他通用编程内容。）

今天我很高兴地宣布 Kappa 的 Alpha 版本，这是一款专为对数据和设计有着奇特痴迷的用户打造的 Twitter 客户端。Kappa 这个名字来源于日本传说中生活在河流与湖泊中的水灵。虽然它们有些调皮，但却是非常讲礼貌的生灵，如果你向它们鞠躬，它们也会回礼。在鞠躬时，它们头上的水——力量之源——会倾泻而出，而旅人就可以安心继续前行了。

你可能会觉得这个故事和名字之间有什么联系，但其实并没有。不过，为了弥补这个误会，我们还是来看看 Kappa 的功能吧。

Kappa 的迷人功能

  • At the top of Kappa's window is a progress bar, which measures the time between the last update and the next one. Never again get antsy wondering when your Twitter client last updated.On the other hand, if you really want to update right now, just click on the progress indicator and Kappa will update its tweets.
  • Equally central is the search field at top, which allows you to search all locally stored tweets using regular expressions. For example, .*@ searches for all messages with an at symbol, and .*aba searches for tweets containing the string aba. The filter searches both usernames and the tweet's themselves, and the text in the search field will turn red when the currently entered text is an invalid regular expression.
  • All retrieved tweets are stored locally. This means you can review and search for old tweets from the comfort of Kappa even if you don't have an internet connection.
  • Speaking of retrieved tweets, using the Feeds menu, you can mix and match retrieving the standard timeline (called the Friends Timeline), the public timeline, and also replies send to your name (@lethain Kappa keeps crashing, why?, for example) --whether or not they are already your friend on Twitter.
  • Kappa tries to maximize its available space, so when Kappa's window isn't in front, then it will hide the filter field, the tweet field, and even the columns on the table. This frees up more room to see tweets. It'll still display the progress bar, though, so you don't have to worry about when you'll get your next hit of social babble.
  • Kappa 支持按时间、用户名和消息内容对列进行排序。虽然看似没太大用处，但这项功能与过滤器结合后，可以实现有趣且复杂的查询。

下载 Kappa

Kappa 只能在 OS X 10.5 (Leopard) 上运行。对于使用其他平台或旧版 OS X 的用户，我只能说抱歉！

希望你下载 Kappa 并试用它。我必须强调，我是从昨天才开始开发 Kappa 的，所以它几乎肯定存在一些 bug 和问题。如果你遇到任何错误、问题或有好的想法，欢迎发邮件到 lethain@gmail.com。

Kappa 目前还不是（什么）

当你第一次打开 Kappa 时，可能会发现它在某些关键方面没有达到你的最低预期。这有三种可能的原因。

  1. I have actively decided against the idea ("I don't like that.").
  2. I have passively decided against the idea ("I won't do that yet.").
  3. I haven't thought of the idea ("...say what?").

目前为止，你可能想到的大多数想法都属于第 2 类，包括：

  • Using a custom view instead of a tableview to display tweets. This ends up catching a number of related complaints: its hard to see full tweet text with a small width, its hard to see full username with small width, it doesn't display a user's profile image, it doesn't display a user's location.These all relate to thus far not choosing to use a custom view. There are a handful of counterarguments: the tableview allows sorting (helpful for a data lover's Twitter client), the tableview allows reordering (customize to your liking), and--perhaps most important--the tableview is already implemented.My current thought is to eventually add additional columns for all desirable content (namely location and images), and to allow users to customize visible columns within the preferences panel.
  • The filter field is frustratingly placed, because it is the first thing you notice when starting the application, and your first urge is to type your tweet into the filter field. However, I don't feel there is a clearly better location for it either.A possible solution is to allow users to choose whether or not they want the filter to be displayed. I'll keep reconsidering this as work on Kappa continues.

目前我能想到的就这些了，但毫无疑问还有其他问题需要解决。下载 Kappa 试用一下吧，并尽可能多地给我反馈。
