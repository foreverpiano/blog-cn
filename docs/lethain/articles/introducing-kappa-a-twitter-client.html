介绍 Kappa，一款 Twitter 客户端

2008-09-03 · 阅读原文

（如果您不想收到与我开发的软件相关的内容，请订阅 Code RSS feed，该订阅将仅包含教程和其他通用编程内容。）

今天我很高兴地宣布 Kappa 的 Alpha 版本，这是一款专为对数据和设计有着奇特痴迷的用户打造的 Twitter 客户端。Kappa 这个名字来源于日本传说中生活在河流与湖泊中的水灵。虽然它们有些调皮，但却是非常讲礼貌的生灵，如果你向它们鞠躬，它们也会回礼。在鞠躬时，它们头上的水——力量之源——会倾泻而出，而旅人就可以安心继续前行了。

你可能会觉得这个故事和名字之间有什么联系，但其实并没有。不过，为了弥补这个误会，我们还是来看看 Kappa 的功能吧。

Kappa 的迷人功能

在 Kappa 窗口顶部有一个进度条，用于显示距离下次更新的时间。你再也不用焦躁地猜测 Twitter 客户端上次是什么时候刷新的了。另一方面，如果你想立即刷新，只需点击进度指示器，Kappa 就会立刻更新推文。同样重要的还有顶部的搜索框，它支持使用正则表达式搜索所有本地存储的推文。例如，.*@ 可以搜索所有包含 @ 符号的消息，而 .*aba 则会找出包含“aba”字符串的推文。过滤器会同时搜索用户名和推文内容，当输入的正则表达式无效时，搜索框内的文字会变成红色。
所有获取的推文都会本地存储。这意味着即使没有网络连接，你也可以在 Kappa 中安心浏览和搜索旧推文。说到获取推文，通过“Feeds”菜单，你可以灵活组合获取标准时间线（称为 Friends Timeline）、公共时间线，以及发送给你的回复（例如 @lethain Kappa keeps crashing, why?）——无论对方是否已经是你的 Twitter 好友。Kappa 会尽量充分利用屏幕空间，当窗口不在前台时，它会自动隐藏过滤框、发推框甚至表格中的列，以便留出更多空间显示推文。不过它仍会显示进度条，这样你就不用担心什么时候能再次看到社交动态了。
Kappa 支持按时间、用户名和消息内容对列进行排序。虽然看似没太大用处，但这项功能与过滤器结合后，可以实现有趣且复杂的查询。

下载 Kappa

Kappa 只能在 OS X 10.5 (Leopard) 上运行。对于使用其他平台或旧版 OS X 的用户，我只能说抱歉！

希望你下载 Kappa 并试用它。我必须强调，我是从昨天才开始开发 Kappa 的，所以它几乎肯定存在一些 bug 和问题。如果你遇到任何错误、问题或有好的想法，欢迎发邮件到 lethain@gmail.com。

Kappa 目前还不是（什么）

当你第一次打开 Kappa 时，可能会发现它在某些关键方面没有达到你的最低预期。这有三种可能的原因。

我主动决定不做（“我不喜欢那个。”）；我被动决定暂缓（“我暂时不做那个。”）；我还没想到这个点子（“……你说什么？”）。

目前为止，你可能想到的大多数想法都属于第 2 类，包括：

使用自定义视图而不是表格视图来显示推文。这也引发了一系列相关抱怨：窗口较窄时很难看清完整的推文内容，很难看清完整的用户名，无法显示用户头像，无法显示用户位置。这些问题都源于目前尚未采用自定义视图。当然也有一些反驳理由：表格视图支持排序（对数据爱好者的 Twitter 客户端很有帮助），支持列的重新排序（可以按自己喜好定制），而且——也许最重要的是——表格视图已经实现了。我目前的打算是在将来为所有需要的内容添加额外的列（主要是位置和图片），并允许用户在偏好设置面板中自定义显示哪些列。过滤框的位置目前有些令人沮丧，因为它是你启动应用后首先注意到的元素，而你第一反应可能是想把要发的推文输入到过滤框里。不过我目前也没想到明显更好的位置。一种可能的解决方案是让用户选择是否显示过滤框。随着 Kappa 的开发，我会继续重新思考这个问题。

目前我能想到的就这些了，但毫无疑问还有其他问题需要解决。下载 Kappa 试用一下吧，并尽可能多地给我反馈。
