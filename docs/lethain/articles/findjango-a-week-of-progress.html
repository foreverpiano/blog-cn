Findjango，一周进展

2009-03-16 · 阅读原文

我一直在开发的 Django 垂直搜索引擎 Findjango 已经开源约一周了。它正朝着良好的方向发展，而且——我得说——进步速度也相当不错。我非常希望 Findjango 能成为一个社区工具，所以让我简单介绍一下目前阻碍它实现这一目标的障碍，以及我正在采取哪些措施来逐步消除它们。

第一周已经产生了约 2500 次查询，不少结果被标记用于相关性调优，还有一位好心人用五十个并发客户端对它运行了负载测试脚本。

扩展内容

我一直努力让内容高度聚焦于 Django，但这样做的副作用之一就是，对于某些查询，可用的内容量明显不足。搜索 Marty Alchin 的 Pro Django，你会得到 258 个极其相关的结果。而搜索 tutorial，你会得到 4218 个平庸至极的结果。搜索 performance，则会得到 3402 个糟糕的结果。

为了改善这一状况，我周日大部分时间都在熟悉 whoosh（一个纯 Python 的全文索引和搜索库）以及 feedparser，现在已经具备了持久化索引 RSS（或 Atom）源的能力。也就是说，从昨天开始，所有经过 Django Community feed、This Week in Django feed 以及几个较小 feed 的内容，都已经被——并将继续被——索引以供搜索。

这种方式无法收录较旧的内容，但它仍是工具箱里一个有用的工具，未来也将让我能够为那些无法向 Findjango 暴露原生搜索 API 的网站索引内容。

如果你有一个 Django 相关内容的 RSS feed，而它尚未被 Django community feed 收录，请告诉我，我也会把它加进来！

下一步将是搭建一个小型的网络爬虫流程，使用 Scrapy 来抓取和提取较旧或非 feed 形式的内容。这大概还需要一两周时间。

（我同时也在几个场合努力争取让对方为 Findjango 开放 API，这仍然是将你的内容接入 Findjango 的最佳方式。）

提升知名度

Findjango 面临的另一个主要障碍是，那些最能从它受益的人——即刚开始使用 Django 进行开发的新手——却最难发现它的存在。

如果我是 Yahoo! 或 Google，我会通过搜索合作协议来推广，但由于我的预算明显有限，我制定了一个不同的策略，希望这个策略对网站所有者和 Findjango 都能有所帮助。

你可以用它在自己的网站上添加一个 Django 专属的搜索功能。我知道仅凭这一点可能还不够有吸引力，所以这里再加一点“秘制酱料”作为额外诱因：你可以通过 site 参数传入自己的域名，这样来自你网站的结果就会被提升到结果集的最上方。

这意味着——只要你告诉我可以在哪里找到你网站的 RSS feed，或者你提供一个搜索 API——你就可以使用 Findjango 为你的 Django 相关网站提供一个增强版的站内搜索。

我认为对很多网站来说，这会让 Findjango 变得真正有用。我正在着手准备一些默认模板和/或 template tag，让大家能更轻松地使用 Findjango 来驱动站内搜索。

需要更好的设计

新的设计应该会在 Findjango 满两周之前上线。很抱歉让大家这么久一直忍受目前这个版本，但很快就会有改善。

以上概述并不是过去一周所有改动的完整清单（还集成了 GitHub 搜索 API、对 DjangoCodeSearch 做了少量集成、Findjango 成为了 Firefox 可自动发现的搜索引擎等等），但希望它能让你放心：Findjango 正朝着正确的方向前进，并逐步演化成一个真正有用的解决方案。

一如既往，欢迎大家提供反馈。
