《非理性繁荣》的第三次重生

2011-03-27 · 阅读原文

在讨论《非理性繁荣》最新版本之前，请允许我先恳求大家给我一些建议！好了，言归正传。这里到底发生了什么？我真的又把自己的定制博客实现换成了另一个定制博客实现吗？

是的。而且我把它叫做 Sisyphus……原因不言自明。

为什么呢？

有两个原因：首先，我之前的博客在工程上已经变得极其臃肿且可怕，我实在无法忍受继续在其基础上做任何扩展（它需要扩展来应对大量涌入的垃圾评论，严重到我最后只能直接关闭评论……而这还花了三次尝试才成功）；其次，过去三年我在职业开发中积累了一些有趣的想法，我需要一个试验场来尝试它们。（并非所有想法都出现在《非理性繁荣》3.0 中，但有一些已经实现了。在投入了将近一周的业余时间开发新版本后，我决定必须先把它上线，而不是在第一个版本就贪心做太多。）

讨论 LifeFlow 那场灾难并不特别令人兴奋（就像吐槽《OC 生活》第三季一样，槽点自己就冒出来了），所以我转而谈谈自己正在尝试实验、未来将要尝试实验的想法，以及为什么这个博客会以这样的方式发生变化。

那我们就开始吧。

《非理性繁荣》的第一个版本是托管在共享主机上的 WordPress 博客。第二个版本是一个定制的 Django 应用，它几乎集齐了“第二系统”该有的所有毛病。希望这个第三版本能坚持得更久一些（而不是像我上辆自行车，只骑了六个月就被停车抄牌的车压坏，而我则被随之而来的羞耻感所击垮）。

在思考新设计时，我主要受到了两个影响：旧版本和 Digg。对于不在 Digg 工作的人来说，这种影响可能并不明显，但右侧边栏模块的处理方式，以及 Popular 内容（下文会详细讨论）的概念，完全是借鉴而来的。

文章

博客的焦点永远应该是它的内容。这一点我认为 V2 做得非常出色，部分得益于它的单栏设计——几乎把整个页面都让给了内容（除了那个确实有点肥的头部和底部，把文章夹成了一个相当诡异的彩虹三明治）。

段落宽度被有意限制，以提升阅读舒适度（嗯……要找到一篇靠谱的研究，说明段落宽度是否以及为什么要被限制以提高可读性，还真挺难的。这就是我能找到的最好的吗？*不，不是。多亏 @cduruk 指出了一项更具公信力的研究）。图片增加了边框，垂直间距也有所缩减。文章可用的宽度从 700px 缩小到了 550px。

总体而言，呈现方式变化并不算大。

头部

另一方面，头部则有了相当大的进化。V2 的头部有点高，但尽管如此，它在建立导航元素的视觉层级上做得相当不错。

我也会怀念它的独特性。我不认为曾经有人把《非理性繁荣》误认为是别的博客。

新的头部力求尽可能紧凑，同时将部分导航职责交给右侧边栏模块，让读者能够立刻开始他们来这里真正想做的事：好好读这篇该死的文章。

搜索是一个重大的新增功能，我很好奇它是否会被真正使用。从理论上讲，搜索是一个通用的导航元素，能够弥补其他任何导航缺陷，同时也能扩展解决用户独特的导航需求（我哪篇文章里提到过 Asheville？Twitter 相关的呢？）。

视觉独特性消失了，但新的头部更简洁，并且带来了搜索功能。这大概算是胜利。

底部和模块

V2 的底部试图做很多事情，而且还要用通常标题很长的文章来实现，这是一个尴尬的限制。（这个限制依然存在，但在模块中比在全宽底部处理得视觉上更好一些。当然，也可以把模块放到底部——这是很标准的博客底部做法——那样的话，这个肥大的底部在视觉上会更容易解析。）

V3 取消了厚重的底部，把它的所有内容都移到了右侧边栏模块中。这些模块扩展性很好，即使是最短的文章也能在视觉上容纳五个以上的模块。

我们的希望是，右侧边栏模块能让导航变得更容易（读者一打开页面就能看到导航选项，而不需要一直滚动到底部才能发现内容），同时也为未来的实验提供一个平台。

之前的版本支持分享到各种新闻社区和社交网络，但使用的是纯文本链接：

新版本正在尝试使用 Digg、Twitter 和 Facebook 的分享按钮，并且会显示 Diggs、推文和分享的数量。

我很好奇最终效果如何。从理论上说，在按钮里直接显示数字可能会阻碍最初的分享（人们通常更愿意把自己和已经成功的东西联系在一起），但对于教程这类技术内容来说，这可能不是什么大问题。要么教程有用，要么没用；要么你的朋友感兴趣，要么不感兴趣。你是第一个分享还是最后一个，可能无关紧要。

好了，数据会比我的内心独白更能说明问题。让我们拭目以待。

大多数模块都相当直白。“Recent”模块显示最新文章，“Previous”和“Next”模块分别显示前一篇和后一篇文章。“Tags”模块（目前仅在故事列表页可见）列出最常用的标签（我移除了顶层标签导航，因为似乎几乎没人真正使用标签，但我需要对 V2 的日志做一些分析，才能确定这句话到底有多准确）。

“Popular”和“Similar”模块则稍微新颖一些，值得在下一篇文章中单独讨论，那篇文章将介绍 Sisyphus 的实现细节。

旧的文章 URL 结构除了 slug 之外，还包含了发布年、月、日。

/entry/2009/oct/11/money-or-meaning-spending-our-wealth-of-time/

如果你担心会出现 slug 冲突，这么做还算勉强合理，但对于一个人的博客来说，这几乎是不可能发生的，而且我讨厌它们变得那么机器友好而对人类极不友好。现在的新 URL 则简洁得多：

/money-or-meaning-spending-our-wealth-of-time/

我对这些新链接满意多了。（我已经把所有旧 URL 都 302 重定向到了新地址，确保旧链接仍然有效。重写规则很简单，只要把除了 slug 之外的所有部分去掉就行。）

其他大多数 URL 结构都保持不变，任何有改动的部分都在 Nginx 中设置了重写规则，以确保不会突然出现意外的 404。

再次强调，我非常希望听到任何关于改进这个最新版《非理性繁荣》的反馈、建议或吐槽。说完这些，我想我终于可以结束这么长时间的停更，回去写一些更有趣的东西了！
