用 Python 为 Yahoo 的 BOSS 搜索食谱

2008-07-11 · 阅读原文

本教程将介绍如何使用 Yahoo BOSS Mashup Framework 的可选 Python 库来（还能是什么？）构建你自己的搜索服务。我们将从安装该库并申请 BOSS 开发者账号开始，然后在 Python 命令行中体验 BOSS，整理出一系列实用的食谱，用于搜索网页、新闻、图片等内容。

本教程不会尝试构建一个完整的应用，仅展示如何直接使用 BOSS 库本身。如果你对在 Web 框架中使用 BOSS 的文章感兴趣，我最近写了一篇在 Django 中使用 BOSS 的文章，应该会对你有所帮助。

在学习这些示例时，你可能需要参考官方的 Yahoo BOSS API 文档（该文档的链接在 BOSS 页面上比较难找到）。

配置 BOSS 库

在开始之前，请注意 BOSS Framework 库依赖于 Python 2.5，无法直接用于更早的版本。

注册一个 BOSS App ID。你需要选择使用浏览器内认证，并提供两个 URL：一个是你的应用地址，另一个是认证成功后的重定向地址。不过，这些 URL 并不被该库实际使用（库也不需要对使用你服务的最终用户进行任何形式的认证，尽管你必须提供 BOSS APP ID 才能让库正常工作），但它们用于验证你的账号，因此你需要选择一个有效的域名，并在该域名下放置一个静态文件以供其验证域名所有权。下载用于控制 BOSS 的 Python 库。解压后删除压缩包。 unzip boss_mashup_framework_0.1.zip rm boss_mashup_framework_0.1.zip 打开 boss_mashup_framework_0.1/config.json 文件，为前三项填写你的信息。appid 是你在第 1 步注册 BOSS 时获得的 ID。email 是你的邮箱地址。org 是你组织的名称（通常就是你的名字）。如果尚未安装 Simple JSON，请先安装它。你可以在 Python 2.5 交互环境中输入 import simplejson 来检查是否已安装。 如果无法导入，请下载 Simple JSON，解压，进入目录后进行安装。 tar -xzvf simplejson-1.9.2.tar.gz cd simplejson-1.9.2 python2.5 setup.py build python2.5 setup.py install cd ../ rm -rf simplejson-1.9.2* 创建文件夹 boss_mashup_framework_0.1/deps/。 cd boss_mashup_framework_0.1 mkdir deps 下载 dict2xml 和 xml2dict，将它们解压到 deps 文件夹中，删除 .tgz 文件，然后返回 boss_mashup_framework_0.1 目录。 cd deps cp ~/Desktop/dict2xml.tgz ./ cp ~/Desktop/xml2dict.tgz ./ tar -xzvf dict2xml.tgz tar -xzvf xml2dict.tgz rm *.tgz cd .. 现在我们可以构建该库了。 python2.5 setup.py build python2.5 setup.py install 最后，让我们测试一下是否一切正常。 python2.5 examples/ex3.py 你应该会在屏幕上看到一些新闻报道输出。成功了。如果你遇到类似以下的错误信息： Traceback (most recent call last): File "examples/ex3.py", line 16, in <module> from yos.yql import db File "/Library/Frameworks/Python.framework/Versions/2.5/lib/python2.5/site-packages/yos/yql/db.py", line 44, in <module> from yos.crawl import rest File "/Library/Frameworks/Python.framework/Versions/2.5/lib/python2.5/site-packages/yos/crawl/rest.py", line 15, in <module> HEADERS = {"User-Agent": simplejson.load(open("config.json", "r"))["agent"]} IOError: [Errno 2] No such file or directory: 'config.json' 那么你很可能是在一个没有 config.json 文件的目录下启动了 Python。我认为这是当前版本库中一个相当糟糕的缺陷：你必须在一个包含 config.json 文件的目录下运行 Python。希望这种情况将来能得到改进。

至此，我们已经完成所有设置，可以继续前进了。如果你在安装过程中遇到问题，请查看 boss_mashup_framework_0.1/README 文件。如果还是无法解决，欢迎在评论中留言，我会尽量提供帮助。
