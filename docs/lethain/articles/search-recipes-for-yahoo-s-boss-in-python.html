用 Python 为 Yahoo 的 BOSS 编写搜索代码实例

2008-07-11 · 阅读原文

本教程将介绍如何使用 Yahoo BOSS Mashup Framework 的可选 Python 库来（还能是什么呢？）构建你自己的搜索服务。我们会先安装该库并申请一个 BOSS 开发者账号，然后在 Python 命令行中体验 BOSS 的用法，整理出一系列实用的代码实例，用于搜索网页、新闻、图片等内容。

本教程不会尝试构建一个完整的应用程序，只会展示如何直接使用 BOSS 库本身。如果你对在 Web 框架中使用 BOSS 的文章感兴趣，我最近写过一篇在 Django 中使用 BOSS 的文章，应该会对你有帮助。

在学习这些示例的过程中，你可能会需要参考官方的 Yahoo BOSS API 文档（它的链接在 BOSS 页面上不太容易找到）。

配置 BOSS 库

在开始之前需要注意，BOSS Framework 库依赖 Python 2.5，无法直接用于之前的版本。

unzip boss_mashup_framework_0.1.zip
rm boss_mashup_framework_0.1.zip

import simplejson

tar -xzvf simplejson-1.9.2.tar.gz
cd simplejson-1.9.2
python2.5 setup.py build
python2.5 setup.py install
cd ../
rm -rf simplejson-1.9.2*

cd boss_mashup_framework_0.1
mkdir deps

cd deps
cp ~/Desktop/dict2xml.tgz ./
cp ~/Desktop/xml2dict.tgz ./
tar -xzvf dict2xml.tgz
tar -xzvf xml2dict.tgz
rm *.tgz
cd ..

python2.5 setup.py build
python2.5 setup.py install

python2.5 examples/ex3.py

注册一个 BOSS App ID。你需要选择使用浏览器内认证方式，并提供两个 URL：一个是你应用的地址，另一个是认证成功后的跳转地址。不过这个库并不使用这些 URL（也不使用任何针对最终用户的认证方式，尽管你必须提供 BOSS APP ID 才能让库正常工作），但它们用于验证你的账号，因此你需要选择一个有效的域名，并在该域名下放置一个静态文件以供其验证域名所有权。下载用于控制 BOSS 的 Python 库。解压后删除压缩包。打开 boss_mashup_framework_0.1/config.json 文件，填写前三项的内容。appid 是你在第一步注册 BOSS 时获得的 ID。email 是你的邮箱地址。org 是你组织的名称（很可能就是你的名字）。如果尚未安装 Simple JSON，请先安装它。你可以在 Python 2.5 交互环境中输入以下命令来检查是否已安装。如果无法导入，则下载 Simple JSON，解压后进入目录进行安装。在 boss_mashup_framework_0.1 目录下创建文件夹 deps/。下载 dict2xml 和 xml2dict，将它们解压到 deps 文件夹中，删除 .tgz 文件，然后返回 boss_mashup_framework_0.1 目录。现在我们可以构建这个库了。最后，让我们测试一下是否一切正常。你应该会看到一些新闻故事被打印到屏幕上。成功了。如果你遇到类似这样的错误信息：那么你很可能是在一个不包含 config.json 文件的目录中启动了 Python。我认为这是目前这个库的一个比较严重的缺陷：你必须在一个包含 config.json 文件的目录中运行 Python。希望这种情况将来能得到改进。

搜索网页

首先来看看如何使用 BOSS Mashup Framework 搜索网页。

>>> from yos.yql import db
>>> data = ysearch.search("Django",count=10)
>>> table = db.create(data=data)

这里需要指出 url 和 clickurl 的区别。在上面的代码中它们是相同的：

{  u'url': u'http://www.djangoproject.com/',
   u'clickurl': u'http://www.djangoproject.com/',
   ...
}

然而，根据 Yahoo 官方文档的说明，这两者有重要区别。即你应当使用 clickurl 作为实际访问该网站的链接。例如，如果你在编写 Django 模板，链接应该写成下面这样：

<a href="{ { row.clickurl }}">{ { row.url }}</a>
<a href="{ { row.clickurl }}">{ { row.title }}</a>

而不应写成下面这样：

<a href="{ { row.url }}">{ { row.url }}</a>
<a href="{ { row.url }}">{ { row.title }}</a>

虽然我目前还没遇到 url 和 clickurl 实际不同的情况，但遵循 Yahoo 的官方建议似乎更安全，因为这背后很可能有合理的解释，尽管他们的文档没有解释得很清楚。

将搜索限制在单个网站

将搜索限制在特定网站非常简单。如果你想在 djangoproject.com 上搜索 HttpRequest，只需这样做：

>>> query = u"%s site:%s" % ("HttpRequest", "djangoproject.com")
>>> query
u'HttpRequest site:djangoproject.com'
>>> data = ysearch.search(query)

下面是一个完整的示例：

>>> data = ysearch("BOSS Framework",lang="es",region="ar")

搜索拼写检查

你也可以用 BOSS 检查拼写。要实现这一点，只需在 ysearch.search 函数中添加 vertical="spelling" 参数。

>>> from yos.boss import ysearch
>>> from yos.yql import db
>>> data = ysearch.search("exubberance",vertical="spelling")
>>> spellings = db.create(data=data)
>>> spellings.rows
[{u'suggestion': u'exuberance'}]
>>> data = ysearch.search("horrifiy",vertical="spelling")
>>> spellings = db.create(data=data)
>>> spellings.rows
[{u'suggestion': u'horrific'}]

分页显示搜索结果

通常你会希望能够翻页浏览搜索结果，先显示前十条，然后是接下来的十条，依此类推。幸运的是，这也很容易实现。只需使用 ysearch.search 函数的 start 命名参数，并逐步增加它的值即可：

>>> pos = 0
>>> first_five = ysearch.search("Django",start=pos,count=5)
>>> pos = pos + 5
>>> second_five = ysearch.search("Django",start=pos,count=5)
>>> pos = pos + 5
>>> third_five = ysearch.search("Django",start=pos,count=5)

下面是一个分页显示搜索结果的完整示例：

>>> from yos.boss import ysearch
>>> from yos.yql import db
>>> data = ysearch.search("Python",start=0,count=5)
>>> results = db.create(data=data)
>>> titles = [ row['title'] for row in results.rows ]
>>> titles
[u'<b>Python</b> Programming Language', u'<b>Python</b> (programming language) - Wikipedia, the free encyclopedia', u'<b>Python</b> (programming language) - Wikipedia, the free encyclopedia', u'Download <b>Python</b> Software', u'<b>Python</b> - Wikipedia, the free encyclopedia']
>>> data = ysearch.search("Python",start=5,count=5)
>>> results = db.create(data=data)
>>> titles = [ row['title'] for row in results.rows ]
>>> titles
[u'<b>Python</b> (programming language) - Wikipedia, the free encyclopedia', u'<b>Python</b> for S60', u'PythOnline', u"<b>Python</b> | O'Reilly Media", u'<b>Python</b> for S60']
