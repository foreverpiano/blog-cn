如何筛选收件箱中的旧邮件

2025-05-03 · 阅读原文

每隔几年，我都会花些时间来整理个人收件箱里的混乱。邮件实在太多了，这通常导致我越来越难以跟进重要的邮件。

到目前为止，我的策略主要是过滤掉那些我永远不想读的邮件。但还有另一类邮件：我希望在它们新鲜出炉时阅读，却不想在过期后再看到。比如日历提醒、某些邮件列表、一些新闻通讯等。

我决定想办法建立一个系统，能将一些邮件标记为“收到三天后过滤”。这是一个不错的折中方案，因为我确实想看到这些内容，但又不想事后还要记得去手动归档。

你可以在 GMail 中写出这样的搜索查询：

from:(calendar-notification@google.com) older_than:3d

然而，如果你试图用这个查询创建 GMail 过滤器，它会把 older_than:3d 变成一个固定的时间点，而不是按照你期望的方式动态处理。

看起来在 GMail 自身功能内无法解决这个问题。不过快速搜索后发现，可以通过编写 Google App Script 来实现，于是我让 Claude 为我生成了这个脚本。

按照说明，我打开了多年未访问的 script.google.com。我对 Claude 生成的脚本进行了修改：将标签改为“TempMsg”，取消了归档操作的注释，并限制只处理前 50 条匹配该标签的邮件。完整代码可以在这篇 gist 中找到。

我尝试直接运行脚本，结果提示需要授予权限。这需要在 Google Scripts 的界面中点击三次确认。

此外还需批准一条有些吓人的提示，确认我信任自己。

之后我再次运行脚本，却因为收件箱中不存在 TempMsg 标签而失败。

于是我创建了这个标签，并设置了一些过滤器，让特定发件人的邮件自动加上这个标签。

之后我再运行脚本就一切正常了。需要说明的是，我一度以为它出错了，因为它不会处理过去三天内的邮件。这其实正是它应有的行为，但我运行后看到标签还在，就会误以为失败。真是乌龙。

确认脚本正常工作后，我又添加了一个定期触发器让它自动运行。

现在这个脚本每天都会运行，为我提供了一个更好地管理邮件的新工具。验证无误后，我还用标签管理器把这个标签“隐藏”在收件箱中，这样就不用到处看到 TempMsg 了。如果以后需要调试，我随时可以重新让它显示出来。
