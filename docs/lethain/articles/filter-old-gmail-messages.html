如何过滤收件箱中的旧邮件

2025-05-03 · 阅读原文

每隔几年，我都会花时间整理个人收件箱里混乱的邮件。邮件实在太多，导致我越来越容易忽略重要邮件的跟进。

到目前为止，我的策略主要是过滤掉那些永远不想读的邮件。但还有另一类邮件，我通常在它们新鲜时想读，一旦过时就不再想看了。比如日历提醒、某些邮件列表、新闻通讯等。

我决定想办法建立一个系统，能将一批邮件标记为“收到三天后过滤”。这是一个不错的折中方案，因为我确实想看到这些内容，但又不想每次都记住事后去归档。

你可以在 GMail 中写出这样的搜索查询：

from:(calendar-notification@google.com) older_than:3d

然而，如果你尝试用这个查询在 GMail 中创建过滤器，它会把 older_than:3d 变成一个固定的时间点，而不是按照你期望的方式动态过滤。

看起来这个问题在 GMail 自身功能里无法解决。不过快速搜索后发现，可以通过编写 Google App Script 来实现，于是我请 Claude 为我生成了这个脚本。

按照说明，我打开了多年未用的 script.google.com。我对 Claude 生成的脚本进行了修改：把标签改成“TempMsg”，取消归档操作的注释，并限制只处理前五十条匹配该标签的邮件。完整代码可以在这个 gist 中找到。

我尝试直接运行，结果提示需要授予权限。这需要在 Google Scripts 界面点击三次确认。

这还需要批准一条有点吓人的提示，表明我信任自己。

之后我再次尝试运行脚本，却失败了，因为我的收件箱里不存在 TempMsg 这个标签。

于是我创建了这个标签，并设置了一些过滤器，让特定发件人的邮件自动加上这个标签。

之后我就能顺利运行脚本了。它确实有效。不过我一度以为它出错了，因为它不会处理过去三天内的邮件——这正是它应该有的行为。可我运行后看到标签还在，就以为失败了。真是乌龙。

确认脚本正常工作后，我又添加了一个定时触发器让它定期运行。

现在这个脚本每天都会自动运行，为我管理邮件提供了一个很好的新工具。验证完成后，我还用标签管理器把“TempMsg”这个标签“隐藏”在收件箱里，这样就不会到处看到它。如果以后需要调试，我随时可以重新显示出来。
