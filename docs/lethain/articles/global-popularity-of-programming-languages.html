编程语言的全球流行度

2008-08-14 · 阅读原文

受 Andrew Chen 一篇关于使用 Google Insights 分析若干 Web 应用采用情况的文章启发，我也整理了一份类似的对比，聚焦于编程语言的全球流行度。我选择的语言（按字母顺序排列）包括：Common Lisp、Erlang、Groovy、Haskell、Java、Objective C、OCaml、Perl、Python、Ruby、Scala 和 Scheme。我通过 Google Insights 执行搜索，并使用编程筛选器进行了限制。

一些结束思考

最终，这些图表并没有提供多少宏观层面的洞见。Ruby 在日本最受欢迎，这点我并不意外（不过它在白俄罗斯也几乎同样受欢迎则有些出乎意料），俄罗斯在榜单上占据突出位置也并不令人惊讶。相反，这些图表或许只是为我们已有的认知提供了一些佐证。你是否认为大量 Java 编程工作被外包到了印度？看起来确实如此，因为印度对 Java 的搜索密度最高（而在 Java 前十搜索国家中，很多都是人均收入较低的国家）。

但它也揭示了一些有趣的小细节。你是否想过印度对 Objective C 的搜索密度也是最高的？或者牙买加对 Haskell 的搜索密度是美国的五倍？又或者美国在这些语言中最高的排名仅为第 5 位，而且还是在 Perl 上？

你在这些图表中看到什么特别有趣的地方吗？
