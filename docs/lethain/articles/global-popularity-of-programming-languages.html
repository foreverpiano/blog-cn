编程语言的全球流行度

2008-08-14 · 阅读原文

受 Andrew Chen 一篇关于使用 Google Insights 分析某些 Web 应用采用情况文章的启发，我决定做一份类似的对比，来看看编程语言在全球的流行程度。我选择的语言（按字母顺序排列）包括：Common Lisp、Erlang、Groovy、Haskell、Java、Objective C、OCaml、Perl、Python、Ruby、Scala 和 Scheme。我使用 Google Insights 进行搜索，并通过编程过滤器进行了限制。

一些结束思考

最终，这些图表并没有提供太多宏观层面的洞见。Ruby 在日本最受欢迎（尽管它在白俄罗斯也几乎同样受欢迎这一点出乎意料），我并不感到惊讶；俄罗斯在其中占据如此强势的位置，我也并不意外。相反，这些图表或许只是为我们已有的认知提供了一些佐证。你是否认为大量的 Java 编程工作被外包到了印度？嗯，这看起来很有可能，因为印度在 Java 的搜索密度上排名最高（而在 Java 前十搜索国家中，很多都是人均收入较低的国家）。

但它也揭示了一些有趣的小细节。你是否会想到印度在 Objective C 的搜索密度上也最高？或者牙买加对 Haskell 的搜索密度是美国的五倍？又或者美国在所有语言中排名最高也仅是第五位，而且还是在 Perl 这门语言上？

你在这些图表里看到了什么特别有趣的东西吗？
