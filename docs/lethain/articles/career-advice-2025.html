2025年的职业建议

2025-03-15 · 阅读原文

昨天，tj-actions 这个被广泛用于 GitHub Actions 的热门仓库遭到入侵（想了解更多背景，可以阅读其中一篇相关文章）。看到 Carta 的基础设施和安全工程团队的应对过程，让我深刻意识到 LLM 目前还远远无法实质性取代软件专业人士的许多核心角色。然而，我也在读 Jennifer Palkha 的《Recoding America》，书中提出了一个重要观点：决策者可以非理性地坚持比你能维持偿付能力（或者在当下语境中，维持就业）更久的时间。

最近我一直在思考这个问题，因为我越来越多地与之前共事过的同事进行“2025 年不太好玩”主题的职业讨论，他们正在艰难地应对当前就业市场。我试着把那些对话中的观点整理如下：

很多在 2010-2020 年期间首次进入高级职位的人发现，现在的角色远没有以前那么有趣。原因有几个。首先，那个时期对管理者的评价主要基于他们招聘、留住和激励团队的能力。而当前市场对这些技能的重视程度并不高，反而更看重另一组技能：深入细节工作、推动节奏，以及驾驭向基础模型 / LLM 的技术转型。这意味着目前这一批高级领导者要么在他们现在需要成功的关键技能上表现较差，要么对这些活动本身的动力不足。无论哪种情况，他们都没那么享受工作了。同样地，那些在 2010-2020 时代擅长深入细节、推动节奏等的潜在高级领导者，则被视为职业发展停滞，因此仍然很难晋升到高级职位。这让很多人感觉自己被当前市场甩在了身后。当然，这并非普遍现象，而是一种很多人都正在经历的普遍感受。还有很多人并没有这种体验。 向基础模型 / LLM 作为核心产品和开发工具的技术转型，正在让许多高级领导者辛苦积累的 playbook 失效。许多过去稳定、耐久的市场领导者如今处境 precarious，因为基础模型正在威胁削弱他们的竞争优势。他们的优势是否真的被削弱仍不确定，但很明显，要有效地将基础模型融入产品，远不是简单地在某个地方塞入一个 OpenAI 或 Anthropic 的 API 调用那么简单。 相反，你必须学会如何进行渐进式验证的设计，在关键工作流中使用数据前，通过 human-in-the-loop 技术对关键数据进行验证。这也要求你针对快速改进的工具包进行设计：2023 年还荒唐不堪的很多工作流，用最新的 reasoning models 已经能运行得惊人地好。有效的产品设计需要在为 2026-2027 年的模型既能实现巨大进步、也能完全没有进步这两种情况同时做好架构。 这对编写软件本身也同样适用。现在关于如何写软件的讨论非常嘈杂，其中很大一部分明显是宣传——这篇博客开头的 tj-actions 仓库事件就证明了专业能力仍然不可或缺——但也并非全是空谈。我在今年一月花了 ，让我惊讶的是，即使 Cursor 还远非完美，我的工作流已经发生了很大变化。从那以后，Claude 已经从 3.5 进步到带 extended thinking 的 3.7。同样，2027 年的初始应用开发可能彻底不同，也可能在复杂代码库的脚手架阶段之后基本保持不变。（我还很好奇上下文窗口的限制是否会再次推动大家逃离单体架构。） 当我们正在重新学习如何开发软件时，选择置身于这场转型之外，感觉是一项高风险的决定。你在团队建设上的娴熟技能相对于三年前已经贬值，而现在你的其他技能也面临贬值的风险。 相对于三年前，非 AI 公司的估值和融资可及性明显降低。当然，顶尖公司无论是否有明确的 AI 角度都还过得去，但保持顶尖的门槛已经提高了。与此同时，公开市场面临挑战，这意味着个人和公司购买产品的意愿降低，导致收入增长放缓，进一步挑战估值和融资。 如果你身处一家私有的非 AI 公司，其结果很可能是招聘更少、晋升更少、薪酬带变动更小，通往流动性的路径也更不可预测。这也意味着其他公司的开放职位变少，当你试图跳槽到更大、薪酬更高的公司时，竞争会更加激烈。 这个趋势的一个主要例外是加入 AI 公司，但这些公司通常处于极度竞争的市场，对投资人来说（他们管理的是投资组合）定价更合理，对希望获得可预测回报的员工来说则不然。如果你现在加入其中一家，你可能已经错过了获得巨大回报的最佳时机，你的股权可能归零，而且未来五到七年你要极度努力工作。这是经典的创业合同，但并不一定是你过去十年所期待的那种——过去十年，最高补偿通常来自加入后期公司或 Magnificent Seven 的成员。 随着公司对估值和融资减少做出反应，它们正在更用力地推动现有团队用现有人员寻找增长。在合适的环境中，这可能具有激励作用，但很多人当初选择的是更放松的工作体验，现在却在未经同意的情况下变得明显不那么放松了。我们自己的智能体及其专属工具

如果把所有这些放在一起，你基本上处在一个 四十年职业生涯 的市场中，必须自己想清楚，你个人想如何在人际、声望和学习之间进行优化。而几年前，我认为这些变量之间的关联要松散得多，但现在我从人们那里听到的并非如此——即使他们的工作在几年前还相当安逸。

再深入一点，我认识一些工作能力很强、却已经苦苦寻找有意义的机会长达六个月以上的人。我也认识一些特别优秀的候选人，他们能找到还不错的工作，但即使是他们也发现，自己真正想要的那类职位现在几乎不存在。我还认识一些很强的候选人，但简历里有一些“异样”（比如太多短期经历），现在他们正在被过滤掉，因为招聘经理需要一些方法来筛选数量比以往更多的候选人。

我无法告诉你你应该做什么，但如果你觉得这个就业市场很难，那绝对不是你个人的问题。我的感觉是，现在几乎每个人在寻找新职位时都在经历类似的情况。如果你目前所处的角色让你感到沮丧，我的建议是比平时更加努力地去尝试，让这段经历变得有回报，即使它并不完美。我个人也不会建议你试图“坐等这一轮过去”，除非你能接受重新进入市场可能相当困难的小概率风险：我认为更有可能的是，五年后的生态系统会发生实质性改变，而不是基本保持不变。

总的来说，这些并不是大家来找我聊天时希望听到的建议，但作为对当前市场的现实评估，似乎普遍引起了他们的共鸣。希望这里面也有一些内容对你有所帮助。
