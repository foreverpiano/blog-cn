Processed Tower Defense 1.0

2008-06-09 · 阅读原文

经过三周的努力，我很高兴地宣布 ptdef.com 正式上线，同时推出 Processed Tower Defense V1.0。在这个网站上，我们将维护一个稳定且持续更新的 PTD 版本，同时还开设了一个简单的论坛，供大家讨论任何与 PTD 相关的话题（包括 bug 报告、功能请求，或者单纯的炫耀）。

对于许久没玩过这款游戏的朋友，它已经在多个重要方面做出了改变。游戏未来还会继续进化，但大部分改动都会放在后续版本中，1.0 版本只会进行 bug 修复，不会再添加新内容。（不用担心，我们会在 ptdef.com 上保留所有重要版本的可玩副本，即使 1.0 版被取代，你依然能随时回到最符合你口味的那个版本。）

寻路系统。Peter Burns 以他众多贡献中的第一个重量级更新开启了合作——他实现了极其优秀的寻路代码，单凭这一点就将 PTD 从“能玩”直接提升到了“值得玩”。现在你可以使用炮塔建造复杂的迷宫，让敌人必须先穿过迷宫才能进攻你的城堡。地形系统。地形的加入为 PTD 增添了新的战术深度。不同地块会对炮塔和敌人产生不同影响，你的防御成败很大程度上取决于如何利用地形的各种特性。（游戏内帮助文档中有更详细的地形说明。）敌人种类。之前已经有四种基础敌人：普通、快速、强壮和 Boss。但我们再也不用忍受单调乏味了——现在每一波敌人都不仅有类型（普通/快速/强壮/Boss），还会随机获得一项特性。可用的特性包括：亲水（在水上移动速度加快）、厌水（在水上移动速度变慢）、亲山（在山地移动速度加快）、厌山（在山地移动速度变慢）、免疫（无视地形加成）、飞行（可以直接飞越炮塔）。炮塔更新。现在共有四种炮塔，每种都有各自的定位来歼灭敌人。加农炮塔通过溅射伤害大范围清除敌人（不过与其他武器不同，加农炮弹不会追踪目标，远距离时精度稍差）。激光炮塔是建造迷宫的廉价基础构件（升级成本低，有时也非常实用）。导弹炮塔能造成惊人的伤害，但射速较慢。加特林炮塔伤害高且射速快，但每次射击后需要较长的换弹时间。完全帧率独立。游戏现在实现了彻底的帧率独立，包括所有敌人移动、武器移动、射击速率以及其他游戏逻辑。这使得游戏在不同平台上都能保持一致的体验，即使它们的 JavaScript 引擎性能差异极大（原版虽然部分实现了帧率独立，但在 Safari 上明显比其他浏览器快很多，现在已经不会了）。快捷键。Peter 坚持不懈地优化快捷键系统，他的努力成果令人愉悦。现在游戏基本可以只用键盘操作，鼠标主要用于瞄准。当然，如果你喜欢，也可以继续使用按钮。压缩后的 JavaScript。通过部署脚本的改进，现在可以轻松将 PTD 所有必要代码打包成一个压缩后的单一 JavaScript 文件（之前文件越来越大，作为单个文件维护已经不太方便）。目前运行 PTD 的全部代码（包含 JQuery 和 Processing.js）最终压缩后只有相当精简的 116K。

未来计划

正如我在前面多次提到的，PTD 目前仍在进行日常开发。接下来有三个值得期待的版本即将推出：

1.1 版本预计在本周内发布，将包含一些视觉上的小幅改进，以及一个重要功能：提交分数和在线高分榜。1.5 版本将包含 2.0 版本的核心玩法，但不包含 2.0 其他根本性的系统变革。2.0 版本将会带来更有方向性的玩法，包括炮塔升级路线、可预测的敌人波次、难度等级、声音支持，以及更多内容（之所以说得比较模糊，是因为具体细节目前还有点模糊 ;-）。

总之，目前我们就先分享这些。希望大家都能喜欢 Processed Tower Defense v1.0。
