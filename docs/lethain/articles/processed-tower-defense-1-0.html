Processed Tower Defense 1.0

2008-06-09 · 阅读原文

经过三周的努力，我很高兴地宣布 ptdef.com 正式上线，同时推出 Processed Tower Defense V1.0。在这个网站上，我们将维护一个稳定且持续更新的 PTD 版本，同时还开设了一个简单的论坛，供大家讨论任何与 PTD 相关的话题（包括bug报告、功能建议，或者单纯的炫耀）。

对于那些许久没玩过这款游戏的朋友来说，它已经在多个重要方面做出了改变。游戏未来还会继续进化，但大部分改动都会出现在后续版本中，1.0 版本除了修复bug之外将不再进行调整。（不用担心，我们计划在 ptdef.com 上保留所有重要版本的可玩存档，所以即使 1.0 被取代，你依然能玩到最符合自己口味的那个版本。）

寻路系统。Peter Burns 以其众多贡献中的第一项——出色寻路代码的实现——一举将 PTD 从“能玩”提升到了“值得玩”。现在你可以用防御塔建造复杂的迷宫，迫使敌军在攻陷你的城堡前不得不艰难穿行。地形系统。地形的加入为 PTD 增添了新的战术考量。不同地块会对塔和敌人产生不同影响，你的防御成败在很大程度上取决于如何利用地形的各种特性。（游戏内的帮助文件对地形有更详细的说明。）敌军类型。之前已经有四种敌军：普通、快速、强壮和Boss。但我们再也不用忍受这种单调了：现在每一波敌军除了有类型（普通/快速/强壮/Boss）之外，还会随机获得一项特性。可用的特性包括：亲水（在水上移动更快）、厌水（在水上移动更慢）、亲山（在山地移动更快）、厌山（在山地移动更慢）、免疫（无视地形加成）和飞行（可以直接从塔上方飞过）。防御塔更新。现在共有四种防御塔，每种都有其独特的歼敌作用。加农炮塔通过溅射伤害大面积消灭敌军（不过与其他武器不同，加农炮弹不会追踪目标，远距离时命中率稍低）。激光塔是建造迷宫的廉价基础模块（升级费用也很低，有时会非常有用）。导弹塔能造成极高的伤害，但射速很慢。加特林塔伤害高且射速快，但每次射击后有较长的装弹暂停时间。完全的帧率独立性。游戏现在已实现完全的帧率无关，包括所有敌军移动、武器移动、射击速率和其他游戏逻辑。这使得游戏在不同平台上的表现保持一致，即使它们的 JavaScript 引擎性能差异巨大（原版尽管部分实现了帧率独立，但在 Safari 上仍比大多数浏览器快得多，现在这种情况已经不存在了）。快捷键。Peter 一直在不懈优化快捷键的使用体验，他的努力成果令人愉悦。现在游戏基本可以只用键盘游玩，鼠标主要用于瞄准。当然，如果你喜欢，仍然可以使用按钮操作。压缩后的 JavaScript。由于部署脚本的改进，现在可以非常轻松地将 PTD 所有必要代码打包成一个压缩后的单一 JavaScript 文件（之前文件越来越大，作为单个文件维护已经有些吃力）。运行 PTD 的代码（包括 JQuery 和 Processing.js）最终压缩到了相当精简的 116K。

未来计划

正如我在前面几段反复提到的，PTD 仍在进行日常开发。接下来有三个值得期待的版本：

1.1 版本预计在本周内发布，将包含一些细微的视觉改进和一个重要功能：提交分数与高分榜。1.5 版本将包含 2.0 版本的核心玩法，但不包含 2.0 的其他基础性改动。2.0 版本将拥有更明确的目标玩法，包括防御塔升级路径、可预测的敌军波次、难度等级、音效支持以及更多内容（之所以描述得比较模糊，是因为具体细节目前还不是特别确定 ;-）。

总之，目前我们就先分享这些。希望大家都能喜欢 Processed Tower Defense v1.0。
