Processed Tower Defense 1.0

2008-06-09 · 阅读原文

经过三周的努力，我很高兴地宣布 ptdef.com 正式上线，同时推出 Processed Tower Defense V1.0。在这个网站上，我们将维护一个稳定且持续更新的 PTD 版本，同时还开设了一个简单的论坛，供大家讨论任何与 PTD 相关的话题（包括 bug 报告、功能请求，或者单纯的炫耀）。

对于许久没玩过这款游戏的朋友，它已经在多个重要方面做出了改变。游戏未来还会继续进化，但大部分改动都会放在后续版本中，1.0 版本只会进行 bug 修复，不会再添加新内容。（不用担心，我们会在 ptdef.com 上保留所有重要版本的可玩副本，即使 1.0 版被取代，你依然能随时回到最符合你口味的那个版本。）

  1. Pathfinding. Peter Burns began his numerous contributions with the implementation of some excellent pathfinding code that singlehandedly catapults PTD from playable to worth playing. You can now use towers to build complex mazes that the creeps must navigate before pillaging your castle.
  2. Terrain. The addition of terrain has added a new layer of tactical consideration to PTD. Different squares affect towers and terrains differently, and the success of your defense rests heavily upon utilizing terrain's various characteristics. (A more helpful description of terrain can be found in the in-game help files.)
  3. Creep Varities. For a while now there have been four types of creeps: normal, quick, strong and boss. But, no longer must we suffer such boredom: each wave of creep now has a type (normal/quick/strong/boss) and also a randomly assigned trait as well. The available traits are water-loving (move quickly on water), water-hating (move slowly on water), mountain-loving (move quickly on mountains), mountain-hating (move slowly on mountains), immune (ignores terrain bonuses), and flying (can move over towers).
  4. Tower Updates. There are now four types of towers, each with their own role in annihilating creeps. Cannon towers lay waste to swathes of creeps with their splash damage (however, unlike other weapons, cannon balls don't home on targets, making them a bit inaccurate at long ranges). Laser towers are cheap building blocks for your mazes (but are cheap to upgrade, and can be quite helpful at times). Missile towers deal absurd quantities of damage, but fire slowly. Gattling towers deal heavy damage and fire quickly, but have long pauses to reload.
  5. Complete Framerate Independence. The game is now completely framerate independent, including all creep movement, weapon movement, firing rates and other game logic. This makes the game play consistently across platforms, even if their javascript engines vary dramatically in effectiveness (the original version, despite partial framerate independence, played much faster on Safari than most other browsers, but no longer).
  6. Hotkeys. Peter has been relentless in making the hotkeys work well, and the results of his efforts are joyful indeed. The game is largely playable from the keyboard now, with the mouse used primary for aiming. Of course, you still can use the buttons if you prefer.
  7. Minified JavaScript. Thanks to some work on a deployment script, it is now easy as pie to create a single minified JavaScript file containing all the necessary code for PTD (it was getting a bit too big to work on it as one file). The code running PTD (including JQuery and Processing.js) boils down to a fairly svelte 116K.

未来计划

正如我在前面多次提到的，PTD 目前仍在进行日常开发。接下来有三个值得期待的版本即将推出：

  1. Version 1.1, which is expected sometime this week, will include some minor visual improvements and one important feature: score submission and a high score list.
  2. Version 1.5 will feature the core gameplay of Version 2.0 without the other fundamental changes that V2.0 will include.
  3. Version 2.0 will have more directed gameplay, with tower upgrade paths, predictable creep waves, difficulty levels, support for sound, and much more (vague because its a bit vague exactly what will happen ;-).

总之，目前我们就先分享这些。希望大家都能喜欢 Processed Tower Defense v1.0。
