Cocos2d iPhone 开发笔记

2008-10-03 · 阅读原文

最近我一直在使用 Cocos2d iPhone 库来开发 iPhone 游戏，这是一个非常棒的开发库。虽然网上可参考的源码并不是很多，所以我整理了一些代码片段和使用心得。

Cocos2d iPhone 概述

Cocos2d iPhone 是 Ricardo Quesada 将 Cocos2d 库移植到 Objective-C 的版本。原始版本是一个 Python 库，非常出色。ObjC 版本无法在 REPL 中运行，所以没那么极致地惊艳，但它仍然是解决 iPhone 游戏开发难题的良药。

在开发我的第一个游戏 Processed Tower Defense 时，我在这个项目中学到了大量知识。我重写了几次，采用了更好的设计，到后期我感觉自己终于开始打开游戏编程知识中那些神奇而稀有的领域之门。因此，当我开始在 iPhone 上开发游戏时，第一步就是将我整体的设计从 JavaScript 移植到 ObjC。虽然两者之间存在一些……不匹配的地方，但整体进展还算顺利。直到我们遇到了 OpenGL，那感觉就像远足时遇到一群臭鼬堵住了小径。你当然可以硬着头皮走过去，但……真的非得这样吗？

iPhone 上 OpenGL 的文档并不丰富，这开始严重阻碍开发进度。我想目前的文档对于已经熟练掌握 OpenGL 的人来说应该足够了——这或许就是他们的目标读者——但它让我完全不知所措，这成了一个大问题。幸运的是，聪明的 Luke Hatcher 建议我们把项目从我自己开发的临时框架迁移到 Cocos2d iPhone。果然，开箱即用，Cocos2d 已经把我辛苦积累的游戏知识（以及更多）巧妙地整合进了一个完整的框架中。

之后的故事就成了历史，尽管是一段没人知道也没人在意的历史。

片段 2：指挥 Director

你的应用程序委托需要承担一些职责，来通知 Director 一些特殊事件。具体来说，它需要知道什么时候开始、暂停、恢复和退出。

最简单的发送这四个通知的方式如下（代码应放在你的 app delegate 中）：

- (void) applicationDidFinishLaunching:(UIApplication*)application {
    // Game began...
    [[Director sharedDirector] setLandscape: YES]; // optional
    [[Director sharedDirector] setDisplayFPS:YES]; // optional
    Scene *menu = [MyCustomMenuClass node];
    [[Director sharedDirector] runScene:menu];
}
-(void) applicationWillResignActive:(UIApplication *)application {
// Incoming phone call…
[[Director sharedDirector] pause];
}
-(void) applicationDidBecomeActive:(UIApplication *)application {
// Phone call rejected…
[[Director sharedDirector] resume];
}
-(void) applicationWillTerminate: (UIApplication*) application {
// Application is ending…
[[Director sharedDirector] release];
}

片段 3：在 Cocos Node 上检测点击

这是一个相对复杂的话题，因为具体处理方式完全取决于你如何设计用户界面，但本质上有两种方法：

- (void)touchesBegan:(NSSet *)touches withEvent:(UIEvent *)event;
- (void)touchesMoved:(NSSet *)touches withEvent:(UIEvent *)event;
- (void)touchesEnded:(NSSet *)touches withEvent:(UIEvent *)event;
为所有需要响应点击的对象重写标准的 UIEvent touches 方法。为一个对象（通常是 Layer 的子类）重写标准的 UIEvent touches 方法，让它作为所包含所有对象的 UI 管理器。

第一种方法更简单，但灵活性较低（更难管理事件传递和其他自定义逻辑）。而第二种方法工作量更大，也不太适合放在代码片段这种格式中。

第一种方法的大致实现如下（在 CocosNode 子类的实现文件中）：

- (void)touchesBegan:(NSSet *)touches withEvent:(UIEvent *)event {
    UITouch *touch = [touches anyObject];
    CGPoint location = [touch locationInView: [touch view]];
    // do stuff
}
- (void)touchesMoved:(NSSet )touches withEvent:(UIEvent )event {
UITouch *touch = [touches anyObject];
CGPoint location = [touch locationInView: [touch view]];
// do stuff
}
- (void)touchesEnded:(NSSet )touches withEvent:(UIEvent )event {
UITouch *touch = [touches anyObject];
CGPoint location = [touch locationInView: [touch view]];
// do stuff
}
