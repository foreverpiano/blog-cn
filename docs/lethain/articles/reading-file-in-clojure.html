在 Clojure 中读取文件

2009-11-15 · 阅读原文

这个周末花了一些时间开始学习 Clojure（得益于《Setting Up Clojure for Mac OS X Leopard》这篇优秀的文章，它指导我搭建了开发环境），但在查找如何读取文件这个问题的简洁答案时，还是比预期多花了一些时间。因此，我想把关于这个主题的一些想法整理出来。

slurp

读取文件最简单的方法就是直接使用 slurp。

user> (slurp "tokenize.clj")
"(ns tokenize\n  (:import (java.io BufferedReader FileR....\n"

对于简单的脚本来说，这可能就足够了，但它存在几个问题：

它会将整个文件读入内存，因此不适合处理大文件；而且不会按行（或其他分隔符）拆分内容，而这通常是我们想要的结果。

java.io.BufferedReader

如果想要更具扩展性的流式处理方式，java.io.BufferedReader 是一个简单而高效的选择。

(ns tokenize
  (:import (java.io BufferedReader FileReader)))
(defn process-file [file-name]
(with-open [rdr (BufferedReader. (FileReader. file-name))]
(doseq [line (line-seq rdr)] (println line))))
(process-file "tokenize.clj")

BufferedReader 包装了 FileReader，为文件提供了一个惰性接口，而 line-seq 则让我们可以将这个流当作一个列表来处理，背后实际是通过调用 BufferedReader 的 readLine 方法实现的。

在上面代码的基础上，你可以写一个通用的函数来对文件中的每一行进行归约处理。

(ns tokenize
  (:import (java.io BufferedReader FileReader)))
(defn process-file [file-name line-func line-acc]
(with-open [rdr (BufferedReader. (FileReader. file-name))]
(reduce line-func line-acc (line-seq rdr))))
(defn process-line [acc line]
(+ acc 1))
(prn (process-file "tokenize.clj" process-line 0))

上面的代码片段只是统计了文件中的行数，但你可以修改 process-line 函数，让它也能从文件中提取 token。

(defn process-line [acc	line]
  (reduce #(assoc %1 %2	(+ (get	%1 %2 0) 1))	acc (.split line " ")))

运行这个脚本后，结果如下：

bash-3.2$ clj read1.clj
{"" 20, "rdr))))" 1, "*command-line-args*))))" 1, ...}

一般来说，对于大多数文件读取场景，BufferedReader 和 line-seq 已经足够了（BufferedReader 也是 Java 中读取大文件的推荐方式），但 Clojure 中总是有更多的方法可供选择。

clojure.contrib.duck-streams

如果你已经安装了 clojure.contrib，那么还有一种稍微更简洁的流式解析文件的方式：duck-streams。

把前面 BufferedReader 的例子改成使用 duck-streams，代码如下：

(ns tokenize
  (:use	[clojure.contrib.duck-streams :only (read-lines)]))
(defn process-file [file-name line-func line-acc]
(reduce line-func line-acc (read-lines file-name)))
(defn process-line [acc line]
(reduce #(assoc %1 %2 (+ (get %1 %2 0) 1)) acc (.split line " ")))
(prn (process-file "tokenize.clj" process-line (hash-map)))

代码更简洁了，但你通常会使用 duck-streams/read-lines，是因为你已经在使用 duck-streams 的其他功能（比如用于写文件的 spit，以及用于追加内容的 append-spit）。

在 Clojure 中读取文件还有很多其他方法，但上面这些应该足以帮助你入门。
