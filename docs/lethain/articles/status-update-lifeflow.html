LifeFlow 状态更新

2008-01-03 · 阅读原文

我已经对 LifeFlow 开发了一段时间，现在是时候和大家聊聊它目前的状况，以及未来的发展方向。

近期更新

支持为文章关联作者。每篇文章可以指定 0 个或多个作者，每个作者都拥有独立的个人传记页面。新增了评论订阅源。新增了动态首页（展示最新评论、最近四篇文章以及 Twitter 内容）。为所有标签添加了订阅源（例如 ‘django’、‘common lisp’、‘japan’ 等）。为所有文章系列添加了订阅源。如果你只想关注 Two-Faced Django 系列，那完全没问题。

目前的发展阶段如何？

目前 LifeFlow 已经是一个功能相当完备的博客解决方案，但还需要一些实用的文档：如何安装 LifeFlow？（它是一个 Django 应用，只需把它的 urls.py 引入你的项目即可）它依赖哪些库？（Pygments）需要做哪些设置工作？（至少创建一个 Author、一个 Flow，如果你想让项目页面正常工作，还需要至少创建一个 Project）它支持哪个版本的 Django？（任何相对较新的 SVN 检出版本。）

这些问题都需要得到解答。

另外两个主要缺陷是：

评论系统需要进行彻底的重构。默认模板已经严重过时，基本上需要从灾难中抢救出来。

看到曙光了吗？

不过请放心，朋友们，一切并非无可救药。下面是我当前的未来路线图。

重构评论模型，并将其集成到 LifeFlow 中。使用 BluePrint CSS 编写一套全新的默认模板。编写一批测试用例。撰写开发环境部署指南。撰写生产环境下的 LifeFlow 部署指南。

这是我目前的短期路线图。更长期的规划如下：

将项目迁移到 Google Code。发布一个能与 Django 1.0（或 2.0，取决于最终的命名）兼容的稳定快照。继续发布稳定的 LifeFlow 版本，使其与每个正式的 Django 版本保持同步。
