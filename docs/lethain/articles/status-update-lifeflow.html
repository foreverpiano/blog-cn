LifeFlow 状态更新

2008-01-03 · 阅读原文

我已经对 LifeFlow 埋头开发了一段时间，现在我觉得是时候来聊聊 LifeFlow 当前的状况，以及它未来的发展方向。

近期更新

  1. Support for attaching Authors to entries. 0+ authors can be assigned to each entry. Each author has their own biographical page.
  2. Added a feed for comments.
  3. Added a dynamic front page (display recent comment(s), four most recent posts, and content from twitter).
  4. Added feeds for all tags (so a feed for 'django', and for 'common lisp', and for 'japan').
  5. Added feeds for all article series. If you only want to know about the Two-Faced Django series, then thats fine with me.

这让我们处于什么位置？

目前 LifeFlow 已经是一个功能相当完善的博客解决方案，但它还需要一些有用的文档。如何安装 LifeFlow？（它是一个 Django 应用，只需将其 urls.py 引入到你的项目中即可）它依赖哪些库？（Pygments）需要做哪些设置工作？（至少创建一个 Author、至少创建一个 Flow，如果你希望项目页面能正常工作，还需要至少创建一个 Project）它能在什么版本的 Django 上运行？（任何相对较新的 SVN 检出版本。）

这些问题都需要得到解答。

另外两个主要缺陷是：

  1. The commenting system requires a serious reworking.
  2. The default templates are woefully out of date, and essentially need to be salvaged from catastrophy.

看到曙光了吗？

不过请放心，亲爱的朋友们，一切都还没有结束。以下是我当前的未来路线图。

  1. Rework commenting model, integrate new model into LifeFlow.
  2. Write a new batch of default templates using BluePrint for CSS.
  3. Write a battery of tests.
  4. Write a guide for setting up a development deployment.
  5. Write a guide for setting up LifeFlow in a production environment.

这是我目前的短期路线图。长期路线图如下：

  1. Push project out to Google Code.
  2. Release a stable snapshot that works with Django 1.0 (or 2.0, depending on what it ends up being titled).
  3. Continue packaging stable LifeFlow releases to coincide with each official Django release.
