LifeFlow 状态更新

2008-01-03 · 阅读原文

我已经对 LifeFlow 埋头开发了一段时间，现在我觉得是时候来聊聊 LifeFlow 当前的状况，以及它未来的发展方向。

近期更新

支持为文章关联作者。每篇文章可以分配 0 个或多个作者，每个作者都有自己的独立传记页面。新增了评论的 feed。新增了动态首页（显示最新评论、四篇最新文章以及 Twitter 内容）。为所有标签添加了 feed（例如 'django'、'common lisp' 和 'japan' 的独立 feed）。为所有文章系列添加了 feed。如果你只想关注 Two-Faced Django 系列，那完全没问题。

这让我们处于什么位置？

目前 LifeFlow 已经是一个功能相当完善的博客解决方案，但它还需要一些有用的文档。如何安装 LifeFlow？（它是一个 Django 应用，只需将其 urls.py 引入到你的项目中即可）它依赖哪些库？（Pygments）需要做哪些设置工作？（至少创建一个 Author、至少创建一个 Flow，如果你希望项目页面能正常工作，还需要至少创建一个 Project）它能在什么版本的 Django 上运行？（任何相对较新的 SVN 检出版本。）

这些问题都需要得到解答。

另外两个主要缺陷是：

评论系统需要进行一次彻底的重构。默认模板已经严重过时，基本上需要从灾难中抢救出来。

看到曙光了吗？

不过请放心，亲爱的朋友们，一切都还没有结束。以下是我当前的未来路线图。

重构评论模型，并将其集成到 LifeFlow 中。使用 BluePrint CSS 编写一套全新的默认模板。编写一批测试用例。编写开发环境部署指南。编写生产环境下的 LifeFlow 部署指南。

这是我目前的短期路线图。长期路线图如下：

将项目迁移到 Google Code。发布一个能与 Django 1.0（或 2.0，取决于最终的命名）兼容的稳定快照。继续打包稳定的 LifeFlow 版本，使其与每个官方 Django 版本保持同步发布。
