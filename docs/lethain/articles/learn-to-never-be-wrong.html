学会永远不犯错

2020-03-21 · 阅读原文

这是 staffeng.com 的一篇草稿指南

大多数人都遇到过那种自以为永远不会错的人。在每一次讨论中，他们都会身体前倾、肩膀张开，强势地把自己变成最终决策者。他们会一直辩论，直到自己的观点获胜，或者时间耗尽。他们往往是正确的，但这种正确会把房间里的氧气都吸走。随着他们在公司任职时间越来越长，他们可能会觉得自己已经变得非常有说服力，但实际上，这往往是一种让同事们无奈妥协的“说服”。

我合作过的一些技术领袖找到了既能永远不犯错、又不必主导整个房间的方法。他们能在坚持正确的同时，为他人创造空间。在我看来，一直完美体现这种方式的人是 Franklin Hu。我见过他多次在有争议的讨论中解除对立——他始终致力于找到对所有人最好的结果，愿意放弃自己最初的立场，并且默认总会存在额外的信息，能把看似冲突的观点统一成一个整体。

要成为一名高级技术领袖，你必须对技术和架构建立深刻认知。而要真正以这样的领袖身份开展工作，你还必须培养同样深刻的务实精神，以及对技术信仰的 agnosticism（不可知态度），从而始终保持对自己的怀疑。这听起来像是一个悖论，但却是你每天都需要行走的平衡线。

倾听、澄清、读懂房间

你会经常看到工程师带着“自己的观点是正确的”这种自信进入讨论，目标是让房间里的其他人同意自己的方案。这种心态把每一次会议都变成了一场零和辩论。即使在“最好的情况”下他们的方案被采纳，他们也没有从房间里的其他人那里学到任何东西，而且其他人离开时也不太可能感到振奋。

最有效率的工程师进入每一次会议时的目标是：就当前的问题达成共识，理解房间里每个人的需求和视角，并明确为了达成方案一致还需要做些什么。他们把每一次会议都视为整个项目以及与房间里这些人关系中的一环。如果房间里的人已经准备好同意并推进某个方案，他们就会带领团队落地该方案。如果房间里还没有准备好，他们不会强行推动。

要擅长这一点，你需要掌握三种方法：通过提问来倾听、明确会议目的，以及学会读懂房间。

通过提问来倾听是一种积极倾听的形式，目的是理解房间里其他人的观点。带着善意提出好问题，会打开一场对话，为其他人提问创造空间和安全感。好的问题源于学习的愿望，而且非常具体。它们能让对话变得更锐利，让回答者不用被迫为自己的立场辩护。在一场可能充满争议的会议中，在表达自己的观点之前先问三个好问题，你会发现房间里的氛围会随之改变。

好的会议从清晰的目的和议程开始，但很多会议并不符合这个标准，尤其是临时讨论。如果你发现自己正身处一场目标不清晰的对话，那就主动明确目的。花点时间问问大家，你对这个群体希望达成的目标的理解是否正确。这种澄清最好以陈述加提问的形式出现，比如：“我确认一下，我们这次的目标是决定是否把项目发布推迟两周，对吗？”

需要注意的是，如果过度使用“明确目的”这个方法，它可能会适得其反。非但不能澄清对话，反而会制造对话的反复。通常来说，如果已经有人尝试过，就尽量不要再用。同一个会议如果多次被重新定义目的，几乎总是以“再安排一次会议”告终。

最后，在每一次会议中你都要读懂房间。很多人常常因为对话不顺而感到沮丧，然后试图强行达成一致，这会给讨论制造过大的压力，导致难以善终。如果房间里的人意见相差太远，那就找出一个小群体，让他们有更多时间一起深入讨论，或者找一个合适的人在会后升级处理。如果抽屉里的东西实在太多，那就别再硬往里塞了。

如何练习

如果这些行为对你来说并不自然，没关系——练习的机会无处不在。每一条文档评论都是机会。每一次会议都是机会。每一个 Pull Request 都是机会。

每周开始时，选择其中一项技能，明确要在即将参加的会议中有意识地使用它。如果你即将面临一场特别难开的会，那就提前花时间在脑子里演练，或者和同事一起练习如何运用这些方法来推动进展，哪怕面对重重挑战。

刺头

上面这种方法在大多数情况下都很有效，但并非总是如此。一个重要的例外就是你在和“刺头”打交道的时候。这里说的刺头是指那些拒绝向团队让步、不愿意妥协、也不愿意倾听的人。这种人还没有意识到：自己的职业发展更多取决于是否容易共事，而不是技术上是否永远正确。

对付刺头最有效的两种方法是：

把一个他不敢耍刺头的人拉进会议（比如他的经理或 CTO），或者在会议前投入大量精力先和他对齐，让他觉得自己被听到，从而降低他扰乱讨论的可能性。

这两种方法可能都会让你觉得很荒谬，要花很多时间，但它们往往是最有效的，尤其是当你和这个刺头不经常打交道的时候。如果这个人属于你职责范围内的领域，或者是你经常合作的对象，那你的责任就会有所不同。在这种情况下，尽可能善意但诚实地给他反馈。给第二次。如果还是没有改进，就把你的顾虑连同具体记录一起面对面或通过视频告诉他的经理。

另外还要意识到，你的职位带来的权威会让你免受很多这种人的影响，所以你感受到的“刺头行为”其实比其他人感受到的要轻。如果这种行为在你看来已经接近界限，那么对其他人可能就更加过分了。

这样做的帮助

这种方法非常强大，因为越复杂的项目，越容易被人际冲突而不是技术复杂度所拖垮，而这是一种可以重复使用的方式，能把紧张关系转变为合作伙伴关系。它看起来可能很慢，因为开始阶段会花更长时间，但最终其实更快，因为你更有可能在没有干扰的情况下完成工作。

此外，作为一名资深领导者，长期成功不仅取决于耀眼的成绩，也同样取决于你能否维护好人际关系。你会看到很多人短暂地光芒四射，但后来却因为缺乏支持而难以推进工作。如果你不想陷入那种境地，那就学会永远不犯错，并且永远不要停止练习。
