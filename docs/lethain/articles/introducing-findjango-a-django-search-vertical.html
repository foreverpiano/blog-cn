Findjango：Django 专属垂直搜索

2009-03-09 · 阅读原文

自从第一次看到 Yahoo! BOSS，我就一直想做一个针对 Django 的垂直搜索。大多数稍具技术性的领域都有十几个 RSS 聚合器，但很少有足够的内容和用户兴趣来支撑一个垂直搜索，而能胜过通用搜索引擎的定向搜索就更少了。

我很高兴地宣布 Findjango 正式上线，这是一个专注于 Django 的垂直搜索引擎。

（如果网站看起来和上面的截图不一样，请尝试强制刷新。）

与其长篇大论地介绍它是什么，不如直接试试几个查询吧：

  1. Search for test.
  2. Search for yahoo.
  3. Search for expire cache.

内容来源

最新的来源列表在 Findjango 网站上随时可以查看。目前它主要利用五个来源获取搜索结果，同时还为 Django 官方文档构建了一个精简索引。

这五个来源分别是：

  1. Yahoo! BOSS web results, restricted to a handful of relevant sites.
  2. lethain.com results, limited to those containing the django tag.
  3. yashh.com results, again limited to the django tag.
  4. Tweets that contain the query term and the term django (the poor man's search vertical).
  5. Amazon book results that meet the query, contain the term django, and don't contain a handful of Jazz related terms.

这绝对只是内容来源的开始。即使你只有一个小型博客，只要能筛选出与 Django 相关的内容，我也非常愿意将其整合进来。只需提供一个可外部访问的搜索 API，最好是使用 Springsteen Service 格式，欢迎随时联系我讨论具体细节。

实现方式

Findjango 是基于 django-springsteen 构建的，而 Springsteen 承担了大部分繁重的工作。目前只有少数几个定制部分：

  1. Reporting irrelevant terms.
  2. A Django specific relevancy and ranking algorithm.
  3. Indexing and matching queries against the Django documentation.
  4. Custom service wrappers to access this blog as well as yashh.com.

未来计划

我为 Findjango 制定了几个相互关联的目标：

  1. The first is to serve in the flagship fleet for django-springsteen as an example of a highly targeted search experience (Springsteen Search being the example of a non-targeted search experience).
  2. The next--although not less important--goal is for Findjango to be a genuinely useful resource for the Django community. A big part of this will be adding more resources, but also continued work on relevancy and other tweaks.
  3. Finally, and perhaps most exciting, in the upcoming days I'll be opening Findjango as an externally accessible api, which will allow other sites in the community to directly query Findjango and display the results in their own pages.

我很期待听到你的反馈，以及任何能让 Findjango 变得更有价值的建议。感谢阅读。

额外分享一个消息：Josh Gourneau 开发了一个 MyCroft 插件，让 Findjango 可以直接从 Firefox 和 IE 的搜索框中使用。

  1. 我知道 djangosearch.com 的存在，但 findjango 和 djangosearch.com 试图做的是完全不同的事情。DS 是 RSS 聚合器、项目列表和 Google Custom Search 的混合体。而 findjango 的设计理念是充分利用现有的社区项目。例如，与其自己维护项目列表，findjango 正致力于与 djangoplugables.com 进行集成。虽然在技术层面还有更深层的差异，但我认为这是两者之间最重要的区别。↩
