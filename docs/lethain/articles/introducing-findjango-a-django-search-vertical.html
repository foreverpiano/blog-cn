Findjango：Django 专属垂直搜索

2009-03-09 · 阅读原文

自从第一次看到 Yahoo! BOSS，我就一直想做一个针对 Django 的垂直搜索。大多数稍具技术性的领域都有十几个 RSS 聚合器，但很少有足够的内容和用户兴趣来支撑一个垂直搜索，而能胜过通用搜索引擎的定向搜索就更少了。

我很高兴地宣布 Findjango 正式上线，这是一个专注于 Django 的垂直搜索引擎。

（如果网站看起来和上面的截图不一样，请尝试强制刷新。）

与其长篇大论地介绍它是什么，不如直接试试几个查询吧：

搜索 test。搜索 yahoo。搜索 expire cache。

内容来源

最新的来源列表在 Findjango 网站上随时可以查看。目前它主要利用五个来源获取搜索结果，同时还为 Django 官方文档构建了一个精简索引。

这五个来源分别是：

Yahoo! BOSS 的网页搜索结果，仅限于少数几个相关网站。lethain.com 的结果，仅包含带有 django 标签的内容。yashh.com 的结果，同样仅限于带有 django 标签的内容。包含查询词和 “django” 两个词的推文（穷人版的垂直搜索）。符合查询条件、包含 “django” 且不包含 Jazz 相关词汇的 Amazon 图书结果。

这绝对只是内容来源的开始。即使你只有一个小型博客，只要能筛选出与 Django 相关的内容，我也非常愿意将其整合进来。只需提供一个可外部访问的搜索 API，最好是使用 Springsteen Service 格式，欢迎随时联系我讨论具体细节。

实现方式

Findjango 是基于 django-springsteen 构建的，而 Springsteen 承担了大部分繁重的工作。目前只有少数几个定制部分：

报告不相关词条。针对 Django 的相关性判断和排序算法。对 Django 文档进行索引并匹配查询。为访问本博客和 yashh.com 开发的定制服务封装。

未来计划

我为 Findjango 制定了几个相互关联的目标：

首先是作为 django-springsteen 的旗舰项目，展示一个高度定向的搜索体验（而 Springsteen Search 则是非定向搜索的示例）。其次（同样非常重要）是让 Findjango 真正成为 Django 社区的有用资源。这需要不断增加更多资源，同时持续改进相关性算法和其他优化。最后，或许也是最令人兴奋的，在未来几天内我将把 Findjango 开放为外部可访问的 API，让社区中的其他网站可以直接查询 Findjango 并在自己的页面中展示结果。

我很期待听到你的反馈，以及任何能让 Findjango 变得更有价值的建议。感谢阅读。

额外分享一个消息：Josh Gourneau 开发了一个 MyCroft 插件，让 Findjango 可以直接从 Firefox 和 IE 的搜索框中使用。

我知道 djangosearch.com 的存在，但 findjango 和 djangosearch.com 试图做的是完全不同的事情。DS 是 RSS 聚合器、项目列表和 Google Custom Search 的混合体。而 findjango 的设计理念是充分利用现有的社区项目。例如，与其自己维护项目列表，findjango 正致力于与 djangoplugables.com 进行集成。虽然在技术层面还有更深层的差异，但我认为这是两者之间最重要的区别。↩
