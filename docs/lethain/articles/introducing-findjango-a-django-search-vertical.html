Findjango：Django 垂直搜索

2009-03-09 · 阅读原文

自从第一次看到 Yahoo! BOSS，我就一直想做一个针对 Django 的垂直搜索引擎。任何稍具技术性的主题通常都有十几个 RSS 聚合站点，但真正拥有足够内容和关注度来支撑垂直搜索的却很少，而能够提供比主流搜索引擎巨头表现更好的定向搜索的就更少了。

我很高兴地宣布 Findjango 正式上线，这是一个专注于 Django 的垂直搜索引擎。

（如果站点看起来和上面的截图不一样，请尝试强制刷新。）

与其长篇大论地介绍它是什么，不如直接试试以下查询：

搜索 test。搜索 yahoo。搜索 expire cache。

内容来源

最新的来源列表始终可以在 Findjango 网站上查看。目前它主要利用五个来源来获取搜索结果，并同时构建了一个轻量级的 Django 文档索引。

这五个来源分别是：

Yahoo! BOSS 的网页搜索结果，限制在少数几个相关站点内。lethain.com 的结果，仅包含带有 django 标签的内容。yashh.com 的结果，同样限制为带有 django 标签的内容。包含查询词和“django”两个词的推文（穷人版的垂直搜索）。符合查询条件、包含“django”一词且不包含若干与 Jazz 相关词汇的 Amazon 图书结果。

这绝对只是内容来源的开始。即使你只有一个小型博客，只要能够过滤出与 Django 相关的内容，我也非常愿意将你的内容整合进来。你只需要提供一个可外部访问的搜索 API，最好是使用 Springsteen Service 的格式，当然也可以直接联系我，我们一起讨论具体细节。

实现方式

Findjango 是基于 django-springsteen 构建的，Springsteen 承担了大部分繁重的工作。目前只有少数几个定制部分：

报告不相关术语。针对 Django 的相关性和排序算法。对 Django 文档进行索引并匹配查询。定制的服务封装器，用于访问本博客以及 yashh.com。

未来规划

我为 Findjango 制定了几个相互关联的目标：

首先是让它成为 django-springsteen 的旗舰项目，作为高度定向搜索体验的范例（而 Springsteen Search 则是非定向搜索体验的示例）。其次（同样非常重要）是让 Findjango 真正成为 Django 社区的有用资源。这其中很大一部分工作是增加更多资源，同时持续改进相关性算法和其他细节。最后，也是最令人兴奋的一点，在未来几天内我将把 Findjango 开放为可外部访问的 API，这将允许社区中的其他网站直接查询 Findjango 并在自己的页面中展示结果。

我很期待听到你的反馈，以及任何能让 Findjango 变得更有用的建议。感谢阅读。

另外还有个惊喜：Josh Gourneau 开发了一个 MyCroft 插件，让 Findjango 可以直接在 Firefox 和 IE 的搜索框中使用。
