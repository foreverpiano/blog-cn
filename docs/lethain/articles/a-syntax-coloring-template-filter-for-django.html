一个用于 Django 的语法高亮模板过滤器

2008-08-09 · 阅读原文

今晚我花了些时间为 Django 编写了一个模板过滤器，它可以在模板内部非常简单地实现语法高亮。你可以调用 Pygments 的任意 lexer，或者让 Pygments 自行检测合适的 lexer。下面是一个快速示例：

这可能不是特别实用，但我认为它很好地展示了，一个简单的模板过滤器就能完成相当令人印象深刻的功能。继续阅读以了解安装细节，或者你可以在这里下载 syntax_colorize 应用。

安装与使用

安装 Pygments 库。最简单的方式是通过 easy_install：sudo easy_install pygments 下载 syntax_colorize 应用。你可以在这里获取它。将 syntax_colorize 应用放到你的 Python 路径中。在 OS X 10.5 上，操作大致如下：ln -s /Users/will/libraries/syntax_colorize /Library/Python/python2.5/site-packages/syntax_colorize 将其添加到 INSTALLED_APPS 设置中。INSTALLED_APPS = ( 'django.contrib.sites', 'syntax_colorize', 'etc etc', ) 为 Pygments 创建 CSS 文件。我在 syntax_colorize/templatetags/syntax_color.py 文件中写了一个简单的辅助函数，所以进入该目录并启动 Python：cd syntax_colorize/templatetags/ python 然后在解释器中运行以下命令：>>> import syntax_color >>> syntax_color.generate_pygments_css() 接着将生成的 pygments.css 文件复制到你的媒体目录中。 更新你的基础模板的 head 标签，引入 pygments.css 文件。大致如下：<head> <link rel="stylesheet" href="/media/pygments.css" type="text/css"> </head> 创建一个简单的视图，向模板传递一段代码。我用来测试的简单示例如下：from django.shortcuts import render_to_response def index(request): code = """def index(request): from django.shortcuts import render_to_response code = "(define x 10)" return render_to_response('index.html',{'code':code}) """ return render_to_response('index.html',{'code':code}) 在实际使用中，你可能需要从数据库中获取代码，或者如果你使用 Google App Engine，则可能从 BigTable 获取。 现在，在你想要使用语法高亮的 Django 模板中进行操作。记住上下文变量 code 是一个包含 Python 代码的字符串。使用 Python lexer 对 code 内容进行高亮的效果如下：{% load syntax_color %} <p> 来看看这段代码： </p> {{ code|colorize:"python" }} <p> 哦，或许你想把它放在表格里？ </p> {{ code|colorize_table:"python" }} 使用 colorize_table 过滤器会将高亮后的代码片段放在带行号的表格中，但其他方面与 colorize 过滤器完全相同。
