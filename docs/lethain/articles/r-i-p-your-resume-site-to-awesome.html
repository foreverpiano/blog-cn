让你的简历网站起死回生，变得超赞

2008-10-18 · 阅读原文

我早就想重新设计 willarson.com 了，很大程度上是因为它沿用了以前博客的设计，而那个设计并不讨所有人喜欢。这个网站的初衷是提供一份简洁随和的简历，但它在这件事上做得相当糟糕。也许有人读过它，但人们读完后并不会想“哇，我想雇他来做我的项目。”（至于他们到底在想什么，还是不知道为好。我猜里面肯定有“色盲”这个词。）

为了解决这个痛点，我开发了 Resume Interactivity Provider，简称 RIP。

从基本层面来说，RIP 和传统简历使用的是相同的信息：姓名、自我陈述、联系方式、相关技能和经历。然而，RIP 借助 AYM CMS 和 jQuery 来展现技能与经历之间的关联，从而让你的经历和技能看起来不再那么像完全站不住脚的吹牛。

不过，它真正有趣的地方其实只有两点：

  1. Only displays the description of one experience at a time.
  2. Highlight the relevant skills used for the experience that is currently displayed.

你可以在 willarson.com 上看到它的实际效果，但最酷的是，你自己也能非常轻松地做一个。

NAME = u"Your name"
NAME_URL = u"http://example.com/"
EMAIL = u"your_name@gmail.com"
PHONE = u"(555) 555-5555"
TWITTER = u"YourTwitterUsername"
STREET = u"999 Somewhere Rd."
CITY = "SomeCity"
ZIP = "99999"
STATE = "AA"
COUNTRY = "BBB"
STATEMENT = """
Write your statement of purpose here.
You may use Markdown syntax. Woohoo.
"""
SKILLS = (
    'Python',
    'Django',
    'Etc',
    'Etc1',
)

EXPERIENCES = (
    {
        "title":"A title",
        "link":"http://link-for-experience.com/",
        "start":"July, 2005",
        "end":"Present",     # optional
        "skills":("Python","Etc",),
        "description":"It was cool. Can include raw html.",
    },
    # add as many more experiences as you want
)

python build.py

scp -r deploy/* myuser@myserver.com:~/mysite.com/
  1. Go grab the source code from its repository on Github. (You can download a zip from there, even if you don't use Git.)
  2. Install a version of Django less than a year old. (A prequisite for AYM CMS.)
  3. In the unzipped/cloned repository, open up the resume.py file.
  4. Fill in some simple customization fields.
  5. Create your list of experiences.Note that the skills value for each experience should contain strings found in the SKILLS tuple above. If they don't match, then the cool highlighting trick won't occur.
  6. Build the project.
  7. Deploy the project to your server.

当然，你也可以（也非常鼓励你）修改 static/rip.css 来调整颜色等样式。我本来想自私地在底部加一个指向自己博客的链接，但发现不加反而好看得多，所以你就免了。不过如果你真的用了它，我还是很想知道的。
