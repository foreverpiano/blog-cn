愿你的简历网站安息，迎来新生

2008-10-18 · 阅读原文

我早就想重新设计 willarson.com 了，很大一部分原因在于它的设计沿用了以前的博客风格，而那个风格并非人见人爱。这个网站的核心使命是提供一份简洁随性的简历，但它之前做得相当糟糕。或许有人读过，但没有人读完后会想：“天哪，我要聘请他来做我的项目。”（至于他们当时到底在想什么，还是不知道为好。我猜大概会用到“色盲”这个词。）

为了解决这个痛点，我开发了 Resume Interactivity Provider，简称 RIP。

从基础层面看，RIP 和传统简历使用的是相同的信息：姓名、目标陈述、联系方式、相关技能和经历。但 RIP 借助 AYM CMS 和 jQuery 来展现技能与经历之间的关联，从而让你的经历和技能看起来不再像是完全站不住脚的吹牛。

不过，它真正有趣的地方其实只有两点：

同一时间只显示一条经历的描述。 突出显示当前显示的经历所用到的相关技能。

你可以在 willarson.com 上看到它的实际效果，但最酷的是，你自己做一个也非常简单。

从它的 Github 仓库获取源代码。（即使你不用 Git，也可以从那里下载 zip 压缩包。） 安装一个一年内版本的 Django。（这是运行 AYM CMS 的前提。） 在解压或克隆后的仓库中，打开 resume.py 文件。 填写一些简单的自定义字段： NAME = u"你的姓名" NAME_URL = u"http://example.com/" EMAIL = u"your_name@gmail.com" PHONE = u"(555) 555-5555" TWITTER = u"YourTwitterUsername" STREET = u"999 Somewhere Rd." CITY = "SomeCity" ZIP = "99999" STATE = "AA" COUNTRY = "BBB" STATEMENT = """ 在这里写下你的目标陈述。 可以使用 Markdown 语法。耶！ """ SKILLS = ( 'Python', 'Django', 'Etc', 'Etc1', ) 创建你的经历列表： EXPERIENCES = ( { "title":"职位标题", "link":"http://link-for-experience.com/", "start":"July, 2005", "end":"Present", # 可选 "skills":("Python","Etc",), "description":"工作内容很酷。可以包含原生 HTML。", }, # 可以继续添加任意多条经历 ) 注意：每条经历的 skills 值必须是上面 SKILLS 元组中出现的字符串。如果不匹配，那项酷炫的高亮功能就不会生效。 构建项目： python build.py 将项目部署到你的服务器： scp -r deploy/* myuser@myserver.com:~/mysite.com/

当然，你也可以（也非常鼓励你）修改 static/rip.css 来更换颜色等样式。我本来自私地想在底部加一个指向自己博客的链接，但发现不加反而好看得多，所以你就免了。不过如果你真的用上了，我还是很想知道的。
