使用 Sparklines.js 在 JavaScript 中绘制迷你图

2008-06-26 · 阅读原文

本周早些时候，我花了两天时间研究迷你图（sparklines）的想法，最终做了一个 JavaScript 库，可以在 canvas 元素中生成迷你图。最近因为一直在用 Processing.js 来处理可视化，我就用它来完成了这个项目。

功能特性

网站上提供了大约十几种不同的示例，展示了如何组合和配置各种迷你图，下面我简单介绍一下。

支持创建柱状或折线迷你图；可以清晰标记百分位数（其中 0.25 为 Q1，0.5 为中位数等，你也可以选择标记任意百分位数）；可以清晰标记任意特定值（例如在 70 和 80 处画线，以突出考试中得 C 的学生人数）；可以在两条线之间填充背景，进一步强调它们之间的范围；可以配置边缘留白、所有颜色、柱状图中柱子间的间距等；设计为支持任意数据类型，你只需编写一个函数来提取对应的数值高度；能够自适应所在 canvas 的高度和宽度：无论你缩小还是放大，它都会尽量将数据展示好。

（抱歉下面的示例实际上是 canvas 的截图 jpg，而不是真实的 canvas 元素，你可以在项目页面看到实际效果。我的博客配置最近刚产生了一些改进想法，还不太适合直接嵌入原始代码。）
