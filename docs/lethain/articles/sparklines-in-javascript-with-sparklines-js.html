使用 Sparklines.js 在 JavaScript 中绘制迷你图

2008-06-26 · 阅读原文

本周早些时候，我花了两天时间研究迷你图（sparklines）的想法，最终制作了一个 JavaScript 库，用于在 canvas 元素中生成迷你图。由于最近一直在使用 Processing.js，我就用它来处理可视化部分。

功能特性

网站上提供了十几个不同示例，展示了如何组合和配置各种迷你图，下面我简单介绍一下。

支持创建柱状或折线迷你图。能够清晰标示百分位数（其中 0.25 为 Q1，0.5 为中位数等，你也可以选择显示任意百分位数）。能够清晰标示任意特定数值（例如在 70 和 80 处画线，以突出考试中获得 C 的学生人数）。可以在两条线之间填充背景，进一步强调它们之间的范围。可以配置边缘留白、所有颜色、柱状图中柱子间距等参数。设计为支持任意数据类型，你只需编写一个函数来从中提取高度值。能够自适应所在 canvas 的高度和宽度：无论缩小还是放大，它都会尽量将数据展示好。

（抱歉下面的示例是 canvas 的截图保存为 jpg，而不是真实的 canvas 元素，你可以在项目页面看到真实效果。我的博客配置最近刚想到几个改进点，目前还不太适合直接嵌入原始代码。）

柱状迷你图示例

这是我最喜欢的柱状迷你图之一。

var data3 =[120,130,80,100,90,105,95,60,70,75,
            70,90,100,110,120,130,150,100,50,
            80,90,100,110,110];
var opts = {'percentage_lines':[0.25,0.75],"fill_between_percentage_lines":true,
            'padding_between_bars':2,"left_padding":30,"right_padding":30,
            'marking_padding':16};
new Sparkline('bar4', data3).draw();

折线迷你图示例

这是一个折线迷你图，在绝对值 90 和 110 之间填充了区域，同时标出了 25% 和 75% 百分位数的位置。

var data3 = [120,130,80,100,90,105,95,60,70,75,
             70,90,100,110,120,130,150,100,50,
             80,90,100,110,110];
var opts ={"value_lines":[90,110],"top_padding":5,
           "bottom_padding":0,"fill_between_value_lines":true,
           "percentage_lines":[0.25,0.75],"percentage_color":"#FF6666"
};
new Sparkline('simple10', data3, opts).draw();
