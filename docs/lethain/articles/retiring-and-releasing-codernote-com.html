退休并开源 Codernote.com

2010-02-20 · 阅读原文

大约一年半以前，我曾希望创建一个可以创建和分享笔记、代码片段与想法的网站。 除了这个博客——它是一个糟糕且难以维护的烂摊子——Codernote 可能是我做过的最有野心的 Django 项目。它集成了 OpenID，大量使用 jQuery，支持客户端排序、多种皮肤，维护笔记的历史版本等等。它也是我最用心的一次设计尝试，虽然我自己觉得成果一般。

当时的构想很简单：用户创建片段或笔记，然后用 Pygments、Markdown、Textile 或 ReStructured Text 进行渲染。随后用户可以为自己的笔记添加标签，并通过排序和筛选来形成一种思维导图。用户之间可以互相分享笔记（通过邀请机制），还可以将笔记发布到半私有的哈希 URL 上，或者发布到带有 RSS 订阅的公共页面。

我依然非常喜欢这个想法，但必须承认过去一年里我完全没有花时间维护它，而且无疑会继续将其搁置到遥远的将来。因此我决定将代码开源。我会把网站再保留几周，然后最终下线。

代码已经放到 GitHub 上，欢迎大家以任何方式使用它。在开发这个项目的过程中，我吸取了不少宝贵的教训，而在那之后我又学到了更多东西。希望在未来的项目中，我能将这些经验全部运用进去，做出更好的作品。谢谢倾听 :)
