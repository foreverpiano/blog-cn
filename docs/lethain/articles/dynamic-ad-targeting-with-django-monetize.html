使用 django-monetize 实现动态广告定向

2008-08-29 · 阅读原文

这可能是我做过的最令人兴奋的 Django 项目，我很高兴它已经达到足够可用的阶段，可以和大家分享。我很荣幸地向大家介绍 django-monetize。

django-monetize 是一个可插拔的 Django 应用，旨在让智能化地变现你的 Django 项目变得极为简单。它基于两个核心原则设计：

变现的形式多种多样，通常混合搭配的方式会优于单一的变现方案（例如，将捐赠、Amazon 联盟计划和 AdSense 巧妙结合，其效果会好于仅使用 AdSense）。在不同变现形式和组合之间切换并进行实验，是成功的关键。你可以通过有效地针对读者中的不同细分群体，大幅提升变现效果。如果能够向来自搜索引擎的用户（可能 AdSense 表现更好）或 Reddit 的用户（也许……搞怪 T 恤会更受欢迎？）展示不同的广告，使用不同浏览器（等等，我在向 Internet Explorer 用户推广我的 macOS 应用？），以及在查看不同类型内容时（深度教程的读者比阅读你吐槽甘草软糖的人更有可能捐赠），你的变现将会更加有效。

支持的变现形式

目前，django-monetize 内置支持 Amazon Affiliates 的 Custom Links、Omakase、Search Links，Amazon Honor System 捐赠、Dreamhost 推荐、Google Adsense 广告单元、Paypal 捐赠以及 SliceHost 推荐。

添加你自己的变现方式或对现有方式进行定制以更适合你的网站非常简单（也非常鼓励这么做）。创建自定义广告也很容易（比如你写的一本电子书、链接到你整理的热门博客文章，或者推广你的新创公司）。

安装

像安装其他 Django 应用一样安装 django_monetize。从它的代码仓库签出代码，将 django_monetize 目录添加到你的 Python site-packages 文件夹中，这样：

import django_monetize

就不会报错了。

然后只需在 settings.py 文件的 INSTALLED_APPS 设置中添加 django_monetize 即可完成。django_monetize 不包含任何模型（也不会以任何方式使用数据库），因此无需执行 syncdb。

使用 django-monetize

django-monetize 的真正魅力在于它所允许的自定义和控制程度。首先我们来看看在模板层面的用法。我们从最简单的例子开始，随着对灵活性的探索逐渐增加复杂度。

{% load monetize %}
{% monetize_slot %}
<p> Welcome to my site! </p>
{% monetize_slot %}

这将显示两个广告位，都使用默认的变现选项（我们会在看完模板配置后，再讨论如何设置定向和默认逻辑）。

{% load monetize %}
{% monetize_slot "header" %}
<p> Welcome to my site! </p>
{% monetize_slot "footer" %}

现在我们给广告位添加了标签。我们可以使用标签在不同位置显示不同类型的变现选项。这是定向最简单的概念。

{% load monetize %}
{% monetize_slot "header" request.META.HTTP_REFERER %}
<p> Welcome to my site! </p>
{% monetize_slot "footer" request.META.HTTP_USER_AGENT %}

现在我们不仅给广告位添加了标签，还分别传入了 referer 和 user agent。django-monetize 会根据我们的定向配置进行检查，看当前 referer 或 user_agent 是否是我们指定了定向的目标，如果存在对应的定向广告就会使用它，否则回退到默认广告。

{% load monetize %}
{% monetize_slot "header" object.title object.series object.tags %}
<p> Welcome to my site! </p>
{% monetize_slot "footer" %}

在顶部广告位这里，我们开始看到定向机制的灵活性。它会首先检查对象标题（title）是否有对应的定向值，然后检查对象 series 列表中的任意值是否有定向，最后检查对象 tags 列表中的任意值是否有定向。

它会在第一个匹配的定向值处停止，并不会继续处理后续参数。

最后请注意，一旦你找到了定向的关键词，你还可以为不同名称的广告位指定该定向所使用的变现类型。因此，即使使用像下面这样非常简单的定向（对于大部分静态内容可能已经足够），你也可以在不同命名的广告位中展示不同的广告：

{% load monetize %}
{% monetize_slot "header" "django" %}
<p> Welcome to my site! </p>
{% monetize_slot "footer" "django" %}

相当灵活，对吧？

monetize_slot 模板标签的有效参数

我们在上面的例子中以各种不同方式使用了 monetize_slot，现在有必要澄清它可以接受的参数。

不传参数调用时，它会使用默认的变现选项。传入一个参数时，该参数必须是广告位的名称。在这种情况下，它会使用该广告位对应的默认变现选项的定向值——如果存在这样的定向的话——否则会回退到使用默认选项。传入两个或更多参数时，第一个参数必须是表示广告位名称的字符串。后续参数可以是：字符串（可以是上下文变量中存储的字符串，也可以是在模板中直接声明的绝对字符串，如 {% monetize_slot "header" "django" %}）、字典（其值会通过 iteritems() 处理），或可迭代对象（定义为非字典、非字符串且具有 __iter__ 方法的对象）。 如果遇到不属于上述类型的对象（例如，处理你的标签 queryset 中的内容时），它会通过调用 unicode(obj) 将对象转换为字符串。这意味着你可以通过其 __unicode__ 方法返回的字符串来针对特定对象进行定向。

配置

首先，django-monetize 对 None 和 False 做了重要的区分。None 表示“使用默认变现方式”，而 False 表示“不使用任何变现方式”。虽然我们知道这是一个随意且可能让人困惑的决定，但目前看来它是一个合理的解决方案。

广告定向的配置在项目的 settings.py 文件中完成。有一个至少在某些方面相似的 Django 项目 django-ads，它将配置存储在数据库中。虽然这允许更动态的修改，但 django-ads 并没有像 django-monetize 这样深入解决广告定向和自定义的问题，而且我没有找到一种将配置合理存储在数据库中的方式（除了存储 Python 代码字符串然后再求值，这在我看来远非可接受的方案）。

在 settings.py 中使用了三个值：MONETIZE_TARGET、MONETIZE_DEFAULT 和 MONETIZE_CONFIG。我们从一个复杂的例子开始，然后逐步分解。

MONETIZE_DEFAULT = (
    'django_monetize/amazon_search.html',
    ('amazon_search_terms','Django book'),
    ('amazon_search_title','Search for Django books!')
)
MONETIZE_TARGET = {
'django':'django_monetize/paypal_donate.html',
'Author (Will Larson)':'django_monetize/amazon_honor.html',
'Author (Joe Somebody)':(
'django_monetize/amazon_honor.html',
('amazon_paypage','Joe Somebodys Amazon Honor Paypage url'),
),
'tutorial':{
'header':'django_monetize/paypal_donate.html',
'footer':'django_monetize/amazon_omakase.html',
None:(
'django_monetize/amazon_search.html',
('amazon_search_terms','JQuery'),
('amazon_search_title','Buy books on JQuery!'),
),
},
}
MONETIZE_CONTEXT = {
'amazon_affiliates_id':'your affiliates tracking id',
'amazon_paypage':'default amazon paypages url',
'paypal_business':'paypal accounts email address',
'paypal_item_name':'My website',
'paypal_currency_code':'USD',
'paypal_tax':'0',
'paypal_lc':'US',
'paypal_bn':'PP-DonationsBF',
'paypal_image':'http://www.paypal.com/en_US/i/btn/btn_donate_LG.gif',
}

好的。首先需要明白，变现选项有三种可能的表现形式：

可以是一个字符串，表示模板的名称。在这种情况下，模板将使用 MONETIZE_CONTEXT 中的上下文进行渲染。可以是一个元组或列表，第一个值是模板名称，其余值是 (key, value) 形式的元组/列表，用于在渲染该变现选项时覆盖 MONETIZE_CONTEXT 中的默认值。可以是一个字典，其键是广告位（header、footer 或你命名的任何名称），值则是上述形式 #1 或 #2。此外还有一个特殊值 None，用于在没有为所有广告位定义值时指定其默认值。

接下来，MONETIZE_DEFAULT 用于设置默认变现选项，它是上述三种形式之一（字符串、带字符串和覆盖的列表、带广告位名称且每个广告位对应字符串或带字符串和覆盖列表的字典）。

最后，MONETIZE_TARGET 是一个定向关键词到对应变现形式的字典，每个定向目标同样采用上述三种形式之一。
