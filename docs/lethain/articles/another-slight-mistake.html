又一个小失误……

2007-12-27 · 阅读原文

周三晚上，我为 LifeFlow（本博客所使用的 Django 博客软件）增加了一些作者相关的功能，允许每篇文章关联 0 个或多个作者。

这次更新进行得很顺利，包括迁移到新的数据库 schema。但没想到在一个看似不起眼的操作上却遇到了麻烦。我在 Django shell 中运行了以下命令：

from lifeflow.models import Author, Entry
a = Author.objects.get(pk=1)
for entry in Entry.objects.all():
    entry.authors.add(a)
    entry.save()

问题出在我目前处理 Entry 模型中手动设置 many2many 字段的方式上（先创建对象，然后在 post_save hook 中修改它，最后再保存一次，并加入一些代码来防止无限循环）。

不知道为什么，这次渲染完全正常，唯独代码片段全部显示成一堆乱七八糟的数据字符串。幸好我后来手动逐一重新保存了这些文章，一切又恢复正常了。

还不清楚到底哪里出了问题，但反正那块代码我也需要好好重构改进一下，应该很快就能解决。

抱歉了。
