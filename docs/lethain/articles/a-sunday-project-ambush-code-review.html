周日项目：Ambush Code Review

2008-06-16 · 阅读原文

这个周末我终于好好研究了一下 Google App Engine——之前好几个月都只是偶尔瞟一眼（至少我觉得有那么久了）。最后我选择了一个既有趣又实用的经典项目：语法高亮工具。这个项目叫做 Ambush Code Review，它的目标与大多数语法高亮应用略有不同。

我希望将 Ambush Code Review 打磨成一个便捷的代码片段分享工具，用户可以轻松发布代码，然后提交评论和改进。当然，它距离理想状态还有一段距离，但基础功能已经实现。在查看某个代码片段时，你可以在同一页面内发布一个回应片段，它会作为独立片段显示（附带指向被回应片段的链接），同时也会完整展现在被评论的那个页面上。

我还在纠结是否要为条目实现专门的评论功能。目前我鼓励用户以非代码形式留言时，直接选择一个友好的高亮器，然后用正确的语法写下评论。比如你可以用 Python 注释的方式这样写：

# Wow... this snippet is wack.
# Did Will try programming in Python again?
# That boy needs to stop

不过，这可能并不是特别友好的评论实现方式。以后再说，以后再说吧。

技术选型

我打算不久后写一篇更深入的关于 Google App Engine 开发的文章，所以这里只简单提一下我用到的组件。

  1. Django from SVN: The differences between 0.96 and the current trunk are simply too many to remember easily. Since its easy enough to use trunk, I decided to use it.
  2. Pygments: The best and simplest of the Python syntax highlighting libraries. I already use in my blog software with Django, so it was a natural choice.
  3. GAE Django Helper: I used the Django helper library, although I didn't actually make use of much of it. More discussion on this in the full write up.
  4. A dash of handwritten xhtml and css (the front page validates correctly, haven't really checked elsewhere ;).
  5. The Google App Engine version of the Django Form library.

快速总结

写 Google App Engine 应用非常有趣，而且和普通的 Django 开发足够相似，一个周日下午就足以完成切换。它也是迄今为止最简单的部署流程（好吧好吧，PHP 和静态页面还是更简单，算了）。去试试看吧，我想你会喜欢它的。
