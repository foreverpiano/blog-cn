周日项目：Ambush Code Review

2008-06-16 · 阅读原文

这个周日，我终于开始接触 Google App Engine——之前好几个月都只是在旁边观察（至少我觉得有那么久了）。最后我选择了一个既有趣又有用的常规项目：语法高亮工具。这个项目叫做 Ambush Code Review，它的定位与大多数语法高亮应用略有不同。

我希望将 Ambush Code Review 打磨成一个便捷的代码片段发布工具，并能轻松提交评论和改进建议。当然，它离理想状态还有一段距离，但基础功能已经实现。在查看代码片段时，你可以在同一个页面内发布一个回复片段，它会作为一个独立片段显示（附带指向被回复片段的链接），同时也会完整展现在被评论的那个片段页面上。

我还在纠结是否要为条目实现显式的评论功能。目前的做法是鼓励用户通过选择一个友好的高亮器，然后用正确的语法来留下非代码评论。比如你可能会留下这样的 Python 注释：

所用技术

最近我准备写一篇更深入的关于 Google App Engine 开发的文章，所以这里就简单提一下我用到的组件。

从 SVN 获取的 Django：0.96 版本与当前主干的差异实在太多，不容易记住。既然使用主干也很方便，我就决定直接用它。Pygments：Python 中最好、最简洁的语法高亮库。我已经在自己的 Django 博客系统中使用它，所以是自然的选择。GAE Django Helper：我使用了这个 Django 辅助库，虽然实际没用到太多功能。更详细的讨论会放在完整文章里。少量手写的 XHTML 和 CSS（首页通过了验证，其他页面就还没仔细检查；）。Google App Engine 版本的 Django Form 库。

快速总结

开发 Google App Engine 应用非常有趣，而且和普通的 Django 开发足够相似，一个周日下午就足以完成切换。它也是迄今为止最简单的部署流程（好吧好吧，PHP 和静态页面还是更简单一点）。去试试看吧，我想你会喜欢它的。
