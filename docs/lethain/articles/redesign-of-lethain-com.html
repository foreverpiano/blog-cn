Lethain.com 网站 redesign

2008-09-21 · 阅读原文

我早就想给博客换个新面貌了，于是这个周日我干脆把其他事情都放到一边，专心做了这次 redesign。我觉得这件事很重要，理由有很多。

通常情况下，我的博客是潜在雇主第一次接触到我的地方，我明显感觉到旧版设计已经有点杂乱，开始有些力不从心（我负责写，它负责呈现，我们是团队）。佐治亚字体也用得不够）。至少有六七个人向我抱怨过旧博客的配色问题。在我看来，这意味着几乎所有访问过旧博客的人都对颜色有意见，只是其中只有六七个人愿意开口说出来。他们可能说得没错（但我什么都不承认）。一年多以前我第一次为 lethain.com 设计网站时，认真使用 HTML 和 CSS 可能才三个月左右。几个月后我第一次 redesign，当时对效果还挺满意。和最初版本比起来，它显得干净利落、颇具水准。又过了一段时间，各种问题开始显现，我觉得是时候给它来一次彻底的 overhaul 了。这个博客的核心就是呈现文字内容，我觉得之前的设计并没有很好地契合这个理念。本质上我希望内容区域能有更多空间，在页面上舒展一些。特别是大尺寸图片和大块代码，比之前的设计需要更大的展示空间。我早期在旧设计中搞砸了图片尺寸问题，最后只能用 CSS 把所有图片都缩放到合适大小。这么做当时很有诱惑力，因为它解决了我的麻烦，但也严重限制了我用不同有趣的方式运用图片的可能。现在很多老图片看起来相当奇怪，不过以后我会有更多灵活性。之前的侧边栏没有很好地向访客展示相关内容。而现在顶部的新栏则会以更容易被注意到的方式，展示一小部分高度相关的内容。顶部栏始终保持三列布局，其中第三列永远是 meta 栏目，但前两列的内容可以有所不同（我打算以后慢慢尝试各种组合）。如果文章属于某个系列，它会展示该系列的所有文章（包括系列名称和 RSS 订阅链接）。如果文章带有标签，则会从其中一两个标签中随机挑选五篇文章，填满剩余位置。如果文章的标签或系列不足以填满，它就会用最近文章或随机文章来补足。目前，非文章页面始终展示随机和最近文章，但我打算再多想想之后再做一些调整。或许可以展示热门标签、热门文章，或者其他我还没想到的内容。在完成 django-monetize 项目后，我在 lethain.com 上加了几个广告位，但上一个设计对广告排版并不友好。特别是系列文章框会完全打乱文章顶部的广告位置，导致很难形成任何一致的呈现效果。这个新版格式在这方面打开了很多可能性，所以我很期待继续多做些尝试。我投放广告的主要目的是推广自己的软件和产品（比如这个），而不是简单地塞满 Adsense。

LifeFlow 里仍然有不少容易优化的地方。归档页面已经改进了很多，但还是有些粗糙。项目页面……真的非常粗糙。文章列表页面也很粗糙……

你懂我的意思。不过经过这轮改动，我对博客最核心的部分——文章列表页和详情页——已经相当满意了。

虽然现在这个博客在我眼里已经很棒了，但我敢肯定一两个月后我又会挑出各种毛病，然后继续打磨下去。在此之前，我非常欢迎大家对新设计或 LifeFlow 整体提出任何批评和建议，看看还能如何改进。
