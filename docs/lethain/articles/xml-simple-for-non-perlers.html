XML::Simple 非 Perl 高手指南

2008-11-07 · 阅读原文

最近我一直在使用 Perl 处理 XML，老实说——这也是为什么 Perl 没有出现在我简历上的原因。不过，在上手 XML::Simple 之后，我对用 Perl 写出来的代码以及整个 Perl 工作流都非常满意（遇到问题，从 CPAN 下载解决方案，写点胶水代码，重复这个过程）。因此，我写了这篇针对非 Perl 高手的 XML::Simple 使用教程。

第一步是从 CPAN 安装 XML::Simple。

稍作感慨：为什么 Ruby Gems 和 CPAN 用起来都比 easy_install（Python 的方案）舒服得多？我觉得 Perl 和 Ruby 是仅有的两个真正喜欢自己模块仓库系统的社区，而且这两个系统非常相似，但我不太确定它们与 easy_install 到底有什么特别的不同。

是因为 easy_install 出现得比较晚吗？（我甚至不确定这个说法是否正确，但感觉 Python 社区从来没有完全接受它，或者接受得相当勉强。）我觉得即使是 Common Lisp 社区在统一到 ASDF:INSTALL 上也比 Python 更成功，而 Common Lisp 在标准化几乎任何事情上都困难重重（没有标准实现带来的必然结果）。

难道就因为那个 :: 吗？如果我们把 easy_install 写成 import datetime::datetime，大家会不会就喜欢它了？也许这都只是我个人的想法。

到目前为止，我在 Perl 学习之旅中唯一的抱怨是，很少有教程能很好地解释引用解引用的语法，也许是因为它确实足够复杂，值得单独写几篇教程。遗憾的是 Perl 没有 Python 和 Ruby 对年轻程序员那么大的吸引力，但它其实是个很有趣的工具。（虽然我也不打算用它来写超出简单脚本和服务之外的东西。）
