XML::Simple 非 Perl 高手指南

2008-11-07 · 阅读原文

最近我一直在同时使用 Perl 和 XML——这么说吧——这就是为什么我的简历上没有写 Perl。不过，在上手 XML::Simple 之后，我对用 Perl 写出来的代码以及整个 Perl 工作流程都非常满意（遇到问题，从 CPAN 下载解决方案，粘合一下，继续下一个问题）。因此我写了这篇针对非 Perl 老手的使用 XML::Simple 教程。

第一步是从 CPAN 安装 XML::Simple。

perl -MCPAN -e shell
install XML::Simple
exit

好，先说点题外话：为什么 Ruby Gems 和 CPAN 用起来都比 easy_install（Python 的方案）舒服得多？我觉得 Perl 和 Ruby 是仅有的两个真正喜欢自己模块仓库系统的社区，而且这两个系统极其相似，但我不太确定它们和 easy_install 具体有什么不同。

难道就因为 easy_install 出现得比较晚？（我甚至不确定时间线是否如此，但社区确实感觉从来没有完全接受它，或者接受得有些勉强。）我觉得连 Common Lisp 社区在统一到 ASDF:INSTALL 上都比 Python 成功得多，而 Common Lisp 在标准化任何事情上都困难重重（没有标准实现带来的必然结果）。

难道只是因为那个 :: 符号？如果我们写成 import datetime::datetime，大家会不会就喜欢 easy_install 了？也许这都只是我自己的臆想。

XML::Simple 的主要作用是以非常简单的 API 把 XML 转换成 Perl 数据结构，同时也能把 Perl 数据结构转换成 XML。使用 XML::Simple 最难的部分，是要对向量（vector）和哈希（hash）数据结构的引用解引用（dereferencing）有一定的理解。

现在我们来从磁盘加载一个 XML 文件。

use XML::Simple;
use Data::Dumper;
my $xml = new XML::Simple;
my $in = $xml->XMLin('my_file.xml');
print Dumper($in);

现在我们创建一个数据结构并保存到磁盘。

use XML::Simple;
my $xml = new XML::Simple;
my $out = {
   'an-attribute' => 'an attribute value',
   'another-attribute' => 'yada yada',
   'types' => ["a","b","c"],
   'people' => [{'name'=>'will','content'=>'etc'},]
};
my $dec = '<?xml version="1.0" encoding="utf-8"?>';
print $xml->XMLout($out, XMLDecl => $dec, RootName => 'random');

要生成你想要的输出，基本上只需要知道下面三条规则：

哈希中的标量会被当作属性。除非它的键是 content，这种情况下它就是元素的主要内容。列表中的标量和哈希会被表示为子元素。

虽然这样解释了，可能还是有点让人困惑。直接看上面脚本生成的 XML 输出会更容易理解：

<?xml version="1.0" encoding="utf-8"?>
<random an-attribute="an attribute value" another-attribute="yada yada">
  <people name="will">etc</people>
  <types>a</types>
  <types>b</types>
  <types>c</types>
</random>

最后一个例子，我们来抓取一个 RSS feed，提取其中的信息，然后以另一种格式保存到磁盘。我们将抓取这个博客的主 RSS feed，它被转换成 Perl 数据结构后（为了节省篇幅去掉了一些数据）大致是这样的：

$VAR1 = {
          'version' => '2.0',
          'channel' => {
                       'link' => 'http://lethain.com/',
                       'lastBuildDate' => 'Thu, 06 Nov 2008 10:48:35 -0600',
                       'language' => 'en-us',
                       'item' => [
                                 {
                                   'link' => 'http://lethain.com/entry/2008/nov/06/you-only-learn-the-first-time/',
                                   'guid' => 'http://lethain.com/entry/2008/nov/06/you-only-learn-the-first-time/',
                                   'title' => 'You Only Learn the First Time',
                                   'pubDate' => 'Thu, 06 Nov 2008 10:48:35 -0600',
                                   'description' => 'full article'
                                 }
                                 ]
                        }
         }

根据上面的结构，我们可以这样写脚本。

use LWP::Simple;
use XML::Simple;
use Data::Dumper;
my $xml = new XML::Simple;
my $uri = 'http://lethain.com/feeds/all/';
my $rss_xml = $xml->XMLin(get($uri));
my @articles = ();
foreach my $article (@{$rss_xml->{channel}->{item}}) {
my $a = {'title' => $article->{title},
'date' => $article->{pubDate},
'link' => $article->{link}};
push(@articles, $a);
}
my $out = $xml->XMLout({'article'=></span>@articles}, RootName => 'articles');
print $out;

</articles>

我自己还是个新手，也清楚我写的其实更像是“Perl 里的 Python”，但我依然觉得 Perl 在完成这些常规任务时极其简洁，而且 CPAN 能如此迅速地帮我们把几个库串起来，相当轻松地完成典型任务，这点非常了不起。

到目前为止，我学习 Perl 的过程中唯一的抱怨是，很少有教程能很好地解释引用解引用的语法，或许是因为它确实足够复杂，值得单独写几篇教程。遗憾的是 Perl 对年轻程序员来说不像 Python 和 Ruby 那么有吸引力，但它其实是个很有趣的工具。（虽然我也不打算用它来写超出简单脚本和服务之外的东西。）
