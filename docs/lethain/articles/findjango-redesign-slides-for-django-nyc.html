Findjango 重新设计及 django-nyc 演讲幻灯片

2009-03-25 · 阅读原文

两条简短消息。首先，Findjango 终于完成重新设计了！设计出自 Kevin Fricovsky（Monty Lounge Industries 的实体化身，同时也是 This Week in Django 的成员），我觉得非常棒。相比之前那个让搜索者倍感痛苦的旧版本，这无疑是一次巨大的改进。

（你可能需要强制刷新 CSS 文件。我这周晚些时候会配置 django-compress 来给 CSS 加上版本号，最近实在太忙了。）

第二条消息是我今晚将在 django-nyc 做一场关于 django-springsteen 的演讲。我是三场演讲的最后一位；前两场分别关于 django-sphinx 和 django-solr，所以今晚会是一场非常“搜索”主题浓厚的聚会。届时会有某种形式的在线直播，关注 @howiworkdaily 获取详细信息。理论上演讲将于美国东部时间 2009 年 3 月 25 日晚上 7:00 开始，但 7:10 或 7:15 开始的可能性更大。（直播可能在 http://www.ustream.tv/channel/django-nyc，但我不能完全确定。）
