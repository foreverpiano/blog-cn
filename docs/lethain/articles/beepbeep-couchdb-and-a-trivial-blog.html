BeepBeep、CouchDB 与一个简易博客

2009-07-09 · 阅读原文

Django 的核心概念之一是松耦合。Django 框架是一个工具齐全的工具箱，里面装满了能很好协作的优秀工具，但它并不会强迫你必须使用它最推荐的那些软件：如果你愿意，完全可以忽略现有工具，引入自己的。

将 BeepBeep 与 Django 比较，有人可能会说“微框架”其实是一种委婉的说法，意思是 BeepBeep 是一个空工具箱。BeepBeep 愿意充当你各个组件之间强大而灵活的胶水，但它坚定奉行“工具自备”（Bring-Your-Own-Tools）的理念。

在本教程中，我们将介绍一个值得与 BeepBeep 搭配使用的强大工具：CouchDB。

我们将使用 CouchDB 创建一个非常简单的博客。通过表单发送 HTTP POST 来创建博客文章，并提供简单的视图来列出所有文章和查看单篇文章。毫无疑问，这个博客功能非常简陋，但涉及的概念却不少，所以我们开始吧。

你可以在 GitHub 上的 BeepBeep Examples 仓库中查看完整的代码。
