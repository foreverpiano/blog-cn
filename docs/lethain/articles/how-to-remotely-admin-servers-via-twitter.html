如何通过 Twitter 远程管理服务器

2009-03-22 · 阅读原文

我一直有个反复出现的想法，就是能用手机远程控制自己的服务器。当然，我完全可以安装一个 SSH 应用，用常规方式来做，但我觉得通过 Twitter 给服务器发送私信会更有趣一些。

暂且不讨论这么做的实际价值，下面就快速介绍一下如何通过 Twitter 远程控制你的服务器。

安装

安装过程依赖于 Python-Twitter 库和一个极简的 python-twitter-remote 库。

设置与配置

第一步是创建一个文件夹，用于存放远程控制的相关配置。

users 是被允许执行某条命令的用户列表，pattern 是私信必须匹配的格式（目前是完全字面匹配，不过改成正则表达式匹配也非常简单），rewrite 则是当 pattern 匹配成功后所要执行的实际命令。

最后一步是设置一个 cron 任务，让脚本定期运行。由于 Twitter 对过于频繁的轮询支持不佳，我建议将脚本设置为每小时轮询两到三次。

每次脚本执行命令后，都会将用户名、输入文本和最终执行的命令记录到 remote/remote.log 文件中。

发送命令

最后，你只需要向监听的 Twitter 账号发送私信命令即可。

d my_account reboot apache

当下一次 cron 任务运行时，你的命令就会被执行。

为什么这么做？

我实际使用这个方案的场景有两个。虽然这两个场景用其他技术（比如邮件）会更好，但我还是喜欢这种略显曲折的实现方式。

第一个场景是在手机上更新网站和重启 Apache，而不需要真正 SSH 到服务器（服务器只允许公钥认证，不使用密码）；第二个场景是允许朋友更新我服务器上的项目（通常是从 Git 仓库拉取代码并运行构建脚本），而不需要为他们单独创建账号和配置公钥。

正如我前面所说，我认为使用邮件会是比依赖 Twitter 更好的方案，而这个方法最多算是一个有趣的新奇玩法。
