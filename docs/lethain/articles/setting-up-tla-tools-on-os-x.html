在 OS X 上安装 TLA+ 工具

2009-10-31 · 阅读原文

我的同事 Mark Z. 最近迷上了 TLA+，这也让我对它产生了谨慎的乐观态度。

在通读了大部分《TLA+ Book》（可免费下载）之后，接下来自然是要开始自己编写并模型检查一些 TLA+ 规范，这意味着我需要先安装 [TLA+ Tools]。

安装过程其实相当简单，但我还是决定简单记录一下步骤。

从 Microsoft Research 网站下载工具。将压缩包解压到 ~/tla/ 目录。更新你 Shell 的 CLASSPATH：emacs ~/.bash_profile 在配置文件中加入下面这行：export CLASSPATH="$CLASSPATH:/Users/<USERNAME>/tla" 然后重新加载配置文件：source ~/.bash_profile
