在 OS X 上安装 TLA+ 工具

2009-10-31 · 阅读原文

同事 Mark Z. 最近迷上了 TLA+，也让我对这个想法产生了谨慎的乐观。

在通读了大部分《TLA+ 手册》（可免费下载）之后，下一步就是开始自己编写和模型检查一些 TLA+ 规范，这意味着我需要先安装 [TLA+ Tools]。

安装过程其实相当简单，但还是觉得有必要简单记录一下。

emacs ~/.bash_profile

export CLASSPATH="$CLASSPATH:/Users/<USERNAME>/tla"

source ~/.bash_profile
  1. Download the tools from the Microsoft Research site.
  2. Unzip the file into ~/tla/.
  3. Update the CLASSPATH for your shell:Add this line to your configuration file:Then re-source the file:

至此安装完成，你可以对示例运行 TLC 模型检查器：

cd ~/tla/examples/AsynchronousInterface
java tlc.TLC AsynchInterface.tla
