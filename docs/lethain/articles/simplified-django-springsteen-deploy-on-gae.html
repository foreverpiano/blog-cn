简化版 django-springsteen 在 GAE 上的部署

2009-03-05 · 阅读原文

我给 django-springsteen 打了补丁，让它能够使用 Google App Engine 的 memcached API，同时也如之前承诺的那样，简化了在 GAE 上部署 Springsteen 的流程。

git clone git://github.com/lethain/django-springsteen.git

chmod +x ./scripts/pack_for_gae.sh
./scripts/pack_for_gae

BOSS_APP_ID = 'my-boss-app-id'

dev_appserver.py ./

  2. Run the pack_for_gae.sh script.
