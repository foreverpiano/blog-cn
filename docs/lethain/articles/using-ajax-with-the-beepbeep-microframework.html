使用 Ajax 与 BeepBeep 微框架

2009-07-06 · 阅读原文

在对 BeepBeep 极简介绍的基础上，在《BeepBeep 入门》系列的这第二篇文章中，我们将一起看看如何在 BeepBeep 中使用 Ajax。

和大多数简单的 Ajax 示例一样，这个例子可能有点刻意人为，但仍然足以说明核心概念。我不会试图说服读者这个例子多么缺乏创意——我们只是让 BeepBeep 应用程序返回当前时间，然后将它显示给用户。

BeepBeep 项目设置

（如果你尚未安装 BeepBeep，请先参考前一篇《BeepBeep 入门教程》再继续。）

使用 BeepBeep 命令创建一个新项目。cd ~/git/beepbeep/ script/new_beep.erl BB_Time ../BB_Time 然后进入项目目录。cd ~/git/BB_Time/bb_time

至此，项目已经初始化完毕，可以开始添加我们的特别功能了。

BeepBeep 后端逻辑

接下来，我们需要配置应用程序的 BeepBeep 部分（与 JavaScript 部分相对，后者我们最后再来配置）。

首先需要创建两个控制器：一个用于显示初始页面；另一个用于被轮询以获取当前时间。打开 src/home_controller.erl 文件，将现有的 handle_request 处理函数（index 和 show 两个）替换为以下代码：handle_request("index",[]) -> {_A,B,_C} = erlang:now(), {render,"home/index.html",[{time, B}]}; handle_request("time",[]) -> {A,B,C} = erlang:now(), {render,"home/ajax.html",[{time, B}]}. 这两个处理函数看起来几乎完全一样，只是渲染不同的视图，这很合理，因为从服务器的角度来看，Ajax 请求与普通的 HTTP 请求并无区别。 此外，将现有的 before_filter 实现替换为：before_filter() -> ok. 然后保存并关闭 home_controller.erl。 接下来编辑基础视图，打开 views/base.html 并将其内容修改为：<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd"> <html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en"> <head> <meta http-equiv="content-type" content="text/html;charset=UTF-8" /> <title>Welcome to BeepBeep Ajax</title> <link href="/stylesheets/style.css" rel="stylesheet" type="text/css"/> <script type="text/javascript" src="http://ajax.googleapis.com/ajax/libs/jquery/1.3.2/jquery.min.js"> </script> <script type="text/javascript" src="/js/time.js"></script> </head> <body> {% block content %}{% endblock %} </body> </html> 主要改动是增加了对尚不存在的 js/time.js 文件的 JavaScript 引用（我们稍后会创建它），以及引入了 Google 托管的 jQuery 库。 第三步，创建视图模板 views/home/ajax.html，内容如下：<p> Time is { { time }}</p> 注意这里不要以 {% extends "../base.html" %} 块开头，因为我们会将这个 HTML 片段注入到已有的 HTML 页面中。 接下来编辑 views/home/index.html 模板，使其内容变为：{% extends "../base.html" %} {% block content %} <div id="time"> {% include "ajax.html" %} </div> {% endblock %} 如果你不熟悉 Django，可能没有见过 include 标签。它会把另一个文件的内容插入到当前文件中，并使用当前模板的上下文来渲染被插入的模板。 这也暴露了 ErlyDTL 的一个尴尬之处：它不理解路径是相对于 views/ 目录的，而是要求路径相对于当前模板。也就是说，home/index.html 必须写出相对于自身的 ../base.html 路径，而 index.html 中的 include 标签也必须引用 ajax.html，而不是 home/ajax.html。这与我们预期的 Django 行为有所不同，请务必注意。 最后，让我们验证这个小应用是否能正常工作。make ./start-server.sh 然后访问 http://localhost:8000/ 和 http://localhost:8000/ajax 页面，确认它们正确渲染了相应的内容。

做到这一步，我们距离完成这个简单的 Ajax 应用已经很近了，只差 Ajax 部分的代码。
