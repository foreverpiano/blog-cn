使用 Ajax 与 BeepBeep 微框架

2009-07-06 · 阅读原文

在对 BeepBeep 极为基础的介绍之上，本系列《BeepBeep 入门》的第二篇文章将带大家了解如何在 BeepBeep 中使用 Ajax。

和大多数简单的 Ajax 示例一样，本例也会有些刻意为之，但依然能够很好地演示这个概念。我不会试图说服读者这个例子有多么平淡无奇——我们只是简单地轮询 BeepBeep 应用获取当前时间，然后将其显示给用户。

BeepBeep 环境搭建

（如果你尚未安装 BeepBeep，请先参考前一篇《BeepBeep 入门教程》再继续阅读。）

cd ~/git/beepbeep/
script/new_beep.erl BB_Time ../BB_Time

cd ~/git/BB_Time/bb_time

至此，项目已经初始化完成，准备好加入我们的“特制酱料”了。

JavaScript 逻辑实现

我们已经在 base.html 中引入了 jQuery，现在只需创建并完善 js/time.js 文件即可。

mkdir www/js
emacs www/js/time.js

然后加入以下代码：

var update = function() {
    $("#time").load("/home/time");
}
setInterval(update, 1000);

最后，刷新 http://localhost:8000/ 页面，你就会看到又一个“ egregious”的 Ajax 应用在你眼前运行，而它的动力正是来自 BeepBeep！

（本教程的完整代码可在 BeeBeep Examples 仓库中的 BB_Time 项目中获取。）
