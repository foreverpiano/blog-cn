为 Django 编写自定义 Context

2007-07-01 · 阅读原文

在构建这个网站的过程中，我遇到了很多使用通用视图（generic views）却需要额外信息的情况，而这些信息又无法直接获取。当然，我可以编写大量自定义视图，但那正是我第一个大型 Django 项目所采用的方式，我并不打算再那么做（之前因为对通用视图的莫名恐惧而浪费了太多时间）。

幸运的是，解决这个问题有一个非常简单优雅的方法：编写自己的 context。

什么是 context？

Context 就是一些信息。通常它们是 QuerySet，但也可以是任何内容。这些信息可以在模板中直接使用。而且，创建它们非常简单。

在构建网站时，我希望在每一页的导航栏上都能显示一些随机条目，下面我们来看看如何通过 context 来实现。

Context 本质上就是一个函数，它接受一个 request 参数，并返回一个包含值的字典。我编写的 context 如下所示：

from blog.models import Entry
def blog(request):
random = Entry.current.all().order_by('?')[:3]
return { 'random_entries' : random, }

就是这样。现在你需要在 settings.py 文件中添加一个简单的配置。假设你的 context 文件位于 myproject/blog/context.py，那么我们只需在 settings.py 中加入以下内容：

TEMPLATE_CONTEXT_PROCESSORS = (
      "django.core.context_processors.auth",
      "django.core.context_processors.debug
      "django.core.context_processors.i18n",
      "django.core.context_processors.media",
      "myproject.blog.context.blog",
      )

就是这么简单，但相关文档却并不多。好啦，现在去征服它们吧。
