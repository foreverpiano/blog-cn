使用 LifeFlow 发布文章的标准流程

2008-01-24 · 阅读原文

最近我经常谈到 LifeFlow 及其功能，以及它如何让你的网站更灵活、为访客带来更好的体验（比如可自定义的皮肤、 threaded comments 等）。但我还没有写过一篇清晰的文章，说明一位使用 LifeFlow 的作者如何将自己的想法转化为一篇可供全世界阅读的已发布博客文章。

因此，这篇文章将用简单的操作指南形式，涵盖所有标准使用场景。如果发现有遗漏的内容，请告诉我！文章首先概述我简洁的发布流程，然后列出一些常见问题解答。

概述

对我来说，使用 LifeFlow 相当简单。目前虽然有一个自定义编辑应用正在逐步变得易用，但目前我采用的流程是这样的：

打开 Emacs。我把所有博客文章都保存在 ~/blog 文件夹下，该文件夹为每个 Flow 都设有子文件夹。新建一个以 .md 结尾的文件，这会自动触发 Emacs 的 Markdown major mode。撰写文章。必要时打开 iPhoto，新建一个图片文件夹，对图片进行排序并选出要使用的图片。从 iPhoto 导出图片文件夹，将图片宽度缩放到约 800 像素（lethain.com 的 LifeFlow 皮肤会将博客文章中的图片缩放到主栏宽度的 100%，所以不需要特别精确。默认行为是直接插入图片并让文字环绕，因此在那种情况下你需要更注意图片尺寸）。登录 LifeFlow 的 Admin 后台。新建一篇文章，填写标题、摘要、正文（从 Emacs 复制粘贴）。为文章中用到的任何文件或图片创建对应的 Resource 实例（下面会更详细说明）。保存文章。在网站上查看该文章，校对并检查是否有明显错误。修正错误并重新保存文章。如果精力允许，再通读全文，仔细检查拼写错误、错别字和错误的链接。修正问题后再次保存文章。

常见问题解答

创建文章

登录到你 LifeFlow 安装的 Admin 后台。点击 Entries 右侧的 Add 按钮。为文章命名，长度不超过 200 个字符。为文章设置时间和日期，通常直接点击“today”和“now”按钮获取当前时间。填写文章摘要。这是一段用 HTML 编写的简短文字，会在列表视图中显示，也会在用户撰写评论时展示。为文章添加正文。默认应使用 Markdown 撰写；如果你在 Options 面板中取消勾选“use markdown”选项，则需要使用原始 HTML 编写。点击保存。

为文章添加图片

创建一篇文章，但先不要保存。点击 Resources 标签。点击现有资源列表顶部的加号（+）。使用文件选择器选中要展示的图片文件，填写描述（第一个字段）和 ID（第二个字段），这个 ID 将用于引用它。假设你给它设置的 ID 是“my_pic”（不含引号）。在创建资源的小弹窗中点击保存。在正文中的适当位置加入类似 ![this is my picture][file my_pic] 的内容。保存文章。

为文章添加文件

创建一篇文章，但先不要保存。点击 Resources 标签。点击现有资源列表顶部的加号（+）。使用文件选择器选中要展示的文件，填写描述（第一个字段）和 ID（第二个字段），这个 ID 将用于引用它。假设你给它设置的 ID 是“my_file”（不含引号）。在创建资源的小弹窗中点击保存。在正文中的适当位置加入类似 [this is my file][file my_file] 的内容。保存文章。

将文章保持为草稿

如果你不希望文章立即发布，可以将其日期设置为未来。你也可以用这个机制来定时发布。如果你想长期确保某篇文章保持草稿状态，可以将其发布日期设置为几千年之后。

将文章添加到 Flow

点击你想将文章加入的 Flow，它们会从左侧列表移到右侧。一个文章可以同时属于任意数量（0 个或更多）的 Flow。

为文章添加标签

点击你要为文章添加的标签，它们会从左侧移到右侧。一个文章可以拥有任意数量（0 个或更多）的标签。请注意，标签列表首先按大小写排序，其次才是字母顺序（确实有点奇怪，我同意）。

创建文章系列

点击 Series 按钮。点击左侧现有 Series 列表顶部的加号（+）。为该 Series 命名。保存新的 Series。保存新的文章。

将文章加入已有的系列

点击 Series。将你希望文章所属的系列从左侧列表移到右侧。

为文章添加翻译

创建一篇包含翻译后文本的新文章。回到主 Admin 页面，点击 Translations 右侧的 Add 按钮。选择翻译所使用的语言、原始文章，以及包含翻译文本的新文章。保存这条翻译记录。
