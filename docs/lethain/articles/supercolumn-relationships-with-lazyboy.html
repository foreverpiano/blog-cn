SuperFamily 与 Lazyboy 的关系

2010-05-23 · 阅读原文

最近我开始研究 Cassandra 及其 Python 客户端 Lazyboy。虽然文档已经相当不错，但我还是自己动手尝试并阅读了部分源代码后才真正理解它（当然，前提是我真的理解对了。如果我只是达到了理解的平台期，还望亲爱的读者不吝赐教）。

我一向认为实践是最好的学习方式，那就让我们来构建一些东西吧。

建模我们的应用

对于这个项目，我决定构建一个简单的开发团队任务管理系统。

我们的系统会有很多人。

我们的系统也会有很多任务。

每个任务会有零个或多个人员参与。

基于这些关系，我们可能需要能够执行以下操作：

获取所有人员、获取所有任务、获取特定人员、获取特定任务、获取正在处理某个特定任务的人员。

那么，我们该如何在 Cassandra 中建模呢？其实非常简单，只需遵循这条基本规则：

每种类型的文档对应一个 ColumnFamily，同时每种文档之间的关系也对应一个 ColumnFamily。

（ColumnFamily 是一组相似文档的集合。同一 ColumnFamily 中的文档不必拥有相同或相似的键/值，但通常保持一致会让你的应用更简洁，尤其是在你需要遍历数据时。）

将这条规则应用到我们的应用中，我们有两种类型的文档：

tasks 和 members，

同时它们之间还存在一种关系：

一个任务由零个或多个成员负责。

换句话说，我们需要三个 ColumnFamily。

接下来，在开始实现之前，我们先安装 Lazyboy 和 Cassandra。

安装前提条件

下载 Cassandra 0.6.1。安装 Cassandra（以下是 OS X 的安装说明，其他操作系统可自行调整目录结构）：cd ~/Download tar -xvf apache-cassandra-*.gz mv apache-cassandra-0.6.1 ~/Library/cassandra 为 Cassandra 创建必要的运行目录：tar -zxvf cassandra-$VERSION.tgz cd cassandra-$VERSION sudo mkdir -p /var/log/cassandra sudo chown -R `whoami` /var/log/cassandra sudo mkdir -p /var/lib/cassandra sudo chown -R `whoami` /var/lib/cassandra 如果还没有 Git，先安装 Git。下载 Lazyboy，我们将把它作为 Cassandra 的 Python 客户端（注意需要使用 Python 2.5 或更高版本，OS X 10.5 或更高版本已自带）：mkdir ~/git && cd ~/git git clone http://github.com/digg/lazyboy.git sudo python setup.py

现在前提条件都已满足，我们可以开始……配置了。
