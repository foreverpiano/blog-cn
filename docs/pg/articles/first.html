Viaweb 是第一个吗？

August 1995 · 阅读原文

据我们当时所知，Viaweb 是第一个基于 Web 的应用程序，但我担心可能存在我们不知道的更早案例。所以如果您知道任何更早的例子，请告诉我。

这当然取决于如何定义“应用程序”。我所说的应用程序是指一个网站，它不仅仅是一个数据库的界面，而更像是桌面应用程序，用户可以在服务器上实际构建东西。也就是说，它具备类似于“文件->新建”这样的功能。

Robert Morris 和我在 向投资人演示了 Viaweb 的第一个版本。当时据我们所知，这是一种新型软件。但我不想说出不真实的内容，所以如果有人知道在那之前还有任何基于 Web 的应用程序，请务必联系我。1995年8月12日：它成功了
