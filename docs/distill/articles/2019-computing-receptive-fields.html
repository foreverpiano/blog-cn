计算卷积神经网络的感受野

2019-11-04 · 阅读原文

虽然深度神经网络已在众多人工智能任务上确立了压倒性的最先进成果，但它们在开发和调试过程中仍可能面临困难。最近关于深度学习可解释性的研究主要集中在特征可视化 [(Erhan et al., 2009; Zeiler et al., 2014)]、理论保证 [(Haeffele et al., 2017; Chizat et al., 2018)]、模型可解释性 [(B. Zhou et al., 2015; Zhou et al., 2018)] 以及泛化能力 [(Neyshabur et al., 2014; Zhang et al., 2017)] 等方面。

本文中，我们从一个互补的角度分析深度神经网络，重点关注卷积模型。我们希望理解输入信号能在多大程度上影响输出特征，并将网络中任意位置的特征映射回输入中产生该特征的区域。将输出特征与输入区域关联起来的关键参数是卷积网络的感受野，它被定义为输入中能产生该特征的区域大小。

作为我们的第一个贡献，我们提出了一种数学推导和一种高效算法，用于计算现代卷积神经网络的感受野。此前的工作 [(Dang-Ha, 2017; Le et al., 2017)] 讨论了简单卷积网络的感受野计算，这类网络从输入到输出只有单条路径，并提供了适用于该情况的递推方程。本文中，我们重新审视这些推导，得到了单路径情况下感受野计算的闭式表达式。此外，我们将感受野计算扩展到现代卷积网络，其中从输入到输出可能存在多条路径。据我们所知，这是首次针对此类最新卷积架构的感受野计算阐述。

如今，感受野计算在各种应用中都十分必要。例如，在计算机视觉的目标检测任务中，为了识别不同尺度的物体实例，需要在多个尺度上表示物体；为此通常需要理解卷积特征的跨度（例如，如果网络的感受野过小，它可能无法识别大型物体）。然而，这些计算通常是人工完成的，既繁琐又容易出错。这是因为目前没有能够自动计算这些参数的库。作为我们的第二个贡献，我们填补了这一空白，推出了一个开源库，可以方便地执行本文所述的计算。该库已集成到 TensorFlow 代码库中，可轻松用于分析各种模型，正如本文所展示的那样。

我们希望这些推导和开源代码能够加深对复杂深度学习模型的理解，从而推动更高效的机器学习研究。

文章概述

我们考虑全卷积神经网络，并推导其相对于输入信号的输出特征的感受野大小和感受野位置。虽然本文给出的推导对卷积神经网络输入的任何类型信号都足够通用，但我们以图像作为贯穿始终的示例，并在合适时引用现代计算机视觉架构。

首先，我们推导当网络从输入到输出只有单条路径时（例如 AlexNet [(Krizhevsky et al., 2012)] 或 VGG [(Simonyan et al., 2015)]）的闭式表达式。然后，我们讨论更一般的任意计算图情况，其中从输入到输出存在多条路径（例如 ResNet [(He et al., 2016)] 或 Inception [(Szegedy et al., 2016)]）。我们考虑这种情况下可能出现的对齐问题，并解释一种计算感受野大小和位置的算法。

最后，我们分析现代卷积神经网络的感受野，并展示使用我们开源库得到的结果。

问题设定

考虑一个具有 \(L\) 层（\(l = 1,2,\ldots,L\)）的全卷积网络（FCN）。定义特征图 \(f_l \in R^{h_l\times w_l\times d_l}\) 表示第 \(l\) 层的输出，具有高度 \(h_l\)、宽度 \(w_l\) 和深度 \(d_l\)。我们用 \(f_0\) 表示输入图像，最终的输出特征图对应 \(f_L\)。

为简化表述，本文中的推导均针对一维输入信号和特征图。对于更高维信号（例如 2D 图像），这些推导可以独立地应用于每个维度。类似地，图示中采用一维深度，因为这不影响感受野的计算。

每一层 \(l\) 的空间配置由 4 个变量参数化，如下图所示：

  • \(k_l\): kernel size (positive integer)
  • \(s_l\): stride (positive integer)
  • \(p_l\): padding applied to the left side of the input feature map (non-negative integer) [1]
  • \(q_l\): padding applied to the right side of the input feature map (non-negative integer)

我们考虑那些输出特征局部依赖于输入特征的层：例如卷积、池化，或逐元素操作如非线性激活、加法和滤波器拼接。这些是当前最先进网络中常用的操作。我们将逐元素操作的“卷积核大小”定义为 \(1\)，因为每个输出特征仅依赖于输入特征图的单个位置。

我们的符号约定通过下面这个简单网络进一步说明。在这个例子中，\(L=4\)，模型由一个卷积层、ReLU 激活、第二个卷积层和最大池化层组成。[2]

单路径网络

本节中，我们为从输入到输出只有单条路径的全卷积网络（例如 AlexNet [(Krizhevsky et al., 2012)] 或 VGG [(Simonyan et al., 2015)]）计算递推关系和闭式表达式。

计算感受野大小

定义 \(r_l\) 为最终输出特征图 \(f_L\) 相对于特征图 \(f_l\) 的感受野大小。换句话说，\(r_l\) 表示特征图 \(f_l\) 中有多少个特征对生成 \(f_L\) 中的一个特征有贡献。注意 \(r_L = 1\)。

作为一个简单示例，考虑第 \(L\) 层，它以 \(f_{L-1}\) 为输入，生成 \(f_L\) 作为输出。以下是示意图：

显然，\(f_{L-1}\) 中的 \(k_L\) 个特征可以影响 \(f_L\) 中的一个特征，因为 \(f_L\) 的每个特征都直接连接到 \(f_{L-1}\) 中的 \(k_L\) 个特征。因此，\(r_{L-1} = k_L\)。

现在考虑更一般的情况：已知 \(r_l\)，要求 \(r_{l-1}\)。每个特征 \(f_l\) 都连接到 \(f_{l-1}\) 中的 \(k_l\) 个特征。

首先考虑 \(k_l = 1\) 的情况：在这种情况下，\(f_l\) 中的 \(r_l\) 个特征将覆盖 \(f_{l-1}\) 中的 \(r_{l-1} = s_l \cdot r_l - (s_l - 1)\) 个特征。下图展示了 \(r_l = 2\)（红色高亮）的情况。第一个项 \(s_l \cdot r_l\)（绿色）覆盖了特征来源的整个区域，但会多覆盖 \(s_l - 1\) 个特征（紫色），因此需要减去这部分。[3]

对于 \(k_l > 1\) 的情况，我们只需额外加上 \(k_l - 1\) 个特征，这些特征会覆盖区域左右两侧。例如，如果使用卷积核大小为 5（\(k_l = 5\)），每侧会额外使用 2 个特征，总共增加 4 个。即使 \(k_l\) 是偶数，这种情况也成立，因为左右填充会共同构成 \(k_l - 1\)。[4]

因此，我们得到通用的递推方程（这是一个一阶非齐次变系数递推关系）：

\(\begin{align} r_{l-1} = s_l \cdot r_{l} + (k_l - s_l) \label{eq:rf_recurrence}\ \end{align}\)

这个方程可用于递归算法来计算网络的感受野大小 \(r_0\)。但我们还能做得更好：我们可以求解这个递推方程，得到用 \(k_l\) 和 \(s_l\) 表示的解：

\begin{equation} r_0 = \sum_{l=1}^{L} \left((k_l-1)\prod_{i=1}^{l-1} s_i\right) + 1 \label{eq:rf_recurrence_final} \end{equation}

这个表达式具有直观的意义，我们可以通过一些特殊情况来观察。例如，如果所有卷积核大小均为 1，那么感受野大小自然也为 1。如果所有步长均为 1，那么感受野大小就是所有层 \((k_l - 1)\) 的总和再加 1，这很容易理解。如果某一层的步长大于 1，那么该层以下所有层的感受野区域都会按比例增大。最后要注意的是，该推导不需要考虑填充。

计算输入图像中的感受野区域

虽然知道输出特征图中一个特征对应的生成区域大小很重要，但在很多情况下，精确地定位生成该特征的区域也至关重要。例如，给定特征 \(f_L(i, j)\)，它在输入图像中对应的区域是什么？本节将讨论这个问题。

我们用 \(u_l\) 和 \(v_l\) 分别表示用于计算 \(f_L\) 中目标特征的区域在 \(f_l\) 中的最左和最右坐标。在这些推导中，坐标采用零索引（即每个特征图的第一个特征位于坐标 0）。注意 \(u_L = v_L\) 对应 \(f_L\) 中目标特征的位置。下图展示了一个简单的两层网络，我们高亮了用于计算 \(f_2\) 中第一个特征的 \(f_0\) 中的区域。注意在这个例子中该区域包含了一些填充。在此例中，\(u_2 = v_2 = 0\)，\(u_1 = 0, v_1 = 1\)，以及 \(u_0 = -1, v_0 = 4\)。

我们首先提出以下问题：给定 \(u_l, v_l\)，能否计算出 \(u_{l-1}, v_{l-1}\)？

从一个简单情况开始：假设 \(u_l = 0\)（这对应 \(f_l\) 中的第一个位置）。在这种情况下，最左特征 \(u_{l-1}\) 显然位于 \(-p_l\)，因为第一个特征是通过将卷积核左端放置在该位置生成的。如果 \(u_l = 1\)，我们关注第二个特征，其最左位置 \(u_{l-1}\) 为 \(-p_l + s_l\)；对于 \(u_l = 2\)，\(u_{l-1} = -p_l + 2 \cdot s_l\)；以此类推。一般地：

\(\begin{align} u_{l-1}&= -p_l + u_{l}\cdot s_l \label{eq:rf_loc_recurrence_u} \\ v_{l-1}&= -p_l + v_{l}\cdot s_l + k_l -1 \label{eq:rf_loc_recurrence_v} \end{align}\)

其中 \(v_l\) 的计算仅多了 \(k_l - 1\)，这是因为我们要找到最右的位置。

注意这些表达式与之前推导的感受野大小递推公式 \eqref{eq:rf_recurrence} 非常相似。同样，我们可以在网络上实现递归来获得每一层的 \(u_l, v_l\)；但我们也可以直接求解 \(u_0, v_0\)，得到用网络参数表示的闭式表达式：

\(\begin{align} u_0&= u_{L}\prod_{i=1}^{L}s_i - \sum_{l=1}^{L} p_l\prod_{i=1}^{l-1} s_i \label{eq:rf_loc_recurrence_final_left} \end{align}\)

这给出了输入图像中最左特征位置，它是网络每一层所应用的填充（\(p_l\)）和步长（\(s_l\)），以及输出特征图中特征位置（\(u_L\)）的函数。

而最右特征位置 \(v_0\) 为：

\(\begin{align} v_0&= v_{L}\prod_{i=1}^{L}s_i -\sum_{l=1}^{L}(1 + p_l - k_l)\prod_{i=1}^{l-1} s_i \label{eq:rf_loc_recurrence_final_right} \end{align}\)

注意，与 \eqref{eq:rf_loc_recurrence_final_left} 不同，该表达式还依赖于每一层的卷积核大小（\(k_l\)）。

感受野大小与区域的关系。你可能会想，感受野大小 \(r_0\) 一定与 \(u_0\) 和 \(v_0\) 直接相关。确实如此；很容易证明 \(r_0 = v_0 - u_0 + 1\)，我们将其留给有兴趣的读者作为练习。需要强调的是，这意味着我们可以将 \eqref{eq:rf_loc_recurrence_final_right} 重写为：

\(\begin{align} v_0&= u_0 + r_0 - 1 \label{eq:rf_loc_recurrence_final_right_rewrite} \end{align}\)

有效步长和有效填充。为了在实践中计算 \(u_0\) 和 \(v_0\)，定义另外两个仅依赖于各层填充和步长的变量会很方便：

  • effective stride \(S_l = \prod_{i=l+1}^{L}s_i\): the stride between a given feature map \(f_l\) and the output feature map \(f_{L}\)
  • effective padding \(P_l = \sum_{m=l+1}^{L}p_m\prod_{i=l+1}^{m-1} s_i\): the padding between a given feature map \(f_l\) and the output feature map \(f_{L}\)

利用这些定义，我们可以将 \eqref{eq:rf_loc_recurrence_final_left} 重写为：

\(\begin{align} u_0&= -P_0 + u_{L}\cdot S_0 \label{eq:rf_loc_recurrence_final_left_effective} \end{align}\)

注意 \eqref{eq:rf_loc_recurrence_final_left_effective} 与 \eqref{eq:rf_loc_recurrence_u} 的相似性。通过使用 \(S_l\) 和 \(P_l\)，我们可以根据输出特征图的位置 \(u_L\) 计算特征图 \(f_l\) 的位置 \(u_l, v_l\)。当我们想为给定网络计算特征位置时，预先计算三个变量 \(P_0, S_0, r_0\) 会非常方便。使用这三个变量，我们可以通过 \eqref{eq:rf_loc_recurrence_final_left_effective} 得到 \(u_0\)，并通过 \eqref{eq:rf_loc_recurrence_final_right_rewrite} 得到 \(v_0\)。这使我们能够建立从任意输出特征位置到影响它的输入区域的映射。

我们也可以推导有效步长和有效填充的递推方程。很容易证明：

\(\begin{align} S_{l-1}&= s_l \cdot S_l \label{eq:effective_stride_recurrence} \\ P_{l-1}&= s_l \cdot P_l + p_l \label{eq:effective_padding_recurrence} \end{align}\)

这些表达式在下一节推导任意计算图的算法时会非常有用。

感受野区域的中心。推导影响特定输出特征的感受野区域的中心位置也很有意义。这可以作为该特征在输入图像中的位置（例如，最近基于深度学习的局部特征工作 [(Noh et al., 2017)] 就是这样做的）。

我们将每一层 \(l\) 的感受野区域中心定义为 \(c_l = \frac{u_l + v_l}{2}\)。给定上述 \(u_0, v_0, r_0\) 的表达式，很容易推导出 \(c_0\)（记住 \(u_L = v_L\)）：

\(\begin{align} c_0&= u_{L}\prod_{i=1}^{L}s_i - \sum_{l=1}^{L} \left(p_l - \frac{k_l - 1}{2}\right)\prod_{i=1}^{l-1} s_i \nonumber \\&= u_{L}\cdot S_0 - \sum_{l=1}^{L} \left(p_l - \frac{k_l - 1}{2}\right)\prod_{i=1}^{l-1} s_i \nonumber \\&= -P_0 + u_{L}\cdot S_0 + \left(\frac{r_0 - 1}{2}\right) \label{eq:rf_loc_recurrence_final_center_effective} \end{align}\)

将这个表达式与 \eqref{eq:rf_loc_recurrence_final_left_effective} 比较，可以看到中心相对于最左侧像素偏移了 \(\frac{r_0 - 1}{2}\)，这是合理的。注意不同输出特征的感受野中心按有效步长 \(S_0\) 间隔排列，这也在预期之中。还有一点值得注意，如果对所有 \(l\) 都有 \(p_l = \frac{k_l - 1}{2}\)，则输出特征的感受野中心将与图像第一个像素对齐，位置为 \({0, S_0, 2S_0, 3S_0, \ldots}\)（注意此时所有 \(k_l\) 必须是奇数）。

其他网络操作。本节提供的推导涵盖了卷积神经网络中的大多数基本操作。有兴趣的读者可能会想到其他常用操作，例如空洞卷积、上采样等。你可以在附录中找到对这些操作的讨论。

任意计算图

当今大多数最先进的卷积神经网络（例如 ResNet [(He et al., 2016)] 或 Inception [(Szegedy et al., 2016)]）都依赖于每一层可能有多个输入的模型，这意味着从输入图像到最终输出特征图之间可能存在多条不同路径。这些架构通常用有向无环计算图表示，其中节点集合 \(\mathcal{L}\) 表示各层，边集合 \(\mathcal{E}\) 编码它们之间的连接（特征图沿着边流动）。

上一节的计算可以独立地应用于从输入到输出的每一条可能路径。当我们希望同时考虑所有不同路径以确定网络的感受野大小以及对应于每个输出特征的感受野区域时，情况会变得更加复杂。

对齐问题。第一个潜在问题是，一个输出特征可能由输入图像中未对齐的区域计算得到，这取决于从输入到输出的路径。此外，用于计算每个输出特征的图像区域之间的相对位置也可能变化。因此，感受野大小可能不是平移不变的。下图用一个玩具示例说明了这一点，其中输入图像中两个路径所用区域的中心位置不同。

在这个例子中，填充仅用于左侧分支。前三层是卷积层，最后一层执行简单的加法运算。左右两条路径的感受野区域之间的相对位置对于不同的输出特征并不一致，这导致了不对齐（可以通过将鼠标悬停在不同输出特征上观察到）。此外，请注意每个输出特征的感受野大小可能不同。对于最左边的第二个特征，使用了 6 个输入样本，而第三个特征只使用了 5 个。这意味着当网络未对齐时，感受野大小可能不是平移不变的。

对于许多计算机视觉任务而言，输出特征保持对齐是非常理想的：“图像到图像翻译”任务（例如语义分割、边缘检测、表面法线估计、着色等）、局部特征匹配和检索等都是如此。

当网络对齐时，所有不同路径都会使输出特征以一致的位置为中心。所有路径必须具有相同的有效步长。容易看出，感受野大小将是所有可能路径中最大的感受野。同时，网络的有效填充对应于具有最大感受野大小的路径的有效填充，这样我们就可以应用 \eqref{eq:rf_loc_recurrence_final_left_effective} 和 \eqref{eq:rf_loc_recurrence_final_center_effective} 来定位生成输出特征的区域。

下图给出了一个对齐网络的简单例子。在这种情况下，两条不同路径使特征中心位于相同的位置。感受野大小为 3，有效步长为 4，有效填充为 1。

对齐准则。更精确地说，为了使网络在每一层都对齐，我们需要任意一对路径 \(i\) 和 \(j\) 在任意层 \(l\) 和输出特征 \(u_L\) 上满足 \(c_l^{(i)} = c_l^{(j)}\)。为此，从 \eqref{eq:rf_loc_recurrence_final_center_effective} 可以看出，必须满足两个条件：

\(\begin{align} S_l^{(i)}&= S_l^{(j)} \label{eq:align_crit_1} \\ -P_l^{(i)} + \left(\frac{r_l^{(i)} - 1}{2}\right)&= -P_l^{(j)} + \left(\frac{r_l^{(j)} - 1}{2}\right) \label{eq:align_crit_2} \end{align}\)

对所有 \(i, j, l\) 成立。

计算感受野参数的算法：概要。开发一个高效算法来计算此类计算图的感受野大小及相关参数是直截了当的。当然，一种暴力方法是使用上面给出的表达式，独立地为从输入到输出的每条路径计算感受野参数，并通过一些簿记来得到整个网络的参数。这种方法的最坏情况复杂度为 \(\mathcal{O}\left(\left|\mathcal{E}\right| \times \left|\mathcal{L}\right|\right)\)。

但我们可以做得更好。首先对计算图进行拓扑排序。排序后的表示按依赖关系排列各层：每一层的输出仅依赖于排在它之前的层。通过以逆拓扑顺序访问各层，我们确保当访问层 \(l\) 时，所有从 \(l\) 到输出层 \(L\) 的路径都已被考虑。当到达输入层 \(l=0\) 时，所有路径都已被考虑，从而得到整个模型的感受野参数。该算法的复杂度为 \(\mathcal{O}\left(\left|\mathcal{E}\right| + \left|\mathcal{L}\right|\right)\)，远优于暴力方法。

在访问每一层时，需要进行一些簿记以跟踪网络的感受野参数。特别需要注意的是，从层 \(l\) 到输出层 \(L\) 可能存在多条不同路径。为了处理这种情况，我们跟踪层 \(l\) 的参数，并在发现具有更大感受野的新路径时使用公式 \eqref{eq:rf_recurrence}、\eqref{eq:effective_stride_recurrence} 和 \eqref{eq:effective_padding_recurrence} 来更新它们。同样，在遍历图的过程中，重要的是检查网络是否对齐。这可以通过确保不同路径的感受野参数满足 \eqref{eq:align_crit_1} 和 \eqref{eq:align_crit_2} 来完成。

我们还可以将感受野的增长与分类精度的提升联系起来。下图绘制了 ImageNet top-1 精度与网络感受野大小的关系，对应于上面列出的相同网络。每个数据点的圆圈大小与该架构的浮点运算次数（FLOPs）成正比。

我们观察到分类精度与感受野大小之间存在对数关系，这表明大型感受野对于高层识别任务是必要的，但回报会逐渐递减。例如，请注意 MobileNets 即使使用非常紧凑的架构也能实现很高的识别性能：通过深度可分离卷积，它以很小的计算开销就增大了感受野。相比之下，VGG-16 需要的 FLOPs 是 MobileNets 的 27 倍，却产生了更小的感受野；尽管结构复杂得多，VGG 的精度仅比 MobileNet 略好一点。这表明那些能够高效生成大感受野的网络可能会获得更好的识别性能。

不过我们需要强调，感受野大小并不是导致上述性能提升的唯一因素。其他因素也起着非常重要的作用：网络深度（即层数）、宽度（即每层滤波器数量）、残差连接、批量归一化等等。换句话说，虽然我们推测大的感受野是必要的，但它绝不是充分条件。[6]

最后需要指出的是，给定的特征并不会同等程度地受到其感受野区域内所有输入像素的影响：靠近感受野中心的输入像素有更多“路径”来影响该特征，因此权重更大。每个输入像素的相对重要性定义了该特征的**有效感受野**。最近的工作 [(Luo et al., 2016)] 提供了数学形式化和测量有效感受野的流程，实验观察到其形状呈高斯分布，峰值位于感受野中心。更好地理解卷积神经网络中输入像素的相对重要性是一个活跃的研究课题。
