Ilyas 等人的评论

Ilyas 等人[[ilyas2019adversarial]] 将特征定义为一个函数 f，它将数据分布 (x,y) \sim \mathcal{D} 中的 x 映射为一个实数，并限制其均值为零、方差为一。若一个特征与标签具有高相关性，则称其为有用的特征。但在存在对抗者的情况下，Ilyas 等人[[ilyas2019adversarial]]认为真正重要的指标是特征的稳健有用性，

\mathbf{E}\left[\inf_{\|\delta\|\leq\epsilon}yf(x+\delta)\right],

即其在遭受攻击时与标签的相关性。Ilyas 等人[[ilyas2019adversarial]]指出，除了我们熟悉的那些稳健特征（例如天空的颜色）外，模型还可能在利用一些有用的非稳健特征，其中部分特征甚至可能超出人类直觉的范畴。这引发了一个问题：这样的非稳健特征可能是什么样子呢？

线性模型中的非稳健特征

当我们意识到以下事实时，搜索会变得简单：非稳健特征并非仅存在于深度学习中那些复杂的非线性模型里。正如 Ilyas 等人[[ilyas2019adversarial]]所观察到的，即使在最朴素的线性模型中，它们也会出现。因此，我们将注意力限制在以下形式的线性特征上：

f(x) = \frac{a^Tx}{\|a\|_\Sigma}\qquad \text{where} \qquad \Sigma = \mathbf{E}[xx^T] \quad \text{and} \quad \mathbf{E}[x] = 0.

一个线性特征的稳健有用性可以优雅地分解[1]为两项：

\mathbf{E}\left[\inf_{\|\delta\|\leq\epsilon}yf(x+\delta)\right]

回复合集

回复摘要：显式构造非稳健特征这项工作非常有趣，它朝着可视化我们实验所发现的有用非稳健特征这一挑战迈出了重要一步。我们也同意，非稳健特征以“干扰项”的形式出现并不被我们的理论框架所排除，尽管我们的实验排除了这种情况。这个简单的理论框架足以让我们对实验结果进行推理和预测[2]。然而，这篇评论正确地指出，找到一个更全面的特征定义是未来重要的研究方向。

回复：这些实验（对不同线性特征的稳健性和有用性进行可视化）非常有趣！它们既进一步证实了有用非稳健特征的存在，也推动了我们对这些非稳健特征实际样貌的可视化工作。

我们也认可文中构造所提出的观点：根据我们的理论框架，由“有用+稳健”和“无用+非稳健”特征组合而成的非稳健特征是可能的。我们的理论框架确实允许这种情况，尽管——正如评论者已经指出的——我们的实验结果并不支持这一点。（从这个意义上说，实验结果和我们的主要结论实际上比理论框架在技术上所能严格涵盖的范围更强。）具体来说，在这种场景下，在构造 \widehat{\mathcal{D}}_{det} 数据集的过程中，只有特征的非稳健且无用的部分会被翻转。因此，在此类数据集上训练的分类器会将具有预测能力的稳健特征与错误标签关联起来，从而无法在测试集上泛化。相比之下，我们的实验显示，在 \widehat{\mathcal{D}}_{det} 上训练的分类器确实能够泛化。

总体而言，我们在开发理论框架时的重点在于，能够形式化地描述并预测我们实验的结果。正如评论所指出的，提出一个能以非常精确的方式刻画非稳健特征的理论框架本身就是一个重要的未来研究方向。
