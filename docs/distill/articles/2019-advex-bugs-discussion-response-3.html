Ilyas 等人的评论

Ilyas 等人 [(Ilyas et al., 2019)] 将特征定义为一个函数 f，它将来自数据分布 (x,y) \sim \mathcal{D} 的输入 x 映射为一个实数，并限制其均值为零且方差为单位方差。如果一个特征与标签具有较高的相关性，则称其为有用的特征。但在存在对抗者的情况下，Ilyas 等人 [(Ilyas et al., 2019)] 认为真正重要的度量是特征的稳健有用性，

\mathbf{E}\left[\inf_{\|\delta\|\leq\epsilon}yf(x+\delta)\right],

即它在遭受攻击时与标签的相关性。Ilyas 等人 [(Ilyas et al., 2019)] 指出，除了我们熟悉的那些稳健特征（例如天空的颜色）之外，我们的模型可能还在利用一些有用的非鲁棒特征，其中一些甚至可能超出人类直觉的范畴。这引发了一个问题：这样的非鲁棒特征可能是什么样子呢？

线性模型中的非鲁棒特征

当我们意识到以下这一点时，搜索工作就变得简单了：非鲁棒特征并非深度学习中复杂非线性模型所独有。正如 Ilyas 等人 [(Ilyas et al., 2019)] 所观察到的，即使在最简单的线性模型中，它们也会出现。因此，我们将注意力限制在以下形式的线性特征上：

f(x) = \frac{a^Tx}{\|a\|_\Sigma}\qquad \text{where} \qquad \Sigma = \mathbf{E}[xx^T] \quad \text{and} \quad \mathbf{E}[x] = 0.

回复摘要：构造显式的非鲁棒特征非常有趣，并在可视化我们实验所检测到的一些有用非鲁棒特征这一挑战上取得了进展。我们也同意，非鲁棒特征以“干扰项”的形式出现并没有被我们的理论框架所排除，尽管我们的实验排除了这种情况。这个简单的理论框架足以用于推理和预测我们实验的结果[2]。然而，这条评论正确地指出了找到一个更全面的特征定义是未来重要的研究方向。

回复：这些实验（可视化不同线性特征的稳健性和有用性）非常有趣！它们既进一步证实了有用非鲁棒特征的存在，也在可视化这些非鲁棒特征实际样貌方面取得了进展。

我们也赞赏所提供的非鲁棒特征构造（按照我们理论框架中的定义）所提出的观点，即这些特征是有用+稳健特征与无用+非鲁棒特征的组合。我们的理论框架确实允许这种情况，即使——正如评论者已经指出的——我们的实验结果并不支持。（从这个意义上说，实验结果和我们的主要结论实际上比我们的理论框架在技术上所能严格捕捉的范围更强。）具体来说，在这种情况下，在构造 \widehat{\mathcal{D}}_{det} 数据集的过程中，只有特征的非鲁棒且无用的那一部分会被翻转。因此，在这样的数据集上训练的分类器会将具有预测能力的稳健特征与错误的标签关联起来，从而无法在测试集上泛化。相比之下，我们的实验显示，在 \widehat{\mathcal{D}}_{det} 上训练的分类器确实能够泛化。

总体而言，我们在开发理论框架时的重点是使其能够形式化地描述和预测我们实验的结果。正如评论所指出的，提出一个能够非常精确地刻画非鲁棒特征的理论框架本身就是一个重要的未来研究方向。
