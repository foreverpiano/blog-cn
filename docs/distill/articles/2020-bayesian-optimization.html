探索贝叶斯优化

2020-05-05 · 阅读原文

许多现代机器学习算法都包含大量超参数。要有效使用这些算法，我们需要挑选合适的超参数值。 在本文中，我们将讨论贝叶斯优化（Bayesian Optimization），这是一组常用于超参数调优的技术。更广泛地说，贝叶斯优化可以用来优化任意黑盒函数。

挖掘黄金！

让我们从黄金开采的例子开始。我们的目标是在一片未知的土地上寻找黄金[1]。 目前我们假设黄金沿一条直线分布。我们希望在只进行少量钻探（因为钻探成本高昂）的情况下，找到这条线上黄金含量最高的位置。

假设黄金分布 f(x) 如下图所示。它是双峰的，在 x = 5 附近达到最大值。目前我们先不关心 X 轴和 Y 轴的具体单位。

起初，我们对黄金分布一无所知。我们可以通过在不同位置钻探来了解黄金分布。然而，钻探成本高昂。因此，我们希望在尽量减少钻探次数的同时，快速找到黄金含量最高的位置。

接下来我们讨论黄金开采问题的两种常见目标。

  • Problem 1: Best Estimate of Gold Distribution (Active Learning) In this problem, we want to accurately estimate the gold distribution on the new land. We can not drill at every location due to the prohibitive cost. Instead, we should drill at locations providing high information about the gold distribution. This problem is akin to Active Learning[(Settles, 2009; Tong, 2001)] .
  • Problem 2: Location of Maximum Gold (Bayesian Optimization) In this problem, we want to find the location of the maximum gold content. We, again, can not drill at every location. Instead, we should drill at locations showing high promise about the gold content. This problem is akin to Bayesian Optimization[(Shahriari et al., 2016; Brochu et al., 2010)] .

我们很快就会看到，这两个问题相互关联，但并不完全相同。

主动学习

在许多机器学习问题中，未标记的数据很容易获得，但标记（或查询）的成本通常很高。例如，在语音转文本任务中，标注需要专家手动为单词和句子打标签。同样，在我们的黄金开采问题中，钻探（类似于标记）成本高昂。

主动学习旨在最小化标记成本，同时最大化模型准确率。虽然主动学习文献中有多种方法，但我们主要关注降低不确定性的方法。该方法建议对模型不确定性最高的点进行标记。通常，方差被用作不确定性的度量。

由于我们只在少数几个点上知道函数的真实值，我们需要一个替代模型（surrogate model）来估计函数在其他位置的取值。这个替代模型需要足够灵活，能够很好地拟合真实函数。使用高斯过程（Gaussian Process，简称 GP）是一种常见选择，因为它既足够灵活，又能提供不确定性估计 [2]。

我们的替代模型从先验 f(x) 开始——在黄金的例子中，我们选择一个假设黄金平滑分布的先验 [3]。 当我们对某些点进行评估（钻探）后，就会获得更多数据供替代模型学习，并根据贝叶斯规则更新模型。

在上面的例子中，我们一开始的不确定性是均匀的。但在第一次更新后，后验在 x = 0.5 附近变得确定，而远离该点的位置则仍不确定。我们可以继续添加更多训练点，从而获得对 f(x) 更确定的估计。

然而，我们希望最小化评估次数。因此，我们应该使用主动学习“聪明地”选择下一个查询点。虽然有多种选择聪明点的方法，但我们这里将选择不确定性最大的那个点。

这就得到了主动学习的以下流程：

  1. 选择不确定性最高的点，查询（标记）它并加入训练集
  2. 在新的训练集上训练模型
  3. 重复第 1 步，直到收敛或预算耗尽

现在让我们可视化这个过程，看看在每次迭代（每次钻探后）我们的后验是如何变化的。

可视化结果表明，我们可以在几次迭代内就估计出真实分布。此外，不确定性最大的位置通常是当前已评估点最远的地方。在每次迭代中，主动学习都在探索整个空间以提升估计质量。

贝叶斯优化

在前一节中，我们选择点的目的是构建一个准确的黄金含量模型。但如果我们的目标仅仅是找到黄金含量最高的位置呢？当然，我们可以先用主动学习准确估计出真实函数，再找到它的最大值。但这显得相当浪费——既然我们只关心最大值，为什么还要浪费评估去改进那些预期黄金含量很低的区域呢？

这就是贝叶斯优化的核心问题：“根据我们目前所知，接下来应该评估哪一个点？”请记住，评估每个点的成本都很高，因此我们必须谨慎选择！在主动学习中，我们选择最不确定的点，从而探索函数。但在贝叶斯优化中，我们需要在探索不确定区域（这些区域可能意外地含有高黄金含量）与利用已知的高含量区域（一种“开发”行为）之间取得平衡。

我们通过一种称为采集函数（acquisition function）的机制来做出这个决策。采集函数是根据当前模型判断评估某个点是否值得的启发式规则[4]。本节的大部分内容将介绍不同的采集函数选项。

这就引出了贝叶斯优化的工作原理。在每一步中，我们根据采集函数优化它，以确定下一个最值得评估的点。然后更新模型，并重复这个过程来确定下一个待评估点。

你可能会好奇，如果我们只是在优化这些采集函数，那么贝叶斯优化中的“贝叶斯”体现在哪里呢？其实，在每一步中，我们都维护着一个描述各点估计值和不确定性的模型，并根据贝叶斯规则(Settles, 2009)不断更新它。我们的采集函数正是建立在这个模型之上的，没有它一切都无从谈起！

形式化贝叶斯优化

现在让我们正式介绍贝叶斯优化。我们的目标是找到对应于某个函数 f: \mathbb{R}^d \mapsto \mathbb{R} 全局最大值（或最小值）的位置 ({x \in \mathbb{R}^d})。 我们将给出贝叶斯优化的一般约束条件，并与黄金开采例子中的约束进行对比[5]。

General Constraints

Constraints in Gold Mining example
f’s feasible set A is simple, e.g., box constraints. Our domain in the gold mining problem is a single-dimensional box constraint: 0 \leq x \leq 6.
f is continuous but lacks special structure, e.g., concavity, that would make it easy to optimize. Our true function is neither a convex nor a concave function, resulting in local optimums.
f is derivative-free: evaluations do not give gradient information. Our evaluation (by drilling) of the amount of gold content at a location did not give us any gradient information.
f is expensive to evaluate: the number of times we can evaluate it is severely limited. Drilling is costly.
f may be noisy. If noise is present, we will assume it is independent and normally distributed, with common but unknown variance. We assume noiseless measurements in our modeling (though, it is easy to incorporate normally distributed noise for GP regression).

为解决这个问题，我们将遵循以下算法：

  1. 首先选择一个替代模型来建模真实函数 f，并定义其先验。
  2. 给定已有的观测集合（函数评估结果），使用贝叶斯规则得到后验分布。
  3. 使用采集函数 \alpha(x)（它是后验的函数）来决定下一个采样点 x_t = \text{argmax}_x \alpha(x)。
  4. 将新采样的数据加入观测集合，回到第 2 步，直到收敛或预算耗尽。

采集函数

采集函数是贝叶斯优化的核心，有各种各样的选择[6]。在接下来的几节中，我们将逐一介绍几种常见方法，并提供直观解释和示例。

改进概率（Probability of Improvement，PI）

该采集函数选择下一个查询点为相对于当前最大值 f(x^+) 具有最高改进概率的点。从数学上，我们将下一个点的选择写为：

x_{t+1} = argmax(\alpha_{PI}(x)) = argmax(P(f(x) \geq (f(x^+) +\epsilon)))
\begin{aligned} x_{t+1} & = argmax(\alpha_{PI}(x))\\ & = argmax(P(f(x) \geq (f(x^+) +\epsilon))) \end{aligned}

其中，

  • P(\cdot) 表示概率
  • \epsilon 是一个很小的正数
  • 并且 x^+ = \text{argmax}_{x_i \in x_{1:t}}f(x_i)，其中 x_i 是在第 i^{th} 个时间步查询的位置。

仔细看，我们其实就是在计算替代模型后验的上尾概率（或累积分布函数 CDF）。如果我们使用高斯过程作为替代模型，上式可以简化为：

x_{t+1} = argmax_x \Phi\left(\frac{\mu_t(x) - f(x^+) - \epsilon}{\sigma_t(x)}\right)

其中，

  • \Phi(\cdot) 表示累积分布函数（CDF）

下面的可视化展示了 \alpha_{PI}(x) 的计算过程。橙色直线表示当前最大值（加上一个 \epsilon），即 f(x^+) + \epsilon。紫色区域显示了每个点的概率密度。灰色区域表示低于当前最大值的概率密度。每个点处紫色区域的“面积”代表“超越当前最大值的改进概率”。通过 PI 准则选择的下一个评估点（用蓝色虚线表示）是 x = 6。

PI 使用 \epsilon 来平衡探索与开发。 增大 \epsilon 会导致查询那些 \sigma 更大的位置，因为它们的概率密度分布更广。

从上面的图可以看出，我们在几次迭代后就到达了全局最大值[7]。 在最初几次迭代中，替代模型在 x \in [2, 4] 处具有很大的不确定性[8]。 采集函数最初会利用那些看起来很有前景的区域[9]，这导致 x \in [2, 4] 区域出现较高的不确定性。这一观察也表明，我们并不需要构建黑盒函数的精确估计，就能找到它的最大值。

如果我们把 \epsilon 再增大一点会发生什么？

我们发现情况变糟了！模型现在主要使用 \epsilon = 3，当我们接近全局最大值时无法有效利用（开发）。而且，高探索程度使得整个过程变得类似于主动学习。

以上快速实验帮助我们得出结论：\epsilon 控制了 PI 采集函数的探索程度。

期望改进（Expected Improvement，EI）

改进概率只考虑了改进发生的可能性，却没有考虑能改进多少。下一个准则称为期望改进（EI），它正是弥补了这一点[10]！ 其思想非常简单——选择下一个查询点为相对于当前最大值 f(x^+) 具有最高期望改进的点，其中 x^+ = \text{argmax}_{x_i \in x_{1:t}}f(x_i) 且 x_i 是在第 i^{th} 个时间步查询的位置。

在这个采集函数中，查询点 x_{t+1} 是按照以下公式选择的：t + 1^{th}

x_{t+1} = argmin_x \mathbb{E} \left( ||h_{t+1}(x) - f(x^\star) || \ | \ \mathcal{D}_t \right)

其中，f 是真实的地面真实函数，h_{t+1} 是替代模型在第 t+1^{th} 步的后验均值，\mathcal{D}_t 是训练数据 \{(x_i, f(x_i))\} \ \forall x \in x_{1:t}，x^\star 是 f 取得最大值的真实位置。

本质上，我们试图选择能最小化与目标函数在最大值处评估结果之间距离的点。不幸的是，我们并不知道真实函数 f。Mockus(B. Mockus et al., 1991) 提出了以下采集函数来解决这个问题：

x_{t+1} = argmax_x \mathbb{E} \left( {max} \{ 0, \ h_{t+1}(x) - f(x^+) \} \ | \ \mathcal{D}_t \right)
\begin{aligned} x_{t+1} = \ & argmax_x \mathbb{E} \\ & \left( {max} \{ 0, \ h_{t+1}(x) - f(x^+) \} \ | \ \mathcal{D}_t \right) \end{aligned}

其中 f(x^+) 是迄今为止遇到的最大值。对于高斯过程替代模型，该式有如下解析表达式：

EI(x)= \begin{cases} (\mu_t(x) - f(x^+) - \epsilon)\Phi(Z) + \sigma_t(x)\phi(Z), & \text{if}\ \sigma_t(x) > 0 \\ 0, & \text{if}\ \sigma_t(x) = 0 \end{cases}
EI(x)= \begin{cases} [(\mu_t(x) - f(x^+) - \epsilon) & \ \sigma_t(x) > 0 \\ \quad * \Phi(Z)] + \sigma_t(x)\phi(Z),\\ 0, & \ \sigma_t(x) = 0 \end{cases}
Z= \frac{\mu_t(x) - f(x^+) - \epsilon}{\sigma_t(x)}

其中 \Phi(\cdot) 表示累积分布函数（CDF），\phi(\cdot) 表示概率密度函数（pdf）。

从上面的表达式可以看出，当以下情况发生时期望改进会比较高：i) \mu_t(x) - f(x^+) 的期望值较高，或者 ii) 某点周围的不确定性 \sigma_t(x) 较高。

和 PI 采集函数一样，我们可以通过修改 \epsilon 来调节 EI 采集函数的探索程度。

当 \epsilon = 0.01 时，我们能在几次迭代内接近全局最大值。

现在我们增大 \epsilon 以进行更多探索。

正如我们所料，将值增大到 \epsilon = 0.3 使采集函数探索得更多。与之前的评估相比，我们看到开发（exploitation）减少了。它只在全局最大值附近评估了两个点。

让我们把 \epsilon 再增大一些。

这比之前更好吗？结果是既好也不好；我们在 \epsilon = 3 探索过多，快速到达全局最大值附近。但遗憾的是，我们没有进行足够的开发以在全局最大值附近获得更多收益。

PI 与 EI 的对比

我们已经看到了两种密切相关的方法：改进概率（PI）和期望改进（EI）。

上面的散点图展示了不同采集函数在不同点上的策略[11]。 我们看到 \alpha_{EI} 和 \alpha_{PI} 分别达到了 0.3 和大约 0.47 的最大值。选择低 \alpha_{PI} 和高 \alpha_{EI} 的点对应于高风险[12] 和高回报[13]。 当多个点具有相同的 \alpha_{EI} 时，我们应该优先选择风险较小的点（更高的 \alpha_{PI}）。类似地，当风险相同时（相同的 \alpha_{PI}），我们应该选择回报更大的点（更高的 \alpha_{EI}）。

Thompson Sampling

另一种常见的采集函数是 Thompson Sampling(Thompson, 1933)。在每一步中，我们从替代模型的后验中采样一个函数，并对它进行优化。例如，在黄金开采问题中，我们会根据已有证据采样一个合理的黄金分布，然后在它峰值所在的位置进行评估（钻探）。

下面这张图展示了针对我们黄金开采问题，从学到的替代模型后验中采样的三个函数。训练数据只包含点 x = 0.5 及其对应的函数值。

我们可以通过两个观察来理解 Thompson Sampling 的直观原理：

  • Locations with high uncertainty ( \sigma(x) ) will show a large variance in the functional values sampled from the surrogate posterior. Thus, there is a non-trivial probability that a sample can take high value in a highly uncertain region. Optimizing such samples can aid exploration. As an example, the three samples (sample #1, #2, #3) show a high variance close to x=6. Optimizing sample 3 will aid in exploration by evaluating x=6.
  • The sampled functions must pass through the current max value, as there is no uncertainty at the evaluated locations. Thus, optimizing samples from the surrogate posterior will ensure exploiting behavior. As an example of this behavior, we see that all the sampled functions above pass through the current max at x = 0.5. If x = 0.5 were close to the global maxima, then we would be able to exploit and choose a better maximum.

上面的可视化使用了 Thompson Sampling 进行优化。同样，我们能在相对较少的迭代中达到全局最优。

采集函数总结

现在让我们总结采集函数的核心思想：i) 它们是评估一个点效用的启发式规则；ii) 它们是替代模型后验的函数；iii) 它们结合了探索与开发；iv) 它们计算成本低廉。

其他采集函数

目前我们已经看到了多种采集函数。构造采集函数的一种简单方法就是对探索和开发进行组合。

上置信界（Upper Confidence Bound，UCB）

一种简单且能平衡探索与开发权衡的采集函数，是将替代模型的均值和不确定性进行线性组合。模型均值代表开发（利用模型已有的知识），模型不确定性代表探索（因为模型缺乏对这些区域的观测）。

\alpha(x) = \mu(x) + \lambda \times \sigma(x)

UCB 采集函数的直观思想是在替代模型的均值与不确定性之间进行权衡。上式中的 \lambda 是一个超参数，可以控制是更偏好开发还是探索。

我们还可以通过组合已有的采集函数来构造新的采集函数，尽管这种组合的物理意义可能不是那么直观。我们想要组合两种方法的原因之一，是为了克服单一方法的局限性。

改进概率 + 期望改进（EI-PI）\lambda \ \times

一种这样的组合可以是 PI 和 EI 的线性加权。 我们知道 PI 关注改进的概率，而 EI 关注改进的期望值。这种组合可以根据 \lambda 的取值，在两者之间取得权衡。

高斯过程上置信界（Gaussian Process Upper Confidence Bound，GP-UCB）

在讨论 GP-UCB 之前，我们先简单介绍一下遗憾（regret）的概念。假设最大黄金含量是 a 单位，而我们的优化算法却采样到一个只含有 b < a 单位的地点，那么我们的单步遗憾为 a - b。如果我们把 n 次迭代的遗憾累加起来，就得到了所谓的累计遗憾。 GP-UCB(Auer, 2003) 的形式化定义为：

\alpha_{GP-UCB}(x) = \mu_t(x) + \sqrt{\beta_t}\sigma_t(x)

其中 t 表示时间步。

Srinivas 等人(Srinivas et al., 2009) 为 \beta 设计了一个调度策略，并在理论上证明它能够最小化累计遗憾。

对比实验

现在我们对比不同采集函数在黄金开采问题上的性能[14]。我们为每种采集函数都使用了最优的超参数。 我们多次运行随机采集函数，使用不同随机种子，并绘制每次迭代感知到的平均黄金含量。

随机策略在一开始的表现与其他采集函数相当甚至更好[15]。然而，随机策略感知到的最大黄金含量增长得非常缓慢。相比之下，其他采集函数能在很少的迭代次数内就找到一个不错的解。事实上，大多数采集函数在仅仅三次迭代内就能非常接近全局最大值。

超参数调优

在讨论用于超参数调优的贝叶斯优化(Snoek et al., 2012; Bergstra et al., 2011; Bergstra et al., 2013)之前，我们先快速区分一下超参数（hyperparameters）和参数（parameters）：超参数是在学习之前设定的，而参数是从数据中学习得到的。为了说明区别，我们以岭回归（Ridge regression）为例。

\hat{\theta}_{ridge} = argmin_{\theta\ \in \ \mathbb{R}^p} \sum\limits_{i=1}^{n} \left(y_i - x_i^T\theta \right)^2 + \lambda \sum\limits_{j=1}^{p} \theta^2_j
\begin{aligned} \hat{\theta}_{ridge} = & argmin_{\theta\ \in \ \mathbb{R}^p} \sum\limits_{i=1}^{n} \left(y_i - x_i^T\theta \right)^2 \\ & + \lambda \sum\limits_{j=1}^{p} \theta^2_j \end{aligned}

在岭回归中，权重矩阵 \theta 是模型参数，而正则化系数 \lambda \geq 0 是超参数。 如果我们通过梯度下降来求解上面的回归问题，我们还会引入另一个优化参数，即学习率 \alpha。

贝叶斯优化最常见的应用场景就是超参数调优：为机器学习模型找到表现最好的超参数组合。

当训练一个模型并不昂贵且耗时不长时，我们可以使用网格搜索来寻找最优超参数。然而，如果函数评估代价很高（例如训练一个大型神经网络可能需要几天），网格搜索就变得不可行。此外，网格搜索在超参数数量增加时的扩展性很差。

因此，我们转向贝叶斯优化来应对评估黑盒函数（模型准确率）代价高昂的问题。

让我们通过这个例子来了解如何将贝叶斯优化应用于神经网络的训练。这里我们将使用 scikit-optim，它还支持对包含类别、整数和实数变量的搜索空间进行优化。我们不会在这里绘制真实函数的图像，因为成本极高。下面是一些代码片段，展示了使用贝叶斯优化包进行超参数调优的便捷性。

代码首先声明了优化问题的搜索空间。我们将搜索空间限制为以下范围：

  • batch_size — This hyperparameter sets the number of training examples to combine to find the gradients for a single step in gradient descent. Our search space for the possible batch sizes consists of integer values s.t. batch_size = 2^i \ \forall \ 2 \leq i \leq 7 \ \& \ i \in \mathbb{Z}.
  • learning rate — This hyperparameter sets the stepsize with which we will perform gradient descent in the neural network. We will be searching over all the real numbers in the range [10^{-6}, \ 1].
  • activation — We will have one categorical variable, i.e. the activation to apply to our neural network layers. This variable can take on values in the set \{ relu, \ sigmoid \}.

          log_batch_size = Integer(
            low=2,
            high=7,
            name='log_batch_size'
          )
            lr = Real(
            low=1e-6,
            high=1e0,
            prior='log-uniform',
            name='lr'
          )
          activation = Categorical(
            categories=['relu', 'sigmoid'],
            name='activation'
          )

          dimensions = [
            dim_num_batch_size_to_base,
            dim_learning_rate,
            dim_activation
          ]

接下来从 scikit-optim 中导入 gp-minimize[18] 来执行优化。下面我们展示的是使用 Expected Improvement 的调用方式，当然我们也可以从其他多种采集函数中选择。

让我们把数字放到整体视角下。如果使用网格搜索完成这个优化，大约需要 (5 \times 2 \times 7) 次迭代。而贝叶斯优化只用了七次迭代。每次迭代大约需要十五分钟，这意味着网格搜索完成大约需要十七个小时！

结论与总结

在本文中，我们介绍了用于优化黑盒函数的贝叶斯优化。当函数评估代价昂贵，使得网格搜索或穷举搜索不切实际时，贝叶斯优化是非常适合的选择。我们探讨了贝叶斯优化的关键组成部分。首先，我们介绍了使用替代函数（带有目标函数空间上的先验）来建模黑盒函数的概念。接着，我们解释了贝叶斯优化中的“贝叶斯”——函数评估结果被当作数据来更新替代模型的后验。我们还介绍了采集函数，它们是替代模型后验的函数，并被依次优化。这种新的序列优化计算开销很小，因此非常实用。我们还介绍了几种采集函数，并展示了它们如何平衡探索与开发。最后，我们通过一些实际例子展示了贝叶斯优化在机器学习模型超参数调优中的应用。
