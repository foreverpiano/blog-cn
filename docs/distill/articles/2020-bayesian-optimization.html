探索贝叶斯优化

2020-05-05 · 阅读原文

许多现代机器学习算法都有大量的超参数。要有效使用这些算法，我们需要选择合适的超参数值。 在本文中，我们将讨论贝叶斯优化（Bayesian Optimization），这是一系列常用于调优超参数的技术。更广泛地说，贝叶斯优化可用于优化任何黑盒函数。

<p> 我们首先研究如何使用贝叶斯优化来最大化（优化）一个黑盒函数。 </p>

采矿找金！

让我们从金矿开采的例子开始。我们的目标是在一片未知的土地上开采黄金[1]。 目前我们假设黄金分布在一条直线上。我们希望仅通过少量钻探（因为钻探成本高昂）就能找到这条线上黄金含量最高的位置。

假设黄金分布 f(x) 看起来像下面这个函数。它是双峰的，在 x = 5 附近达到最大值。目前我们不用担心 X 轴或 Y 轴的单位。

最初，我们对黄金分布一无所知。我们可以通过在不同位置钻探来了解黄金分布。然而，钻探成本高昂。因此，我们希望在尽可能少钻探的情况下，快速找到黄金含量最高的位置。

现在我们讨论黄金开采问题的两个常见目标。

问题 1：黄金分布的最佳估计（主动学习） 在这个问题中，我们希望准确估计新土地上的黄金分布。由于成本过高，我们无法在每个位置都钻探。相反，我们应该在那些能提供关于黄金分布最多信息的位置钻探。这个问题类似于 主动学习（Active Learning）[[settles2009active,Tong2001]] 。 问题 2：黄金含量最高的位置（贝叶斯优化） 在这个问题中，我们希望找到黄金含量最高的位置。我们同样无法在每个位置都钻探。相反，我们应该在那些显示出高含金量前景的位置钻探。这个问题类似于 贝叶斯优化（Bayesian Optimization）[[humanOut,nandoBOtut]] 。

我们很快就会看到这两个问题既相关但又不完全相同。

主动学习

对于许多机器学习问题，无标签数据很容易获得。然而，标注（或查询）通常代价高昂。例如，在语音转文本任务中，标注需要专家手动标记单词和句子。同样，在我们的黄金开采问题中，钻探（类似于标注）代价昂贵。

主动学习旨在最小化标注成本，同时最大化模型准确率。虽然主动学习文献中有多种方法，但我们重点关注不确定性减少。这种方法建议标注模型不确定性最高的数据点。通常，方差被用作不确定性的度量。

由于我们只在少数几个点知道函数的真实值，我们需要一个替代模型来估计函数在其他地方的值。这个替代模型应该足够灵活，能够模拟真实函数。使用高斯过程（Gaussian Process，简称 GP）是一种常见选择，既因为它的灵活性，也因为它能提供不确定性估计 [2]。

我们的替代模型从先验 f(x) 开始——在黄金的例子中，我们选择一个假设黄金平滑分布的先验 [3]。 当我们评估点（钻探）时，会获得更多数据供替代模型学习，并根据贝叶斯法则更新模型。

在上面的例子中，我们最初对所有位置的不确定性是均匀的。但在第一次更新后，后验在 x = 0.5 附近变得确定，而远离该点的位置则仍不确定。我们可以继续添加更多训练点，从而获得对 f(x) 更确定的估计。

然而，我们希望最小化评估次数。因此，我们应该使用主动学习“聪明地”选择下一个查询点。虽然有多种选择聪明点的方法，但我们将选择不确定性最大的那个。

贝叶斯优化

在前一节中，我们选择点是为了建立一个准确的黄金含量模型。但如果我们的目标仅仅是找到黄金含量最高的位置呢？当然，我们可以先进行主动学习来准确估计真实函数，然后再找到其最大值。但这似乎相当浪费——为什么要在那些函数预期含金量很低的区域花费评估来改进估计呢，当我们只关心最大值的时候？

这正是贝叶斯优化的核心问题：“基于我们目前所知，接下来应该评估哪个点？”请记住，评估每个点的代价都很高，因此我们必须谨慎选择！在主动学习中，我们选择不确定性最大的点，从而探索函数。但在贝叶斯优化中，我们需要在探索不确定区域（这些区域可能意外含有高金含量）与专注于已知含金量较高的区域（一种利用策略）之间取得平衡。

我们通过所谓的采集函数（acquisition function）来做出这个决策。采集函数是根据当前模型判断评估某个点有多值得的启发式方法[4]。本节的大部分内容将介绍不同的采集函数选项。

这就引出了贝叶斯优化的工作原理。在每一步中，我们根据采集函数优化它来确定下一个最佳评估点。然后更新我们的模型，并重复这个过程来确定下一个要评估的点。

你可能会好奇，如果我们只是在优化这些采集函数，那么贝叶斯优化中的“贝叶斯”体现在哪里呢？实际上，在每一步中，我们都维护一个描述每个点估计值和不确定性的模型，并根据贝叶斯法则在每一步更新它[settles2009active]。我们的采集函数正是基于这个模型，如果没有它，一切都无从谈起！

<p> 在这个问题中，我们的目标是找到黄金含量最高的位置。找到最大值的一种方法是先运行主动学习来准确估计真实函数，然后再找到其最大值。然而，当我们只关心找到最大值时，是否应该浪费评估来改进估计呢？假设我们的黑盒函数是光滑的，那么在替代模型预测值最高的位置或其附近进行评估（即<strong>利用</strong>）可能是个好主意。然而，由于评估次数有限，我们模型的预测并不准确。可以通过在方差较大的点进行评估来改进模型，即进行<strong>探索</strong>。贝叶斯优化将<strong>利用</strong>和<strong>探索</strong>结合起来，而主动学习则只进行<strong>探索</strong>。 </p>

General Constraints

Constraints in Gold Mining example
f’s feasible set A is simple, e.g., box constraints. Our domain in the gold mining problem is a single-dimensional box constraint: 0 \leq x \leq 6.
f is continuous but lacks special structure, e.g., concavity, that would make it easy to optimize. Our true function is neither a convex nor a concave function, resulting in local optimums.
f is derivative-free: evaluations do not give gradient information. Our evaluation (by drilling) of the amount of gold content at a location did not give us any gradient information.
f is expensive to evaluate: the number of times we can evaluate it is severely limited. Drilling is costly.
f may be noisy. If noise is present, we will assume it is independent and normally distributed, with common but unknown variance. We assume noiseless measurements in our modeling (though, it is easy to incorporate normally distributed noise for GP regression).

为了解决这个问题，我们将遵循以下算法：

首先选择一个替代模型来建模真实函数 f，并定义其先验。 给定观测集合（函数评估值），使用贝叶斯法则获得后验。 使用采集函数 \alpha(x)（它是后验的函数）来决定下一个采样点 x_t = \text{argmax}_x \alpha(x)。 将新采样的数据添加到观测集合中，然后返回第 2 步，直到收敛或预算用尽。

改进概率（Probability of Improvement，PI）

这个采集函数选择下一个查询点为那个相比当前最大值 f(x^+) 具有最高改进概率的点。从数学上，我们将下一个点的选择写成如下形式，

x_{t+1} = argmax(\alpha_{PI}(x)) = argmax(P(f(x) \geq (f(x^+) +\epsilon)))
\begin{aligned} x_{t+1} & = argmax(\alpha_{PI}(x))\\ & = argmax(P(f(x) \geq (f(x^+) +\epsilon))) \end{aligned}

其中，

P(\cdot) 表示概率 \epsilon 是一个小的正数 并且， x^+ = \text{argmax}_{x_i \in x_{1:t}}f(x_i) 其中 x_i 是在第 i^{th} 时间步查询的位置。

仔细观察，我们只是在计算替代模型后验的上尾概率（或累积分布函数）。此外，如果我们使用 GP 作为替代模型，上面的表达式可以转化为，

x_{t+1} = argmax_x \Phi\left(\frac{\mu_t(x) - f(x^+) - \epsilon}{\sigma_t(x)}\right)

其中，

\Phi(\cdot) 表示累积分布函数

下面的可视化展示了 \alpha_{PI}(x) 的计算过程。橙色线表示当前最大值（加上一个 \epsilon）或 f(x^+) + \epsilon。紫色区域显示了每个点的概率密度。灰色区域显示了当前最大值以下的概率密度。每个点处紫色区域的“面积”代表“超过当前最大值的改进概率”。通过 PI 准则选择的下一个评估点（用蓝色虚线表示）是 x = 6。

的直观理解

PI 使用 \epsilon 来平衡探索和利用。 增大 \epsilon 会导致查询那些具有更大 \sigma 的位置，因为它们的概率密度分布更广。

期望改进（Expected Improvement，EI）

改进概率只考虑了改进的可能性，但没有考虑我们可以改进多少。下一个准则称为期望改进（EI），它正是做这件事的[10]！ 其思想相当简单——选择下一个查询点为那个相比当前最大值 f(x^+) 具有最高期望改进的点，其中 x^+ = \text{argmax}_{x_i \in x_{1:t}}f(x_i) 且 x_i 是在第 i^{th} 时间步查询的位置。

在这个采集函数中，t + 1^{th} 查询点 x_{t+1} 是根据以下方程选择的。

x_{t+1} = argmin_x \mathbb{E} \left( ||h_{t+1}(x) - f(x^\star) || \ | \ \mathcal{D}_t \right)

其中，f 是真实的地面真实函数，h_{t+1} 是替代模型在第 t+1^{th} 时间步的后验均值，\mathcal{D}_t 是训练数据 \{(x_i, f(x_i))\} \ \forall x \in x_{1:t}，而 x^\star 是 f 取得最大值的实际位置。

本质上，我们试图选择能最小化到目标在最大值处评估结果的距离的点。不幸的是，我们不知道地面真实函数 f。Mockus[[mockusEI]] 提出了以下采集函数来解决这个问题。

x_{t+1} = argmax_x \mathbb{E} \left( {max} \{ 0, \ h_{t+1}(x) - f(x^+) \} \ | \ \mathcal{D}_t \right)
\begin{aligned} x_{t+1} = \ & argmax_x \mathbb{E} \\ & \left( {max} \{ 0, \ h_{t+1}(x) - f(x^+) \} \ | \ \mathcal{D}_t \right) \end{aligned}

其中 f(x^+) 是迄今为止遇到的最大值。对于 GP 替代模型，这个方程有一个解析表达式，如下所示。

EI(x)= \begin{cases} (\mu_t(x) - f(x^+) - \epsilon)\Phi(Z) + \sigma_t(x)\phi(Z), & \text{if}\ \sigma_t(x) > 0 \\ 0, & \text{if}\ \sigma_t(x) = 0 \end{cases}
EI(x)= \begin{cases} [(\mu_t(x) - f(x^+) - \epsilon) & \ \sigma_t(x) > 0 \\ \quad * \Phi(Z)] + \sigma_t(x)\phi(Z),\\ 0, & \ \sigma_t(x) = 0 \end{cases}
Z= \frac{\mu_t(x) - f(x^+) - \epsilon}{\sigma_t(x)}

其中 \Phi(\cdot) 表示累积分布函数，\phi(\cdot) 表示概率密度函数。

从上面的表达式可以看出，当以下情况之一发生时，期望改进会较高：i) \mu_t(x) - f(x^+) 的期望值较高，或者 ii) 某个点周围的不确定性 \sigma_t(x) 较高。

与 PI 采集函数类似，我们可以通过修改 \epsilon 来调节 EI 采集函数的探索量。

对于 \epsilon = 0.01，我们在几次迭代内就接近了全局最大值。

现在我们增加 \epsilon 以进行更多探索。

正如我们所料，将值增加到 \epsilon = 0.3 使采集函数探索得更多。与之前的评估相比，我们看到利用行为减少了。我们看到它只在全局最大值附近评估了两个点。

PI 与 EI

我们已经看到了两种密切相关的方法：改进概率和期望改进。

上面的散点图显示了不同策略的采集函数在不同点上的评估结果[11]。 我们看到 \alpha_{EI} 和 \alpha_{PI} 分别达到了 0.3 和大约 0.47 的最大值。选择具有低 \alpha_{PI} 和高 \alpha_{EI} 的点意味着高风险[12]和高回报[13]。 如果有多个点具有相同的 \alpha_{EI}，我们应该优先选择风险较低（\alpha_{PI} 较高）的点。类似地，当风险相同时（\alpha_{PI} 相同），我们应该选择回报更大的点（\alpha_{EI} 更高）。

Thompson 采样

另一个常见的采集函数是 Thompson 采样[[thompson]]。在每一步中，我们从替代模型的后验中采样一个函数并对其进行优化。例如，在黄金开采的例子中，我们会根据已有证据采样一个可能的黄金分布，然后在它峰值所在的位置进行评估（钻探）。

下面是一张图片，展示了针对我们黄金开采问题，从学到的替代模型后验中采样的三个函数。训练数据由点 x = 0.5 及其对应的函数值构成。

我们可以通过两个观察来理解 Thompson 采样的直观原理：

具有高不确定性（ \sigma(x) ）的位置，在从替代模型后验中采样的函数值上会表现出较大的方差。因此，存在非平凡的概率使样本在高度不确定的区域取得高值。优化这样的样本有助于探索。 例如，三个样本（样本 #1、#2、#3）在 x=6 附近显示出较高的方差。优化样本 3 将通过评估 x=6 来帮助探索。 采样的函数必须经过当前最大值，因为在已评估的位置没有不确定性。因此，优化来自替代模型后验的样本将确保利用行为。 作为这种行为的一个例子，我们看到上面所有采样的函数都经过了当前最大值所在的 x = 0.5。如果 x = 0.5 接近全局最大值，那么我们就能够进行利用并选择更好的最大值。

上面的可视化使用了 Thompson 采样进行优化。同样，我们可以在相对较少的迭代中达到全局最优。

采集函数总结

现在让我们总结与采集函数相关的核心思想：i) 它们是评估点效用的启发式方法；ii) 它们是替代模型后验的函数；iii) 它们结合了探索和利用；iv) 它们评估起来代价低廉。

其他采集函数

截至目前我们已经看到了多种采集函数。想出采集函数的一个简单方法是进行探索/利用的组合。

上置信界（Upper Confidence Bound，UCB）

一种将探索/利用权衡结合起来的简单采集函数，是我们替代模型均值和不确定性的线性组合。模型均值代表利用（利用我们模型的知识），而模型不确定性代表探索（由于我们模型缺乏观测）。

\alpha(x) = \mu(x) + \lambda \times \sigma(x)

UCB 采集函数背后的直观理解是在替代模型的均值与不确定性之间权衡重要性。上面的 \lambda 是一个超参数，可以控制是偏好利用还是探索。

我们还可以通过组合现有的采集函数来形成新的采集函数，尽管这种组合的物理可解释性可能并不那么直接。我们可能想要组合两种方法的一个原因是克服单个方法的局限性。

改进概率 +\lambda \ \times期望改进（EI-PI）

一种这样的组合可以是 PI 和 EI 的线性组合。 我们知道 PI 关注改进的概率，而 EI 关注期望的改进。这种组合可以帮助根据 \lambda 的值在这两者之间取得权衡。

高斯过程上置信界（Gaussian Process Upper Confidence Bound，GP-UCB）

在讨论 GP-UCB 之前，让我们快速谈谈遗憾（regret）。想象一下，如果最大黄金含量是 a 单位，而我们的优化却采样了一个含有 b < a 单位的位置，那么我们的遗憾是 a - b。如果我们将 n 次迭代的遗憾累加起来，就得到了所谓的累积遗憾。 GP-UCB[[gpucb]] 的公式为：

\alpha_{GP-UCB}(x) = \mu_t(x) + \sqrt{\beta_t}\sigma_t(x)

其中 t 是时间步。

Srinivas 等人[[gpucbBounds]] 为 \beta 开发了一个调度方案，他们在理论上证明该方案可以最小化累积遗憾。

现在我们比较不同采集函数在黄金开采问题上的性能[14]。我们为每个采集函数都使用了最优的超参数。 我们使用不同的随机种子多次运行随机采集函数，并绘制每次迭代感知到的平均黄金量。

随机策略在最初的表现与其他采集函数相当甚至更好[15]。然而，随机策略感知到的最大黄金量增长得较为缓慢。相比之下，其他采集函数可以在较少的迭代次数内找到一个好的解。事实上，大多数采集函数在仅仅三次迭代内就能达到非常接近全局最大值的位置。

超参数调优

在讨论用于超参数调优的贝叶斯优化[[Snoek2012,NIPS2011_4443,Bergstra]]之前，我们先快速区分超参数和参数：超参数是在学习之前设置的，而参数则是从数据中学习得到的。为了说明这种区别，我们以岭回归为例。

\hat{\theta}_{ridge} = argmin_{\theta\ \in \ \mathbb{R}^p} \sum\limits_{i=1}^{n} \left(y_i - x_i^T\theta \right)^2 + \lambda \sum\limits_{j=1}^{p} \theta^2_j
\begin{aligned} \hat{\theta}_{ridge} = & argmin_{\theta\ \in \ \mathbb{R}^p} \sum\limits_{i=1}^{n} \left(y_i - x_i^T\theta \right)^2 \\ & + \lambda \sum\limits_{j=1}^{p} \theta^2_j \end{aligned}

在岭回归中，权重矩阵 \theta 是参数，而正则化系数 \lambda \geq 0 是超参数。 如果我们通过梯度下降优化来求解上述回归问题，我们还会引入另一个优化参数，即学习率 \alpha。

贝叶斯优化最常见的应用场景是超参数调优：为机器学习模型找到表现最佳的超参数。

当训练一个模型并不昂贵且不耗时，我们可以使用网格搜索来找到最优超参数。然而，如果函数评估代价高昂（如训练一个大型神经网络需要数天），网格搜索就不可行了。此外，网格搜索在超参数数量增加时扩展性很差。

我们转向贝叶斯优化来应对评估黑盒函数（准确率）代价高昂的问题。

示例 3——神经网络

让我们通过这个例子来了解如何将贝叶斯优化应用于训练神经网络。这里我们将使用 scikit-optim，它还支持对具有分类、整数和实数变量搜索空间的函数进行优化。我们不会在这里绘制地面真实函数，因为这样做代价极高。下面是一些代码片段，展示了使用贝叶斯优化包进行超参数调优的简便性。

代码首先为优化问题声明了一个搜索空间。我们将搜索空间限制为以下内容：

batch_size——这个超参数设置了在梯度下降的单步中组合多少个训练样本来计算梯度。 我们搜索的批量大小可能值为满足 batch_size = 2^i \ \forall \ 2 \leq i \leq 7 \ \& \ i \in \mathbb{Z} 的整数。 learning rate——这个超参数设置了我们在神经网络中进行梯度下降的步长。 我们将在 [10^{-6}, \ 1] 范围内的所有实数上进行搜索。 activation——我们将有一个分类变量，即应用于神经网络层的激活函数。这个变量可以取 \{ relu, \ sigmoid \} 集合中的值。

          log_batch_size = Integer(
            low=2,
            high=7,
            name='log_batch_size'
          )
            lr = Real(
            low=1e-6,
            high=1e0,
            prior='log-uniform',
            name='lr'
          )
          activation = Categorical(
            categories=['relu', 'sigmoid'],
            name='activation'
          )

          dimensions = [
            dim_num_batch_size_to_base,
            dim_learning_rate,
            dim_activation
          ]

结论与总结

在本文中，我们介绍了用于优化黑盒函数的贝叶斯优化。当函数评估代价高昂，使得网格搜索或穷举搜索不切实际时，贝叶斯优化非常适用。我们介绍了贝叶斯优化的关键组成部分。首先，我们了解了使用替代函数（对目标函数空间设置先验）来建模黑盒函数的概念。接下来，我们介绍了贝叶斯优化中的“贝叶斯”——函数评估被用作数据来获得替代模型的后验。我们介绍了采集函数，它们是替代模型后验的函数，并被依次优化。这种新的序贯优化代价低廉，因此对我们很有用。我们还介绍了几种采集函数，并展示了这些不同函数如何平衡探索和利用。最后，我们看了一些将贝叶斯优化用于优化机器学习模型超参数的实际例子。
