Distill 2018 年更新

大约一年多以前，我们正式推出了 Distill——一本开放获取的科学期刊。[1]

此后我们经历了一段激动人心的旅程！从一些非常具体的指标来看，Distill 已经拥有超过百万的独立读者，文章总浏览量超过 290 万次。Distill 论文平均被引用 23 次。[2] 更重要的是，我们发表了几篇高度重视清晰度和可复现性的新论文，我们相信这有助于推动一种新型科学交流风格的发展。

尽管如此，我们仍觉得自己在某些方面做得不够好，或者可以做得更好。为此，我们对如何改进进行了很多反思。具体来说，我们计划做出以下调整：

将指导作者与评估文章分开。 明确并简化 Distill 的审稿流程，包括新增一份审稿人工作表。 优先创建帮助所有人的资源，而非针对个人的长期指导，首先是创建一个 Slack 工作空间（在此加入）。 简化引入代理编辑以解决利益冲突的流程。 明确我们的双重投稿政策。 扩大 Distill 编辑团队，并为进入更多领域建立通道。Arvind Satyanarayan 将加入编辑团队，负责监督 HCI + AI 方向的作品集。

进展顺利的事项

思想的交互界面

我们很容易把解释看作是思想之上的一层润色。我们相信，最好的解释往往要深刻得多：它们是思想的交互界面，是一种思考和与概念互动的方式。在此基础上，我们看到多篇 Distill 文章创建了可视化工具，这些工具将那些思考和互动方式具体化了。

最能体现这类贡献的文章之一是 Gabriel Goh 的动量为何真正有效。Gabe 和其他优化研究者对这个问题的视角可能与从业者熟悉的观点不同。它涉及对优化问题特征值谱的数学形式化，以及一种更非正式的解释和思考方式。在我们看来，传统的学术出版物并不重视阐述技术思想所伴随的直觉——也就是老师在白板上与学生分享的那种直觉。

相比之下，文章中的这张图不仅传达了形式化内容，还分享了作者的部分直觉。在交互性的加持下，它邀请读者进入一种思考方式。最有趣的是，通过将心智模型具体化为一个由计算驱动的界面，作者发现了自己思考不完善的地方——具体来说，引入动量会以出人意料的方式展平特征值谱。

这种界面设计和思考方式对 Distill 来说并不新鲜，但在过去一年里，我们得以帮助推动它向前发展，我们很期待它未来的走向。

作为光谱的参与度

我们发现特别令人兴奋的一点是，文章能够让深入参与思想的过程变得更容易、更流畅。通常，从阅读论文到测试和在其基础上开展工作之间存在巨大跳跃。但我们开始看到一些论文把参与度变成一个连续的光谱：

已经探索了这个想法。 不仅重要概念都配有交互图表，随后还附带一个可以重现该图表的笔记本。 而且包含笔记本的作用远不止让读者测试想法——它让读者无需任何准备就能投入新的研究。 有时只需几分钟就能运行有趣的新实验。特征可视化可解释性的基本构建块可微分图像参数化

截至今天，已有超过 6000 名读者打开过这些笔记本。这大约占到查看了带笔记本链接文章的读者的 3%。

可复现性长期以来被认为是维持科学严谨性的关键组成部分，作者们也越来越倾向于将自己的成果开源，甚至把中间产物（例如数据分析脚本）放到 GitHub 上。浏览器内笔记本让作者能够更进一步，实践我们所说的“主动可复现性”：不仅在技术上可以复现他们的工作，还让这样做变得非常方便。我们希望看到更多作者在这方面投入精力。

科学出版中的软件工程最佳实践

在过去一年里，我们还看到了将软件工程最佳实践应用于运营科学期刊的诸多优势。每一篇 Distill 文章都托管在 GitHub 仓库中，同行评审通过 issue 跟踪器进行。我们发现这种设置让读者对出版过程有了更高的透明度。例如，读者可以看到 Gabriel Goh 的动量文章自首次发表以来的更新，可以逐一查看早期开发过程来了解文章思想的起源，还能阅读审稿过程中的来回讨论。更令人兴奋的是，我们看到读者参与了持续的、发表后的同行评审，包括发送 pull request 来修正错别字，进行更多 深入 编辑 修改，甚至引发了与作者的讨论。

作者也从这种设置中受益，因为 Distill 为科学论文提供了持续集成。在发表前，草稿文章会自动构建并通过受密码保护的 URL 提供服务。作者可以自由分享这些地址来征求初步反馈，并且可以确信读者始终看到的是草稿的最新版本。

挑战与改进

Distill 奖项

遗憾的是，我们尚未颁发 2018 年的 Distill 奖。我们收到了 59 份投稿，其中有几份是包含多个小时内容的讲座系列。我们没有预料到这类内容，因此没有（至今也没有）一个合适的评估流程。部分问题在于我们在内容评估上过于追求完美。未来，我们希望在这一点上更好地平衡，做到既严谨又高效。

我们争取在 2018 年感恩节前颁发 Distill 奖，并希望今后以更及时的方式开展评选流程。

规模较小的社区

Distill 旨在培育一种新型科学交流风格，并建立支持它的生态系统。我们希望随着时间推移扩大这个社区，但目前，与更传统的学术 venues 相比，我们的潜在作者和编辑群体仍然相对较小。

这带来的一个后果是 Distill 的发文量较低（目前共 12 篇论文）。我们对此思考了很多：我们是否应该降低标准？这是不是值得我们担心的问题？

归根结底，我们相信，只要我们的内容足够出色，在可预见的未来做一个规模较小但“量身定制”的期刊也是可以的。我们认为 Distill 主要通过让非传统研究成果获得认可、并展示什么是可能的来服务社区。这需要的是出版物的质量，而非数量。

身处小社区的另一个挑战是，社区成员之间常常存在社会关系。这固然很好，但也意味着我们必须处理大量潜在的利益冲突。这类围绕利益冲突的挑战在新兴领域很常见，我们预计随着编辑团队的成长，这个问题在未来几年会逐渐缓解。然而，在此期间，我们经常需要引入独立的代理编辑来解决利益冲突。

我们之前引入独立编辑的流程是先联系 Distill 指导委员会的成员。（我们非常感谢 Ian Goodfellow 在这方面的耐心帮助。）但由于这种情况越来越常见，我们希望建立一个不需要麻烦指导委员会的机制：

在出现利益冲突时，Distill 编辑将从研究社区中选择一位成员担任该文章的临时“代理编辑”。代理编辑应是相关研究社区的成员，且与作者保持适当距离。使用代理编辑及其身份信息将在审稿流程日志中记录，并在文章发表时公开。

审稿流程

创办 Distill 时，我们采用了一种相当激进的审稿流程。我们知道大多数研究者并不具备撰写 Distill 所追求的那类文章所需的全部技能——尤其是设计技能。因此，我们提供了大量的指导和协助来帮助作者改进文章。

遗憾的是，虽然这确实产出了一些我们引以为傲的文章，但我们也发现自己开始力不从心。Distill 编辑都是志愿者，他们在正常的研究工作之外完成这些任务，而我们一直尝试的这类指导每篇文章可能需要 20 到 80 个小时。因此，编辑们已经严重超负荷。我们还发现编辑们陷入了一种令人瘫痪的双重角色：既要指导作者，又需要对他们的工作做出编辑决定。

对部分作者来说，结果就是审稿流程缓慢且犹豫不决。

我们的作者和编辑都值得被更好对待。为此，Distill 将对审稿流程实施以下政策调整：

Distill 的审稿流程将不再包含指导环节。取而代之的是，我们正在创建其他支持作者的渠道（见下文）。 Distill 将只接收完整的文章投稿，并按其现状进行评估。 我们正在制作一份公开的审稿人工作表，更清晰地定义我们的评审标准。

我们的新政策已在文章投稿页面详细说明。旧政策已归档在此。默认情况下，此政策变更不适用于根据旧政策提交的文章。

Distill 的角色之一是让作者能够进行实验，并为不常见的学术成果提供家园。规范我们的审稿流程并不会改变这一点；我们仍然欢迎那些常规审稿流程未预料到的投稿，并在必要时调整流程。特别是，在接下来的一年里，我们希望增加专注于窄题目的短文章数量。

我们也有兴趣找到支持早期研究结果交流的方式。我们担心当前的期望可能会促使作者等到研究足够成熟才分享，而这可能并非对领域最有利。目前我们不会针对这一点实施任何政策变更，但正在积极考虑各种选项。如果您有想法希望我们考虑，请随时联系！

其他调整

双重投稿政策

为了让 Distill 有效确立非传统出版物的合法地位，它必须被视为一种主要的学术出版物。这意味着 Distill 必须遵循典型的“双重发表”规范。我们也必须避免让外界认为 Distill 是 arXiv 论文之类的“配套博客文章”。

结果就是 Distill 只能考虑与已在其他地方正式发表的内容有实质性差异的文章，并对在其他地方非正式发表的文章持谨慎态度。下面我们针对特定情况提供指引：

无先前发表 / 低调的非正式发表：无需担心！ arXiv 论文：我们完全理解研究者有时需要快速发布结果，而 arXiv 是很好的渠道。只要明确 Distill 是正式出版物，我们很乐意发表你们的论文。无论如何，Distill 版本几乎一定会更加完善。:) 先前的 Workshop / 会议论文：Distill 很高兴发表更完善、更精美的“期刊版本”。（这是科学出版中的正常模式，尽管在机器学习领域较少见。）这些版本必须通过改进阐述、更好地呈现底层洞见和思考方式、整合一系列论文、或增加更好的实验等方式，在先前发表的基础上有实质性推进。 高调的非正式发表：我们将其视为与 workshop 或会议发表非常类似的情况，因此有相同的期望。

支持作者

在过去一年，我们投入了大量精力指导个人撰写 Distill 文章。这通常意味着编辑为每篇投稿自愿提供数十小时的指导。虽然这很有价值，但难以扩展。

在接下来的一年，我们计划更多地关注可扩展的帮助方式，包括：

继续完善Distill 模板，它提供了撰写精美、网页优先的学术论文所需的基础工具。我们即将开始模板第 3 版的开发，并计划通过对作者工作流做出更多明确决策来让它更易于使用。 撰写Distill 风格指南，总结我们发现的最佳实践。我们在编辑文章时经常遇到相同的问题，希望通过将解决方案整合到风格指南中，帮助所有作者避免这些陷阱。 分享我们的Distill 审稿人工作表，让作者可以用来自我评估文章并寻找改进空间。 开设 Distill 社区 Slack 工作空间，让大家可以寻求建议、指导和共同作者。

扩大 Distill 团队

我们认为，扩大 Distill 编辑团队是其长期成功的最重要因素之一。扩大参与 Distill 日常运营的人员范围，能让它更具韧性、更容易扩展，并减少利益冲突问题。

扩大编辑队伍固然重要，但确保我们选对编辑同样重要。这意味着要组建一个深度认同 Distill 独特价值观和使命的团队。为了实现这一点，我们计划对潜在编辑采用以下评估流程：

撰写一篇优秀的 Distill 论文，向我们证明他们深刻理解 Distill 的使命，并具备评估他人工作的技术能力。 与现有编辑进行面试，讨论 Distill 的使命以及编辑的角色。

担任 Distill 编辑意味着要为 Distill 的成功以及你所负责领域作品集的发表决策承担所有权和责任。Distill 编辑是志愿职位，没有报酬——唯一的回报是能在推进一种新型科学出版中扮演关键角色。

作为这个方向的第一步，我们很高兴Arvind Satyanarayan 已经加入 Distill 编辑团队。Arvind 来自数据可视化和人机交互（HCI）社区，最初将专注于这些领域与机器学习交叉的文章。如果 Distill 找到合适的其他编辑，我们很乐意更广泛地扩展对 HCI 的覆盖。

拓展 Distill 领域范围

从长远来看，我们相信 Distill 应该对扩展到其他学科持开放态度，由新的编辑负责不同主题的作品集。

我们之前认为，在探索一种新型出版方式时，Distill 最好专注于一个它拥有编辑专长的“垂直领域”（即机器学习）。我们仍然相信 Distill 只应在拥有专家编辑的领域开展工作，但我们也认为这并非全部故事。只专注于机器学习加剧了我们社区规模小的问题，因为它把我们限制在机器学习与这种交流风格的交集上。

我们现在认为，Distill 的正确策略是在找到合适编辑的前提下，缓慢而谨慎地扩展到其他学科。这些新主题将成为同一个跨学科 Distill 期刊的一部分，就像 PLoS 或 Nature 一样。我们目前不计划细分或特许经营。

在考虑新主题的编辑时，Distill 将采用与所有编辑相同的期望（见上文），但有两点调整：

虽然 Distill 通常不审阅其现有主题范围之外的论文，但我们会为潜在编辑候选人破例。现有编辑团队将评估阐述质量，同时邀请第三方编辑按照 Distill 常规审稿流程帮助我们评估科学价值。由于这类审稿特别困难且成本高昂，我们只会在投稿明显是一篇极具实力的文章时才会推进。 必须有第二位编辑能够共同承担新主题的责任。这可以是现有编辑扩展到另一个主题，也可以是与新编辑一起申请的人。拥有第二位编辑很重要，这样编辑们在遇到困难案例时有人可以讨论，也避免出现单点故障。

结语

Distill 是一本探索新型科学交流风格的年轻期刊。我们在第一年学到了许多宝贵经验，但仍有很大的成长空间。我们希望你能和我们一起，推动科学论文的边界！

Distill 感谢所有至今支持它的研究社区成员——我们的作者、审稿人、编辑、指导委员会成员、每一位在 GitHub 上提供反馈的人，当然还有我们的读者。很高兴有你们与我们同行！
