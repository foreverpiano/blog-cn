关于《对抗样本不是 bug，而是 feature》的讨论

2019-08-06 · 阅读原文

5月6日，Andrew Ilyas 及其同事发表了一篇论文 [[ilyas2019adversarial]]，其中描述了两组实验。首先，他们证明了在对抗样本上训练的模型能够迁移到真实数据上；其次，在从鲁棒神经网络的表征中导出的数据集上训练的模型，似乎也继承了一定程度的非平凡鲁棒性。他们对实验结果提出了一种引人入胜的解释：对抗样本的成因是“non-robust features”，这些特征具有很强的预测能力，但对人类而言却难以察觉。

这篇论文在全球范围内的社交媒体、邮件列表和阅读小组中引发了热烈的关注与讨论。我们应该如何解读这些实验？它们的结果是否可重复？[1] 如果 non-robust features 真的存在……它们又是什么？

为了探讨这些问题，Distill 决定以实验性的方式推出了一篇“讨论文章”。[2] 我们邀请了多位研究者针对该论文撰写评论，并组织了原作者的讨论与回应。

机器学习社区 有时 担忧 同行评审不够深入。与此形成对比的是，我们被评论者们投入的深度所打动。有些评论者真的花了几周时间来复现结果、运行新的实验，并对原论文进行了深入思考。我们还看到评论者在实验过程中不断更新自己对 non-robust features 的看法——有时甚至来回反复。原作者们也同样深度参与讨论，澄清误解，甚至针对评论中的问题运行了新的实验。

我们认为这种深入的参与和讨论非常令人振奋，并希望未来能继续尝试更多类似的讨论文章。

讨论主题

澄清：评论者与原作者之间的讨论揭示了几处误解，同时也为 sharpening 一些表述提供了机会。原作者在他们的反驳中对这些内容进行了总结。

成功复现：评论者成功复现了 Ilyas 等人的论文[[ilyas2019adversarial]]中的许多实验，且没有出现复现失败的情况。这在很大程度上得益于原作者公开了代码、模型和数据集。Gabriel Goh 和 Preetum Nakkiran 两人独立重新实现了 non-robust dataset 实验并成功复现。[3] Preetum 还部分复现了 robust dataset 实验——他在提供的 robust 数据集上训练模型，发现它们确实具有非平凡的鲁棒性。从认识论角度看，值得注意的是 Preetum 和 Gabriel 最初都持怀疑态度。Preetum 强调，他发现让这种现象生效非常容易，而且对其尝试的多种变体和超参数都具有鲁棒性。

探索 non-robust transfer 的边界：三篇评论聚焦于“non-robust dataset”实验的各种变体，即在对抗样本上训练能够迁移到真实数据。这种现象何时、如何以及为何会发生？Gabriel Goh 探索了产生该结果的另一种可能机制；Preetum Nakkiran 展示了一种特殊构造，其中迁移不会发生；Eric Wallace 则表明，对于其他类型的错误标记数据，迁移同样可以发生。

鲁棒与非鲁棒特征的性质：另外三篇评论聚焦于鲁棒和非鲁棒模型的特性。Gabriel Goh 探讨了在线性模型中 non-robust features 可能呈现的样子；Dan Hendrycks 和 Justin Gilmer 讨论了这些结果与分布偏移鲁棒性这一更广泛问题的关联；Reiichiro Nakano 则在风格迁移的背景下探究了鲁棒模型的定性差异。

评论

Distill 收集了六篇针对原论文的评论。它们按作者姓氏的字母顺序呈现，每篇附有简短摘要以及原作者的相应回应。

Justin 和 Dan 将“non-robust features”视为模型因抓住表面相关性而缺乏鲁棒性的一种特例，这种观点在分布鲁棒性文献中很常见。他们以神经网络在频率空间中的行为最新分析为例，强调我们应该思考更广泛的鲁棒性概念。 阅读全文

原作者评论：

模型仅从数据的高频成分中学习的演示是一个有趣的发现，它为我们的模型如何从对人类而言看似“无意义”的数据中学习提供了另一种解释。作者们完全同意，研究更宽泛的鲁棒性概念在机器学习中将变得越来越重要，这将帮助我们更好地理解哪些特征是我们真正希望模型依赖的。

Gabriel 探索了一种可能导致 non-robust transfer 结果的替代机制。他建立了一个下界，表明该机制对 \widehat{\mathcal{D}}_{rand} 实验有少量贡献，但在 \widehat{\mathcal{D}}_{det} 实验中没有发现其产生影响的证据。 阅读全文

原作者评论：

这是一项细致深入的调查，它突出了（并清晰可视化了）设计 \widehat{\mathcal{D}}_{det} 数据集的动机之一。

Gabriel 探索了在线性情况下 non-robust useful features 可能呈现的样子。他给出了两种构造：“contaminated”特征（仅因混入了非有用特征而成为 non-robust），以及可能成为真正的 useful non-robust features 的“ensembles”。 阅读全文

原作者评论：

这些线性模型实验是可视化真实数据集上 non-robust features 的良好开端（同时也很好地印证了它们的存在）。此外，“contaminated” non-robust features 的理论构造为发展更精细的特征定义开辟了一个有趣的方向。

Reiichiro 证明了在非 VGG 架构上，对抗鲁棒性使神经风格迁移默认就能生效。他发现匹配 robust features 会让风格迁移的输出在人类感知上更好看。 阅读全文

原作者评论：

非常有趣的结果，它突出了 non-robust features 的潜在作用，以及鲁棒模型在下游任务中的实用价值。我们很高兴看到经过鲁棒训练的模型在神经网络艺术中将产生怎样的影响！受这些发现启发，我们也对（non-robust）VGG 进行了更深入的分析，并发现了一些鲁棒性与风格迁移之间有趣的联系。

Preetum 构造了一族不会迁移到真实数据的对抗样本，这表明按照原论文的框架，某些对抗样本是“bugs”。Preetum 还证明，即使底层分布不存在“non-robust features”，对抗样本仍然可能出现。 阅读全文

原作者评论：

这是一次细致的分析，它巧妙地支持了我们的论点（即 non-robust features 存在，且对抗样本由它们产生，参见要点 #1），同时也提供了一个由“bugs”产生的对抗样本的例子。构造出的基于“bugs”的对抗样本无法迁移，这一事实为可迁移性与（non-robust）特征之间的联系提供了又一个证据。

Eric 表明，在模型的训练误差上训练，或者在一个不相关数据集上根据其预测方式进行训练，都能迁移到真实的测试集。这些实验与原论文的 non-robust transfer 结果类似——三者都是某种“从错误标记数据中学习”的例子。 阅读全文

原作者评论：

这些实验创造性地证明了，从对“人类无意义”的数据中学习特征这一底层现象，其实可以在极其广泛的情境中出现。

[1] 对抗样本研究特别容易在机器学习不同分支间出现某种非复现现象，因为它要求研究者同时扮演攻击者和防御者的角色。即使非常严谨的研究者也容易不小心使用较弱的攻击。不过正如我们将看到的，Ilyas 等人的结果经受住了初步的严格检验。
[2] 运行讨论文章是 Distill 几年来一直想尝试的事情。最初由 Ferenc Huszár 向我们建议，他经常在自己的博客上撰写精彩的论文讨论。 为什么不让每个人像 Ferenc 一样写私人博客文章呢？Distill 希望通过提供一个更有组织性的平台，让更多人能够参与，从而给予更多研究者投入精力讨论他人工作的许可，并确保各方在最终版本发表前都有机会评论和回应。
[3] Preetum 按照论文所述复现了 \widehat{\mathcal{D}}_{det} non-robust dataset 实验，针对的是 L_\infty 和 L_2 攻击。 Gabriel 复现了针对 L_2 攻击的 \widehat{\mathcal{D}}_{det} 和 \widehat{\mathcal{D}}_{rand} 实验。
