关于《对抗样本不是缺陷，而是特征》的讨论：稳健特征泄漏

其他评论

Ilyas 等人的评论

Ilyas 等[[ilyas2019adversarial]]报告了一个令人惊讶的结果：在一个对抗样本上训练的模型在干净数据上也能有效。他们认为这种迁移是由对抗样本中包含真正有用的非稳健线索所驱动的。但另一种可能的迁移机制是某种“稳健特征泄漏”，即模型捕捉到了攻击中微弱的稳健线索。

Ilyas 等<d-cite key="ilyas2019adversarial"></d-cite>表明，在对抗样本上训练的模型在干净数据上也有效，这是一个非常令人惊讶的结果。<d-cite key="ilyas2019adversarial"></d-cite>认为，其背后的主要驱动力是对手叠加在数据集上的非稳健线索。然而，如果对抗样本也包含稳健线索（尽管可能很微弱），这就为这种迁移提供了另一种机制。

我们证明，在D_\text{rand}上，至少23.5%（总准确率88%）的精度可以由稳健特征来解释。这是一个较弱的下界，由线性模型得出，并不排除进一步泄漏的可能性。另一方面，我们在D_\text{det}中没有发现泄漏的证据。

对泄漏进行下界估计

我们量化泄漏的方法包括两个步骤：

首先，我们构造特征f_i(x) = w_i^Tx，这些特征在即将说明的意义上被证明是稳健的。 接下来，我们仅使用这些稳健特征，在数据集\hat{\mathcal{D}}_{\text{det}}和\hat{\mathcal{D}}_{\text{rand}}（定义见[[ilyas2019adversarial]]，表 1）上训练一个线性分类器[1]。

在\hat{\mathcal{D}}_{\text{rand}}上使用上述稳健特征训练线性模型，并在 CIFAR 测试集上测试，得到的准确率为 23.5%（总准确率 88%）。在\hat{\mathcal{D}}_{\text{det}}上进行相同操作，得到的准确率为 6.81%（总准确率 44%）。

对比结果表明，这两个实验应被区别解读。[[ilyas2019adversarial]] 表 1 中\hat{\mathcal{D}}_{\text{rand}}的迁移结果需要谨慎对待：其中有相当一部分准确率可以归因于稳健特征。请注意这个界限较弱：如果我们使用非线性特征（例如来自稳健深度神经网络），这个界限可能还会提高。

然而，[[ilyas2019adversarial]] 表 1 中\hat{\mathcal{D}}_{\text{det}}的结果则更为稳固。我们没有发现特征泄漏的证据（事实上，我们发现了负泄漏——即流入！）。因此我们得出结论，大部分准确率由非稳健特征驱动是合理的，这正是[[ilyas2019adversarial]]的核心论点。

因此，对比结果指向了一种方法论建议——当我们要在图像中分离两种线索时，我们认为让相关性变为负值比让它变为 0 更安全。

回应摘要

：这是一个合理的担忧，实际上这也是我们创建

\widehat{\mathcal{D}}_{det}

数据集的动机之一（正如评论所指出的，该数据集确实存在

误导性的

稳健特征）。所提供的实验进一步加深了我们对底层现象的理解。

回应：这条评论提出了一个合理的担忧，而这实际上正是我们设计\widehat{\mathcal{D}}_{det}数据集的主要原因之一。 特别要回顾\widehat{\mathcal{D}}_{rand}数据集的构造方式：为每个输入分配一个随机的目标标签，然后朝该标签方向进行 PGD 攻击。 请注意，与\widehat{\mathcal{D}}_{det}数据集（其中目标类别是确定性选择的）不同，\widehat{\mathcal{D}}_{rand}数据集允许稳健特征与标签产生（较小的）正相关。

要理解这如何发生，可以考虑以下简单场景：我们有一个单一特征f(x)，对猫是1，对狗是-1。如果\epsilon = 0.1，那么f(x)当然是一个稳健特征。然而，随机分配标签（如在数据集\widehat{\mathcal{D}}_{rand}中）会使该特征与分配的标签不相关，即我们会有E[f(x)\cdot y] = 0。在这种情况下，进行针对性攻击可能会诱导出与分配标签的某种相关性，因为我们可能得到\mathbb{E}[f(x+\eta\cdot\nabla f(x))\cdot y] > \mathbb{E}[f(x)\cdot y] = 0，从而让模型能够正确分类新的输入。

换句话说，从一个没有任何特征的数据集出发，可以在微小扰动内编码稳健特征。相反，在\widehat{\mathcal{D}}_{det}数据集中，稳健特征与原始标签是相关的（因为标签被置换了），并且由于它们是稳健的，无法被翻转为与新分配的（错误）标签相关。尽管如此，\widehat{\mathcal{D}}_{rand}数据集仍然让我们能够证明：(a) 基于 PGD 的对抗样本确实改变了数据中的特征；(b) 模型可以从人类无意义/错标的数据中学习。而\widehat{\mathcal{D}}_{det}数据集则说明，非稳健特征实际上足以实现泛化，并且在自然场景下可能优于稳健特征。

评论中提出的实验巧妙地表明这种泄漏确实是可能的。然而，我们想强调（正如评论本身所做的），稳健特征泄漏并不影响我们的主要论点——\widehat{\mathcal{D}}_{det}数据集明确控制了稳健特征泄漏（事实上，它还允许我们量化模型对稳健特征与非稳健特征的偏好——见paper的附录 D.6）。
