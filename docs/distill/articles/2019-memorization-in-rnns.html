可视化 RNN 中的记忆机制

2019-03-25 · 阅读原文

循环神经网络（RNN）中的记忆机制在许多应用中仍然是一个挑战。我们希望 RNN 能够在多个时间步上存储信息，并在需要时将其检索出来——但普通的 vanilla RNN 往往难以做到这一点。

研究者提出了多种网络架构来解决这一问题的不同方面，例如 Long-Short-Term Memory (LSTM)[(Hochreiter et al., 1997)] 单元和 Gated Recurrent Units (GRU)[(Cho et al., 2014)]。然而，记忆机制在实践中的问题依然存在。因此，开发更擅长记忆的新型循环单元仍是当前活跃的研究领域。

无论是较早还是最近的论文，例如 Monzi 等人的 Nested LSTM 论文[(Moniz et al., 2018)]，在比较循环单元与其替代方案时，都严重依赖定量对比。这些对比通常在 Penn Treebank[(Marcus et al., 1994)]、Chinese Poetry Generation 或 text8[(Mahoney, 2006)] 等标准任务上衡量准确率或交叉熵损失，任务目标是根据已有输入预测下一个字符。

虽然定量对比很有用，但它们只能部分揭示循环单元如何进行记忆。例如，一个模型可能仅通过在只需短期记忆的任务上提供高准确率的预测，就能获得很高的准确率和较低的交叉熵损失，而在需要长期记忆的预测上表现不佳。在句子中自动补全单词时，仅具备短期理解的模型，在大部分字符已出现的情况下，仍能以高准确率补全单词末尾。但若缺乏长期上下文理解，当只有少量字符已知时，它就无法准确预测单词。

本文提出了一种定性可视化方法，用于比较循环单元在记忆能力和上下文理解方面的表现。该方法被应用于上述三种循环单元：Nested LSTM、LSTM 和 GRU。

多年来，人们提出了多种解决梯度消失问题的方法。其中最流行的是前面提到的 LSTM 和 GRU 单元，但这一领域仍在积极研究中。LSTM 和 GRU 都广为人知，并且在文献中已有详细解释。最近，Nested LSTM 也被提出[(Moniz et al., 2018)]——关于 Nested LSTM 的解释可参见附录。

目前尚不清楚为什么在某些应用中一种循环单元表现更好，而在另一些应用中则是另一种单元表现更优。理论上它们都能解决梯度消失问题，但在实践中它们的性能高度依赖于具体应用。

理解这些差异出现的原因很可能是一个不透明且具有挑战性的问题。本文的目的是展示一种可视化技术，它能更好地凸显这些差异。希望这样的理解能够带来更深入的认知。

比较循环单元

比较不同的循环单元往往比简单对比准确率或交叉熵损失要复杂得多。这些高层定量指标的差异可能有多种解释，可能仅仅来自只需短期上下文理解的预测上的微小改进，而我们通常更关心的是长期上下文理解能力。

定性分析面临的问题

因此，一个适合定性分析上下文理解的好问题，应该具有人类可解释的输出，并且同时依赖于长期和短期的上下文理解。通常使用的典型问题，如 Penn Treebank[(Marcus et al., 1994)]、Chinese Poetry Generation 或 text8[(Mahoney, 2006)] 生成任务，其输出并不容易进行推理，因为它们需要深入理解语法、中文诗歌，或者仅输出单个字母。

为此，本文研究了自动补全（autocomplete）问题。将每个字符映射到一个代表整个单词的目标，单词前的空格也应映射到同一目标。基于空格字符的预测特别有利于展示上下文理解能力。

自动补全问题与 text8 生成问题非常相似：唯一的区别是模型不再预测下一个字母，而是预测整个单词。这使得输出更具可解释性。最后，由于它与 text8 生成任务密切相关，现有关于 text8 生成的文献也具有参考价值——在 text8 生成上表现良好的模型，在自动补全问题上也应表现良好。

自动补全问题中的连接性

在最近发表的 Nested LSTM 论文[(Moniz et al., 2018)]中，作者通过可视化单个细胞的激活情况，定性地将其 Nested LSTM 单元与其他循环单元进行了比较，以展示其记忆方式。

这种可视化方法受到 Karpathy 等人的启发[(Karpathy et al., 2015)]，他们通过这种方式识别出捕捉特定特征的细胞。对于识别特定特征而言，这种方法效果很好。但作为衡量记忆能力的通用论据，它并不有效，因为输出完全取决于特定细胞所捕捉的特征。

未来工作：定量指标

从上述观察来看，短期上下文理解通常与正在预测的单词本身有关。也就是说，随着更多字母出现，模型会转而利用该单词中已见过的字母。相反，在预测一个单词的开头时，模型——尤其是 GRU 网络——会利用先前见过的单词作为预测的上下文。

这一观察启发我们提出一个定量指标：根据已知正在预测单词的字母数量来衡量准确率。目前尚不清楚这是否是最佳的定量指标，因为它高度依赖于具体问题，而且无法将模型总结为单一数值，而单一数值通常更便于直接比较。

[准确率图：显示在已知单词中固定数量字符的情况下模型的准确率。0 个字符表示 RNN 仅看到了单词前的空格，以及之前的所有文本（这些文本应提供上下文）。不同的线型表示正确单词是否出现在前 1、2 或 3 个候选建议中。] · 查看原文

这些结果表明，GRU 模型在长期上下文理解上表现更好，而 LSTM 模型在短期上下文理解上更强。这些观察很有价值，因为它解释了为什么 GRU 和 LSTM 模型的整体准确率几乎相同，但连接性可视化却显示 GRU 在长期上下文理解上要出色得多。

虽然这类更细致的定量指标能带来新的洞见，但本文所提出的连接性图这样的定性分析仍然具有重要价值。因为连接性可视化能让人直观地理解模型的工作原理，这是定量指标无法做到的。它还表明，一个错误的预测仍可能是有用的，例如同义词或在上下文语境下合理的预测。

结论

仅仅关注整体准确率和交叉熵损失本身并没有那么有意义。不同的模型可能分别侧重长期或短期的上下文理解，而两者却能获得相似的准确率和交叉熵。

因此，在评估模型时，对先前输入如何被用于预测进行定性分析同样重要。在本例中，连接性可视化结合自动补全预测的结果显示，与 LSTM 和 Nested LSTM 相比，GRU 模型在长期上下文理解能力上要强得多。在 LSTM 的情况下，这种差异远比仅查看整体准确率和交叉熵损失所预期的要大得多。这一观察本身并不特别有趣，因为它很可能高度依赖于超参数和具体应用场景。

更具价值的是，这种可视化方法能够让我们直观地理解模型之间的差异，其程度远超仅看准确率和交叉熵。在这个应用中，很明显 GRU 模型在更大程度上利用了重复出现的单词以及过去单词的语义含义来进行预测，而 LSTM 和 Nested LSTM 模型则较少如此。这不仅是在选择最终模型时的宝贵洞见，同时也是未来开发更好的模型时必不可少的知识。
