可视化循环神经网络中的记忆机制

2019-03-25 · 阅读原文

循环神经网络（RNN）中的记忆机制在许多应用中仍然是一个挑战。我们希望 RNN 能够在多个时间步上存储信息，并在需要时将其提取出来——但普通的 vanilla RNN 往往难以做到这一点。

为了解决这一问题的不同方面，研究者们提出了多种网络架构，例如 Long-Short-Term Memory (LSTM)[hochreiter1997lstm]单元和 Gated Recurrent Units (GRU)[cho2014gru]。然而，记忆机制在实际应用中仍旧是一个难题。因此，开发更擅长记忆的新型循环单元依然是一个活跃的研究领域。

为了将某种循环单元与其替代方案进行对比，过去和最近的论文（例如 Monzi 等人的 Nested LSTM 论文[moniz2018nlstm]）都 heavily 依赖定量比较。这些比较通常在 Penn Treebank[penntreebank]、中文诗歌生成或 text8[text8] 等标准任务上衡量准确率或交叉熵损失，任务目标是根据已有输入预测下一个字符。

虽然定量比较很有用，但它们只能部分揭示循环单元如何进行记忆。例如，一个模型可能仅通过在只需要短期记忆的任务上提供高准确率的预测，就能获得很高的整体准确率和较低的交叉熵损失，而在需要长期记忆的预测上表现不佳。在句子中自动补全单词时，一个只有短期理解的模型，在大部分字符已经出现的情况下，仍然可以表现出很高的补全词尾的准确率。然而，如果缺乏较长期的上下文理解，它就无法在只知道少数几个字符时预测出整个单词。

本文提出了一种定性的可视化方法，用于比较循环单元在记忆能力和上下文理解方面的表现。该方法被应用于上述三种循环单元：Nested LSTM、LSTM 和 GRU。

多年来，人们提出了多种解决梯度消失问题的方法。其中最受欢迎的是前面提到的 LSTM 和 GRU，但这一领域仍在积极研究中。LSTM 和 GRU 都广为人知，并且在文献中得到了详尽的解释。最近，Nested LSTM 也被提出[moniz2018nlstm]——关于 Nested LSTM 的解释可以在附录中找到。

目前尚不完全清楚为什么在某些应用中一种循环单元表现优于另一种，而在其他应用中却是另一种循环单元更优。从理论上讲，它们都能解决梯度消失问题，但在实践中，它们的性能高度依赖于具体应用。

理解这些差异出现的原因很可能是一个不透明且具有挑战性的问题。本文的目的是展示一种可视化技术，它能够更好地凸显这些差异。希望这样的理解能够带来更深入的认知。

比较循环单元

比较不同的循环单元往往比简单比较准确率或交叉熵损失更为复杂。这些高层定量指标的差异可能有多种解释，可能只是因为在仅需要短期上下文理解的任务上有了微小改进，而我们通常更关心的是长期上下文理解能力。

定性分析的一个合适问题

因此，一个适合定性分析上下文理解的好问题，应该具有人类可解释的输出，并且同时依赖于长期和短期的上下文理解。通常使用的典型问题，例如 Penn Treebank[penntreebank]、中文诗歌生成或 text8[text8] 生成，其输出并不容易进行推理，因为它们需要深入理解语法、中文诗歌，或者每次只输出单个字母。

为此，本文研究了自动补全（autocomplete）问题。将每个字符映射到一个代表整个单词的目标。单词前面的空格也应映射到该目标。特别地，基于空格字符的预测对于展示上下文理解能力非常有用。

自动补全问题与 text8 生成问题非常相似：唯一的区别是模型不是预测下一个字母，而是预测整个单词。这使得输出更具可解释性。最后，由于它与 text8 生成任务密切相关，关于 text8 生成的现有文献也具有参考价值——在 text8 生成上表现良好的模型，在自动补全问题上也应该表现良好。

[Interactive figure: User types input sequence. — view original: https://distill.pub/2019/memorization-in-rnns]

自动补全数据集是从完整的text8 数据集中构建而来的。用于解决该问题的循环神经网络包含两层，每层有 600 个单元。共有三个模型，分别使用 GRU、LSTM 和 Nested LSTM。更多细节请参见附录。

自动补全问题中的连接性

在最近发表的 Nested LSTM 论文[moniz2018nlstm]中，他们通过可视化单个细胞激活的方式，定性地将其 Nested LSTM 单元与其他循环单元进行比较，以展示它在记忆方面的表现。

这种可视化方法受到了 Karpathy 等人的启发[karpathy2015rnnvis]，他们在其中识别出能够捕捉特定特征的细胞。对于识别特定特征，这种可视化方法效果很好。然而，它并不能作为衡量记忆能力的通用论据，因为输出完全取决于特定细胞捕捉到的特征是什么。

未来工作：定量指标

从上述观察来看，短期上下文理解通常与正在预测的单词本身有关。也就是说，随着越来越多的字母出现，模型会转而利用已经看到的该单词本身的字母。相比之下，在预测一个单词的开头时，模型——尤其是 GRU 网络——会使用之前看到的单词作为预测的上下文。

这一观察启发我们提出一个定量指标：根据已经知道的正在预测单词的字母数量来衡量准确率。目前尚不清楚这是否是最佳的定量指标，因为它高度依赖于具体问题，而且它也不能将模型总结为一个单一的数值，而人们可能希望用单一数值来进行更直接的比较。

[Interactive figure: Accuracy Graph: shows the accuracy given a fixed number of characters in a word that the RNN has seen. 0 characters mean that the RNN has only seen the space leading up to the word, including all the previous text which should provide context. The different line styles, indicates if the correct word should appear among the top 1, 2, or 3 suggestions. — view original: https://distill.pub/2019/memorization-in-rnns]

这些结果表明，GRU 模型在长期上下文理解方面表现更好，而 LSTM 模型在短期上下文理解方面更强。这些观察很有价值，因为它解释了为什么 GRU 和 LSTM 模型的整体准确率几乎相同，但连接性可视化却显示 GRU 模型在长期上下文理解上要强得多。

虽然这种更细致的定量指标能够提供新的洞见，但像本文中提出的连接性图这样的定性分析依然具有重要价值。因为连接性可视化能够直观地帮助我们理解模型的工作原理，这是定量指标无法做到的。它还表明，一个错误的预测仍然可能是有用的，例如预测出一个同义词或一个在上下文语义上合理的词。

结论

仅仅关注整体准确率和交叉熵损失本身并没有太大意义。不同的模型可能会侧重于长期或短期的上下文理解，而两者可能具有相似的准确率和交叉熵。

因此，在评估模型时，观察先前输入如何被用于预测的定性分析同样重要。在本例中，连接性可视化结合自动补全预测的结果表明，与 LSTM 和 Nested LSTM 相比，GRU 模型在长期上下文理解能力上要强得多。就 LSTM 而言，这种差异远远大于仅从整体准确率和交叉熵损失所能推断出的程度。这一观察本身并不特别重要，因为它很可能高度依赖于超参数和具体应用场景。

更有价值的是，这种可视化方法能够让我们直观地理解模型之间的差异，其程度远高于仅查看准确率和交叉熵。在这个应用中，很明显 GRU 模型在更大程度上利用了重复出现的单词以及过去单词的语义含义来进行预测，而 LSTM 和 Nested LSTM 模型则较少这样做。这不仅是在选择最终模型时的重要洞见，也是未来开发更好模型时必不可少的知识。
