可微分图像参数化

2018-07-25 · 阅读原文

经过训练用于图像分类的神经网络具有惊人——且出乎意料！——的图像生成能力。 DeepDream[(Mordvintsev et al., 2015)]、风格迁移[(Gatys et al., 2015)]和特征可视化[(Olah et al., 2017)]等技术正是利用这一能力，成为探索神经网络内部工作机制的强大工具，也催生了一小股基于神经艺术的艺术运动。

这些技术的工作原理大体相同。 计算机视觉中使用的神经网络对其所观察的图像具有丰富的内部表示。 我们可以利用这种表示来描述我们希望图像具备的属性（例如风格），然后优化输入图像，使其呈现这些属性。 这种优化之所以可行，是因为网络对输入是可微分的：我们可以轻微调整图像，使其更好地符合预期属性，然后通过梯度下降迭代地应用这些调整。

通常，我们将输入图像参数化为每个像素的 RGB 值，但这并非唯一方式。 只要参数到图像的映射是可微分的，我们就可以用梯度下降来优化其他参数化方式。

可微分图像参数化促使我们思考：“什么样的图像生成过程可以进行反向传播？” 答案是相当多的，其中一些更奇特的方式能产生丰富多样的有趣效果，包括 3D 神经艺术、带透明度的图像以及对齐插值。 此前使用特定非常规图像参数化方式的工作[(Nguyen et al., 2015; Athalye et al., 2017; Olah et al., 2017)]已经展示了令人兴奋的结果——我们认为，从整体视角审视这一领域，表明其中还有更大的潜力。

为什么参数化方式很重要？

改变优化问题的参数化方式可能会显著改变结果，即使实际优化的目标函数保持不变，这可能让人感到惊讶。 我们认为参数化选择会产生显著影响的原因有四个：

（1）—— 优化改进 — 将输入进行变换以简化优化问题——这项称为“预条件”（preconditioning）的技术——是优化中的常用手段。 [1] 我们发现，参数化的简单改变能让神经艺术的图像优化变得容易得多。

（2）—— 吸引盆 — 当我们优化神经网络的输入时，通常存在多个不同的解，对应不同的局部极小值。 [2] 优化过程落入某个特定局部极小值的概率由其吸引盆（basin of attraction，即受该极小值影响的优化地形区域）所控制。 已知改变优化问题的参数化方式会改变不同吸引盆的大小，从而影响可能的结果。

（3）—— 额外约束 — 某些参数化方式仅覆盖可能输入的子集，而非整个空间。 在这种参数化下工作的优化器仍能找到最小化或最大化目标函数的解，但这些解会受到参数化本身的约束。 通过选择合适的一组约束，我们可以施加各种限制，从简单约束（例如图像边界必须为黑色），到丰富而微妙的约束。

（4）—— 隐式优化其他对象 — 参数化方式内部可能使用一种与它最终输出并进行优化的对象不同的对象。 例如，虽然视觉网络的自然输入是 RGB 图像，但我们可以将其参数化为一个 3D 对象的渲染结果，并通过对渲染过程进行反向传播来优化该 3D 对象。 由于 3D 对象比图像具有更多自由度，我们通常会使用随机参数化方式，生成从不同视角渲染的图像。

在本文后续部分，我们将给出这些方法切实有益并产生惊人且有趣视觉结果的具体例子。

对齐的特征可视化插值

特征可视化最常用于可视化单个神经元， 但它也可以用来特征可视化，以研究它们如何相互作用[(Olah et al., 2017)]。 不是优化图像让单个神经元激活，而是优化它让多个神经元同时激活。

当我们想要真正理解两个神经元之间的相互作用时， 可以更进一步，创建多个可视化结果， 逐步将优化目标从一个神经元转移到更重视另一个神经元的激活。 这在某种程度上类似于 GAN 等生成模型潜在空间中的插值。

尽管如此，仍存在一个小挑战：特征可视化具有随机性。 即使针对完全相同的目标进行优化，每次产生的可视化布局也会不同。 通常这不是问题，但在插值可视化中却会产生影响。 如果我们简单地进行插值，得到的可视化结果将无法对齐： 眼睛等视觉标志在每张图像中会出现在不同位置。 这种缺乏对齐的情况会让我们难以看清由于目标函数细微差异导致的变化， 因为它们会被布局上更大的差异所掩盖。

使用非 VGG 架构进行风格迁移

神经风格迁移存在一个谜题： 尽管它取得了显著成功，但几乎所有风格迁移都使用 VGG 架构的变体[(Simonyan et al., 2014)]。 这并非因为没人对其他架构上的风格迁移感兴趣，而是因为在其他架构上尝试时效果一直很差。 [6]

已有几种假说试图解释为什么 VGG 远优于其他模型。 一种解释是 VGG 较大的规模使其能捕捉到其他模型丢弃的信息。 这种额外信息对分类没有帮助，但却让模型在风格迁移上表现更好。 另一种假说是其他模型的下采样比 VGG 更激进，导致空间信息丢失。 我们猜测可能还有另一个因素：大多数现代视觉模型在梯度中存在棋盘格 artifact[(Odena et al., 2016; Olah et al., 2017)]，这可能会使风格化图像的优化变得更加困难。

组合模式生成网络

到目前为止，我们探索的参数化方式都与我们通常对图像的认知较为接近，使用像素或傅里叶分量。 在本节中，我们探索通过使用不同参数化方式来（3）为优化过程增加额外约束的可能性。 更具体地说，我们将图像参数化为一个神经网络[(Ulyanov et al., 2017)]——特别是组合模式生成网络（Compositional Pattern Producing Network，CPPN）[(Stanley, 2007)]。

CPPN 是将(x,y)位置映射到图像颜色的神经网络：

(x,y) ~\xrightarrow{\tiny CPPN}~ (r,g,b)

通过将 CPPN 应用于位置网格，可以生成任意分辨率的图像。 CPPN 网络的参数——即权重和偏置——决定了生成的图像。 根据为 CPPN 选择的架构，结果图像中的像素会在一定程度上被约束为与其邻近像素共享颜色。

随机参数可以产生具有美学趣味的图像[(Ha, 2015)]，但我们可以通过学习 CPPN 的参数[(Karpathy, 2014; Ha, 2016)]来生成更有趣的图像。 这通常通过进化算法[(Sims, 1991; Stanley, 2007; Nguyen et al., 2015)]实现；这里我们探索通过反向传播某个目标函数（例如特征可视化目标）来优化的可能性。 这很容易实现，因为 CPPN 网络与卷积神经网络一样是可微分的，目标函数可以穿过 CPPN 传播并相应地更新其参数。 也就是说，CPPN 是一种可微分图像参数化方式——可用于任何神经艺术或可视化任务的参数化图像的通用工具。

使用 CPPN 作为图像参数化方式能为神经艺术增添一种有趣的艺术品质，隐约让人联想到光绘（light-painting）。[7] 在更理论的层面上，它们可以被视为对图像组合复杂性的约束。 当用于优化特征可视化目标时，它们会产生具有鲜明特色的可视化图像：

生成半透明图案

本文中使用的神经网络是针对 2D RGB 图像作为输入训练的。 是否可能使用相同的网络来合成超出（4）这一领域的产物呢？ 事实证明，我们可以通过让可微分参数化定义一个图像家族而非单个图像，并在每个优化步骤中从中采样一个或多个图像来实现这一点。 这很重要，因为我们将要探索优化的许多对象，其自由度都比输入网络的图像更多。

具体来说，让我们考虑半透明图像的情况。这些图像除了 RGB 通道外，还有一个 alpha 通道，用于编码每个像素的不透明度（范围为[0,1]）。为了将此类图像输入到在 RGB 图像上训练的神经网络，我们需要以某种方式折叠 alpha 通道。一种方法是使用标准 alpha 混合公式[8]，将 RGBA 图像I叠加到背景图像BG之上

O_{rgb} ~~=~~ I_{rgb} * I_a ~~+~~ BG_{rgb} * (1 - I_a)

其中I_a是图像I的 alpha 通道。

如果我们使用静态背景BG（例如黑色），透明度将仅仅表示背景直接贡献于优化目标的像素位置。 实际上，这等价于优化一个 RGB 图像，并在颜色与背景匹配的区域将其设为透明！ 直观上，我们希望透明区域对应于类似“这个区域的内容可以是任何东西”的含义。 基于这一直觉，我们在每个优化步骤使用不同的随机背景。 [9]

默认情况下，优化我们的半透明图像会使其完全不透明，这样网络始终能获得其最优输入。 为避免这种情况，我们需要修改目标函数，加入鼓励一定透明度的项。 我们发现用以下目标替换原始目标非常有效：

\text{obj}_{\text{new}} ~~=~~ \text{obj}_{\text{old}} ~~*~~ (1-\text{mean}(I_a))

这个新目标会自动在原始目标\text{obj}_{\text{old}}与降低平均透明度之间取得平衡。 如果图像变得非常透明，它会专注于原始目标。如果它变得过于不透明，它会暂时停止关注原始目标，转而专注于降低平均不透明度。

事实证明，生成半透明图像在特征可视化中非常有用。 特征可视化的目的是通过创建能最大程度激活神经元的图像，来理解视觉模型中的神经元在寻找什么。 不幸的是，这些可视化无法区分图像中哪些区域强烈影响神经元的激活，哪些区域仅产生边缘影响。 [10]

理想情况下，我们希望可视化能够体现这种重要性差异——表示图像某部分不重要的一种自然方式是让它透明。 因此，如果我们优化带 alpha 通道的图像并鼓励整体图像具有透明度，那么根据特征可视化目标不重要的部分就应该变得透明。

通过 3D 渲染实现高效的纹理优化

在上一节中，我们能够使用针对 RGB 图像的神经网络来创建半透明的 RGBA 图像。 我们能否进一步推进，创建（4）甚至更远离 RGB 输入的其他类型对象呢？ 在本节中，我们探索针对特征可视化目标[(Olah et al., 2017)]优化 3D 对象。 我们使用 3D 渲染过程将其转换为可以输入网络的 2D RGB 图像，并通过渲染过程进行反向传播来优化 3D 对象的纹理。

我们的技术与 Athalye 等人[(Athalye et al., 2017)]用于创建现实世界对抗样本的方法类似，都依赖于将目标函数反向传播到 3D 模型的随机采样视角。 我们与现有的艺术纹理生成方法[(Kato et al., 2017)]不同，因为我们在反向传播过程中不修改对象的几何形状。 通过将纹理生成与顶点位置解耦，我们可以为复杂对象创建非常精细的纹理。

在描述我们的方法之前，我们首先需要了解 3D 对象是如何存储并在屏幕上渲染的。对象的几何形状通常保存为相互连接的三角形集合，称为三角网格（triangle mesh），或简称为 mesh。为了渲染出逼真的模型，需要在 mesh 上绘制纹理。纹理保存为图像，并通过所谓的 UV 映射（UV-mapping）应用到模型上。mesh 中的每个顶点c_i都与纹理图像中的一个(u_i,v_i)坐标相关联。然后通过用纹理图像中由其顶点(u,v)坐标所界定的区域对每个三角形着色，来渲染（即在屏幕上绘制）该模型。

创建 3D 对象纹理的一种简单朴素方法是按常规方式优化图像，然后将其作为纹理绘制到对象上。 然而，这种方法生成的纹理没有考虑底层的 UV 映射，因此会在渲染后的对象中产生各种视觉 artifact。 首先，渲染纹理上会出现明显的接缝，因为优化过程不知道底层的 UV 映射，因此无法在纹理被分割的各个块之间保持一致地优化。 其次，生成的图案在对象的不同部分随机定向（例如垂直和弯曲的图案），因为它们在底层的 UV 映射中没有保持一致的方向。 最后，生成的图案缩放比例也不一致，因为 UV 映射没有在三角形面积与其在纹理中的映射区域之间强制保持一致的比例。

在渲染内容图像和学习图像之后，我们针对 Gatys 等人[(Gatys et al., 2015)]提出的风格迁移目标函数进行优化，并按照上一节介绍的方法将参数化映射回 UV 映射的纹理中。 然后重复这个过程，直到目标纹理中获得所需的内容与风格的混合。

17： 对各种 3D 模型进行风格迁移。请注意，内容纹理中的视觉标志（如眼睛）在生成的纹理中能正确显现。

由于每个视角都是独立优化的，优化过程被迫在每次迭代中尝试添加风格的所有元素。 例如，如果我们使用梵高的《星空》作为风格图像，那么星星将在每一个视角中都被添加。 我们发现，通过引入对先前视角风格的某种“记忆”，可以获得更令人满意的结果（如上面展示的那些）。 为此，我们在最近采样的视点上维护风格表示 Gram 矩阵的移动平均值。 在每次优化迭代中，我们针对这些平均矩阵计算风格损失，而不是针对该特定视角计算的矩阵。 [11]

最终得到的纹理融合了目标风格的元素，同时保留了原始纹理的特征。 以使用梵高《星空》作为风格图像创建的模型为例。 结果纹理包含了梵高作品特有的富有节奏且有力的笔触。 然而，尽管风格图像主要使用冷色调，结果毛皮却带有温暖的橙色底色，因为它保留自原始纹理。 更有趣的是，当迁移不同风格时，兔子的眼睛仍能被保留。 例如，当风格来自梵高的画作时，眼睛被转化为星状漩涡；而当使用康定斯基的作品时，它们变成抽象图案，但仍能让人联想到原始的眼睛。

使用本方法生成的带纹理模型可以轻松用于流行的 3D 建模软件或游戏引擎。为了展示这一点，我们将其中一个设计 3D 打印成了真实世界的物理 artifact[12]。

结论

对于有创造力的艺术家或研究者来说，存在一个庞大的图像参数化方式空间可用于优化。 这不仅能打开截然不同的图像结果，还包括动画和 3D 对象！ 我们认为本文探索的可能性仅仅触及表面。 例如，人们可以探索将 3D 对象纹理优化扩展到优化材质或反射率——甚至朝着 Kato 等人[(Kato et al., 2017)]的方向前进，优化网格顶点位置。

本文重点关注可微分图像参数化，因为它们易于优化且能覆盖广泛的应用场景。 但使用强化学习或进化策略[(Wierstra et al., 2014; Salimans et al., 2017)]来优化不可微分或仅部分可微分的图像参数化当然也是可能的。 使用不可微分的参数化方式可能为图像或场景生成打开激动人心的新可能性。
