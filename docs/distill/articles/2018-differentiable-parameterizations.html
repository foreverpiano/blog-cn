可微分图像参数化

2018-07-25 · 阅读原文

经过训练用于图像分类的神经网络具有惊人——且出乎意料！——的图像生成能力。 DeepDream[[mordvintsev2015inceptionism]]、风格迁移[[gatys2015]]和特征可视化[[olah2017feature]]等技术正是利用这一能力，作为探索神经网络内部工作机制的强大工具，并催生了一场基于神经艺术的小型艺术运动。

所有这些技术的工作原理大致相同。 计算机视觉中使用的神经网络对其所观察的图像具有丰富的内部表征。 我们可以利用这种表征来描述我们希望图像具备的属性（例如风格），然后优化输入图像使其具有这些属性。 这种优化之所以可行，是因为网络对输入是可微分的：我们可以对图像进行微小调整，使其更好地符合期望属性，然后通过梯度下降迭代地应用这些调整。

通常，我们将输入图像参数化为每个像素的 RGB 值，但这并非唯一方式。 只要参数到图像的映射是可微分的，我们就可以使用梯度下降来优化其他参数化方式。

可微分图像参数化促使我们思考：“我们能够对哪些类型的图像生成过程进行反向传播？” 答案是相当多，其中一些较为奇特的可能性能够产生各种各样有趣的效果，包括 3D 神经艺术、带透明度的图像以及对齐的插值。 之前使用特定非寻常图像参数化的工作[[Nguyen2015:easilyFooled,athalye2017synthesizing,olah2017feature]]已展现出令人兴奋的结果——我们认为，从整体视角审视这一领域，暗示着还有更大的潜力。

为什么参数化很重要？

改变优化问题的参数化方式可能会显著改变结果，尽管实际被优化的目标函数保持不变，这一点可能令人惊讶。 我们认为参数化选择会产生显著影响的原因有四个：

(1) - 优化改进 - 将输入进行变换以简化优化问题——这种技术称为“预条件”（preconditioning）——是优化中的常用手段。 [1] 我们发现，参数化上的简单改变能让用于神经艺术和图像优化的过程变得容易得多。

(2) - 吸引盆 - 当我们优化神经网络的输入时，通常存在许多不同的解，对应不同的局部最小值。 [2] 优化过程落入某个特定局部最小值的概率由其吸引盆（basin of attraction，即受该最小值影响的优化景观区域）控制。 已知改变优化问题的参数化会改变不同吸引盆的大小，从而影响可能的结果。

(3) - 额外约束 - 某些参数化仅覆盖可能输入的一个子集，而非整个空间。 在这种参数化下工作的优化器仍能找到最小化或最大化目标函数的解，但这些解会受到参数化本身的约束。 通过选择合适的约束集，可以施加各种约束，从简单约束（例如图像边界必须为黑色），到丰富而微妙的约束。

(4) - 隐式优化其他对象 - 参数化内部可能使用与它输出并进行优化的对象不同类型的对象。 例如，虽然视觉网络的自然输入是 RGB 图像，但我们可以将其参数化为一个 3D 对象的渲染结果，并通过对渲染过程进行反向传播来优化该 3D 对象。 由于 3D 对象比图像具有更多自由度，我们通常使用随机参数化来生成从不同视角渲染的图像。

在本文的剩余部分，我们将给出这些方法有益且能带来令人惊讶且有趣视觉结果的具体示例。

对齐的特征可视化插值

特征可视化最常用于可视化单个神经元， 但它也可以用于，以研究它们如何相互作用[[olah2017feature]]。 不是优化图像让单个神经元激活，而是优化它让多个神经元同时激活。特征可视化

当我们想要真正理解两个神经元之间的相互作用时， 我们可以更进一步，创建多个可视化结果， 逐步将优化目标从一个神经元转移到更重视另一个神经元的激活。 这在某种程度上类似于 GAN 等生成模型潜空间中的插值。

尽管如此，仍存在一个小挑战：特征可视化具有随机性。 即使你针对完全相同的目标进行优化，每次可视化的布局都会有所不同。 通常这不是问题，但它会影响插值可视化的效果。 如果我们简单地进行插值，得到的可视化结果将无法对齐： 眼睛等视觉标志在每张图像中会出现在不同的位置。 这种缺乏对齐的情况会让因目标略有不同而产生的差异变得难以观察， 因为它们会被布局上更大的差异所淹没。

如果我们将插值帧看作动画，就能看到独立优化存在的问题：

[交互图——查看原图：https://distill.pub/2018/differentiable-parameterizations]

我们如何实现这种对齐的插值，让视觉标志在帧之间不发生移动呢？ 有多种可能的方法可以尝试 [3] ，其中之一是使用共享参数化：每个帧都被参数化为其自身独特参数化与一个共享参数化的组合。

[交互图——查看原图：https://distill.pub/2018/differentiable-parameterizations]

通过在帧之间部分共享参数化，我们鼓励生成的可视化结果自然地对齐。 直观上，共享参数化提供了一个视觉标志位移的共同参考，而独特参数化则让每个帧根据其插值权重拥有自身的视觉吸引力。 [4] 这种参数化并没有改变目标函数，但它确实扩大了(2) 那些可视化结果对齐的吸引盆。 [5]

这是可微分参数化总体上如何成为可视化神经网络的有用额外工具的一个初步示例。

使用非 VGG 架构进行风格迁移

神经风格迁移存在一个谜题： 尽管它取得了显著成功，但几乎所有风格迁移都使用 VGG 架构的变体[[simonyan2014vgg]]。 这并非因为没人对其他架构上的风格迁移感兴趣，而是因为在其他架构上尝试时，效果通常很差。 [6]

已有几种假设被提出，用于解释为什么 VGG 比其他模型好得多。 一种解释是 VGG 的庞大规模使其能够捕捉到其他模型丢弃的信息。 这种额外信息对分类没有帮助，但却让模型在风格迁移上表现更好。 另一种假设是其他模型的下采样比 VGG 更激进，从而丢失了空间信息。 我们怀疑可能还有另一个因素：大多数现代视觉模型在其梯度中存在棋盘格 artifact[[odena2016deconvolution,olah2017feature]]，这可能使风格化图像的优化变得更加困难。

组合模式生成网络

到目前为止，我们探索的参数化方式都比较接近我们通常对图像的认知，使用像素或傅里叶分量。 在本节中，我们探索通过使用不同参数化来(3) 为优化过程增加额外约束的可能性。 更具体地说，我们将图像参数化为一个神经网络[[ulyanov2017deepimageprior]]——特别是组合模式生成网络（Compositional Pattern Producing Network，简称 CPPN）[[stanley2007cppn]]。

CPPN 是将(x,y)位置映射到图像颜色的神经网络：

(x,y) ~\xrightarrow{\tiny CPPN}~ (r,g,b)

通过将 CPPN 应用于位置网格，可以生成任意分辨率的图像。 CPPN 网络的参数——权重和偏置——决定了生成的图像。 根据为 CPPN 选择的架构，结果图像中的像素会在一定程度上被约束为与其邻居共享颜色。

随机参数可以产生具有美学趣味的图像[[CPPN:random]]，但我们可以通过学习 CPPN 的参数[[karpathy2014cppns,ha2016cppns]]来生成更有趣的图像。 这通常通过进化[[sims1991evolution,stanley2007cppn,Nguyen2015:easilyFooled]]来完成；这里我们探索通过反向传播某个目标函数（例如特征可视化目标）来优化的可能性。 这很容易实现，因为 CPPN 网络像卷积神经网络一样是可微分的，目标函数也可以通过 CPPN 传播，从而相应地更新其参数。 也就是说，CPPN 是一种可微分图像参数化——可用于任何神经艺术或可视化任务中对图像进行参数化的通用工具。

将 CPPN 用作图像参数化可以为神经艺术增添一种有趣的艺术品质，隐约让人联想到光绘（light-painting）。[7] 在更理论的层面，它们可以被视为对图像组合复杂性的约束。 当用于优化特征可视化目标时，它们会产生独特风格的图像：

[交互图：7： 使用[stanley2007cppn]作为在不同层[[olah2017feature]]可视化特征的可微分参数化。——查看原图：https://distill.pub/2018/differentiable-parameterizations]

生成图像的视觉质量深受所选 CPPN 架构的影响。 不仅网络的形状（即层数和滤波器数量）很重要，所选择的激活函数和归一化方式也很关键。例如，更深的网络会比浅层网络产生更精细的细节。 我们鼓励读者通过改变 CPPN 架构来实验生成不同的图像。这可以通过修改补充 notebook 中的代码轻松实现。

CPPN 生成的模式演化过程本身就是艺术品。 为了延续光绘的比喻，优化过程对应于对光束方向和形状的迭代调整。 由于迭代变化比像素参数化具有更全局的影响，在优化初期只能看到主要模式。 通过迭代调整权重，我们想象中的光束被定位，从而使精细细节逐渐显现。

半透明图案的生成

本文使用的神经网络被训练为接收 2D RGB 图像作为输入。 是否有可能使用相同的网络来合成超出(4) 该域的产物呢？ 事实证明我们可以做到，方法是让我们的可微分参数化定义一个图像家族而非单个图像，然后在每个优化步骤中从该家族中采样一个或几个图像。 这很重要，因为我们将要优化探索的许多对象，其自由度比输入网络的图像更多。

具体来说，让我们考虑半透明图像的情况。这些图像除了 RGB 通道外，还有一个 alpha 通道，用于编码每个像素的不透明度（范围为[0,1]）。为了将这样的图像输入到在 RGB 图像上训练的神经网络，我们需要以某种方式折叠 alpha 通道。一种实现方式是使用标准 alpha 混合公式，将 RGBA 图像I叠加在背景图像BG之上[8]

O_{rgb} ~~=~~ I_{rgb} * I_a ~~+~~ BG_{rgb} * (1 - I_a)

其中I_a是图像I的 alpha 通道。

如果我们使用静态背景BG（例如黑色），那么透明度仅表示背景直接对优化目标做出贡献的像素位置。 事实上，这等价于优化一个 RGB 图像，并在颜色与背景匹配的区域使其透明！ 直观上，我们希望透明区域对应于“这个区域的内容可以是任何东西”。 基于这一直觉，我们在每个优化步骤中使用不同的随机背景。 [9]

默认情况下，优化我们的半透明图像会使图像完全不透明，这样网络总是能得到其最优输入。 为了避免这种情况，我们需要修改目标函数，加入鼓励一定透明度的项。 我们发现用以下目标替换原始目标很有效：

\text{obj}_{\text{new}} ~~=~~ \text{obj}_{\text{old}} ~~*~~ (1-\text{mean}(I_a))

这个新目标会自动在原始目标\text{obj}_{\text{old}}与减少平均透明度之间取得平衡。 如果图像变得非常透明，它会专注于原始目标。如果它变得过于不透明，它会暂时停止关心原始目标，转而专注于降低平均不透明度。

[交互图——查看原图：https://distill.pub/2018/differentiable-parameterizations]

11： 针对不同层和单元优化半透明图像的示例。

事实证明，生成半透明图像在特征可视化中非常有用。 特征可视化旨在通过创建能最大程度激活神经元的图像，来理解视觉模型中的神经元在寻找什么。 不幸的是，这些可视化无法区分图像中哪些区域强烈影响神经元的激活，哪些区域仅产生边缘影响。 [10]

理想情况下，我们希望可视化能够做出这种重要性区分——表示图像某部分不重要的一种自然方式是让它透明。 因此，如果我们优化一个带 alpha 通道的图像并鼓励整体图像保持透明，根据特征可视化目标不重要的部分就应该变得透明。

通过 3D 渲染进行高效的纹理优化

在前一节中，我们能够使用针对 RGB 图像的神经网络来创建半透明的 RGBA 图像。 我们能否更进一步，创建(4) 甚至更远离 RGB 输入的其他类型对象呢？ 本节中我们探索针对特征可视化目标[[olah2017feature]]优化 3D 对象。 我们使用 3D 渲染过程将其转换为可输入网络的 2D RGB 图像，并通过渲染过程进行反向传播来优化 3D 对象的纹理。

我们的技术与 Athalye 等人[[athalye2017synthesizing]]用于创建真实世界对抗样本的方法类似，因为我们依赖于将目标函数反向传播到 3D 模型的随机采样视角。 我们与现有的艺术纹理生成方法[[kato2017neural3D]]不同，因为我们在反向传播过程中不修改对象的几何形状。 通过将纹理生成与顶点位置解耦，我们可以为复杂对象创建非常精细的纹理。

在描述我们的方法之前，我们首先需要了解 3D 对象是如何存储和在屏幕上渲染的。对象的几何形状通常保存为相互连接的三角形集合，称为三角网格（triangle mesh），或简称为 mesh。为了渲染逼真的模型，会在 mesh 上绘制纹理。纹理保存为图像，通过所谓的 UV 映射（UV-mapping）应用到模型上。mesh 中的每个顶点c_i都关联到纹理图像中的一个(u_i,v_i)坐标。然后通过用由其顶点的(u,v)坐标所界定的图像区域对每个三角形着色，来渲染（即在屏幕上绘制）模型。

创建 3D 对象纹理的一种简单朴素的方法是按常规方式优化一张图像，然后将其作为纹理绘制到对象上。 然而，这种方法生成的纹理没有考虑底层的 UV 映射，因此会在渲染的对象中产生各种视觉 artifact。 首先，渲染纹理上会出现接缝，因为优化过程不了解底层的 UV 映射，因此无法沿纹理的分割块一致地优化纹理。 其次，生成的模式在对象的不同部分随机定向（参见垂直和弯曲的模式），因为它们在底层的 UV 映射中没有保持一致的定向。 最后，生成的模式缩放不一致，因为 UV 映射没有在三角形区域与其在纹理中的映射三角形之间强制保持一致的比例。

我们以使用傅里叶参数化随机初始化纹理开始。 在每次训练迭代中，我们采样一个随机相机位置（朝向对象包围盒中心），并将带纹理的对象渲染为图像。 然后我们将期望目标函数（即神经网络中感兴趣的特征）的梯度反向传播到渲染图像上。

然而，对渲染图像的更新并不对应于对我们希望优化的纹理的更新。因此，我们需要进一步将变化传播到对象的纹理。 这种传播很容易通过应用逆 UV 映射来实现，因为对于屏幕上的每个像素，我们都知道它在纹理中的坐标。 通过在后续优化迭代中修改纹理，渲染图像将融入前几次迭代中应用的变化。

该算法的工作方式与前一节介绍的方法类似，从随机初始化的纹理开始。 在每次迭代中，我们采样一个朝向对象包围盒中心的随机视点，并渲染它的两张图像：一张使用原始纹理（内容图像），另一张使用我们当前正在优化的纹理（学习到的图像）。

在内容图像和学习图像被渲染后，我们针对由 Gatys 等人[[gatys2015]]提出的风格迁移目标函数进行优化，并像前一节介绍的那样，将参数化映射回 UV 映射的纹理中。 然后重复这一过程，直到目标纹理中获得期望的内容与风格的混合。

由于每个视角都是独立优化的，优化过程被迫在每次迭代中尝试添加风格的所有元素。 例如，如果我们使用梵高的《星空》作为风格图像，那么星星将在每一个视角中都被添加。 我们发现，通过引入对先前视角风格的某种“记忆”，可以获得更令人满意的结果（如上面展示的那些）。为此，我们维护最近采样视点的风格表示 Gram 矩阵的移动平均值。 在每次优化迭代中，我们针对这些平均矩阵计算风格损失，而不是针对该特定视角计算的矩阵。 [11]

生成的纹理结合了期望风格的元素，同时保留了原始纹理的特征。 以使用梵高《星空》作为风格图像创建的模型为例。 生成的纹理包含了梵高作品特有的富有节奏且有力的笔触。 然而，尽管风格图像主要使用冷色调，但生成的毛皮仍带有温暖的橙色底调，因为它保留自原始纹理。 更有趣的是，当迁移不同风格时，兔子的眼睛被保留了下来。 例如，当风格来自梵高的画作时，眼睛被转化为星状漩涡；而当使用康定斯基的作品时，它们则变成抽象图案，但仍能让人联想到原始的眼睛。

使用本文方法生成的带纹理模型可以轻松用于流行的 3D 建模软件或游戏引擎。为了展示这一点，我们将其中一个设计 3D 打印成了真实世界的物理 artifact[12]。

结论

对于有创意的艺术家或研究者来说，存在一个巨大的图像参数化空间可用于优化。 这不仅打开了截然不同的图像结果，还包括动画和 3D 对象！ 我们认为本文所探索的可能性只是冰山一角。 例如，可以探索将 3D 对象纹理的优化扩展到优化材质或反射率——甚至朝着 Kato 等人[[kato2017neural3D]]的方向前进，优化网格顶点位置。

本文聚焦于可微分图像参数化，因为它们易于优化且覆盖了广泛的应用范围。 但使用强化学习或进化策略[[wierstra2014naturalEvolutionStrategies,salimans2017evolution]]来优化不可微分或仅部分可微分的图像参数化当然也是可能的。 使用不可微分参数化可能会为图像或场景生成打开令人兴奋的新可能性。
