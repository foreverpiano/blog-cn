用特征语言重访《一个数学框架》

当我们撰写 变压器电路的数学框架 时，还没有办法从叠加态中提取特征。因此，许多最自然用“特征”来描述的关于 Transformer 的思考方式，当时只能用不同矩阵乘法的特征值来表述。这里我们用特征的语言重新审视其中一些想法，希望能让相关工作变得更清晰。

每个注意力头都可以用两个矩阵来理解：OV 电路（描述注意力头读取和写入什么信息）和 QK 电路（描述要关注什么位置）。我们可以用特征来描述这两个矩阵。

在描述这些内容时，我们会大量使用经过变换的特征集合。例如，我们可能有一个特征 X 用于检测某种属性，一个特征 prev(X) 用于检测前一个 token 存在 X，以及一个特征 say(X) 会让模型产生触发 X 的输出。这些经过变换的特征与原始特征存在 1:1 的对应关系，可以看作对原始特征施加了某种关系。（实际上，我们认为对应这些原始特征的方向往往是原始特征经过线性变换后的版本。关于这一点的动机，可参考 Wattenberg & Viegas 2024 关于矩阵绑定和“回声”特征的讨论。）

在《框架》一文中，我们使用 W_U W_{OV} W_E 的正特征值（即对 token 进行 embedding，经过 OV 后再经过 token unembedding）作为这种机制正在发生的粗略证据。为什么这样做是合理的？因为在非常早的层中，embedding 为每个 token 提供了一组类似极简单特征的基底，而 unembedding 则在非常晚的层中给出了对应的“say(X)”特征。因此，尤其在小型模型中，我们可以把它们当作这两组特征的一种近似基底，从而分离出右上角的子矩阵，该子矩阵理论上应该是接近对角的。

这意味着它会具有正特征值。更深入地说，该子矩阵中的正特征值代表的是那些会同时提升同一组对应 say 特征的特征集合。

前一个 token 头（Previous Token Heads）

另一个有趣的注意力头是前一个 token 头。我们认为它们会把前一个 token 的信息复制过来，形成描述“前一个 token”的独立特征。因此，特征 X 会被映射为特征 prev(X)——“前一个 token 是 X”。

需要注意的是，如果模型中已经存在表示“前一个 token”的特征，那么这些特征也可能被复制为“前前一个 token”的特征。（这些特征也可以由一个关注两个 token 之前的注意力头直接构造出来。）

归纳头（Induction Head）

变压器电路的数学框架 的 OV 电路与上述复制头类似。它将特征 X 映射到 say(X)。

有趣的部分在于它的 QK 电路，我们认为它大致如下：“如果 query token 是 X，我们希望找到前面跟着 X 的 key；如果 query token 前面是 Y，我们希望找到两个 token 之前是 Y 的 key token。”

可解释性在生物学中的应用

本文总结了将稀疏自编码器（SAE）应用于生物 AI 系统（特别是蛋白质语言模型）的最新进展。随着模型在药物发现和蛋白质工程中变得越来越重要，理解它们的内部表征对于安全性和科学发现都至关重要。

与大语言模型在语言领域的应用类似，生物 AI 模型制造了一种引人入胜的张力：这些模型在预测蛋白质结构和细胞行为上达到了惊人的准确率，但我们对其工作原理却知之甚少。

填补这一可解释性鸿沟，对于在药物发现、蛋白质工程和疾病理解中安全且有效地应用这些模型至关重要。最近将稀疏自编码器应用于生物模型的工作，展示了一条前景广阔的前进道路。[1]

生物 AI 中的黑箱问题

像 ESM-2 这样的蛋白质语言模型以及单细胞基础模型已经彻底改变了计算生物学。ESMFold 能以接近实验水平的精度预测结构，细胞模型则捕捉了复杂的调控动态。然而这些系统本质上仍然是不透明的。

这种不透明性带来了具体的问题：

我们无法辨别模型是否因错误原因做出预测；模型学到的生物学洞见仍然无法获取；蛋白质工程缺乏来自模型理解的原理性指导；新机制仍隐藏在数十亿参数之中。

曾经推动语言模型稀疏自编码器发展的可解释性挑战，如今在生物学领域重现——鉴于其治疗应用，风险更高。

这个领域特别令人兴奋的一个机会是，我们或许能将可解释性方法当作一种“显微镜”。从某种意义上说，为了很好地预测数据，模型必须发展出对数据的某种理解，而我们也许可以通过可解释性将其提取出来。[2] 实际上，InterProt 的结果正是这一思路的例证！

生物学中的稀疏自编码器

对于熟悉语言模型 SAE 的读者来说，生物学中的应用遵循类似原则，但面临领域特定的挑战。语言模型处理的是离散 token 和语义概念，而生物模型处理的是离散氨基酸序列和进化关系。[3] 这里叠加假设甚至更为明显——蛋白质模型中的单个神经元往往纠缠着数十个生物概念，而 SAE 能够成功地将它们解纠缠。

一个实例：发现缺失的蛋白质注释

为了理解这些模型在实践中如何工作，我们来看 InterPLM 论文 [1] 中的特征 f/939。研究者发现该特征会在一种称为“Nudix box 基序”的特定模式上激活——这是一种在某些酶中发现的保守序列模式。当他们检查该特征强烈激活的蛋白质时，发现了一个有趣的现象：大多数蛋白质在 Swiss-Prot 数据库中都有预期的 Nudix box 注释，但有一个蛋白质（B2GFH1）在缺少该注释的情况下仍触发了强烈的激活。

这并不是模型的错误。当研究者更仔细地查看该蛋白质的结构并查阅 InterPro 等其他数据库后，他们确认该蛋白质确实含有 Nudix box 基序——只是 Swiss-Prot 的注释漏掉了。SAE 特征实际上发现了我们生物数据库中的一个空白。

这个例子说明了可解释 AI 在生物学中的双重价值。首先，它表明蛋白质语言模型真正学会了识别有意义的生物模式。其次，或许更重要的是，它展示了这些可解释特征如何主动推动生物学发现——帮助我们找到缺失的注释、识别新的蛋白质基序，并更好地理解进化在蛋白质序列中编码的组织原则。InterPLM 的研究者发现了多起此类案例：SAE 特征的“假阳性”激活实际上揭示了数据库中缺失的注释，而非模型错误。

通过特征发现进化关系

最近对 Evo 2 的工作将可解释性从单个特征扩展到了进化过程。对特征 f/19746 的分析显示，它在细菌基因组的原噬菌体区域（包括大肠杆菌中的隐蔽原噬菌体）中持续激活。同一个特征也会在 CRISPR 间隔序列上激活——但这种相关性反映了更深层的生物学理解 [6]。

CRISPR 系统会将病毒 DNA 片段存储为免疫记忆。当研究者打乱这些间隔序列时，特征激活依然存在；但当他们打乱 CRISPR 直接重复序列时，激活则消失了。这表明模型学到的是噬菌体与细菌免疫之间的功能关系，而非表面序列相似性。该特征还突出了此前未注释的基因组区域，这些区域含有整合酶等与噬菌体相关的基因。

这个原噬菌体特征不仅能识别已知的病毒序列，还会在此前未注释的基因组区域上激活。研究者调查这些激活后发现，这些区域含有通常与原噬菌体相关的基因，如整合酶和倒位酶，说明 Evo 2 识别出了当前注释工具遗漏的病毒元件。这与 InterProt 发现数据库缺失注释的案例类似，表明不同模型中的可解释特征都能主动帮助改进我们的基因组数据库。

这些发现表明，在基因组数据上训练的语言模型能够在没有明确监督的情况下推断进化关系。这种能力对于注释移动遗传元件和理解微生物基因组中的水平基因转移可能非常有价值 [6]。[6]

发现谱系：从蛋白质基序到细胞动态

InterPLM [1] 首次证明了将 SAE 应用于蛋白质语言模型的可行性。他们使用 ESM-2-8M 训练了带有 L1 正则化的 SAE，隐藏维度为 10,420。他们发现了 Swiss-Prot 注释中不存在但在 InterPro 等其他数据库中得到证实的蛋白质特征，表明模型学到了超出人类注释的模式。

InterProt [2] 将规模扩展到 6.5 亿参数，并引入了 TopK SAE 以获得更好的重构-稀疏性权衡。他们通过下游任务的线性探针进行了全面验证，在保持预测精度的同时揭示了机制。他们识别出核定位信号、热稳定性决定因素以及家族特异性模式。重要的是，他们发现了一些能预测 CHO 细胞表达的特征，却没有明确的生物学解释，这暗示存在尚未表征的机制。

Evo 2 的 SAE 分析揭示了类似的蛋白质水平理解 [6]。研究者识别出专门在 α-螺旋（f/28741）和 β-折叠（f/22326）上激活的特征，这些激活可以精确映射到 AlphaFold 3 的结构预测上。这种从 DNA 序列到蛋白质结构的多模态理解，纯粹从基因组序列训练中涌现出来 [6]。

Reticular [3] 将规模扩展到 ESMFold 的 30 亿参数基础模型，成功突破到结构预测。他们提出的 Matryoshka 架构自然地捕捉了从残基到结构域的蛋白质层级。他们发现每个位置仅需 8–32 个活跃潜在变量就能重构结构特征，揭示了结构决定因素惊人的稀疏性。在更高层，他们达到了对 Swiss-Prot 生物学概念 49% 的覆盖率。

Markov Biosciences [4] 采取了完全不同的路线，专注于细胞模型而非蛋白质语言模型。他们从基因表达模型中构建了特征到特征的调控网络，并通过网络分析算法识别细胞命运驱动因子。值得注意的是，他们在非空间训练数据中发现了空间模式，这与语言模型学习隐式世界模型的方式类似。这项工作展示了 SAE 如何超越蛋白质序列，应用于理解细胞动态。

跨研究发现

在不同规模和模态中浮现出若干共同模式：

生物模型中存在严重的叠加：单个神经元纠缠的概念远多于语言模型，这使得 SAE 特别有价值 [1, 2]。

规模带来质的提升：从较小模型转向更大模型后，生物概念覆盖率提高，内部表征也更加丰富 [3]。

特征与生物组织结构一致：特征并非任意模式，而是与已知功能单元对齐——从氨基酸性质到蛋白质结构域 [1, 2]。

模型学会了隐式结构：Evo 2 的特征能直接从 DNA 序列中捕捉 α-螺旋、β-折叠等蛋白质结构元件，而无需任何结构监督，展示了涌现的多模态理解 [6]。

跨物种泛化：从人类基因组学到的特征能够成功注释猛犸象基因组——尽管训练数据中没有它——这表明这些表征捕捉了基因组组织的通用模式。这使得仅凭基因组数据就能推断已灭绝物种的生物学特性成为可能 [6]。

技术进展与应用

当前的应用展示了实际价值：

自动化注释：InterPLM 发现缺失数据库注释的成果表明，模型理解能加速生物学数据的整理。例如，他们在 Swiss-Prot 缺少注释但 InterPLM 确认存在的蛋白质中识别出了 Nudix box 基序 [1]。

机制阐明：InterProt 追踪了特定特征如何驱动预测。

结构控制：Reticular 在 ESMFold 上展示了通过操纵特征来控制蛋白质性质的能力——在保持骨架结构的同时修改表面性质。这表明可解释特征有望指导有针对性的蛋白质工程 [3]。[7]

从特征到电路：更高级的可解释性

自然的下一步与语言模型可解释性的发展路径一致：从单个特征转向计算电路。这些生物学论文暗示了几个有前景的方向：

特征聚类揭示功能模块：InterPLM 的聚类分析发现了具有细微特化的相关特征群——例如多个激酶结合特征分别在结合位点的不同亚区域激活，或 β-桶特征在不同特异性水平上运作（通用 β-桶 vs. TonB 依赖型受体）。这些聚类表明模型学会了可构成更大计算电路的层级表征。

跨层依赖：Reticular 发现仅第 36 层就能保留结构预测，这暗示了网络中关键的计算通路。结合其自然捕捉从残基到结构域的蛋白质层级的 Matryoshka 架构，这表明追踪特征如何跨层转换，有望揭示序列模式如何组合成结构预测。

进化电路：Evo 2 的原噬菌体特征（f/19746）是生物电路发现的典范。该特征同时在原噬菌体区域和 CRISPR 间隔序列上激活——但只有当间隔序列保持其噬菌体来源序列时才会如此。关键的是，打乱间隔序列仍保留激活，而打乱 CRISPR 重复序列则完全消除激活，这表明模型学到的是功能关系而非死记序列。这揭示了一个连接不同基因组情境下病毒 DNA 检测的学习电路，暗示系统性的电路发现方法有可能绘制出这些模型学到的完整宿主-病原体互作网络。

调控网络作为原型电路：Markov Biosciences 的特征到特征调控网络提供了最直接的电路式组织证据。通过识别哪些特征在细胞命运决策中影响其他特征，他们已经开始绘制模型的计算图。将类似网络分析应用于蛋白质模型，有望揭示序列特征如何组合成功能预测。

与语言模型相比，生物模型表现出更强的层级电路特性，正如 Evo 2 的特征从氨基酸捕捉到基序、结构域直至完整蛋白质的组织方式。这不仅可能带来可解释性方法的新应用，还可能成为方法论进步的有利环境。

挑战与审慎乐观

仍然存在重大挑战。生物学验证需要湿实验，而非仅靠计算指标。SAE 特征与因果生物机制之间的关系需要实验支撑。目前的工作主要集中在单一模态上——据我们所知，多模态生物模型仍未被探索。[8]

对多样生物系统的相关工作表明，这些方法可以泛化到分子生物学之外。Gašper Beguš 使用极值因果解纠缠（CDEV）解码抹香鲸交流的工作，展示了可解释性技术如何照亮完全未知的生物系统——在该案例中揭示了鲸鱼通过点击模式、时间规律性和声学特性来编码信息 [5]。这种更广泛的适用性暗示了神经网络可解释性在从分子结构到动物交流等生物领域中存在的基本原则。

实际下一步

可解释性方法与生物 AI 的融合带来了具体机会：

验证协议：建立超越数据库匹配的生物特征验证标准，可能通过对已解释特征进行有针对性的实验来实现。

集成架构：开发能够以统一表征自然处理多模态生物数据（序列、结构、表达）的 SAE 变体。

高效训练：将 k-稀疏自编码器和基于梯度的特征学习等最新进展适配到数十亿参数的生物模型上，以降低计算需求。

电路发现方法：虽然 Evo 2 已经展示了进化电路（如 CRISPR-噬菌体联系），但系统性发现和验证生物电路的方法仍处于起步阶段。依托 Evo 2 的开放框架（包括训练代码、400 亿参数模型权重和 OpenGenome2 数据集），研究者可以开发自动化技术，利用生物学天然的层级结构（序列→结构→功能）来绘制完整的计算通路。我们非常期待可解释归因图（interpretable attribution graphs）在这一领域的表现，它有可能揭示简单序列特征如何组合成复杂的生物功能。

随着这些方法逐渐成熟，解释 AI 与理解生物学之间的界限可能会完全消失。在这个未来中，透明的 AI 将不仅仅是一项技术成就，更将成为科学进步的基础工具。
