机制可解释性、变量以及可解释基的重要性

June 2022 · 阅读原文

机制可解释性旨在对神经网络进行逆向工程，就像逆向工程一个编译后的二进制计算机程序一样。毕竟，从某种意义上说，神经网络的参数就是一个运行在我们称为神经网络架构的奇特虚拟机上的二进制计算机程序。

这个类比实际上非常深刻。随着本文展开，我们会进一步讨论，但一些相似之处已列在下表中：

Regular Computer Programs

Neural Networks

Reverse Engineering

Mechanistic Interpretability

Program Binary

Network Parameters

VM / Processor / Interpreter

Network Architecture

Program State / Memory

Layer Representation / Activations

Variable / Memory Location

Neuron / Feature Direction

认真对待这个类比，能帮助我们探讨机制可解释性中的一些大局问题。通常，那些在逆向工程神经网络时显得推测性强且难以捉摸的问题，如果换成逆向工程普通计算机程序来提问，就会变得清晰起来。而且，这些答案中的许多似乎都能合理地迁移回神经网络的情形。

或许最有意思的观察是，这个类比似乎表明：找到并理解可解释神经元——类比于理解计算机程序中的变量——不仅仅是众多有趣问题中的一个。可以说，它是核心任务。

攻克维度灾难

每种可解释性方法都必须以某种方式克服维度灾难。神经网络通常是输入空间维度极高的函数。随着维度增加，输入空间的n维体积呈指数级增长，变得极其庞大。这就是维度灾难。它通常被视为学习函数的挑战：我们如何在如此巨大的输入空间上学习一个函数，而不需要指数级的数据量？但它也是可解释性的挑战：我们如何有望理解这样一个大空间上的函数，而不需要指数级的时间？一种可能的反对意见是，虽然输入空间是高维的，但我们只需要理解函数在真实输入的数据流形上的行为。（我曾经一度非常投入这种方法！）然而，尽管数据流形肯定比输入空间的维度低，但对于我们关心的视觉或语言等任务来说，它似乎仍然必须是非常高维的。例如，对于任何给定的自然图像，似乎都可以通过让任意物体从视野的任意一侧进入图像来沿数据流形移动——这已经是很多维度了！

一种方法是研究输入维度较低的玩具神经网络，从而轻松实现完全理解，绕过这个问题。另一种方法是研究神经网络在感兴趣的单个数据点附近的局部行为——这大致就是显著性图（saliency maps）的做法。

机制可解释性如何解决维度灾难？这个问题也值得对常规逆向工程提出！不知何故，逆向工程计算机程序的程序员能够理解其行为，而且往往是在维度极高的输入空间上。他们之所以能做到这一点，是因为代码提供了程序行为的非指数级描述，这是一种替代“将程序视为在巨大输入空间上的函数”来理解的方式。我们可以在人工神经网络的背景下追求同样的答案。归根结底，参数是对神经网络的有限描述，如果我们能以某种方式理解它们的话。

当然，参数可能非常庞大——最大语言模型的参数量可达数千亿！但像编译后的操作系统这样的二进制计算机程序也可以非常大，而我们最终往往还是能够理解它们。

另一个结果是，我们不应期望机制可解释性会很容易，或者存在一套可以照搬的标准化流程。人们常常希望可解释性能提供简单答案、简短解释。但我们应该预期，机制可解释性至少和逆向工程一个大型、复杂的计算机程序一样困难。

变量与激活值

理解一个计算机程序需要我们既理解变量，也理解作用于这些变量的操作。像“y = x + 5;”这样的语句，如果不理解y和x是什么，就毫无意义。同时，y和x的最终含义又来自它们在程序某处被操作使用的方式。这大概就是为什么变量名如此有用的原因！

逆向工程师通常无法受益于变量名。他们需要弄清楚每个变量实际代表什么。事实上，这还低估了问题。程序实际上操作的是计算机内存的集合——即其状态——而人类则用离散变量来思考它。在许多情况下，内存如何映射到变量是显而易见的，但并非总是如此。因此，逆向工程师必须找出如何将内存分割成可以单独理解的变量，然后弄清楚这些变量的含义。换句话说，逆向工程师必须为内存中的位置赋予含义。

逆向工程神经网络面临着几乎完全相同的挑战。正如Voss等人所讨论的，神经网络参数可以被视为二进制指令，而神经元激活值则类似于变量或内存。每个参数描述了先前的激活值如何影响后续的激活值。我们只有理解了输入和输出的激活值，才能理解一个参数的含义。

但激活值是高维向量：我们如何才能理解它们？我们又回到了维度灾难，但常规逆向工程再次指出了解决方案。理解计算机程序的内存——同样是一个高维空间！——是可能的，因为我们可以将其分割成可以分别推理和理解的变量。类似地，我们需要将神经网络的激活值分解为可以独立理解的片段。

在一些非常特殊的情况下，包括仅注意力（attention-only）Transformer（参见变压器电路的数学框架变压器电路的数学框架），我们可以使用线性性，用模型的输入和输出来描述网络的所有操作。这类似于计算机程序中某些函数可以仅用参数和返回值来描述，而无需中间变量。由于我们通常理解输入和输出，这就让我们能够绕过问题。但在大多数情况下，我们无法这样做——那该怎么办？

如果我们无法用特殊技巧避开这个问题，那么机制可解释性就要求我们必须以某种方式将激活值分解为可以独立理解的部分。

简单的内存布局与神经元

计算机程序通常具有便于理解的内存布局。例如，内存中的大多数字节都表示一个单一的事物，而不是让每个比特表示不相关的东西。这部分是因为这样的布局更容易让程序员思考，但也因为我们的硬件通常让“简单”的连续内存布局更高效。拥有这些简单的内存布局使得逆向工程计算机程序变得更容易。它让我们更容易弄清楚应该如何将内存分解为可以独立理解的变量。

在神经网络中，常常会发生某种类似的情况。

让我们暂时假设神经网络可以用对一组独立“可解释特征”进行操作来理解。原则上，人们可以想象“可解释特征”被嵌入到激活空间中的任意方向上。但通常情况下，似乎带有激活函数的神经网络层会将特征与它们的基维度对齐。这是因为激活函数在某种意义上让这些方向变得自然且有用。正如CPU拥有对字节进行操作的指令会鼓励信息按字节分组，而不是随机分散在内存中，激活函数也常常鼓励特征与单个神经元对齐，而不是对应于神经元的随机线性组合。我们称之为变压器电路的数学框架。

如果特征与神经元对齐，将会让神经网络容易逆向工程得多。这并不是说如果神经元无法单独理解，神经网络就无法被逆向工程。但它似乎会困难得多，就像具有奇怪内存布局的计算机程序更难逆向工程一样。

不幸的是，许多神经元无法以这种方式被理解。这些多义神经元（polysemantic neurons）似乎有助于表示那些最好不要用单个神经元来理解的特征。这对神经网络的逆向工程来说是一个非常棘手的问题，我们在Softmax线性单元（尤其是Softmax线性单元）中对此有更多讨论。

目前，我们希望强调的主要观点是：将表征分解为可以独立理解的部分的能力，对于机制可解释性的成功似乎至关重要。
